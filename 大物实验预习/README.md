## 命名约定

- 每次实验的预习报告统一命名：`预习报告-<实验名>.md`，直接放本目录（不另建子目录）。
- 制作流程封装在 `skills/大物实验预习报告/SKILL.md`：上传教室号/实验名即自动产出（触发式工作流）。
