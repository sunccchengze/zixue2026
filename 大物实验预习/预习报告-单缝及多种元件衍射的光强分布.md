## 一、实验原理简述

单色平行光垂直照射宽度为 b 的狭缝，在夫琅禾费条件下，光强为 I = I₀(sin u/u)²，u = πb sinθ/λ　(2.23.1)。θ = 0 为中央主极大；暗纹满足 sinθₖ = kλ/b（k = ±1, ±2, …），小角度时 θₖ ≈ kλ/b　(2.23.2)。中央主极大的角宽约为 2λ/b，且 I₀∝b²；狭缝越窄，衍射越展宽。若屏距为 D、暗纹距中央的横向距离为 xₖ，则 b = kλD/xₖ　(2.23.3)。双缝（缝宽 b、中心距 d）的光强是在单缝衍射包络上叠加干涉：I = I₀(sin u/u)²·4cos²(Δφ/2)，Δφ = 2πd sinθ/λ　(2.23.4)；d 减小时，包络不变而内部细条纹变疏，趋向单缝分布。实验还比较单孔、双孔、多缝、光栅图样；硅光电池将光强转换为光电流，以 I/I₀ 表示相对光强。

## 二、预习思考题与解答

**1. 若测出的衍射图样对中央主极大左右不对称，是什么原因造成的？怎样调整实验装置才能纠正？（课本“思考与讨论”1）**

理想单缝衍射关于 θ = 0 对称；不对称通常说明光路没有对准：入射光未垂直狭缝，或激光器、狭缝、光电探头不在同一水平线上，探头移动方向也可能没有通过中央主极大。调整时先调激光器与狭缝，使光垂直入射；再调小孔和探头高度，使光源、狭缝、探头共线，并把中央主极大对准探头的测量中心。调整后再从中心向两侧测量，比较两侧暗纹位置。

**2. 用两台输出光强不同的同类激光器作单缝衍射光源，衍射图样及相对光强分布有无区别？为什么？（课本“思考与讨论”2）**

衍射条纹的位置、宽度和归一化后的相对光强分布没有区别；绝对光强会随入射光强改变。由 I = I₀(sin u/u)² 可见，I₀ 只整体缩放光强，除以中央主极大 I₀ 后，I/I₀ = (sin u/u)² 不含光源亮度。两台同类激光器的波长相同，因此暗纹角位置也相同。

**3. 若用白光作光源，可以观察到什么样的衍射图样？（课本“思考与讨论”3）**

中央主极大处 θ = 0，各波长的光都重合，呈白色；离开中心后，θₖ ≈ kλ/b 表明波长越长，衍射角越大。因此两侧会出现彩色条纹，紫光靠近中央，红光在外侧；级次越高，各色条纹越容易交叠，且旁瓣光强较弱。
