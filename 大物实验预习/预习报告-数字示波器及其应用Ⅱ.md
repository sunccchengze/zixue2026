## 一、实验原理简述

数字存储示波器因应用了微处理器，屏幕除显示波形外还显示有关参数，可用直接测量法或
光标法直接读出时间和幅度，省去模拟示波器数格子的繁琐与误差。RC 并联电路的暂态过程中，
切断电源后电容经电阻放电，U_C(t) = E e^(−t/RC)ᶜ　(2.16.1)，时间常量 τ = RC 即端电压下降到
0.368E 所需时间；由示波器放电曲线上找 0.368E 对应点测出 τ，进而由 C = τ/R 求电容。
两相互垂直同频率交流信号的相位差 φ 有三种测法：电工学法由阻容移相电路的矢量合成得
tan φ = U_AB/U_BD = 2πfCR，即 φ = arctan(2πfCR)　(2.16.2, 2.16.3)；双踪显示法读出两波形
水平位移 x 与一个周期 x_T，φ = (x/x_T)×360°　(2.16.4)；李萨如图形法选 XY 模式，合成轨迹为
斜椭圆，φ = arcsin(B/A)　(2.16.5)，A、B 分别为纵（横）方向最大偏转距离与椭圆和纵（横）轴
相截距离。傅里叶变换（FFT）分析中，方波为奇函数，展开只含奇次谐波、幅度按 1/(2n−1) 递减
　(2.16.7)，频谱为离散谱线（图 2-105）；正弦波 x(t) = A cos(ω₀t + φ₀)　(2.16.8) 只有单一频率，
频谱仅一根谱线，称"单色"信号。

## 二、预习思考题与解答

**1. RC 放电实验中，为什么把 τ 取为 U_C 下降到 0.368E 所需的时间？示波器上如何测 τ、求 C？**

由式 (2.16.1) U_C(t) = E e^(−t/RC)，代入 t = τ = RC 得 U_C(τ) = E e⁻¹ = 0.368E，即电压按指数
衰减到初值的 36.8%；反之放电曲线上 0.368E 对应的时间就是 τ（图 2-99）。课本步骤：示波器设
直流耦合、"边沿触发"中的"下降沿触发"、触发电平为最大值 10%~20%、时基 500 ms、单次
"Single"，关闭变压器开关待放电曲线显示后用光标读出 τ，再由 C = τ/R 计算电容并与理论值比较
（图 2-107 电路 C = 47 μF、R = 20 kΩ）。

**2. 双踪显示法 φ = (x/x_T)×360° 中 x 与 x_T 各指什么？为什么要与式 (2.16.3) 比较？**

x_T 是一个周期波形在屏幕上占的水平距离，x 是两波形对应点（峰、过零点等）间的水平位移
（图 2-102）；一个周期对应 360°，按比例即得相位差 (2.16.4)。式 (2.16.3) φ = arctan(2πfCR)
是由电路参数 R、C、f 推出的理论值；课本要求实测值与理论值比较并计算百分误差，以检验测量方法。

**3. 李萨如图形法测 φ 时，什么条件下合成轨迹是斜椭圆？φ = arcsin(B/A) 的 A、B 是什么？**

两正弦电压同时输入 Y 轴与 X 轴、示波器选"XY"模式；当相位差 φ 在 0~π/2 之间时，两振动合成
轨迹为斜椭圆（图 2-103）。A 为纵（横）方向最大偏转距离，B 为椭圆与纵（横）轴相截的距离，
φ = arcsin(B/A)　(2.16.5)。

**4. 方波的频谱为什么只含奇次谐波？它与正弦波的频谱有何不同？**

方波 (2.16.6) 是奇函数，其傅里叶展开 f(t) = (4h/π)(sin ωt + (1/3)sin 3ωt + (1/5)sin 5ωt + ⋯)
　(2.16.7) 只含 ω 的奇次谐波，幅度按 1/(2n−1) 递减，故频谱是一列逐渐变矮的离散谱线
（图 2-105）。正弦波 x(t) = A cos(ω₀t + φ₀)　(2.16.8) 只有单一频率，频谱只含一根谱线，
课本称其为"单色"信号。
