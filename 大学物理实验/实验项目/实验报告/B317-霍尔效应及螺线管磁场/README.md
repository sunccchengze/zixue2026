# B317-霍尔效应及螺线管磁场

先看[当前版本](当前版本.md)。本包目前仅提供**可填写的完整报告框架**，不是已完成的实测报告。

严格按此前约定的五部分组织：实验目的、实验原理、原始数据记录、数据处理与作图、结论。仪器参数与实验步骤放在原始数据记录部分，误差分析与讨论放在数据处理与作图部分，不另增一级章节。由于尚未取得原始实验记录，三组实测表均保留“待填”，未编造任何结果或图线。请补交表 3-2-1、表 3-2-2、表 3-2-3 左右扫描的原始 U₁–U₄ 读数，以及螺线管 N、L、D、霍尔元件有效厚度 d 和仪器分辨率。收到后才能进行回归、计算 K_H、R_H、载流子浓度和 B−x 分布，并形成可验收的完整报告。
