# B317-霍尔效应及螺线管磁场

请先看[当前版本](当前版本.md)。此目录现包含基于实测数据完成的完整报告（Markdown、DOCX）、原始数据/派生数据 CSV、三幅 Python 图表及可复现生成脚本。

报告严格遵循用户提供的五部分格式：一、实验目的；二、实验仪器与实验方法；三、测量内容及数据处理；四、小结（结论、误差分析及建议等）；五、实验思考题。所有原始读数均取自用户给定表格；所有四极性 UH 均经公式重算核对。

**重要核验项：**线圈内径 Φ40 mm、外径 Φ56 mm，采用两者平均值 48 mm 近似计算中心场；B–x 图只绘制原表 L、R 两栏数据，不把 x=0 擅自认作线圈中心；霍尔元件尺寸 400×400×260 μm，载流子浓度使用 260 μm 作为沿 B 方向有效厚度。请核实这两个模型/安装约定，及实验日期年份（手写页只注明 11.16）。没有仪表分辨率资料，因此报告未虚构数值不确定度；载流子正负类型也未在缺少完整方向定义时武断判定。报告适合作为完整初稿，仍应人工核对并由教师验收，不宣称可免审直接提交。
