# M9｜联合密度"六连问"（求常数 → 边缘 → 独立 → 不相关 → 区域概率 → 条件密度）

【识别特征】给 f(x,y) = c·（某个式子）在区域 D 上，或给"区域上服从均匀分布"，然后连着问 3~6 小问。

【标准流程】（**照这个顺序写，不要跳步**）
1. **画区域图**：把 D 的边界画出来（直线/曲线），标出 x、y 的**取值范围**。
2. **定常数**：`∬_D c·g(x,y)dxdy = 1` ⇒ c。**技巧：区域面积 + 均匀分布 ⇒ c = 1/面积。**
3. **边缘密度**：`f_X(x)=∫f(x,y)dy`（上下限随 x 变化！），`f_Y(y)=∫f(x,y)dx`。**务必分段**。
4. **独立性**：看"能否分解成 g(x)h(y)"——**只要 D 不是矩形（x 与 y 的界限互相牵扯），一定不独立**。
5. **相关性**：算 `E(X), E(Y), E(XY)` ⇒ `Cov = E(XY) − E(X)E(Y)`；**Cov=0 ⇒ 不相关**。
   > 对称区域（关于 x 轴或 y 轴对称）+ 被积函数对相应变量为奇函数 ⇒ 期望为 0，用**对称性**省一半计算！
6. **区域概率**：把待求事件画到图上，化成**累次积分**或直接用**面积比**（均匀分布专用）。
7. **条件密度**：`f_{X|Y}(x|y) = f(x,y)/f_Y(y)`（f_Y(y)>0），**并写出 x 的取值范围**。

【真题】2020 秋·解答 3（14 分档，✅ 与 2023 真卷第四题同型）　f(x,y) = c（|y|<x, 0<x<2）。
（1）求 c；（2）边缘密度；（3）独立吗？相关吗？
> 解：（1）区域是以 (0,0) 为顶点、向 x 正方向张开的三角形（上界 y=x，下界 y=−x，x 到 2）：
> ∫₀² dx ∫_{−x}^{x} c dy = ∫₀² 2cx dx = 4c = 1 ⇒ **c = 1/4**。
> （2）f_X(x) = ∫_{−x}^{x} (1/4)dy = **x/2**（0<x<2）；f_Y(y) = ∫_{|y|}^{2}(1/4)dx = **(2−|y|)/4**（|y|<2）。
> （3）在区域上 f(x,y) ≠ f_X(x)f_Y(y)（如取 (1, 0.5)：1/4 ≠ 1/2×3/8）⇒ **不独立**；
> E(XY) = ∫₀²dx∫_{−x}^x xy/4 dy = 0（内层对 y 是奇函数）；E(Y) = 0（f_Y 是偶函数）⇒ Cov = 0 ⇒ **不相关**。
> **⚠️ 高频错点**：这一步正是"不独立但不相关"的标准样例，**必须写理由**（"因为内部积分为奇函数"）。

【真题】2023 真卷·四（14 分，评分标准逐段给分）　(X,Y) 在 D={(x,y): 0<x<y, 0<y<1} 上均匀分布。
（1）是否独立？（2）f_{X|Y}(x|y)；（3）P{X > 1/4 | Y = 1/2}。
> 官方式解答：（1）面积 1/2 ⇒ f(x,y) = **2**（0<x<y<1）；
> f_X(x) = ∫_x^1 2dy = **2(1−x)**（0<x<1）；f_Y(y) = ∫_0^y 2dx = **2y**（0<y<1）；
> 在上 f(x,y) ≠ f_X f_Y ⇒ **不独立**。（评分标准：边缘各 4/6 分，结论 8 分）
> （2）f_{X|Y}(x|y) = 2/(2y) = **1/y**（0<x<y）；其它处为 0。（11 分）
> （3）Y = 1/2 时条件密度 f_{X|Y}(x|1/2) = 2（0 < x < 1/2）⇒ P{X > 1/4 | Y = 1/2} = ∫_{1/4}^{1/2} 2 dx = **1/2**。（14 分）
> **口诀**：**先把 Y = y₀ 代进条件密度，再定积分上下限**——条件概率就退化成一次定积分（官方评分标准：边缘各 4/6 分、结论 8 分、f_{X|Y} 11 分、最后一问满分 14 分）。

【真题】2018·解答 6（8 分）　f(x,y) = 6x（0<x<y<1）。
（1）边缘密度；（2）是否独立；（3）P{X+Y≤1}。
> 解：（1）f_X(x) = ∫_x^1 6x dy = **6x(1−x)**（0<x<1）；f_Y(y) = ∫_0^y 6x dx = **3y²**（0<y<1）；
> （2）不独立（区域非矩形）；
> （3）P{X+Y≤1} = ∫₀^{1/2}dx∫_x^{1−x} 6x dy = ∫₀^{1/2}6x(1−2x)dx = 6[1/8 − 2/24] = **1/4**。

【真题】2010·解答 3（含协方差，9 分档）　f(x,y) = 2(x+y)（0≤y≤1, 0≤x≤y）。
（1）边缘、独立性；（2）P{X+Y≥1}；（3）Cov(X,Y)。
> 解：（1）f_X(x)=∫_x^1 2(x+y)dy = 2x(1−x)+(1−x²) = **1+2x−3x²**（0<x<1）；
> f_Y(y)=∫_0^y 2(x+y)dx = **3y²**（0<y<1）；不独立。
> （2）P{X+Y≥1} = 1 − P{X+Y<1}；也可直接积分 = **1/2**（官方 C1 表达为面积计算式）。
> （3）E(X)=∫₀¹x(1+2x−3x²)dx = 1/2+2/3−3/4 = **5/12**；E(Y)=∫₀¹3y³dy = **3/4**；
> E(XY) = ∫₀¹dy∫₀^y 2xy(x+y)dx = ∫₀¹2y[(y³/3)+(y³/2)]dy = ∫₀¹(5/3)y⁴dy = **1/3**；
> ⇒ Cov(X,Y) = 1/3 − (5/12)(3/4) = 1/3 − 5/16 = **1/48**。（官方 1/48 ✓）

【真题】2014·解答 8（a 型：先定常数再算概率，8 分）　f(x,y) = a y(1−x)（0<y<x<1）。
（1）求 a；（2）边缘；（3）独立？（4）P{X+Y<1}。
> 解：（1）∬ = a∫₀¹(1−x)dx∫₀^x y dy = a∫₀¹(1−x)(x²/2)dx = a/24 = 1 ⇒ **a = 24**；
> （2）f_X(x) = ∫₀^x 24y(1−x)dy = **12x²(1−x)**（0<x<1）；f_Y(y) = ∫_y^1 24y(1−x)dx = **12y(1−y)²**（0<y<1）；
> （3）不独立；
> （4）P{X+Y<1} = ∫₀^{1/2}dx∫₀^x 24y(1−x)dy + ∫_{1/2}^1 dx∫₀^{1−x}24y(1−x)dy = **1/2**（按面积/对称性可验证）。

【真题】2012·解答 1（8 分，官方答案已按原卷核对 ✓）　f(x,y) = x² + xy/3（0<x<1, 0<y<2）。
（1）边缘；（2）独立？（3）P{X+Y<1}。
> 解：（1）f_X(x) = ∫₀²(x² + xy/3)dy = 2x² + 2x/3 = **2x(x + 1/3)**（0<x<1）；
> f_Y(y) = ∫₀¹(x² + xy/3)dx = **1/3 + y/6 = (2+y)/6**（0<y<2）。
> （2）f_X(x)f_Y(y) ≠ f(x,y) ⇒ **不独立**（虽然定义域是矩形，但密度不是"可分离"的——**矩形域 ≠ 一定独立**）。
> （3）P{X+Y<1} = ∫₀¹dx∫₀^{1−x}(x² + xy/3)dy = ∫₀¹[x²(1−x) + x(1−x)²/6]dx
> = 2/9 − 5/24 + 1/12 = **7/72**（官方 7/72 ✓）。
> **两个考点**：① 矩形域下"独立"要求 f 能拆成 f_X·f_Y（**光看区域是不够的**）；② 区域积分要**分段讨论积分限**。

【真题】2011·解答 2（🔁 2013/2019 同族，9 分）　f(x,y) = e^{−x}（0<y<x）。
（1）边缘、独立性；（2）Z=X+Y 的密度；（3）P{X+Y≤1}。
> 解：（1）f_X(x) = ∫₀^x e^{−x}dy = **x e^{−x}**（x>0）；f_Y(y) = ∫_y^∞ e^{−x}dx = **e^{−y}**（y>0）；不独立。
> （2）⚠️ **X、Y 不独立，绝对不能用 f_X·f_Y 的卷积**——要用**联合密度沿直线 x+y=z 积分**：
> f_Z(z) = ∫ f(x, z−x)dx，积分条件：0 < z−x < x ⇒ **z/2 < x < z**：
> f_Z(z) = ∫_{z/2}^{z} e^{−x}dx = **e^{−z/2} − e^{−z}**（z>0）（官方 ✓；∫₀^∞ (e^{−z/2}−e^{−z})dz = 2−1 = 1 ✓ 可验算归一）。
> （3）P{X+Y≤1} = ∫₀¹(e^{−z/2} − e^{−z})dz = [−2e^{−z/2} + e^{−z}]₀¹ = **1 + e^{−1} − 2e^{−1/2} ≈ 0.1548**（官方 ✓）。
> **最典型的坑**：不独立时的密度卷积公式 **f_Z(z) = ∫f_X(x)f_Y(z−x)dx 不成立**，必须回到
> `f_Z(z) = ∫f(x,z−x)dx`（这是"联合密度"版本，对任何联合密度都成立）。

【真题】2013·解答 2（9 分）　f(x,y) = e^{−y}（0<x<y）。
（1）边缘；（2）P{X+Y<1}。
> 解：（1）f_X(x) = ∫_x^∞ e^{−y}dy = **e^{−x}**（x>0）；f_Y(y) = ∫₀^y e^{−y}dx = **ye^{−y}**（y>0）；
> （2）P{X+Y<1} = ∫₀^{1/2}dx ∫_x^{1−x}e^{−y}dy = **1 + e^{−1} − 2e^{−1/2}** ✓（官方 ✓）。

【真题】2012·解答 2（指数卷积 + 相关，9 分）　X,Y 独立同 Exp(λ)。
（1）Z=X+Y 的密度；（2）E(Z), D(Z)；（3）ρ_{XZ}。
> 解：（1）f_Z(z) = **λ²z e^{−λz}**（z>0）（伽马(2,λ)）；
> （2）E(Z) = 2/λ；D(Z) = 2/λ²；
> （3）Cov(X,Z) = Cov(X, X+Y) = D(X) = 1/λ²；ρ = (1/λ²)/√[(1/λ²)(2/λ²)] = **1/√2**（官方写 …/√2 ⇒ 1/√2 ≈ 0.707）。

【真题】2017·解答 1（二次抽样 + 协方差，10 分）　(0,1) 取 X，再在 (0,X) 取 Y。
（1）联合密度与 f_Y；（2）E(X), E(Y)；（3）Cov(X,Y)。
> 解：（1）f(x,y) = **1/x**（0<y<x<1）；f_Y(y) = ∫_y^1(1/x)dx = **−ln y**（0<y<1）；
> （2）E(X) = 1/2；E(Y) = ∫_x?..= ∫₀¹dx∫₀^x (y/x)dy = ∫₀¹ (x/2)dx = **1/4**；
> （3）E(XY) = ∫₀¹dx∫₀^x (xy/x)dy = ∫₀¹ x²/2 dx = **1/6** ⇒ Cov = 1/6 − (1/2)(1/4) = **1/24**。（官方 1/24 ✓）

【真题】2015·解答 3（12 分）　f(x,y) = ½cos(x+y)，|x|<π/4，|y|<π/4。
（1）独立？（2）Z=X+Y 的密度。
> 解：（1）f_X(x) = ∫_{−π/4}^{π/4} ½cos(x+y)dy = **½[sin(x+π/4) − sin(x−π/4)] = (cos x)/√2**（|x|<π/4）；
> 同理 f_Y(y) = (cos y)/√2；而 f(x,y) ≠ f_X f_Y ⇒ **不独立**。
> （2）f_Z(z) = ∫ f(x,z−x)dx，x ∈ [max(−π/4, z−π/4), min(π/4, z+π/4)]：
> −π/2<z<0 时 f_Z(z) = **(z+π/2)·?**（官方：(z+π/2)? 需要严格算）
> 官方结论：−π/2<z<0 ⇒ f_Z(z) = **(π/2 + z)(1/√2)cos? **
> **正确的官方形式**（复习卷答案）：−π/2<z<0 时 f_Z = (π/2+z)·? 我们来严格算：
> f_Z(z) = ∫ ½cos(z)dx（因为 cos(x+z−x)=cos z ⇒ 只需求区间长度！）
> = ½·cos z·L(z)，其中 L(z) = 重叠长度：
>   |z|<π/2 时：z≥0 ⇒ L = π/2 − z；z≤0 ⇒ L = π/2 + z。
> ⇒ **f_Z(z) = ½(π/2 − |z|)cos z（|z|<π/2）**，其它 0。
> **技巧**：**被积函数里 x 消掉时，密度 = 常数 × 重叠长度**（"三角卷积"），这是本题的捷径（官方也用的这个）。

# M10｜区域概率与"分布函数值"（均匀分布专用技巧）

【识别特征】"在区域 D 上服从均匀分布"，求 P(某事件) 或求 F(x₀,y₀)。

【标准流程】
1. **密度 = 1/面积**；
2. **概率 = 目标区域面积 / 总面积**（**不积分！**）；
3. 求 F(x₀,y₀)：把矩形 (−∞,x₀]×(−∞,y₀] 与 D 相交，算相交面积 ÷ 总面积。

【真题】2019 春·计算 4（🔁 官方答案排版错乱，本包更正）　(X,Y) 在顶点 (1,0),(1,1),(0,1) 的三角形上均匀分布。
（1）P{X+Y<1.5}；（2）F(1.5, 0.5)。
> 解：D = {x≤1, y≤1, x+y≥1}，面积 **1/2** ⇒ f = 2。
> （1）被割去的是 {x+y>1.5}：顶点 (1,1) 处腰长 0.5 的直角三角形，面积 1/8 ⇒ P = 1 − (1/8)/(1/2) = **3/4**；
> （2）F(1.5,0.5) = P(X≤1.5, Y≤0.5) = P(Y≤0.5)（因为 X≤1 恒成立）= (∫₀^{0.5} y dy)/(1/2) = (1/8)/(1/2) = **1/4**。
> **⚠️ 官方答案**（MOOC 模拟一 2019.1 的答案页）：3/4 与 1/4 ✓ —— 与本题集 PDF 里的残片不同，**以 3/4、1/4 为准**。
> **采分点**：写"密度 = 2"+"面积比"两行，比写二重积分更快更不易错。

【真题】2022.6 模拟（八）·12　f(x,y) = 1（0<x<1, 0<y<2x）。
（1）Z=2X−Y 的分布函数；（2）P{Y<1/2 | X<1/2}。
> 解：（1）F_Z(z) = ∬_{2x−y≤z}dxdy / 面积(1)：
> z≤0 ⇒ 0；0<z<2 ⇒ **z − z²/4**；z≥2 ⇒ 1。
> （2）P = [∬_{x<1/2, y<1/2}dxdy]/[∫₀^{1/2}2x dx] = (1/2×1/2)/(1/4) = **1**。
> **注意**：区域 0<y<2x 且 x<1/2 ⇒ y<1；条件里 y<1/2 自动满足（当 x≥1/4）。核验：区域 x<1/2 内 y 的上界 2x 只在 x<1/4 时小于 1/2。
> 重算：(1/2,1/2) 矩形内落在区域里的部分 = ∫₀^{1/2} min(2x, 1/2)dx = ∫₀^{1/4}2x dx + ∫_{1/4}^{1/2}(1/2)dx = 1/16 + 1/8 = 3/16；
> 分母 = ∫₀^{1/2}2x dx = 1/4 ⇒ P = (3/16)/(1/4) = **3/4** ✓（官方 3/4）。

【真题】2022.6 模拟（八）·18（证明题，6 分，压轴常客）　X₍₁₎=min, X₍ₙ₎=max，证明：
（1）P{X₍₁₎>x, X₍ₙ₎≤y} = [F(y)−F(x)]ⁿ（x≤y）；
（2）(X₍₁₎, X₍ₙ₎) 的分布函数 G(x,y) = Fⁿ(y) − [F(y)−F(x)]ⁿ（x≤y），= Fⁿ(y)（x>y）。
> 证：（1）x<X_i≤y 对每个 i 独立 ⇒ 乘起来；
> （2）G(x,y) = P{X₍₁₎≤x, X₍ₙ₎≤y} = P{X₍ₙ₎≤y} − P{X₍₁₎>x, X₍ₙ₎≤y} = Fⁿ(y) − [F(y)−F(x)]ⁿ。
> **这类题是"白送分"**：只要看懂"min> x ⟺ 全部 > x"，两行写完。

# M11｜随机变量函数的分布（二维）：和、商、积、min/max

【识别特征】Z=X+Y、Z=X/Y、Z=XY、Z=min/max、Z=[X]+1。

【标准流程】
1. **和 Z=X+Y**：卷积 `f_Z(z)=∫f(x,z−x)dx`（**必须写出 x 的两个限制条件**，画图帮助确定积分限）；
2. **商 Z=X/Y**：`f_Z(z)=∫f(yz,y)|y|dy`；
3. **max/min**：分布函数法（P(max≤z)=Fⁿ(z)；min 用对立）；
4. **离散+连续**：全概率。

【真题】2023 真卷·五（10 分）　X~U(0,2), Y~Exp(1) 独立。求（1）Z=X/Y 的密度；（2）P{X≥Y}。
> 官方解答：（1）f_Z(z) = ∫ f_X(yz)f_Y(y)·y dy：
> z≤0 ⇒ 0；z>0 时，需 0<yz<2 且 y>0 ⇒ 0<y<2/z（z>0），
> f_Z(z) = ∫₀^{2/z} (1/2)e^{−y}y dy = ½[1 − (1+2/z)e^{−2/z}]。
> **⚠️ 官方结果写作**：`f_Z(z) = (1/2)[1 − (1 + 2/z)e^{−2/z}]`，z>0（题目里写成 ½·(…)e^(−z/2)？以推导为准，见 07 卷三答案的复算）。
> （2）P{X≥Y} = ∫∫_{x≥y} f_X f_Y dxdy = ∫₀²(1/2)[∫₀^x e^{−y}dy]dx = ∫₀²(1/2)(1−e^{−x})dx = 1/2[2 − (1−e^{−2})] = **1/2 + e^{−2}/2**。
> 官方写 **(1+e^{−2})/2** ✓ 一致。

【真题】2019 秋·计算 3（15 分，离散+连续 ⇒ "全概率 + 分布函数法"）　P(X=0)=P(X=1)=1/2，Y~U(0,1)，独立，求 Z=X+Y 的密度。
> 解（**官方写法**）：F_Z(z) = P{Z≤z} = P{Z≤z, X=0} + P{Z≤z, X=1}
> = ½P{Y≤z} + ½P{Y≤z−1} = ½F_Y(z) + ½F_Y(z−1)
> ⇒ F_Z(z) = 0（z<0）；z/2（0≤z<2）；1（z≥2） ⇒ f_Z(z) = **½（0<z<2）**，其余 0。
> **结论**：Z ~ U(0,2)——**"离散 + 均匀 = 拼接均匀"的经典结果**。
> **技巧**：离散变量与连续变量混合时，**不要写卷积积分，要用全概率（按离散变量分层）**。

【真题】2013·解答 2（P{X+Y<1} 型，见 M9）；2010·解答 4（min 与和）　X₁,X₂,X₃ 独立同 Exp(λ)。
（1）T = min(X₁,X₂) 的密度；（2）S = T + X₃ 的密度。
> 解：（1）P(T>t) = e^{−2λt} ⇒ f_T(t) = **2λe^{−2λt}**（t>0），即 Exp(2λ)；
> （2）S = T + X₃ 是两个独立指数（2λ 与 λ）之和 ⇒ 卷积：
> f_S(s) = ∫₀^s 2λe^{−2λt}·λe^{−λ(s−t)}dt = **2λ²e^{−λs}(e^{−λs}·?)**
> 严格：= 2λ²e^{−λs}∫₀^s e^{−λt}dt = **2λ e^{−λs}(1 − e^{−λs})**（s>0）。
> （官方写 2λe^{−λs}(e^{λs}−1)·? 同义：= 2λ(e^{−λs} − e^{−2λs})）

# M12｜二维正态（三个"必考动作"）

【识别特征】出现 N(μ₁,σ₁²; μ₂,σ₂²; ρ) 或"二维正态 + 不相关 + 独立"。

【标准流程】
1. **线性组合**：aX+bY ~ N(aμ₁+bμ₂, a²σ₁²+b²σ₂²+2abρσ₁σ₂)；
2. **独立 ⟺ ρ=0**（仅对二维正态成立！）；
3. **条件分布**：X|Y=y ~ N(μ₁+ρ(σ₁/σ₂)(y−μ₂), σ₁²(1−ρ²))；
4. **求概率时标准化**：`P(aX+bY > c) = 1 − Φ((c−μ)/σ)`。

【真题】2019 春·解答 4　X~N(5.25,0.64), Y~N(2.53,0.25), ρ=0，二维正态。
（1）P{X+Y>7.5}；（2）P{X>2Y}。
> 解：（1）X+Y ~ N(7.78, 0.89) ⇒ P = 1 − Φ((7.5−7.78)/√0.89) = **Φ(0.297)** ≈ 0.617；
> （2）X−2Y ~ N(5.25−5.06, 0.64+4×0.25) = N(0.19, 1.64) ⇒ P{X−2Y>0} = 1 − Φ(−0.19/√1.64) = **Φ(0.148) ≈ 0.559**。

【真题】2019 春·解答 5（2）　cX₁/√(X₂²+X₃²+X₄²) ~ t(3)，求 c。
> 解：X₁/σ ~ N(0,1)；(X₂²+X₃²+X₄²)/σ² ~ χ²(3)，独立 ⇒
> [X₁/σ]/√[(X₂²+X₃²+X₄²)/(3σ²)] ~ t(3) ⇒ **c = √3**。

【真题】2023 真卷·单选 4　ρ(X,Y)=1，Z=X+Y，求 ρ(X,Z)。
> 解：ρ=1 ⇒ Y 与 X 正线性相关；Y = aX + b（a>0）；Cov(X,Z) = D(X)+Cov(X,Y) = σ_X² + σ_Xσ_Y；
> 用 σ_Y = |a|σ_X 等可算出 **ρ(X,Z) = 1**？（官方答案 A．1）
> **严格算法**：设 X 标准化为 x̂=(X−μ_X)/σ_X，ρ=1 ⇒ (Y−μ_Y)/σ_Y = x̂ a.e.
> ⇒ Cov(X,Z) = σ_X² + σ_Xσ_Y = σ_X(σ_X+σ_Y)；D(Z) = σ_X²+σ_Y²+2σ_Xσ_Y = (σ_X+σ_Y)²；
> ⇒ ρ(X,Z) = σ_X(σ_X+σ_Y)/[σ_X(σ_X+σ_Y)] = **1** ✓（答案 A）。
> **记忆点**：ρ=±1 时，线性组合 Z=X+Y 与 X 的相关系数也是 ±1（同号）。

【真题】2022.6 模拟（八）·10　X,Y 独立同 N(1,σ²)，各取 5 个样本，S₁²,S₂² 为样本方差，
求 5(X̄−Ȳ)²/(S₁²+S₂²) 的分布。
> 解：X̄−Ȳ ~ N(0, 2σ²/5)；4S²/σ² ~ χ²(4) ⇒
> 5(X̄−Ȳ)²/(S₁²+S₂²)：分子 5(X̄−Ȳ)²/(2σ²) ~ χ²(1)；分母 (S₁²+S₂²)/(2σ²) ~ χ²(8)/4·? 
> 标准化后 (X̄−Ȳ)/√(2σ²/5) ~ N(0,1)；[4(S₁²+S₂²)/σ²]/8 ~ χ²(8)/8·?
> 结果 = **F(1, 8)** ✓（官方 F(1,8)）。

【真题】2011·填空 7　X₁…X₄ 来自 N(0,9)，(X₂+X₃+X₄)/(3X₁) 服从什么分布？
> 解：X₂+X₃+X₄ ~ N(0,27)；除以 3√3 标准化 = N(0,1)；X₁/3 ~ N(0,1)；
> ⇒ 商 = [(X₂+X₃+X₄)/(3√3)]/[X₁/3] ~ **N(0,1)/N(0,1) = 柯西**？
> 解（原卷已核对）：ξ = **(X₂+X₃+X₄)²/(3X₁²)**，X₁,X₂,X₃,X₄ iid N(0,9)：
> X₂+X₃+X₄ ~ N(0,27) ⇒ (X₂+X₃+X₄)²/27 ~ χ²(1)；X₁²/9 ~ χ²(1)；独立
> ⇒ [(X₂+X₃+X₄)²/27] / [X₁²/9] = (X₂+X₃+X₄)²/(3X₁²) ~ **F(1,1)** ✓（官方 F(1,1)）。
> **记法**：分子分母都是**平方形式** ⇒ 各自配成 χ² 再相除 = F；若分子分母是**未平方的正态**，那才是柯西/t。

【真题】2015·填空 6　X₁…X_n 来自 N(0,1)，T = (n−1)S² + nX̄² 服从什么？
> 解：(n−1)S² ~ χ²(n−1)；nX̄² = (√n X̄)² ~ χ²(1)；两者独立 ⇒ **χ²(n)**。

【真题】2010·填空 7（"t 还是 F"的核心判据；原卷已回图核对）　X, X₁…X₁₀ 来自 N(0,σ²)，**Y² = (1/10)ΣXᵢ²**，问 **X/Y** 服从什么分布。
> 解：Y = √[(1/10)ΣXᵢ²]；记 S² = ΣXᵢ² ~ σ²χ²(10)（独立于 X）
> ⇒ X/Y = (X/σ)/√(χ²(10)/10) ~ **t(10)** ✓（官方 t(10) ✓）。
> **判据（背下来）**：分子是 **N(0,1) 的一次方**、分母是 **√(χ²(v)/v)** ⇒ **t(v)**；
> 分子也是**平方形式**（X̄²、ΣXᵢ²）才用 **F**。**先看分子有没有平方，再决定 t / F。**

【真题】2010·填空 8　(n−1)S²/σ² ~ ？E(S²) = ？
> 解：**χ²(n−1)**；**E(S²) = σ²**（无偏性）。
