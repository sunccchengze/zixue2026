# 05 · 考场应试手册（120 分钟）

> 本课程的卷面结构（2022 年后定型，2026 年大概率沿用）：
> **单选 5×3 = 15 分 · 填空 5×3 = 15 分 · 解答 5–8 道 = 70 分 · 共 100 分 / 120 分钟。**
> 解答题占比 70%——**决定满分的不是你会不会，而是你会的东西有没有全部落到答题纸上的"得分点"上。**

---

## §1 时间分配（120 分钟版）

| 阶段 | 时间 | 任务 | 心跳线 |
|---|---|---|---|
| ① 通览 | 0–3′ | 翻全卷，标记"秒杀题 / 熟题 / 硬骨头"，在题号旁打 ✓、○、△ | — |
| ② 客观题 | 3–35′ | 单选 5 + 填空 5，每题 ≤3 分钟，超过就跳（**先拿满 30 分**） | 35′ 时应在解答题 |
| ③ 解答 1 轮 | 35–95′ | 从**最有把握的题**开始（不按题号顺序！），每题 10–12 分钟 | 95′ 时做完 5 道以上 |
| ④ 收尾 2 轮 | 95–115′ | 回头做标记的硬骨头；每题写"模型 + 关键式"先拿过程分 | 115′ 停笔检查 |
| ⑤ 检查 | 115–120′ | 见 §4 检查单 | — |

**三条硬纪律**：
1. **不许在单选上恋战**：3 分钟做不出的单选立刻猜一个（标记）继续——3 分而损失 8 分钟是巨亏。
2. **解答题写在答题纸指定位置**：写错位置、超出框线的部分**阅卷老师可能看不到**。
3. **不会的题也要写**：写出分布、写出公式、写出"因为…所以…"，**这一步能拿 30–50% 的题分**。

---

## §2 客观题提速技巧（30 分 ≈ 20 分钟拿满）

**单选题的四把刀**：
1. **排除法优先**：先删"绝对化"选项（一定/必/任意），再删"概念置换"选项（把密度性质写成分布函数的）。
2. **特例法**：取极端值/特殊分布验算（如令 n=1, p=0.5 验证统计量选项）。
3. **量纲/范围法**：概率必在 [0,1]，方差必 ≥0，相关系数必 ≤1——选项超范围直接排除。
4. **反向验证**：把选项代回题干条件（尤其"求常数 c"型）。

**填空题三条**：
- **看清要不要约分/是否分数**：题面写"用分数表示"就必须写 95/104、11/21、20/27 这类**最简分数**。
- **看清单位与参数**：`N(μ, σ²)` 第二项是**方差**；`s²` 与 `s` 差一个根号；"p 是概率"还是"λ 是参数"。
- **没有把握不要空**：填一个"看起来最合理"的值也比空着强（有些老师给部分分或者至少不扣分）。

## §3 解答题书写模板（**照抄这 6 步，稳拿过程分**）

**通用版（每道题都这样排版）**
```
解：(1) 写"由题意/由定义" → 列式（把已知量抄成符号）
    (2) 关键式单独一行居中（阅卷老师一眼能找到）
    (3) 代入数值计算 → 写出中间值
    (4) 结论：用规范语言写"故 …… 为 ……"
```

**按题型的"必写句子"**：
| 题型 | 必写句（漏了扣分） |
|---|---|
| 求分布函数/密度 | "当 x ∉ …… 时，f(x) = 0"（**必须写"其它为 0"**） |
| 独立性判断 | "因为 f(x,y) ≠ f_X(x)f_Y(y)（或等于），所以 X 与 Y 独立/不独立" |
| 相关性判断 | "因为 Cov(X,Y) = E(XY)−E(X)E(Y) = … = 0，所以不相关；又因为……，所以不独立" |
| 矩估计/MLE | "令 E(X) = X̄，解得 θ̂ = …"；"ln L(θ) = …，令 dlnL/dθ = 0，解得 θ̂ = …"（**四步齐全**） |
| 无偏/相合 | "因为 E(θ̂) = θ，所以无偏"；"由辛钦大数定律/切比雪夫，θ̂ → θ（依概率），故相合" |
| 区间估计 | "因为 σ² 未知，故用 t 分布：……（写出枢轴量与区间两端）" |
| 假设检验 | "H₀: μ=μ₀ ←→ H₁: μ≠μ₀；统计量 T=…~t(n−1)；拒绝域为…；代入得 T=…；因为…所以**拒绝/不拒绝** H₀" |
| CLT 求 n | "由中心极限定理，近似有 …… ~ N(…)，令 P{…} ≥ …，解得 n ≥ …，故 n 至少取 …（取整）" |

**三个"绝不能写"**：
1. 不写"**证明 H₀ 成立**"——只能写"**没有充分理由拒绝 H₀**"；
2. 不写"**因为 n 大所以服从正态**"——要写出 `E`、`D` 再套 CLT；
3. 不写"**显然**"——凡是能算的先算一遍再写结论。

**答题纸空间管理**：解答题 6–8 道 × (1/3–1/2 页)；**先写小标题编号**（(1)(2)(3)），避免漏答。

## §4 收卷前 5 分钟检查单

**A. 客观题**
- [ ] 单选题有没有因为"看错问的是错误项"而反选？
- [ ] 填空题：分数约分了吗？区间左右端大小对吗？带单位吗？

**B. 解答题**
- [ ] 每道题的**小问**都有对应答案吗（(1)(2)(3) 别漏）？
- [ ] 分段密度的"**其它为 0**"写了吗？定义域对吗？
- [ ] 条件密度的 x 范围写了吗？
- [ ] 假设检验的**结论句**写了吗（"拒绝/不拒绝"）？方向对吗？
- [ ] 区间估计里**小的分位数配大的界限**了吗？
- [ ] 自由度算对吗（t: n−1；两样本: n₁+n₂−2）？

**C. 数字**
- [ ] 求"至少 n"有没有**向上取整**？求"最多"有没有**向下取整**？
- [ ] 分位数查的是 α 还是 α/2？（**α=0.1 双侧 ⇒ 查 t_{0.05}**）

## §5 三类突发情况的处置

| 情况 | 处置 |
|---|---|
| **题干印刷/答案疑似有误** | 按**印刷数据老实推**，卷面注明"按题面数据推得…"。不要为了凑官方答案改自己的数据。 |
| **卡在一道 10 分题上** | 5 分钟没思路 ⇒ 立刻跳走做后面的，回来时把"模型、分布、公式"写出来，往往能拿一半分。 |
| **时间不够** | 放弃需要 15 分钟的大积分（如三重积分求 E(XY)），把时间换成 **两道小问的完整过程** = 更划算。 |

## §6 最后一晚的 90 分钟复习法

1. **0–25′**：抄写 04 文件的 §8"极简 A4"（默写下分位数表，对一遍）。
2. **25–55′**：默写 **M13–M18 的六张流程表**（χ²/t/F 构造、矩估计与 MLE 四步、区间估计四表、检验六表）。
3. **55–80′**：翻 03 文件的**加粗条目**（T/R/N/G 系），每题回忆"原型来自哪年"。
4. **80–90′**：看 06 文件里"**近五年 5 次以上出现的题型**"，确认自己每种都能 3 分钟内起手。

**睡觉前不要碰新题**；不要刷难题；不要跟同学对答案。
