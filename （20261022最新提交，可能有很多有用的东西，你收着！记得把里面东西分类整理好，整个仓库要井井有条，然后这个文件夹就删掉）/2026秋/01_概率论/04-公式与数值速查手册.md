## §1 概率论基础（第 1 章）

**事件运算**：`Ā∪B = A∪B 的长横线 = Ā∩B̄`；`A−B = AB̄`；`A∪B = A + ĀB`；
**对偶律**：`(A∪B)̄ = Ā∩B̄`，`(AB)̄ = Ā∪B̄`（**长横线要"拆括号 + 变号"**）。

**概率性质**：`P(Ā) = 1−P(A)`；`P(A−B) = P(A) − P(AB)`；
`P(A∪B) = P(A) + P(B) − P(AB)`；
`P(ABC) = P(A)P(B|A)P(C|AB)`。

**条件概率**：`P(A|B) = P(AB)/P(B)`；**独立**：`P(AB) = P(A)P(B)` ⟺ `P(A|B) = P(A)`。
三事件相互独立：两两独立 + `P(ABC)=P(A)P(B)P(C)`（**两者缺一不可**）。

**全概率**：`P(A) = Σ P(Bᵢ)P(A|Bᵢ)`；**贝叶斯**：`P(Bₖ|A) = P(Bₖ)P(A|Bₖ) / Σ P(Bᵢ)P(A|Bᵢ)`。

**古典概型**：`P = 有利/全部`；组合 `C_n^m = n!/(m!(n−m)!)`；**有放回 vs 无放回**先分清。

**伯努利**：n 重独立试验中"至少一次" 用 `1 − (1−p)ⁿ`。

## §2 一维随机变量（第 2 章）

**分布函数**：`F(x) = P{X ≤ x}`；右连续；`P{a<X≤b} = F(b) − F(a)`；
`P{X = x₀} = F(x₀) − F(x₀−0)`（**跳跃高度 = 点概率**）。

**密度**：`F(x) = ∫_{−∞}^{x} f(t)dt`；`f(x) = F′(x)`（在连续点）；`∫f = 1`，`f ≥ 0`；
**f 可以大于 1、可以不连续、可以不单调**（← 选择必考坑）。

**函数分布（一维）**：
- 公式法（单调）：`f_Y(y) = f_X(g^{−1}(y))·|(g^{−1}(y))′|`；
- 分布函数法（通用）：先写 `F_Y(y) = P{g(X) ≤ y}` 再求导；
- **平方型**：`Y = X²` ⇒ `f_Y(y) = [f_X(√y) + f_X(−√y)]/(2√y)`（y>0）。

## §3 常见分布（第 2、3 章）

| 分布 | 记号 | 分布律/密度 | E(X) | D(X) |
|---|---|---|---|---|
| 0-1 | B(1,p) | P(1)=p | p | p(1−p) |
| 二项 | B(n,p) | C_n^k p^k q^{n−k} | np | np(1−p) |
| 泊松 | P(λ) | λ^k e^{−λ}/k! | λ | λ |
| 几何 | G(p) | (1−p)^{k−1}p | 1/p | (1−p)/p² |
| 均匀 | U(a,b) | 1/(b−a) | (a+b)/2 | (b−a)²/12 |
| 指数 | Exp(λ) | λe^{−λx} | 1/λ | 1/λ² |
| 正态 | N(μ,σ²) | — | μ | σ² |

**可加性（再生性）**：二项（同 p）、泊松、正态、χ²、Gamma（同 λ）**可加**；**均匀、指数不可加**。
（2020 秋·解答 2 就是"指数分布**不**具有可加性"的证明 + 举例）

**正态标准化**：`Z = (X−μ)/σ ~ N(0,1)`；`P{μ−σ<X<μ+σ} = 0.6826`，`2σ: 0.9544`，`3σ: 0.9974`。

**泊松定理**：n 大 p 小，`B(n,p) ≈ P(np)`。

## §4 随机向量（第 3 章）

**联合 → 边缘**：`f_X(x) = ∫ f(x,y)dy`；`f_Y(y) = ∫ f(x,y)dx`。
**条件**：`f_{X|Y}(x|y) = f(x,y)/f_Y(y)`（**写 x 的范围**）；`f_{Y|X}` 同理。
**独立**：`f(x,y) = f_X(x)f_Y(y)` 对所有 (x,y)（**注意定义域要是矩形/直积**）。

**二维均匀**：`f = 1/S_D`（面积倒数）；`P{(X,Y)∈G} = S_G/S_D`（**面积比**）。
`F(x,y) = (x−a₁)(y−a₂)/((b₁−a₁)(b₂−a₂))` 仅当**矩形**。

**二维正态**：`(X,Y) ~ N(μ₁,μ₂,σ₁²,σ₂²,ρ)`：
- 边缘正态、条件正态、线性组合正态；
- **ρ = 0 ⟺ 独立**（**只有二维正态才有这等价！**）；
- `aX+bY+c ~ N(aμ₁+bμ₂+c, a²σ₁²+b²σ₂²+2abρσ₁σ₂)`。

**和的分布（独立）**：卷积 `f_Z(z) = ∫ f_X(x)f_Y(z−x)dx`；
**商的分布**：`f_Z(z) = ∫ f_X(xz)f_Y(x)|x|dx`（或先 F 再导）；
**min/max**：`F_max(z) = F_X(z)F_Y(z)`，`F_min(z) = 1−[1−F_X(z)][1−F_Y(z)]`。
**指数卷积口诀**：`Exp(λ₁)` 与 `Exp(λ₂)` 之和的密度 = `λ₁λ₂(e^{−λ₁z} − e^{−λ₂z})/(λ₂−λ₁)`（λ₁≠λ₂）。

## §5 数字特征与极限定理（第 4、5 章）

**期望**：`E(X) = Σx_kp_k` 或 `∫xf(x)dx`；`E(g(X)) = ∫g(x)f(x)dx`（**不必求分布**）；
`E(X+Y) = E(X)+E(Y)`（**恒成立**）；独立 ⇒ `E(XY) = E(X)E(Y)`。

**方差**：`D(X) = E(X²) − [E(X)]²`；`D(aX+b) = a²D(X)`；
`D(X±Y) = D(X)+D(Y) ± 2Cov(X,Y)`。

**协方差**：`Cov(X,Y) = E(XY) − E(X)E(Y)`；`Cov(aX,bY) = ab·Cov(X,Y)`；`Cov(X,X) = D(X)`。
**相关系数**：`ρ = Cov(X,Y)/(√D(X)√D(Y))`，`|ρ| ≤ 1`；`ρ = 0 ⇔ 不相关 ⇔ E(XY)=E(X)E(Y)`。

**不相关 ↔ 独立**：独立 ⇒ 不相关；**不相关 ⇏ 独立**（反例：`Y = X²` 型、`X~U(−1,1)`）；（X,Y）正态时等价。

**k 阶矩的常用值**：`E(X>0 的幂)`……**正态偶数阶中心矩**：`E(X−μ)^{2k} = (2k−1)!!σ^{2k}`，
即 `E(X−μ)⁴ = 3σ⁴`、**`E(X−μ)⁶ = 15σ⁶`**（2016 单选 3 考的正是它）。

**切比雪夫**：`P{|X−EX| ≥ ε} ≤ D(X)/ε²`；**推论**：`P{|X−EX| < ε} ≥ 1 − D(X)/ε²`。
（2016 单选 2 的错误项就是把 σ² 和 ε² 位置颠倒）

**两个极限定理**：

| 定理 | 条件 | 结论 |
|---|---|---|
| **辛钦大数定律** | iid，E 存在 | `(1/n)ΣXᵢ → E(X)`（依概率） |
| **伯努利大数定律** | iid 0-1 | `频率 → p` |
| **中心极限定理（林德伯格-列维）** | iid，E,D 存在 | `ΣXᵢ ≈ N(nμ, nσ²)`；`(ΣXᵢ − nμ)/(σ√n) ≈ N(0,1)` |

**CLT 的四种用法**：① 求概率；② 求 n（**最少多少次** ⇒ 向上取整）；③ 频率误差；④ 二项的正态近似（`np≥5, nq≥5`）。

## §6 数理统计（第 6–8 章）

**三大抽样分布**：
`Σ(Xᵢ−μ)²/σ² ~ χ²(n)`（μ 已知）；`(n−1)S²/σ² ~ χ²(n−1)`（μ 未知）；
`(X̄−μ)/(σ/√n) ~ N(0,1)`；`(X̄−μ)/(S/√n) ~ t(n−1)`；
`[χ²(n₁)/n₁]/[χ²(n₂)/n₂] ~ F(n₁,n₂)`；**t 与 F 的关系**：`t²(n) = F(1,n)`。

**数字特征**：`E(X̄) = μ`，`D(X̄) = σ²/n`；`E(S²) = σ²`；`E(B₂) = (n−1)σ²/n`。

**矩估计**：`E(X) = X̄`（解出参数）；必要时用二阶矩 `E(X²) = A₂ = (1/n)ΣXᵢ²`。
**MLE**：`L = Πf(xᵢ)` → `ln L` → 求导置零 → 解；**参数在取值端点 ⇒ 用 min/max**。

**有效性**：无偏估计的方差越小越有效；`θ̂ = ΣcᵢXᵢ` 无偏 ⟺ `Σcᵢ = 1`，`D = σ²Σcᵢ²`（**系数平方和最小最优**）。

**区间估计**（1−α，双侧）：
| 对象 | 条件 | 区间 |
|---|---|---|
| μ | σ 已知 | `X̄ ± u_{α/2}·σ/√n` |
| μ | σ 未知 | `X̄ ± t_{α/2}(n−1)·S/√n` |
| σ² | μ 未知 | `[(n−1)S²/χ²_{α/2}(n−1), (n−1)S²/χ²_{1−α/2}(n−1)]` |
| σ² | μ 已知 | 同式，换 `n` 与 `Σ(Xᵢ−μ)²` |
| μ₁−μ₂ | 方差齐 | `(X̄−Ȳ) ± t_{α/2}(n₁+n₂−2)·S_w√(1/n₁+1/n₂)` |

`S_w² = [(n₁−1)S₁² + (n₂−1)S₂²]/(n₁+n₂−2)`。

**假设检验**（H₀ 为"等于/不小于"时）：
| 对象 | 统计量 | 拒绝域 |
|---|---|---|
| μ, σ 已知 | `Z = (X̄−μ₀)/(σ/√n)` | `\|Z\| > u_{α/2}` |
| μ, σ 未知 | `T = (X̄−μ₀)/(S/√n)` | `\|T\| > t_{α/2}(n−1)` |
| σ² | `χ² = (n−1)S²/σ₀²` | `χ² > χ²_{α/2}` 或 `χ² < χ²_{1−α/2}` |
| σ₁²/σ₂² | `F = S₁²/S₂²` | `F > F_{α/2}` 或 `F < F_{1−α/2}` |
| μ₁−μ₂ | `T = (X̄−Ȳ)/(S_w√(1/n₁+1/n₂))` | `\|T\| > t_{α/2}(n₁+n₂−2)` |
| 成对 μ_D | `T = D̄/(S_D/√n)` | `\|T\| > t_{α/2}(n−1)` |

**两类错误**：α = P(弃真) = P(拒绝H₀|H₀真)；β = P(纳伪)；**功效 = 1 − β**；n 固定时 α↓ ⇒ β↑。
**F 的双侧临界值**：`F_{1−α/2}(n₁,n₂) = 1 / F_{α/2}(n₂,n₁)`（**必须用倒数换算**）。

## §9 分布拟合（8.6）/ 一元回归（第10章）——2026 课表新增 · 考前 1 页

```
一元线性回归（M19）   ŷ = â + b̂x
  l_xx = Σx² − n x̄²   l_yy = Σy² − n ȳ²   l_xy = Σxy − n x̄ ȳ
  b̂ = l_xy / l_xx     â = ȳ − b̂ x̄        （直线过 (x̄, ȳ)）
  Q_e = l_yy − b̂·l_xy = Σ(y−ŷ)²           σ̂² = Q_e/(n−2)   ← 自由度 n−2（a、b 都估过）
  显著性检验：H0: b=0，T = (b̂/σ̂)·√l_xx ~ t(n−2)，|t| ≥ t_{α/2}(n−2) ⇒ 线性显著
```
