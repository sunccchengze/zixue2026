# 03 · 陷阱清单 · 选择填空雷达（T / R / N / G / A / K / X 七系）

> 这份文件是**从 20 套真题里反向提取的"坑法词典"**。
> 考场上遇到似曾相识的题，先在这里找编号 → 想起对应坑 → 用反制动作解决。
> 建议：① 模考后把每道错题标注坑编号；② 考前一晚只看本文件的**加粗条目**。

---

## 0. 总览：七系坑法索引

| 系 | 名称 | 出现场合 | 反制总纲 |
|---|---|---|---|
| **T** | 概念置换 / 限定词 | 判断、单选"下列说法错误的是" | 抓**限定词**（一定/必/任何/必为）+ 找**反例** |
| **R** | 选项工程 | 单选 | 看**问法方向**（错误/不正确）+ 排除法 |
| **N** | 数值拐弯 | 填空、计算 | 每一步都**检查单位/方向/取整** |
| **G** | 反推链 | 填空、单选 | 由结果反推参数（跳跃量、矩、相关系数） |
| **A** | 心理战 | 压轴、长题干 | 稳住节奏，**先跳过 30 秒再看** |
| **K** | 库存坑（教材有、真题少考） | 偶发 | 只记结论，不深挖 |
| **X** | 考古 / 越纲 | 偶发（1–2 题） | 认出来就写"过程分"，不恋战 |

## 1. T 系 · 概念置换与限定词（选择/判断题的 70%）

- **T1【绝对化量词】** "一定/必/任何/总是/必为"入句即高危。
  原型：2020 秋 判断 1（P(A∪B)=P(A)+P(B) ⇒ AB=∅？**错**，概率为 0 ≠ 不可能事件）；
  2020 秋 判断 3（取值范围是连续区间 ⇒ 连续型？**错**，还有奇异型）；
  2020 秋 单选 1 D（基本事件一定独立？**错**）。
  **反制**：见到"一定"先想**零概率事件**与**反例**。
- **T2【主体/口径置换】** 把 A 的性质安在 B 上、把"函数的性质"安在"密度"上。
  原型：2020 秋 单选 2（密度的性质：f 可以 >1！只有 F 才在 [0,1]；f 不必连续、不必单调）；
  2019 秋 单选 5（**二维均匀分布的边缘不一定是均匀分布**；**条件分布也不是**）。
  **反制**：问"密度"就答"非负+积分为 1"，**别答"≤1"或"连续"**。
- **T3【半对半错拼接】** 前句对后句错，一锹挖一坑。
  原型：2020 秋 单选 3（C：X、Y 各自正态 **且独立** ⇒ 和正态 ✓；D：各自正态且 ρ=0 ⇒ 独立 ✗，缺"联合正态"）。
  **反制**：逐分句判，**不看整体感觉**。
- **T4【全称命题要反例】** "都/所有/任取" ⇒ 找个反例就推翻。
  原型：2016 单选 1（A∪B 的运算律：A 错，B 对）；2017 模拟（A 发生时 B 必发生⇒……）。
- **T5【摘条件】** 把"独立"漏掉、把"方差相等"漏掉、把"正态"漏掉。
  原型：2020 秋 单选 1 C、2023 真卷 单选 3（X~U(0,2), Y~P(3) **且独立** ⇒ D(3X−Y−2) 才可加）。
- **T6【方向性概念】** 一类错误 vs 二类错误；α 越小越难拒绝；"没有拒绝 ≠ 证明正确"。
  原型：2018 单选 6（第一类错误 = H₀ 真而拒绝）；2015 单选 4（α=0.01 不能拒绝 ⇒ α=0.05 下**可能拒绝也可能不拒绝**）；
  2022.6 单选 5（不拒绝原假设意味着"没有充分证据证明原假设是错的"）。
- **T7【独立性三种等价性的顺序】** 相互独立 ⇒ 两两独立 ⇒ 不相关（**反过来全不成立**）。
  原型：2019 秋 填空 3（三者的关系填空）；2015 单选 2（ξ=X+Y, η=X−Y 不相关但**不独立**）。
- **T8【"离散/连续"混用】** "取值范围是连续区间就是连续型"（错）、"连续型才有密度"（对）。
- **T9【统计量定义】** 统计量**不能含未知参数**；X̄、S² 是统计量，X̄−μ 不是。

## 2. R 系 · 选项工程

- **R1【反向设问】** "错误的是/不正确的是/不等价的是"。
  原型：2020 秋 单选 1、3；2019 秋 单选 5；2018 单选 1、6。**做时在题干上圈出"错误"二字。**
- **R2【镜像对】** 一对互为镜像的选项摆在相邻位置（Φ vs 1−Φ；t_α vs t_{α/2}；左尾 vs 右尾）。
  原型：2023 真卷 单选 1（0.5 与 0.75）；2019 秋 单选 2（p₁=p₂ vs >）；2015 单选 3（t(5)>t(6)>u 的方向）。
- **R3【诱饵数值】** 未约分/用错口径的数字。
  原型：2020 秋 填空 4（95/104 vs 95/100）；2019 秋 单选 3（1−e^{−1} 是 F(1)，正确答案 1/2−e^{−1}）；
  2018 解答 5（给了 t 分位数，实际该用 u）；2023 真卷 填空 3（20/27 vs 8/27）。
- **R4【三真一假/全对型】** 四个陈述挑一个错的（或四个都对时挑"最有效"）。
  原型：2018 单选 1（三个等价 + 一个不等价）。
- **R5【"最"字题】** 最有效/最接近/至少/最多 ⇒ 一定要比较**全部选项**再选。
  原型：2018 单选 5、2020 秋 单选 5（有效估计 = 系数平方和最小）。

## 3. N 系 · 数值拐弯（填空与大题的计算陷阱）

- **N1【方差 vs 标准差】** 题目给"s²"还是"σ"？`N(μ, σ²)` 的第二个数是**方差**。
  原型：2023 真卷 单选 5（N(12,4) 要用 σ=2）；2019 秋 计算 8（s²=7.8 ⇒ s=√7.8）；2023 真卷 六（方差 4 ⇒ σ=2）。
- **N2【χ² 区间方向】** σ² 区间：**小的分位数（χ²_{1−α/2}）当分母 ⇒ 得到大界限**。
  原型：2020 秋 解答 4（(8.048, 64.734)）。**写下区间后再核对一次大小顺序**。
- **N3【α 与 α/2】** α=0.1 的双侧 ⇒ 查 t_{0.05}；α=0.05 的单侧 ⇒ 查 t_{0.05}。
  原型：2019 秋 计算 8（α=0.1 用 1.7531）；2019 春 解答 6（单侧 1.86）。
- **N4【自由度的四种数法】** t: n−1；两独立样本: n₁+n₂−2；成对: n−1；χ²: n−1（μ 未知）或 n（μ 已知）；F: (n₁−1, n₂−1)。
  原型：2016 解答 6（19 vs 20）；2014 解答 6（t(8) 不是 t(9)）。
- **N5【取整方向】** 求"至少 n" ⇒ **向上取整**；求"最多多少个数相加" ⇒ **向下取整**。
  原型：2023 真卷 六（n=62，61.47 向上）；2017 计算 4（n=136，135.3 向上）；2020 秋 解答 1（n≤312）。
- **N6【幂/根号运算】** 方差开根号、区间长度 2uσ/√n 的 **2** 别丢。
  原型：2011 解答 4（√(6.75×10⁸)）；2017 计算 4。
- **N7【均匀分布的方差】** U(a,b) 的方差 = (b−a)²/12；U(−0.5,0.5) ⇒ 1/12；U(0,2θ) ⇒ θ²/3。
  原型：2020 秋 解答 1、2018 填空 5、2011 解答 4。
- **N8【条件概率的分母】** 条件概率的样本空间是**条件事件**；全概率要**并全部情况**。
  原型：2015 填空 2（5/12）；2020 秋 填空 4（分母 0.104 不是 0.1）。
- **N9【连续化/条件密度的定义域】** "f_{X|Y}(x|y) 要在给定 y 下写出 x 的范围"。
  原型：2023 真卷 四（2）（1/y, 0<x<y）。**漏写范围就丢分。**
- **N10【密度可以大于 1】** 如 f(x)=2 on (0,1/2)。**别再写"0≤f≤1"**。
- **N11【正态对称化】** P{X≤μ−2σ} = P{X≥μ+2σ} = (1−0.9544)/2 = 0.0228。
  原型：2019 秋 单选 2（p₁=p₂）；2023 真卷 单选 5。
- **N12【排列组合的"含 0"】** 数字排列题：末位/首位/是否重复三者分开讨论。
  原型：2016 单选 4（4/9）。
- **N13【样本容量与"长度"】** 置信区间长度 L 与 √n 成反比，与 u_{α/2} 成正比。
  原型：2019 秋 填空 5、2017 计算 4、2016 填空 5。
- **N14【小数/分数要求】** 题面写"结果用分数表示" ⇒ 必须约分（95/104，不是 0.9135）。

## 4. G 系 · 反推链（"给结果求参数"）

- **G1【由 F 的跳跃求点概率】** P{X=x₀}=F(x₀)−F(x₀−0)。原型：2020 秋 填空 2；2019 秋 单选 3。
- **G2【由矩反推参数】** E[(X−2)(X−3)]=2 ⇒ 泊松 λ²−4λ+4=0 ⇒ λ=2；E(X²)=6 ⇒ λ=2。
  原型：2018 填空 3；2015 填空 4。
- **G3【由方差反推相关系数】** D(2X−Y)=1 ⇒ Cov=7/4 ⇒ ρ=7/8。原型：2011 填空 5。
- **G4【由 P{X≥1}=5/9 反推 p ⇒ 再求 D(Y)】** 原型：2023.2 模拟（九）填空（D(Y)=6）。
- **G4c【回归/拟合 · 三个自由度】** 回归的 σ̂² 分母是 **n−2**；χ² 拟合检验 df = **k−1−r**；
  （超纲备用：单因素方差分析 df = (s−1, N−s)，**N 是总观测数不是组数**——第9章课表未列，可略。）（见 09 号文件 §2–§3）
- **G4b【根号密度/根号参数】** f(x)=A√x 型：∫₀¹A√x dx = (2/3)A = 1 ⇒ **A=3/2**（不是 2）；F(x)=x^{3/2}（2010 解答 2）。
  同理看到 **√θ** 在密度里（2023 真卷七）⇒ 答案要比"无根号版"多一个平方：θ̂=[X̄/(1−X̄)]²。
- **G5【由统计量分布反推常数】** 2023 真卷 九（C=1/(2(n−1))）；2013 计算 6（C=1/8）；2019 春 计算 5（c=√3）。
- **G6【由分布律反推联合分布】** P{XY=0}=1 ⇒ 联合分布律（2019 秋 计算 1、2019 春 计算 1）。
- **G7【由无偏性反推系数】** a+b=2/3 与 a−b=1/3 ⇒ a=1/2, b=1/6。原型：2013 计算 7。
- **G8【由两类错误反推功效】** 功效 = 1 − β。原型：2017 计算 5（α=1/4, β=5/8, 功效 3/8）。

## 5. A 系 · 心理战（失分重灾区）

- **A1【长题干阅读量】** 2014 解答 12、2019 春 解答 6（成对数据带表格）、2023 真卷 八。
  **反制**：先**圈出 n、x̄、s、α**，再看问什么；表格题**先算差值列**。
- **A2【"越纲"陷阱题】** 2015 解答 5（泊松过程/Gamma：第 5 次与第 10 次发生时刻的协方差 = 5/λ²）、
  2017 解答 7（Monty Hall）、2016 解答 4（E[max{X,Y}]=1/√π）、2017 解答 6（标准分比较两班成绩）。
  **反制**：这些题每题 7–10 分，**用 5 分钟写"模型 + 关键式子"**，拿过程分就撤，**不要死磕**。
- **A3【争议题 / 印刷异常】** 2018 填空 1（与题面不自洽）、2019 春 计算 4（官方漏除区域面积 1/2）、2011 填空 6（官方把 σ 当成 2，忘了 X̄ 的方差是 σ²/n）、
  2011 填空 2（官方 2/9 其实是 P{X=3} 的计数）、2010 填空 1（卷面数据缺条件，官方按"P(B̄|A)=1/3"给 1/2）、2014 解答 10（官方 12073 与其自列公式矛盾）。
  **反制**：按**印刷数据老实推**，卷面写清你自己的记号；不自乱阵脚、不改数据凑答案。
- **A4【计算量炸弹】** 2020 秋 解答 3（|y|<x 分段积分）、2014 解答 8（a=24 的三重积分）、
  2012 解答 2（卷积）。
  **反制**：先用**对称性**砍一半（E(XY)=0、E(Y)=0），再动笔积分。
- **A5【"看起来简单"的证明题】** 2013 解答 7（A∪B 与 C 独立）、2022.6 解答 18（min/max 的分布函数）。
  **反制**：证明题**先写定义式**（按定义展开 P(...)），再逐步化简——几乎都能拿到 80% 分。

## 7. X 系 · 考古与超纲（认出来就写过程分）

- **X1【泊松过程的协方差】** 独立增量的和：Cov(W_m, W_n) = m/λ²（m≤n）。原型：2015 解答 5（λ=1/5 ⇒ 5×1/5²·? = 5/λ² = 125? 
  **正确**：W_m = Σ_{i=1}^m X_i，Cov(W_m,W_n) = Var(W_m) = m/λ² = 5/(1/25) = **125**？官方写 5/λ²·? 
  **以官方为准**：Concov = 5/λ²，λ=1/5 ⇒ 5×25 = 125。**注意单位**：题中"间隔 ~ E(5)"若 5 是**均值**则 λ=1/5。
  官方答案写 (1/5)·? ⇒ 请按原卷的 λ 定义核对；**记方法：Cov(W_m,W_n)=Var(W_m)=m/λ²**。
- **X2【E[max{X,Y}]】** X,Y iid N(0,1) ⇒ E[max] = 1/√π ≈ 0.5642（推导：E[max] = E[(X+Y+|X−Y|)/2] = E|X−Y|/2 = √2·√(2/π)/2）。
- **X3【标准分比较】** 2017 解答 6：用 z = (x−x̄)/s 比较不同均值/标准差班级 ⇒ z₁=1.22 < z₂=1.69 ⇒ 刘梅更好。
- **X4【"超物理"式的合理讨论】** 2017 计算 4 的 n=136 是上取整、2023 真卷 六的 62——**凡是 n 都往上取**。

## 8. 收卷前 60 秒 · 检查单（按顺序默念）

1. **填空题**：分数约分了吗？"用分数表示"的写成分数了吗？区间写成"**小于在前、大于在后**"了吗？
2. **密度/分布函数**：写"**其它为 0**"了吗？分段边界用 **≤** 号了吗（右连续）？
3. **条件密度**：写了 x 的取值范围了吗？
4. **独立性/相关性**：结论 + 理由（奇函数/不相关）都写了吗？
5. **区间估计**：**小的分位数配大界限**了吗？μ 与 σ² 的公式用对了吗？
6. **假设检验**：H₀/H₁ 方向、单侧/双侧、临界值、结论措辞（"拒绝/不拒绝"，**不是"证明"**）都写了吗？
7. **统计量自由度和 n 的取整**：核对了吗？
8. **计算题**：有没有漏答某小问？（2023 真卷一道题最多 3 小问，**别答两问就走**）
