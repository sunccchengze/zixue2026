> **触发条件**：用户给出下一次课的教室号（Bxxx）/实验名/课表截图/周次中的任意一种 → **不再询问，直接按 §1–§7 全流程执行**，交付预习报告并推送。

## §0 红线纪律（违反即返工）

1. **内容唯一来源 = 第三版课本**：《大学物理实验（第三版）》高博 主编，ISBN 978-7-04-061177-9。**不搜网、不引外部说明书/讲义、不编造课本不存在的任何参数与数据**。旧 `大学物理实验/资料原件/大物实验讲义.pdf` 与 `提示词-初版.txt` 均已废弃（后者被本 SKILL 版式取代：5 节→2 部分、LaTeX→单行 Unicode）。
2. **版式两部分**：一、实验原理简述；二、预习思考题与解答（**恰好 3 道**）。原理部分按用户要求呈现。**B317 实验 3.2 第一部分明确只用一张生成的原理信息图作为唯一正文**：图内用精确核验过的课本内容呈现原理、公式、变量和必要示意；Markdown 中不另行重复打公式，图片说明仅作简短无公式 caption。图像须清晰完整、排版不裁切，关键公式及编号生成后逐项核对；图中文字不替代事实核验。此信息图版式不自动扩展到其他实验。每题解答都按计算题标准展开：先依据/物理理由，再给公式或文本证据，随后推导或代入，最后说明结论；定性题也要分步论证，禁止只写判断。思考题讲解须图文并茂；优先将课本对应图紧邻相关解答，不能配无关图或引入课本外材料。详尽程度以 2.10 和 2.16 的报告为参照，不因题目看似简单就压缩论证。**恰好 3 道思考题必须由报告作者自行提出，是从课本原理、实验步骤、数据处理或误差机制引出的真实、深入问题；绝不抄录、近义改写或挑选课本“思考与讨论”原题。**课本原题只提取留档，不能进入报告题目。
3. **题解公式禁用 LaTeX**（`$$ \frac \sqrt \theta` 等一律不用——md2docx 转换会竖排散架）；题解中用单行纯文本 Unicode 排版，编号照课本，如 `J d²θ/dt² = −kθ − b dθ/dt + M₀cos ωt　(2.10.1)`。原理信息图内的公式由生图呈现，但必须人工逐字符核对后才能交付。
4. **git 纪律**（服从 AGENTS.md v2.0 回合级保存）：
   - 允许 `git add -A`，但**提交前必须 `git status --short` 逐条目视**：出现意料之外的 `D`/`M`/`R`（尤其 Bin 大文件）先 `git checkout <基线commit> -- <路径>` 恢复，禁止把快照丢失当成用户删除提交（判例：2026-09-23 误删 123 文件）。
   - 只推送平台指定的当前工作分支：`git push origin <当前会话分支>`。**不得推送或快进 main**；分支名必须取当前平台指示，不得沿用旧会话分支名。
   - 沙箱重置后按平台指定的当前分支从 origin 接回工作；如远端分支缺失或分叉，先检查并报告，不要自行切换分支、硬重置 main 或强推；**永不 -f 强推、从不 merge/close PR**。
   - commit 作者：`sunccchengze <sunccchengze@users.noreply.github.com>`。
5. **大文件不随快照持久**（>~128MB 总量上限）：扫描 PDF 会在沙箱重置后从工作区消失，但 git（origin）里有。每回合开工先核对：`git ls-tree --name-only HEAD -- <目录>` vs `ls <目录>`；缺了就 `git checkout HEAD -- <路径>` 恢复，见判例（2026-09-23 曾因 add -A 误删 123 个文件，已恢复于 6a719c5）。

## §2 取课本页（扫描 PDF 视觉读）

- 位置：`大学物理实验/大学物理实验 第三版_1-348/（已压缩）大学物理实验 第三版_1-348_<范围>.pdf`（7 册：1-50/51-100/101-150/151-200/201-250/251-300/301-348）。
- **无文字层、无可用目录 → 禁止全文检索/get_toc**，只能渲染成图视觉读。
- 工具：`/home/user/.venv`（无则 `python3 -m venv /home/user/.venv && /home/user/.venv/bin/pip install -q pymupdf`），~110 dpi 渲染目标页 PNG 后 `read_file` 读图。
- 页码换算**自校准**：先渲染该册 PDF 第 0 页，读出其印刷页码 p₀ → 该册印刷页 = p₀ + idx（idx 为 0 基页索引）。实测：1-50 册 印刷页=PDF页(1基)−5；101-150 册 印刷页=idx+96；151-200 册 印刷页=idx+146（2026-09-23）；201-250 册首页印刷 196，印刷页=idx+196（2026-09-28，2.23 对应 idx 29–34）。其余册用前必校准。注意：书首目录仅一页（止于 2.15/164），2.16 及之后的实验直接扫对应册定位（如 2.16 在印刷 172–176）。

## §5 自检（全过才能提交）

1. B317 原理部分只用一张信息图；图中文字、公式、编号等逐项对照课本核验，确保完整清晰、未裁切，Markdown 不重复打公式。其他实验按用户指定版式自检。
2. 思考题恰好 3 道；逐题与课本“思考与讨论”原题对照，确认既非照抄也非近义改写，问题确由作者自拟且有实质推理价值。
