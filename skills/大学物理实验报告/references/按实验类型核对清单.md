# 按实验类型核对清单（冗余核对 + 常见抄错）

> 用法：做任何实验，先在本表找到大类，挑至少两项冗余核对；具体公式以本次课件为准。本表给的是“怎么互查”，不是公式汇编。

## 通用（所有实验先过这四条）
- 定义/单位/量程：每列是谁、单位、测之前是否换量程——错行错列是最常见整组报废原因。
- 量级预估：用标准值/理论值先估结果量级，实测偏一个数量级先查单位与倍率（×10 档、分压/分流、游标倍率）。
- 趋势：自变量增大时读数应按理论单调/线性/平方变化，反趋势的那组先标出复核。
- 同伴对比：同批多组中误差大一个量级的那组，先怀疑抄错整数位，不要先写误差分析。

## 力学 / 热学
核对：零点与有效长度定义是否与公式一致；计时“次数×周期”总量闭合（总时/次数应≈周期）；重复计时散布应远小于周期；质量/长度正反测互查。
常见抄错：摆长漏加/多加小球半径、圈数多计一次、温度未到稳态就读、砝码等级/单位 g 与 kg 混。
思考题多为：某量改变对结果的影响、为何多次测量、系统误差改进——答“影响哪一项、按公式如何变”。

## 电学 / 电磁学
核对：电路图与实物接线、量程与极性、读数×倍率；回路电压闭合、桥平衡时比例关系；正负接反读数符号；拟合 U-I 等图线截距的物理意义。
常见抄错：电表读数忘乘量程倍率、分压分流公式用反、示波器 /div 与探头倍率漏乘、平衡点读数错一位。
思考题多为：量程选择、接法误差（内接/外接）、如何消除某系统误差——答要给出接法与公式依据。

## 光学
核对：共轴/垂直调好再读数；角度双读数差约 180°、±两侧夹角互等；级次/圈数连续不跳变；波长排序与颜色顺序一致（λ 大角大）。
常见抄错：整度数抄错（本次案例 223°→225°）、级次 k 用错、狭缝像与谱线混淆、黄双线压错条。
思考题多为：衍射/干涉角计算（先由线密度求 d）、调不好会怎样——答给出可观察判据。

## 近代 / 传感器 / 综合设计
核对：先定标拟合再反求未知，标定点是否覆盖待测范围；零点漂移前后复测；控制变量是否真的只变一个。
常见抄错：标定与测量单位不一致、拟合外推过远、把相关当因果。
思考题多为：方案设计与判据——答写自变量、控制量、观测判据、预期图线四要素。
