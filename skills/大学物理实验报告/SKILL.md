# 大学物理实验报告（通用）Skill

## 0. 定位与禁区

- **通用性优先**：教材实验包罗万象——密度/黏度/单摆/杨氏模量/转动惯量/声速/比热比/导热、电桥/电势差计/静电场模拟/示波器、光学干涉衍射分光、近代与综合实验等。每个实验的原理、公式、表格、思考题都不同，**必须现读现推，禁止把示例实验（光栅）的公式、数据结构当模板套用**。
- 示例文件（`examples/示例-光栅测波长-成品.docx`、`scripts/example_grating_calc.py`）只示范“文稿长什么样、核对怎么做”，不是内容模板。
- 不编造未测的数据、不替改已签字的原始数据、不代签姓名学号日期、不覆盖用户已手抄的部分。

## 1. 何时调用

用户意图包括但不限于：“帮我写/续写实验报告”“老师屏幕上是要求”“数据处理怎么做”“算误差/不确定度”“完成表格”“思考题第 X 题”，且提供了（哪怕只提供一部分）实验材料时调用。若用户只问概念、只要某一步计算，则只做那一步，不必强行走完全流程。

## 2. 先盘点：六类输入（缺关键项先问）

| 类别 | 要拿到什么 | 缺失时怎么办 |
|------|------------|--------------|
| ① 老师要求 | 课件/黑板照片、实验讲义任务页：测什么、重复几次、要算什么、指定推导哪个量的误差、思考题题号、要不要作图/拟合 | **最高优先级**。没有就问；教材通用要求只能兜底，不能冒充老师要求 |
| ② 报告进度 | 报告册扫描/照片：哪几节已抄、格式分节、已写仪器/目的 | 已抄的一字不改，在清单里标“跳过” |
| ③ 原始数据 | 原始读数本体 + **每列/每行数字的定义、单位、对应测点**（如哪列是哪个游标、哪行是第几次、哪组是改变了什么量） | 定义不明必须问；只给中间结果的，要原始读数 |
| ④ 仪器规格 | 量程、最小分度、准确度等级、仪器常数（如光栅常数、螺距、砝码等级） | 不确定度要用；不知道就问，不知道分度时写明默认假设 |
| ⑤ 已知常数/标准值 | 标准值、公认值、理论公式出处（老师给的表 > 讲义 > 教材附录） | 算百分误差必需；没有就问或留空标注，不得默默编 |
| ⑥ 成品形式 | 手抄文稿 / 填进 PDF / 对话文字稿；纸质册页码对应 | 默认可手抄的 docx，按册子原分节 |

教材链接/扫描教材的使用：只查本实验的原理、仪器、标准值表那几页；扫描件无文字层时渲染成图看目录定位，不要整卷翻。**要求冲突时顺序：老师课件/当堂交代 > 实验讲义 > 教材。**

## 3. 通用工作流（七步，任何实验都走这七步）

### 第 1 步　定实验与任务清单
读课件照片 + 报告扫描，列两张清单：
- 任务清单：实验名称、要测的直接量、要算的间接量、重复/单次/变参量的安排、要交的表/图、指定误差推导对象、思考题题号；
- 进度清单：已抄节 / 空白节 / 只有题干的节。后续只写空白节。

### 第 2 步　重建原理（现推，不套示例）
用 3~5 行写清：被测量定义 → 核心公式（注明适用条件与符号）→ 直接量如何变成待测量 → 老师指定的计算式（若与教材不同，以老师为准并照抄其形式）。电学类补电路/接线要点，光学类补光路/对准判据，力学热学类补计时/平衡/稳态判据。写进“方法”时压缩为：原理公式 → 调节/组装 → 测量与读数，三段。

### 第 3 步　只信原始数据，独立复算
- 单位先统一，角度/时间/长度等注意进制（1°=60′、1 min=60 s）与仪器读数规则（游标、螺旋测微器、电表读数与估读位）。
- 用户粘贴的聊天记录、同学算稿、AI 旧答案里的中间结果**一律不采信**，只取原始读数重算；正文只呈现规范过程（带绝对值、取正值、进位正确）。
- 每个间接量至少独立算一遍并保留中间量（如差值、乘积、sin 值），便于查错位。

### 第 4 步　冗余核对（通用方法，按本实验物理现选，至少做两项）
这是本 Skill 的核心习惯：**同一个量往往有两条独立来路，先互查再出结果。** 按实验类型选用：
- **对称/互补**：±级、正反面、左右游标、往返测量应互相对应（如双游标差约 180°、两侧夹角都≈2θ）；
- **守恒/闭合**：回路电压和、能量/动量账、桥路平衡条件、干涉级次连续性；
- **单调与量级**：待测量随自变量应单调、图线形状应符合理论（线性/平方/指数），先用标准值反推理论值看量级差多少；
- **重复散布**：重复测量只应有末位小跳动，整数量级/整度数跳变必查；
- **图象自查**：作图后看残差是否随机、截距是否合物理意义、拟合斜率量纲对不对；
- **同伴对比**：同一批多条线/多组数据中，某组百分误差比同伴大一个量级，先怀疑抄错（整度、量程、单位）而非先写误差分析。
发现异常：停、用工具向用户提问，并**把两种可能的结果都算出来给用户看**（“按 A 则结果 X/误差 p%，按 B 则 Y/q%，请对记录本看是 A 还是 B”），附兜底选项“先按原数写并单列提示”。用户确认抄错才改文稿数字；原始记录已签字的，绝不改原始数，只能据实计算并在小结中如实讨论。

### 第 5 步　选数据处理方法（按任务选，不要一律求平均）
| 数据形态 | 方法 |
|----------|------|
| 同一量等精度重复 n 次 | 平均值 + 标准偏差/平均值标准偏差，见 §4 |
| 单次测量 | 直接用读数，不确定度只算 B 类（仪器） |
| 一组 (x,y) 找规律 | 列表 → 作图 → 最小二乘线性拟合（或线性化后拟合），报斜率/截距及其不确定度、相关系数，斜率对应待测量时写清换算 |
| 与标准值比较 | 百分误差 E＝\|测－标\|/标×100%（分母永远是标准值） |
| 多组变参量验证规律 | 逐组算待测量看是否恒定，或拟合看斜率/指数是否合预期 |
工具脚本 `scripts/lab_calc.py` 提供：重复统计、线性拟合、误差传递数值微分、结果格式化、度分秒互换。作图要求：标轴名称+单位、数据点、拟合线、图名；手抄场景给出关键点坐标表以便描图。

### 第 6 步　误差/不确定度（只推老师指定的那个量，但概念要全对）
- **分清两个数**：百分误差（对标准值的偏差）≠ 相对不确定度（由仪器/散布传递）。老师同时要两个时分开算、分开写，并加一句注区分。
- 通用传递：y＝f(x₁,x₂,…) ⇒ 先取对数或全微分得 Δy/y 或 Δy 表达式；乘除→相对量相加，幂→乘指数，三角/对数函数→乘相应导数因子（角度必须弧度）。`lab_calc.py` 的 `propagate()` 可数值验算。
- 合成：A 类（重复散布）与 B 类（仪器分度/等级）方和根合成；用户不懂口径/老师没说时，采用教材常规默认并**在文稿中写明假设**（如“分度取 1′、d 视为准确；若不同只换该项”），不要卡住追问。
- 正确表达：不确定度取 1 位（粗时最多 2 位）有效数字，测量值末位与之对齐，如 (548±1) nm、g＝(9.79±0.03) m/s²，并给相对值。有效数字全程一致：原始读数不添零、中间多留一位、结果按不确定度收尾。

### 第 7 步　成文、交付与 QA
按报告册原有分节续写（通用骨架见 `templates/报告结构模板.md`）：
一目的（已抄不改）→ 二仪器与方法（仪器一行；方法三段）→ 三测量内容及数据处理（原始表 → 一个完整算例，其余同理 → 汇总表/图 → 指定量误差推导与结果表达）→ 四小结（结论 → 逐条对应本实验的误差分析 → 可操作建议）→ 五思考题（只写答：公式→代入→结论，概念题给判据与反例）→ 附原始数据记录表（与正文三处数值一致，供签字，不代签）。
成品默认 docx：开头黄框“抄写说明（不要抄）”写页码对应、核对结论、标准值与假设。交付前过 §5 清单，并清理教材下载、渲染图等中间文件。

## 4. 数据处理速查（配合 scripts/lab_calc.py）

```
平均值        x̄ = Σxi/n
标准偏差      S = √[Σ(xi－x̄)²/(n－1)]；平均值标准偏差 S_x̄ = S/√n（A 类）
B 类          ΔB 取仪器最小分度或准确度等级允差（老师/教材另有规定从其规定）
合成          Δx = √(S_x̄² + ΔB²)（同量纲先统一）
百分误差      E = |x测－x标| / x标 × 100%
传递（示例）  乘除：Δy/y = Σ|Δxi/xi|（或方和根，注明用哪种）；y=xⁿ：Δy/y=|n|Δx/x
线性拟合      y=a+bx：报 b（斜率）、a、r；由斜率求待测量时写换算式与量纲
结果表达      x = (x̄ ± Δx) 单位，E = Δx/x̄ ×100%
```

## 5. 交付前 QA 清单（逐项打勾）

- [ ] 任务清单与老师照片逐项对上（条数、重复次数、思考题号、要推的量没漏）
- [ ] 已抄部分未改动；正文公式与老师课件形式一致
- [ ] 每个结果由原始读数独立复算；单位、进制、进位（如 10°01′60″→10°02′）无误
- [ ] 至少两项冗余核对已做，异常已问用户且留痕；未擅改已签字原始数据
- [ ] 百分误差分母是标准值；平均/拟合/逐组方法的选择与数据形态匹配
- [ ] 不确定度：A/B 来源写明、角度弧度、末位对齐；与百分误差概念分开
- [ ] 图：轴名单位、拟合式、斜率量纲与换算齐全（若要求作图）
- [ ] 正文算例、汇总表、原始附表三处同一数字完全一致
- [ ] 思考题只答所问，计算题给公式与代入，概念题给结论与理由
- [ ] 无代签、无编造数据；假设（分度、标准值来源）已明写

## 6. 按实验大类的特别提醒（现读现用，不要背公式套）

- **力学/热学**：计时类多次重复去异常值、注意零点与有效长度定义；热学注意稳态/平衡判据与散热讨论，温度读数等间隔记录。
- **电学/电磁学**：先画电路图核对量程极性，电表读数按分度与量程换算，桥/补偿类写平衡条件，示波器类写触发与/div 换算；核对闭合回路与量纲。
- **光学**：先调共轴/垂直再测，角度类做双读数与 ± 对称核对，干涉计数防漏圈，谱线对准压中心。
- **近代/传感器/综合**：先校准定标（拟合标定线），再由标定反求未知量；设计类写清自变量控制与判据。
以上只是核对方向，**具体公式、表格列、思考题一律以本次实验的课件与讲义为准**。
