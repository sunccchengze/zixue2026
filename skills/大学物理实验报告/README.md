# 大学物理实验报告 Skill（通用版 v2）

> v2 说明：上一版被指出“只针对光栅一个实验”——已重做。**本版适用于教材里任意实验**（力学、热学、电学、光学、近代与综合实验），光栅测波长只保留为一个成品示例，不再是 Skill 的核心。核心是七步通用流程：定任务 → 现推原理 → 只信原始数据复算 → 冗余核对抓抄错 → 按数据形态选处理方法 → 误差/不确定度 → 按报告册分节成文。

## 包里有什么

```
university-physics-lab-report/
├── SKILL.md                        ← 主文件：给 AI 的通用执行规范（任意实验）
├── README.md                       ← 本文件：给你看的说明
├── templates/
│   ├── 下次提问模板.md              ← 下次任意实验直接填空的给料模板
│   └── 报告结构模板.md              ← 空白报告骨架 + 数据处理工作表
├── scripts/
│   ├── lab_calc.py                  ← 通用计算器：重复统计/线性拟合/误差传递/结果格式化
│   └── example_grating_calc.py      ← 光栅示例脚本（仅示范，勿套用到别的实验）
├── references/
│   ├── 通用数据处理与不确定度.md
│   ├── 按实验类型核对清单.md        ← 力学热学/电学/光学/近代 各自怎么互查
│   ├── 案例复盘-光栅实验仅示例.md   ← 一次完整复盘：如何发现绿光抄错 2°
│   └── 用户指令存档-本次原文拆解.md ← 你这次指令的拆解，下次照此给料
└── examples/
    └── 示例-光栅测波长-成品.docx    ← 成品文稿长什么样（内容仅限该实验）
```

## 以后怎么调用

开新对话时把 `SKILL.md` 给助手（支持 Skill 文件夹的客户端直接导入本文件夹；Arena 里把 SKILL.md 全文贴在第一条即可），然后说：

> 按 university-physics-lab-report Skill 帮我写实验报告。材料按模板给你：……（贴 `templates/下次提问模板.md` 填好的内容 + 照片/扫描/数据）

## 下次给料记住三句话

1. **老师要求拍照片**（测什么、重复几次、思考题第几题，都在老师课件里，不在教材里猜）；
2. **原始数据连“每列是谁、单位是什么”一起给**（这是最容易出错、也最值得花 30 秒自查的地方：对称/闭合/180° 这类冗余关系先自己扫一眼）；
3. **标准值和仪器分度给全**（算百分误差和不确定度就靠它们；不知道分度就写“按教材默认”，别卡住）。

## 通用脚本用法

```bash
python3 scripts/lab_calc.py          # 内置演示：重复测量、线性拟合、误差传递各跑一个例子
```

在自己的数据上用：改脚本底部 `if __name__ == "__main__":` 里的示例数字，或把 `lab_calc.py` 当模块 import（`repeated_stats`、`linear_fit`、`propagate`、`format_result`、`dms_to_deg` 等函数）。光栅脚本同理，但只适用于光栅实验。
