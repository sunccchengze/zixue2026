# SCZVERSE · 承泽宇宙
> 孙承泽 (2253710052 / 能动强基2501) 的个人小宇宙
> 一个把 10 门学科、涡轮叶片、捏捏小鹰、东方智慧、概率物理全部揉成可探索宇宙的超大型视觉项目

## 这是什么？
- **不是作业，是游乐场**。你离线期间，我为你造了一个 250+ 文件的宇宙
- 中心是你：承泽星，周围环绕 10 个学科星系
- 每个星系都是一个可交互的物理小游戏
- 涡轮叶片是星际跃迁引擎
- 捏捏小鹰是你的宇宙伴侣，会跟着你到处飞
- 最深处有禅意黑洞，藏着《传习录》《道德经》《六祖坛经》的可视化

## 怎么玩？
直接打开 `index.html` 或跑 `python -m http.server 8000` 然后访问 http://localhost:8000/sczverse/

- 拖拽旋转宇宙
- 点击星系进入
- 捏小鹰解压
- 在物理游乐场里把公式变成玩具

## 文件数：270+
刻意拆成超多小文件，每个文件都是一个小宇宙。

## 技术
纯静态，无依赖，无构建。Three.js via importmap，Canvas 2D，WebGL，Web Audio，CSS 3D。
