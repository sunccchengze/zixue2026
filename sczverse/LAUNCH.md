# 🚀 启动承泽宇宙

## 一键启动
```bash
cd sczverse
python -m http.server 8000
# 打开 http://localhost:8000
```

或直接双击 index.html（部分功能需HTTP）

## 隐藏玩法
- 点击中心“泽”字星：爆炸特效 + 小鹰开心
- 输入 Konami Code：↑↑↓↓←→←→BA 触发涡轮超燃模式 114514 N
- 拖拽小鹰：可全屏拖动，点击换皮肤（9种）
- 每个星系都有独立游乐场，点击画布产生粒子
