## 一、全书骨架（两大部分）

- **第一部分 如何认识世界**（03–06 章）：预测 → 经验预测的失效 → 模型预测 → 语言与符号世界。

## 二、第一部分核心链条

1. **预测是存活与认知的核心**：情况 = 一件事的前兆 + 后继；现象/对象 = 前兆与后继的统称；经验 = 已经历的情况。
2. **经验预测**：记忆经历过的情况，遇到相同情况时靠回忆预测；但物质世界几乎处处是**未见情况**，经验预测无处发力（宏观现象本身是大脑对微观"处处不同"的预测结果）。
3. **模型预测**：模型 = 脑中的思维单元（概念），作为一群现象的代表间接推演（"心理模型/思维模型"）。两种预测能力来源：经验预测（已见）+ 模型预测（有机会覆盖未见）。
4. **模型的两种能力**：
   - **压缩能力**：把满足同一共性的众多经验概括进一个模型，节省存储；
   - **泛化能力**：预测未见情况的能力——**学习的真正目标**。泛化不足 = 模型只适用于已见。
5. **非永生 → 语言**：语言 = 代理其他概念的符号及其组织规则构成的系统；四个子类：自然语言、数学语言、编程语言、图形语言。三个世界：现象世界 / 符号世界（语言世界）/ 含义世界（意义世界）。用语言材料学习比用现象材料多出一个**语义理解**环节；很多人"不擅长学习"，实质是不擅长**用语言材料学习**。

## 三、第二部分核心链条

1. **思考 = 信息推测**：从一堆信息加工得到另一堆信息（打车算总价、打球推测神经信号）；任何复杂思维都可拆解为若干**基础信息推测**的组合；分**经验推测**与**模型推测**（是否动用可泛化模型处理未见信息）。
2. **学习与记忆是两种独立行为**（病人 HM、Jim Pike 等证据）：
   - 验证**记住**：能否重现已见情况；
   - 验证**学会**：能否泛化未见情况。
   - 用"是否记住"验证"是否学会"会产生两类错判：学会以为没学会 / 没学会以为学会。
   - "学会做人"≠"记住做人"：学习要求**超越被嘱咐的行为**。
3. **学习的两个等价定义**：
   - 一般定义：塑造推测未见情况的能力（明确目标）；
   - 标准定义：**渐构可泛化模型的行为**（明确手段）；警惕把手段当目的。
4. **材料分层**：
   - **下层材料（下料）**：展现"输入常量 → 输出常量"对应关系的材料；即数据/样本/经验/例子/示范（指代差别：数据=尚未明确推测任务；经验=已明确任务但未必体现规律；例子=体现某规律的具体推测过程）；
   - **上层材料（上料）**：展现"输入空间 → 输出空间"映射规律的材料；只出现在继承学习中；
   - **材料 ≠ 知识**：材料扁平碎片（食材），知识立体结构化（菜肴）；记住材料 ≠ 学会知识。
5. **下料用法四行为"抽编寻归"**：
   - **抽象**：比较多个具体现象，剔除差异属性、提取共有属性，渐构判别模型；
   - **编码**：用判别模型把具体现象归类到概念，并以概念代替原现象；
   - **寻因**：寻找可由一方推测另一方的输入、输出因素；
   - **归纳**：从多组输入-输出对应关系中找到共有映射关系。
   - 注意：抽象/编码常需多次；脑中已有判别模型时可跳过抽象直接编码；归纳出规律后还需与判别模型连接下上两层。
6. **上料用法**：依靠语言；语料 = 包含待学词的语言用法材料（本质是对规律的间接抽象描述，属上料/规述的一种）；**词络约束**：从词语之间的关系网络中约束出概念属性（孩子从"快去学习别玩了"等话语中渐构"学习"概念）；**家长是第一任老师**：日常语料无声传递家长的世界模型与价值模型；**自上学习（用语言学习）非先天**，需后天训练，是人类独有的学习方式。

| 三个世界 | 现象世界 / 符号世界 / 含义世界 |
| 学习（一般定义） | 塑造推测未见情况的能力 |
| 学习（标准定义） | 渐构可泛化模型的行为 |
| 记忆 vs 学习验证 | 重现已见 / 泛化未见 |
| 下料 / 上料 | 输入-输出对应关系 / 输入空间-输出空间映射规律 |

## 六、与本仓库方法论的对接与落地动作

- 与 `skills/科研式学习导师/SKILL.md` 的命题/判卷纪律同构：**"会不会"的唯一验证 = 未见变式能否做对**；一切"看懂了/记住了"都不算学会。
- 落地动作：
  1. 每完成一个课题/章节练习，自编或自找 2-3 道**未见变式题**做泛化自测，结果记入对应 memory；
  2. 错题本按"抽编寻归"流程整理：提取共性（抽象）→ 题型归类（编码）→ 找因果因素（寻因）→ 归纳可迁移规律（归纳），而非抄答案；
  3. 读教材/PPT（语言材料）时警惕"语义理解错觉"：能复述 ≠ 有模型；用完语言材料必须落回下料（例题/实验/真题）验证；
  4. 善用数学语言与图形语言改写模糊的自然语言表述（本书列为四类语言中最精确的两种），与仓库"图卡"实践一致。
