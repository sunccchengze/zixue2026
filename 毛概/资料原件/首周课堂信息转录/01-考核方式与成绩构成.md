# 考核方式：注重过程性考核

> 2026-09-17 首次课投影转录（IMG_20260917_172246）

## 期末成绩构成

| 成绩构成 | 具体考核 | 所占比例 | 备注 |
|---|---|---|---|
| **期末考试** | 闭卷考试，统一安排 | **50%** | 题型：单选、多选、简述、政论文写作等 |
| **平时成绩（50%）** | 小组讨论 | **15%** | 根据选题分组展示与讨论（15–16 周） |
| | 期末作业 | **10%** | 二选一，后面详述 |
| | 慕课成绩 | **5%** | 在线观看慕课（具体网址后续通知） |
| | 综合表现 | **15%** | 考勤、互动等课堂表现 |
| | 课前展示 | **5%** | 红色名言名句我来讲 |

## 要点速读

- 平时分 = 15+10+5+15+5 = **50%**，与期末卷面对半开——过程性考核权重很大
- **综合表现（15%）= 平时表现**：含"线下不定期点名 **3 次**，旷课相应扣分"（详见 06）——不是天天点，但不能有被抓到的缺勤
- **课前展示（5%）"红色名言名句我来讲"**：3–4 人一组 5 分钟、每次课前 2 组，名言附件后续发课程群自选 1 句（详见 06）
- **慕课（5%）**：**中国大学MOOC，2–14 周**，观看完成度 75% 以上即满分（详见 05）
- 期末题型明确含**政论文写作**——读书报告与小组讨论的选题可以直接服务这道大题的素材积累
