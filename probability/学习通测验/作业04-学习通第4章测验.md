## 一、判断题（1–3 题，对 / 错）

**1.** 设随机变量 X 与 Y 的相关系数 ρ=0，则 X 与 Y 相互独立。

**2.** 设随机变量 X 与 Y 相互独立，则 Cov(X,Y)=0；反之，若 Cov(X,Y)=0，则 X 与 Y 相互独立。

**3.** 设随机变量 X 与 Y 满足 E(XY)=E(X)E(Y)，则 X 与 Y 相互独立。

## 二、填空题（4–9 题，用小数或最简分数作答）

**4.** 设 X₁, X₂, ⋯, X₁₀ 独立同分布，密度均为 f(x)=2x（0<x<1）。令 Y=max{X₁, X₂, ⋯, X₁₀}，则 E(Y)=____。（用最简分数作答，如 1/3）

**5.** 设随机变量 X 服从区间 (a,3) 上的均匀分布，且 E(X)=2，则 D(X)=____。（用最简分数作答）

**6.** 设 D(X)=4，D(Y)=2，X 与 Y 相互独立，则 D(3X−2Y)=____。

**7.** 设 D(X)=1，D(Y)=1/4，X 与 Y 的相关系数 ρ=1/3，则 D(X−3Y)=____。（用最简分数作答）

**8.** 设 (X,Y) 的概率密度为 f(x,y)=3x（0<x<1，−x<y<0），则 E(Y)=____。（用最简分数作答）

**9.** 设随机变量 X 的分布列为 P{X=k}=(k+1)/10（k=0,1,2,3），则 E(X)=____。（用小数作答）
