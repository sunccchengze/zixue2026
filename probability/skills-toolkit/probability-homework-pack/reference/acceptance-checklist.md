# 概率论作业包交付门禁

## A. 题面真实性（硬门禁）

- [ ] 教材、版次、章、习题编号已确认
- [ ] 指定题号集合完整，无偶数/奇数或A/B部分遗漏
- [ ] 每题已与放大原页逐字符比对
- [ ] 补集范围、上下标、分式、条件线、括号无歧义
- [ ] 跨页续题和图表已纳入

## B. 解析正确性（硬门禁）

- [ ] 每题有主解法
- [ ] 每题有独立校验路径
- [ ] 样本空间题已检查遗漏、重复和停止条件
- [ ] 组合题已检查分母、分类互斥与覆盖完整
- [ ] 几何概型已分别核对直接区域和补集区域
- [ ] 条件概率题已核对联合、边缘和条件方向
- [ ] 独立性题未混淆互斥
- [ ] 证明题的定义、关键展开和结论完整
- [ ] 精确分数已约分，数量级合理

## C. 教学质量

- [ ] 优先使用最简方法
- [ ] 新概念在首次使用前有一句解释或最小示例
- [ ] 没有“显然”“同理”掩盖关键步骤
- [ ] 补事件关系明确写出
- [ ] 最终答案醒目且与推导一致

## D. 试卷版式（硬门禁）

- [ ] A4尺寸
- [ ] 页数严格满足要求
- [ ] 题号、题面无截断或溢出
- [ ] 答题空间与题目工作量相称
- [ ] 标题与学生信息正确
- [ ] 无教材水印、二维码、扫描背景
- [ ] 必要图形清楚

## E. PDF技术验收（硬门禁）

- [ ] PDF可正常打开
- [ ] 无空白页
- [ ] 文本提取能找到全部题号
- [ ] 关键公式文本提取无整段缺失
- [ ] 每页已渲染为图片并目检
- [ ] 上下标、补集、空集、全集、幂和减号正常显示
- [ ] 长公式换行不破坏含义
- [ ] 修改后已重新构建所有关联PDF
- [ ] 查看器已重新打开最新文件，排除缓存

## F. 交付纪律

- [ ] 用户只看到要求的成品，不被内部日志干扰
- [ ] 构建脚本可重复运行
- [ ] 内部校验脚本通过
- [ ] PROGRESS/HANDOFF已更新
- [ ] Git状态和diff已检查
- [ ] 已提交并推送当前会话分支
