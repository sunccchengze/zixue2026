# 课题 03 · 为什么要发明"随机变量"这种东西？ · 研究报告

> 作者：自学生 · 2026-08-16 · 导师批注版（批注见文末）

---

## 1. 我研究的问题

**概率的两种全景图：分布列和累积分布函数——随机变量凭什么把一堆事件打包成一个数，又把一个数展开成一张概率表。**

---

## 2. 我的核心思路

我的起点很朴素：**数字能算，集合不能算**。

课题01、02 里我一直在数事件：硬币、门、阳性——事件之间只有并、交、补三种操作。
但我真正想做的，是对"正面次数"做算术。所以我把每次试验的结果 ω（一个 10 位序列）
装进一个函数 X(ω)，让它吐出数字。从此，1024 个序列不再是 1024 行档案，
而是一张只有 11 行的表——每个可能值 k 配一个概率 P(X=k)。**损失细节，换取可操作性。**

这个跃迁当时挨过一棒：我开题时说"Ω = ω ∈ 0~10"，把桥这头（样本空间）和桥那头
（值域）焊在了一起。后来才拆清：ω 是序列，X(ω) 是数，X 是中间那座桥。

---

## 3. 我的结论

### 三件套：同一条跃迁的三面

**（一）X 是桥，发明它有三个理由**

```
Ω:  HTHH...T   →X→   7        （1024个序列 → 11个数）
    TTTH...H   →X→   3
```

1. **数能算**：数字支持加减乘除、求和、平均——后面所有课题的期望、方差、分布全靠这一跃；
2. **压缩细节**：1024 行档案压成一个数，留下真正关心的信息；
3. **打包一族事件**：{X=3} 不是单个序列，是 120 个序列的**并集**——
   随机变量用"一个数 + 一张表"管理整族事件。

**（二）分布列——概率的第一种全景图**

| k | 0 | 1 | 2 | 3 | … | 10 |
|---|---|---|---|---|---|---|
| P(X=k) | C(10,0)/1024 | C(10,1)/1024 | C(10,2)/1024 | C(10,3)/1024 | … | C(10,10)/1024 |

- 每一行 = 原像的总概率（公理三：互斥序列的概率相加）；
- 11 行概率之和 = 1 —— 公理二兜底：{X=k} 一族事件把 Ω 分割干净了；
- 对称性发现：P(X≥7) = P(X≤3)，因为 C(10,7) = C(10,3)，"至少 7 正"与"至多 3 正"互为镜像。

**（三）累积分布函数——概率的第二种全景图**

F(k) = P(X ≤ k)，好处：
- 累积：F(6) = 前 7 项之和；
- 区间：P(3 < X ≤ 7) = F(7) − F(3)；
- 尾部：P(X ≥ 7) = F(10) − F(6) = 1 − F(6) = 176/1024。

### 实验证据（数字）

- C(10,3) = 120：恰好 3 正面的序列数；
- X ≥ 7：120+45+10+1 = 176 个序列；
- P(X ≥ 7) = 176/1024 = 11/64 ≈ 17.2%；
- P(X≥7) = P(X≤3) 的镜像对称。

## 4. 我还存疑的地方

1. **0/0 的裂缝**："已知恰好落在 0.5"——概率是精确的 0，条件概率 = 0/0，
   在初等框架里**无定义**。直观上这句话明明有意义，数学却接不住。听说连续世界的补救
   （条件密度、正则条件分布）是高等概率论的核心工程——它们到底怎么补的？
2. **压缩会不会丢信息**：X 把 1024 行档案压成 11 个数。假如我关心的东西不在 X 里
   （比如"正反面交替次数"），压缩就丢了我需要的东西。怎么知道该选哪个 X？
3. **概率怎么过的桥**：值域比 Ω 好用，但值域上的概率凭什么"继承"Ω 的概率？
   这座桥保证不乱套，靠的到底是什么？

## 导师审稿意见（2026-08-16）

**① 柯尔莫哥洛夫（下次必考，唯一实质性修改）**：你的第二个存疑其实已经有一半答案——
X 是我们**主动选的**：先问"我要研究什么量"，再定义 X。任何"Ω 上可测量的函数"都能当
随机变量；你的交替次数完全可以自己定义一个 Y。选 X 是建模自由，不是限制。
但"哪些函数合法"（可测性）要到课题18 才能正面回答——现在记住这句：
**先有量，后有桥。**

**② 费勒（要你记住，不用改）**：你的第三个存疑问的是"概率怎么过的桥"。
反过来说更锋利：X 的分布列之所以总和 = 1，是因为 {X=k} 一族事件把 Ω **分割**了
（互斥 + 并成全集）——公理二、公理三早就把桥的承重算好了。你不是在桥上赌，你是在
用公理搬砖。

**③ 杰恩斯（预告，不追究）**：你第一节说的"两种全景图"，我会换成我的说法：
分布列是**微观账本**（逐点），F 是**宏观累计**（从小到大）。真正的对决在课题04——
连续变量没有分布列（每个点概率都是 0，你在课题01 亲手算过），那时 F 从"备胎"变"正主"。
这个悬念，下一课见。
