# 课题 01 · 概率到底是什么？怎么严谨地定义？ · 研究报告

> 作者：自学生 · 2026-08-16 · 导师批注版（批注见文末）

---

## 1. 我研究的问题

**给"不确定"一个可靠的数字描述：找出一套规则（公理），让掷硬币、布丰投针、连续取点
这三种完全不同的随机场景，能在同一套规则下自洽地算出概率，而且永远不打架。**

---

## 2. 我的核心思路

我的起点是两个混在一起的直觉："只有两种情况，所以各占一半"；"扔非常多硬币，
比例会是 1:1"。这条路我只走了一小段就被自己打脸——**错误直觉不是我的敌人，
它是我的向导。每一站挨一次打，规则就清楚一层。**

- **第①站 · 频率直觉**：发现"接近"这个词藏了两层。绝对差距的典型大小按 √n 增长
  （总次数 ×100，差距只 ×10）；频率的相对偏差按 1/√n 收缩。大数定律的精确说法是：
  **不管界限定多小，"偏差超过它"的概率都趋近 0**——趋近 0 的是概率，不是偏差本身。
- **第②站 · 对称直觉的葬礼**：布丰投针。针只有"压线/不压线"两种情况，
  我按自己的规则预测概率 1/2。**100 万次模拟：0.3186；理论值 1/π ≈ 0.3183**。
  两种情况不假，但情况之间**不等重**——数个数失效了，得用长度来量。
  我重构了解法：固定夹角 θ，压线的 y 范围宽 (d/2)·sinθ；再对 θ 平均，
  sinθ 在 [0,π] 的拱面积是 2，底宽是 π，平均 2/π；乘 1/2，得 **P = 1/π**。
- **第③站 · 连续取点撞出的裂缝**：单点概率是 0（n 个点若每个概率 ≥ ε，加起来就 ≥ nε，
  会爆过 1）；但 [0,1] 由**不可数**无穷多个单点拼成，"把所有单点概率加起来"这个操作
  **不合法**——加法规则只管**可数**多个事件。同时我意识到：
  **概率为 0 的事件，未必不可能发生。**
- **第④站 · 自己立规矩**：把前三站撞出来的坑，写成三条公理。

**实验证据（附录于结论）**：布丰 Monte Carlo 100 万次 = 0.3186 vs 1/π ≈ 0.3183；
√n 两轨推演：10⁸ 次典型差 √(10⁸)/2 = 5000，10¹⁰ 次为 50000——总次数 ×100，差距只 ×10。

---

## 3. 我的结论

### 我自己立的公理（与柯尔莫哥洛夫 1933 年公理一致，包括"可数"这个限定）

1. **非负性**：P(A) ≥ 0。概率是份额，份额不该是负的。
2. **归一性**：P(Ω) = 1。先确定研究对象的整体；全体就是必然发生的事，归为 1。
3. **可加性**：若 A、B 互斥，则 P(A) + P(B) = P(A∪B)。更准确地说，相加只认可数多个：
   有限个可以加，可数无穷个也可以加（½ + ¼ + ⅛ + … = 1），**不可数无穷个不能加**——
   "逐点求和"这个操作不存在。

### 我证明的三个小定理

- **0 ≤ P(A) ≤ 1**：由 A ∪ Ā = Ω 且互斥，1 = P(Ω) = P(A) + P(Ā)（公理2+公理3），
  又 P(Ā) ≥ 0（公理1），故 P(A) ≤ 1；下界直接来自公理1。∎
- **P(∅) = 0**：Ω = Ω ∪ ∅ 且互斥，1 = P(Ω) = P(Ω) + P(∅) = 1 + P(∅)，故 P(∅) = 0。∎
- **P(A) + P(Ā) = 1**：A 与 Ā 互斥且并为 Ω，直接由公理2、3 得。∎

### 我认领的隐藏假设（每个模型都背着包袱，我不装看不见）

1. 抛硬币时硬币可能立起来、滚走——**"只算正反两种结果"是人为约定**，不是自然规律；
2. 布丰投针里"角度和位置均匀分布"是假设——真拿一根针去扔，未必服从；
3. "在 [0,1] 上每处等可能地取一个点"——物理上根本做不到无限精度，这是数学的理想化。

## 4. 我还存疑的地方

1. **"概率为 0 但可能发生"**：0 是数，不是过程。可这个 0 真的抓得住"可能性"吗？
2. **频率 vs 信念**：只发生一次的事（"明天下雨概率 70%"），我的频率直觉完全用不上。
   概率到底是世界的属性，还是认知的状态？
3. **可数可加性**：为什么偏偏是"可数"，不是"有限"也不是"任意多"？
   这是我撞坑撞出来的规则，但我还不知道它到底有多重。
