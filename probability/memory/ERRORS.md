# ERRORS · 判例库（红线禁区）

> 记录用户在学习中反复出现的典型误区，转成"判例"，之后审稿/提问必须先查这里，
> 同一个坑不能让用户第二次义正词严地掉进去而不被提前预警。

## 通用红线（导师自身纪律，非用户错误）
- 绝不直接给定理证明——只给线索/反例/追问，不给答案。
- 报告必须有"我还存疑的地方"，缺这条视为不完整。
- **批量提问**（2026-08-16 用户指令覆盖旧铁律）：每条消息给 3~5 个编号问题，不零碎一问一答；
  仅当用户卡壳/答错时，临时退回"一次一问+提示阶梯"。
- 说"完全可能"之前先算σ：√n量级才叫典型波动；10σ量级（概率约10⁻²³）必须说"几乎不可能"。
  判例：2026-08-16 曾把"抛10¹⁰次、正面偏差50万次"（=10σ，σ=5万）说成"完全可能发生"，后更正。

## 用户判例
- **判例①（2026-08-16）验证公理凭感觉不动手**：检验"P′(A)=P(A)² 是否满足公理"时，
  说"平方后可能不是1，公理二翻车"——没有实算。P(Ω)=1→P′(Ω)=1²=1，公理二没翻；
  真正翻的是公理三（互斥事件：¼+¼≠1）。**红线**：以后任何"验证是否满足公理/性质"的题，
  必须先带具体数字算，算完再下结论。
- **判例②（2026-08-16）把积分当成可数求和**：说过"积分就是可数的无穷多段"。
  积分=有限段求和→细分→取极限，是独立于"可数级数求和"的第四种操作。
  **红线**：遇到"无穷求和"先分档——有限/可数/不可数/积分，四者不同。
