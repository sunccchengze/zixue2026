阿姨带小麦克 · B7 整页重写 · 一道看符号抵消

XY 的依赖藏在 xy 的符号里，平方把符号抹掉就独立了

正方形上 f=(1/4)(1+xy)。边缘都是 1/2，看似像两个均匀独立的分布，但乘积 1/4 丢了 +xy。平方后四个象限对折，+ 与 − 抵消，交叉项消失。

这一页的词

  • 边缘均匀：fX=1/2（|x|≤1），fY=1/2。只看一边，都是均匀。
  • 不独立：fX·fY=1/4 ≠ (1/4)(1+xy)=f。少了那一坨 xy。
  • 变换四个原像：U=X²，V=Y²。0<u,v<1 时有 (±√u, ±√v) 四个点，雅可比 |J|=1/(4√(uv))。

1. 边缘是均匀，但乘积对不上

固定 x，y 从 −1 到 1：

fX(x)=∫−11 (1/4)(1+xy) dy = (1/4)[ y + x·y²/2 ]−11

= (1/4)[ (1 + x/2) − (−1 + x/2) ] = (1/4)·2 = 1/2，　|x|≤1

xy 那一项对 y 是奇函数，积为 0。同理 fY=1/2。

乘积 fXfY=1/4，而 f=(1/4)(1+xy)。两者不等。例如 (1,1) 处 f=1/2，乘积 1/4。

故 X,Y 不独立。

左：(X,Y) 按 xy 上色，一三象限暖、二四象限冷，说明依赖的符号。
右：(U,V)=(X²,Y²) 之后四个象限叠在一起，颜色对消。

2. 平方之后为什么独立

令 U=X²，V=Y²，0<u,v<1。固定 (u,v)，原像四个：

(x,y) = (±√u, ±√v)

每个的雅可比：dx dy = |J| du dv，|J|=1/(4√(uv))。这四个点上 f 依次是

(1/4)(1 ± √(uv))，符号两正两负

xy = (±√u)(±√v) = ±√(uv)，四点之和：(1+√)+(1−√)+(1−√)+(1+√)=4，交叉项抵消。

所以

fU,V(u,v)= 4 · (1/4) · (1/(4√(uv))) = 1/(4√(uv))

单维：U=X² 的密度 fU(u)=1/(2√u)（可由 X 的均匀导出：FU(u)=P(|X|≤√u)=√u，所以 f=1/(2√u)）。同理 fV=1/(2√v)。

fU,V = (1/(2√u))(1/(2√v)) = fU fV

故 X² 与 Y² 相互独立。

带走

  1. 边缘均匀 ≠ 独立（差 xy）。
  2. 平方后四个原像，+ 与 − 抵消。
  3. X,Y 不独立；X²,Y² 独立。
