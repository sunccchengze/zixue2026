# ERRORS · 判例库（红线禁区）

> 记录用户在学习中反复出现的典型误区，转成"判例"，之后审稿/提问必须先查这里，
> 同一个坑不能让用户第二次义正词严地掉进去而不被提前预警。

## 通用红线（导师自身纪律，非用户错误）

- 绝不直接给定理证明——只给线索/反例/追问，不给答案。
- 报告必须有"我还存疑的地方"，缺这条视为不完整。
- **批量提问**（用户指令）：每条消息给 3~5 个编号问题，不零碎一问一答；
  仅当用户卡壳/答错时，临时退回"一次一问+提示阶梯"。
- 数学图表用生图模型生成 PNG，禁用 ASCII 图；重要公式出"手写体课堂笔记风"公式卡。
- 导师自己出错必须当场认领并写入本判例库（示范作用，用户会模仿这个诚实）。
- **作业流程红线（2026-09-20，导师自错，用户当场点名"别胡闹了"）**：用户上传作业截图后，正确动作是"题面定位誊录 + 完整参考答案"一步归档；当回合却先抛了 3 个互动问题，被用户纠正："看到我上传了作业，就开始给我生成答案，不是让你问我问题"。**规则**：作业语境 ≠ 课题攻关语境——提问属后者，作业流程直接出答案。已固化进仓库根 `AGENTS.md`《学校作业处理流程》（全学科）。
- **辐角记号判例（2026-09-14，导师自错，用户当场纠正）**：王绵森《复变函数》约定
  **Arg z = 辐角（多值，Arg z = θ₁ + 2kπ）；arg z = 辐角主值（−π < arg z ≤ π）**，见课本 P7 式(1.1.4)。
  当回合详解把 1(2)、1(4) 的主值误记成 Arg、把记号用反，已当场认领并改写。
  此后本学科一切解答/判卷涉及辐角记号先查本条，不许凭"别的书习惯"印象下笔。
- 概率量级判断纪律（迁自概率论项目）：说"完全可能"之前先算σ；√n 量级才叫典型波动。
- 报告写完照写审稿意见（3-5条：必考项/要记住/预告项），但**不等用户审阅**，标✅开下一课题。


## 全学科通用判例（继承段 · 源自大学化学 2026-09-05 判例⑬–⑯，学科中性版）

> 细则见 `skills/科研式学习导师/SKILL.md` §5a"命题与判卷纪律"；原始判例全文在
> `大学化学/memory/ERRORS.md`。以下四条对**本学科同样具有约束力**：

- **通用判例⑬（题干不得含答案）**：出题/提问时，题干只给条件与待求，
  不得写进结论、公式名、示例形状——否则该题作废重出。
- **通用判例⑭（旁白不算错）**：用户的思考旁白、括号吐槽、手滑联想不构成答案；
  判卷只看其最终结论与论证。
- **通用判例⑮（字符级核对）**：指数、上下标、角标、正负号必须逐字符放大核对再判；
  看不准就明说"这一处我不确定"并定点确认，不许凭印象误判。
- **通用判例⑯（收口要有证据）**：禁止用少量基础题"检测/安慰"；掌握 = 当次对 +
  隔 1~3 天无提示再对 + 能讲清；课题/阶段收口的最低门槛为真题级综合卷（C 档）
  正确率 ≥70%，且同点错 ≥3 次升级为 leech 换角度重教。发现题目过易，主动自首重出。
