## 一、核心直觉池（解析性/共形直觉）
- **复数乘法 = 缩放+旋转**：模相乘、辐角相加，$|zw|=|z||w|$，$\Arg(zw)=\Arg z+\Arg w$（De Moivre 高次幂秒算基础）
- **单连通 = 无洞**：环形 $1<|z|<3$ 多连通，切掉一条缝或限制幅角 $<2\pi$ 后变单连通（橡皮筋可缩）；与有界/无界独立
- **含共轭的极限**：$\bar z$ 连续但不解析，$z\bar z+...$ 型可因式分解 $(z-1)(\bar z+2)$ 后看连续性，不能一见 $\bar z$ 就判不存在
- **$n$次根通式**：$\sqrt[n]{re^{i\theta}}=\sqrt[n]{r}e^{i(\theta+2k\pi)/n}$，幅角 $\theta/n+k2\pi/n$，$n$个等分圆
