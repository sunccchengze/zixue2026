## 一、我们怎么一起工作（约定）

每个课题（研究项目）都包含五件东西：

1. **研究背景** —— 这个问题从哪来？谁在历史上真的卡在这里过？
2. **研究问题** —— 一个开放的、值得写的科学问题（不是一道填空题）。
3. **攻关线索** —— 我给你的引导性提问，是"路标"，不是"答案"。
4. **里程碑** —— 你要交出来的中间产出，我来检查。
5. **研究报告** —— 每个课题最终要写成一页"论文"，这是你的交付物。

**关卡规则**：我会在你的报告里挑毛病（找反例、追边界），但**绝不直接给定理证明**——
除非你已经卡死，那时候我给"线索"，而不是"答案"。你写、你证、你被我问倒，然后你再站起。

> 你已在概率论项目跑通本套方法论（18课题地图），本学科沿用同一章程：
> 批量提问、里程碑五项验收、一页报告四段结构、大师天团过审。详见 `科研式学习方法论.md`。

## 二、全程课题地图（14课题 · 六阶段）

### 阶段一 · 地基 —— 让"虚"变成可计算的数

- **课题 01**　复数与复平面：i²=−1 到底"存在"吗？模、辐角、共轭、加减乘除在几何上是什么？
- **课题 02**　解析函数与柯西-黎曼方程：凭什么一个复函数可以"求导"？C-R 方程是解析性的试金石。
- **课题 03**　初等解析函数：指数 / 三角 / 对数 / 幂函数；欧拉公式 e^{iθ}=cosθ+isinθ（指数与三角的桥梁）；
  第一次撞见**多值函数**（对数、根式——为黎曼面和留数埋线）。

### 阶段二 · 复积分四大定理（全课心脏 🔴 最高优先级）

> 你亲自认可的速成战略（`三小时搞定.md`）：四大定理——柯西积分定理、柯西积分公式、
> 高阶导数公式、留数定理——本质是**同一个思想**的四个版本。这一阶段只打前两个。

- **课题 04**　复积分与柯西-古萨定理：沿闭曲线一圈，积分为 0——为什么？路径无关性从哪来？
- **课题 05**　柯西积分公式与高阶导数公式：解析函数在内部任一点的值，**完全由边界上的值决定**；
  更惊人的推论：解析一次可导 ⟹ 任意阶可导（实数世界里没有这种事）。

### 阶段三 · 级数

- **课题 06**　泰勒级数：解析函数 = 幂级数；展开半径从哪来？
- **课题 07**　洛朗级数与孤立奇点：泰勒只管"好点"，洛朗连"坏点"都能展开（负幂项！）；
  奇点三分类：可去 / 极点 / 本性。

### 阶段四 · 留数（四大定理收官）

- **课题 08**　留数定理：留数 = 洛朗级数的 a₋₁ 系数；∮f(z)dz = 2πi·Σ留数。
  一个闭路积分，退化成**挑系数**的代数活。
- **课题 09**　留数计算实积分：∫ 有理三角式、∫_{-∞}^{+∞} 有理函数、约当引理等**四大引理**；
  配套《非数同学必须会的特殊积分》：欧拉积分 Γ 函数 / B 函数 + 围道积分法全套路。

### 阶段五 · 积分变换

> 换个视角看函数：不在"时间轴"上解方程，而在"频率轴 / 复频率轴"上解。

- **课题 11**　傅里叶变换：F(ω)=∫f(t)e^{−iωt}dt；谱、卷积、位移/调制/对称性（作业册第 7 章）。
- **课题 12**　拉普拉斯变换：F(s)=∫f(t)e^{−st}dt；微分⟼乘 s、积分⟼除 s、卷积⟼乘积（作业册第 8 章）。
- **课题 13**　变换解微分方程：微分方程 ⟼ 代数方程 ⟼ 反演。初值条件自动入账；
  方程组、延迟、周期函数、变系数全题型（作业册 8.12–8.16）。

### 阶段六 · 选修与收官

- **课题 10**　共形映射（**选修**）：保角变换、分式线性映射、黎曼映射定理概览；
  工程应用：流体、电磁场。时间紧可整课跳过，不影响主线。
- **课题 14**　真题综合（收官总攻）：四大定理 + 积分变换串联；《特殊积分》第三部分方法集
  （泊松积分、Dirichlet 积分十法、椭圆积分、含参变量积分）作为总攻弹药库。

## 三、里程碑验收标准（我拿什么衡量你"掌握了"）

对每个课题，能交齐下面这几样，就算"攻克"：

- [ ] **解释**：不用数学符号，也能把一个概念讲给我听懂（费曼式）。
- [ ] **推导**：核心定理你能独立证明，或至少完整走一遍关键步骤。
- [ ] **反例**：你能造出一个"边界情形"，说明某个想当然的说法是错的
      （比如：一个处处连续却处处不可导的复函数；有界闭集上不连续的"解析"？不存在的）。
- [ ] **联系**：你能说出这个课题跟前面/后面哪个课题是"同一个问题换了个说法"。
- [ ] **论文**：一页研究报告，结构：问题 → 我的思路 → 结论 → 我还存疑的地方。

## 四、学习节奏建议

科研不是赶进度。建议**每周 1~2 个课题**（复变公认是数学四大科里最容易"速通"的一门——
你自备的《三小时搞定》把核心压到三块：积分与留数 100min / 解析判定 40min / 级数展开 40min，
本路线图完全继承这个重心：**阶段二/三/四是绝对主线**）。

每个课题结束交一页报告，我写"审稿意见"。**按你的指令：报告照写归档，不逐篇审阅，
全部课题结束后统一回顾。**

## 五、跨学科钩子（来自总调度表，攻关时我会主动提）

- **↔ 概率论**：特征函数 φ(t)=E[e^{itX}] 就是欧拉公式 e^{iθ} 在概率里的化身（你已在概率课题08见过）。
- **↔ 数理方程**：傅里叶/拉普拉斯变换解 PDE 是数理方程的"积分变换法"——复变教变换本体，
  数理方程教变换的应用，两边 Agent 已对齐口径，不会重复灌。
- **↔ 大学物理**：复数是交流电路/波动分析的母语（相量 = 复平面上的旋转箭头），大物里会重逢。
