## 读这些记录的三条提醒

1. **台账≠验收**。"解析成功""字节一致""测试通过"都不等于内容在学术上正确、排版无误或已逐页语义精读。各批次 README 均已自陈边界，勿断章取用。
2. **历史不会被当前树修改消除**。已跟踪文件被删除或脱敏，只影响当前树；旧提交、旧克隆与 GitHub 历史仍可取回。凡涉及凭据泄露、版权授权、仓库可见性，均需仓库所有者另行处置。
3. **分支处置有门禁**。删除任何远端分支前必须：内容已归并进已推送提交 → 该分支 tip 是 HEAD 祖先 → 再次向 GitHub 核对 tip 未变化 → 才通过 refs 接口删除。不强推、不新建/合并/关闭 PR。
