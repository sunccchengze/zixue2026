## 第 12 次　机械波

**本次考点：**波动方程 · 干涉 · 驻波 · 多普勒

### 一、机械波的描述与“读参数”（本单元第一考点）

**1. 波函数到底在描述什么？**

先把一根长绳想成一串用弹簧连着的小珠子。你握住左端上下抖一下，这个“上”的动作会沿着绳子**一个传一个**地向右走，但每个小珠子本身只在原地上下动，并不向右跑。

波函数 y(x, t) 就是说这句话：**站在位置 x 的那个质元，在时刻 t 偏离平衡位置多远**。它有两个自变量：x（在哪儿）和 t（什么时候）。

> **【结论要点】** 波传走的是“振动状态”（相位）和能量，不是介质本身。质元只在原地振动，向前跑的是波形。

**2. 标准式，逐个字母认一遍**

> **y(x, t) = A·cos[ω(t − x/u) + φ₀] = A·cos(ωt − kx + φ₀)**

- **A 振幅**：质元离平衡位置的最大距离。
- **ω 角频率** = 2π/T = 2πf：相位每秒转过多少弧度，反映“抖得多快”。
- **k 波数** = 2π/λ：每前进 1 m 相位变多少弧度，反映“波挤得多密”。
- **u 波速** = ω/k = λ/T：波形（等相位面）平移的速度，**由介质决定**（绳子的张力和线密度、空气的温度等），与振幅、频率无关。
- **φ₀ 初相**：t = 0、x = 0 处质元的相位，决定“从哪儿开始抖”。

**3. 三个“速度”千万别混**

- **波速 u**：波形跑多快，由介质定，λ/T。
- **质元振动速度 v = ∂y/∂t**：质元自己上下动多快，最大值 Aω。
- **相速度**：等相位面走多快，简谐波里就是 u。

> **v_max / u = Aω / u = 2πA / λ**

这个比值完全可以大于 1，也可以小于 1，一点也不矛盾——它们根本不是同一个东西在比。考试就爱在这个地方设陷阱。

**4. 怎么判断传播方向**

盯住括号里的组合。沿 +x 传播时，等相位面满足 ωt − kx = 常数，解出 x = (ω/k)t + 常数，t 增大时 x 也增大，所以是向 +x 走。

> **【结论要点】** 括号里 t 与 x **异号**（ωt − kx 或 kx − ωt）→ 沿 **+x**；**同号**（ωt + kx）→ 沿 **−x**。

- 系数可以被吸收：a(x − bt) = −ab(t − x/b)，它仍然是“t − x/u”型，u = b，沿 +x。看的是**相对符号**，不是表面上有没有减号。
- 图像法：把整幅波形朝传播方向“微移”一点点，看某个点的位移是变大还是变小——变大就说明它此刻正向 +y 运动。

**5. 由“某点的振动”反推波函数**

- 已知 x₀ 处的振动 y(x₀, t) = A cos(ωt + φ)，波沿 +x 传：把式中的 t 换成 **t − (x − x₀)/u**。

> **y(x, t) = A·cos[ω(t − (x − x₀)/u) + φ]**

道理很朴素：x 处此刻发生的事，是 x₀ 处在 (x − x₀)/u 时间**之前**发生过的事——离波源越远，“消息”到得越晚。沿 −x 传则换成 t + (x − x₀)/u。

**6. 两点的相位差**

> **Δφ = 2π·Δx / λ**

- 沿传播方向，**先到的点相位超前**（它先把这个状态做完，后面的点还在学它）。
- 多值性：Δφ = 2πΔx/λ 加上任意 2nπ 都描述同一个物理状态。题目给“两点距离小于一个波长”“λ 在某某范围”这类条件，就是让你定 n。

**7. 波形图 vs 振动图（本单元最高频失分点）**

- **y − x 图（波形图）**：把某一时刻**定格**，横轴是位置。能读出 λ、A、各点此刻的位移。
- **y − t 图（振动图）**：盯住**某一个质元**，横轴是时间。能读出 T、A、该点的初相。

> **【易错提醒】** 拿到图先问一句：横轴是 x 还是 t？横轴不同，斜率的物理意义完全不同（一个是空间斜率，一个是速度）。

**8. 选择题速记**

- (1) 读参数：先对标准式，认出 ω 与 k，再算 u = ω/k、λ = 2π/k。
- (2) 判方向：看 t 与 x 的相对符号，不看表面减号。
- (3) 判质点运动方向：波形朝传播方向微移，看该点位移增减。
- (4) 由点振动写波函数：沿 +x 就把 t 换成 t − (x − x₀)/u。

> **【口诀 · 对应题目】** 一句话串起来：波函数是“谁在什么时候动到哪儿”——先认 ω、k、φ₀ 三个数，再判方向，最后才谈能量。


### 二、两列相干波的干涉

**1. 叠加原理：先加位移，再平方得强度**

两列波同时经过空间某点，该点的位移就是两列波各自位移的**代数和**；而光强（波的强度）正比于**合振幅的平方**，不是两列波的强度直接相加。

> **A² = A₁² + A₂² + 2·A₁·A₂·cos Δφ**

中间那一项 2A₁A₂cosΔφ 就叫**干涉项**，它是“干涉”这个词的全部秘密：强度不再等于 1 + 1 = 2，而是随位置忽大忽小。

**2. 什么时候最强、什么时候最弱**

- Δφ = 0, ±2π, ±4π…（同相）→ A = A₁ + A₂ → **最强**。
- Δφ = ±π, ±3π…（反相）→ A = |A₁ − A₂| → **最弱**；两波等幅时 A = 0，完全相消。
- 等幅（A₁ = A₂ = A₀）时：I_max ∝ (2A₀)² = 4A₀²，I_min = 0。注意是 **4 倍**不是 2 倍。

**3. 相位差从哪儿来**

> **Δφ = 2π(r₂ − r₁)/λ + (φ₁₀ − φ₂₀)**

- 第一项：两源到该点的**路程差**（波程差）造成的；第二项：两个波源本身的**初相差**。
- （把 r₁、r₂ 或下标 1、2 整体对调，Δφ 只差一个负号；干涉看的是 cos Δφ，是偶函数，所以结论不变。）
- 同相源（φ₁₀ = φ₂₀）时最常用：Δφ = 2πδ/λ，δ 为波程差。

> **加强：δ = kλ　　减弱：δ = (2k + 1)λ/2　　(k = 0, 1, 2…)**

**4. 前提：两列波必须相干**

- 频率相同、振动方向相同、相位差恒定。光还要加一条：光程差小于相干长度。
- **非相干**叠加时，干涉项在时间平均中抹平：I = I₁ + I₂，看不到稳定条纹。

> **【口诀 · 对应题目】** 相干三条件为什么必须、两个独立钠灯为什么不相干，在第十三次作业“知识精讲 §一”里从头讲了一遍，那里是全年最常考的概念题。

**5. 球面波：强度随距离怎么衰减**

> **I ∝ 1/r²，　A ∝ 1/r**

道理：点源发出的能量摊在半径 r 的球面上，球面面积 4πr²，单位面积的功率自然 ∝ 1/r²；而 I ∝ A²，所以振幅 ∝ 1/r。

- 同一列波在 r₁ 与 r₂ 处：强度比 I₁/I₂ = r₂²/r₁²，振幅比 A₁/A₂ = r₂/r₁。

> **【易错提醒】** 干涉题里若两源距离场点远近不同，先别急着套“等幅”的结论——振幅可能不相等，此时极小处强度不为零（I_min ∝ (A₁ − A₂)²）。

**6. 易错清单**

- (1) “强度相加”只在**非相干**时成立；相干时必须先合振幅再平方。
- (2) 减弱不是“消失”，只有等幅时才完全相消。
- (3) 条纹是**强度的空间分布**，能量并没有被消灭，只是从暗处搬到了亮处（空间平均仍是 I₁ + I₂）。

### 三、驻波

**1. 驻波是怎么来的**

两列**振幅相同、频率相同、传播方向相反**的相干波叠加。最典型的场景：一列波撞到边界反射回来，入射波与反射波在同一根绳上共存。

> **y = A cos(ωt − kx) + A cos(ωt + kx) = 2A·cos(kx)·cos(ωt)**

看结果的形式：空间因子 2Acos(kx) 与时间因子 cos(ωt) **彻底分家**了。这意味着每个点都还在做简谐振动，但**振幅被位置锁死**，波形不再向左或向右跑——所以叫驻波。

**2. 波节与波腹**

- **波腹**：|cos kx| = 1 的位置，振幅最大 = 2A。
- **波节**：cos kx = 0 的位置，振幅恒为 0，那里的质元**永远不动**。

> **相邻波腹（或相邻波节）间距 = λ/2　　波腹与相邻波节间距 = λ/4**

> **【易错提醒】** 高频笔误：把“相邻波节间距”写成 λ/4。**正确的是 λ/2**——两个波节中间还夹着一个波腹，数一下就明白。λ/4 是波节到波腹的距离。实测弦上驻波：数一段长度里有多少个“鼓包”，相邻鼓包间距是 λ/2。

**3. 相位关系（与行波截然不同）**

- 相邻两个波节之间的**所有点同相**：一起到最大、一起过平衡位置。
- 隔一个波节的两段**反相**：同一时刻向相反方向运动。

行波里相隔 Δx 的两点有 2πΔx/λ 的连续相位差；驻波里只有“同相”和“反相”两种，中间没有过渡——因为空间因子 cos(kx) 变号就翻 180°。

**4. 能量：驻波不“送”能量**

- 入射波与反射波携带的能流大小相等、方向相反 → **净能流为零**，能量不再定向输运，只在波腹与波节之间来回倒腾。
- 质元位移最大的时刻：各点速度为 0 → 动能为 0；形变（斜率）最大 → 弹性势能最大，且集中在波节附近。
- 过平衡位置的时刻：形变最小 → 势能最小；速度最大 → 动能最大，且集中在波腹附近。

> **【易错提醒】** **行波**中质元的动能与弹性势能在时间上**同相**（同时最大、同时为零）；**驻波**整体的动能与势能在时间上**互补**（你多我少）。题目问的是哪一个，先看清楚。

**5. 边界条件决定本征频率**

- 两端固定的弦：两端必须是波节 → L = n·λ/2 → λ_n = 2L/n，f_n = n·u/(2L)（n = 1, 2, 3…）。
- 一端固定一端自由：固定端是波节、自由端是波腹 → L = (2n − 1)λ/4。

只有满足边界条件的那些频率才能形成稳定驻波，这叫**本征频率**——吉他弦、管乐器的音高就是这么定下来的，不是任意频率都行。

**6. 反射与“半波损失”**

- 波从**波疏**介质射向**波密**介质（相当于固定端）→ 反射波在反射点相位突变 π → 反射点为**波节**。
- 从波密到波疏（相当于自由端）→ 无相位突变 → 反射点为**波腹**。

> **【口诀 · 对应题目】** 光学里完全同构：光疏→光密反射有“半波损失”（多走 λ/2 光程），光密→光疏没有。第十三次作业的薄膜、劈尖、牛顿环，天天在用这条判据。


### 四、波的能量 · 多普勒效应 · 反射

**1. 波的能量与能流**

> **平均能量密度 w̄ = ½ρ ω² A²　　波强（平均能流密度）I = w̄·u = ½ρ ω² A² u**

- I ∝ A²，也 ∝ ω²：振幅加倍 → 强度 4 倍；频率加倍 → 强度 4 倍。
- 能流（功率）P = I·S。球面波无吸收时穿过任一球面的 P 相同 → I ∝ 1/r²（与上一节呼应）。

> **【易错提醒】** 不要把“质元的机械能”与“波强”混为一谈。行波中单个质元不断从上游吸收能量、又交给下游，它的总机械能**不守恒**（这正是波在输送能量的表现）。

**2. 多普勒效应：先判“相向还是背离”，再选符号**

> **f′ = f · (u ± v_观) / (u ∓ v_源)**

- **分子**管观察者：观察者迎着波走（与波相向）→ 分子用 **+**；背离 → 用 **−**。
- **分母**管波源：波源朝观察者来（相向）→ 分母用 **−**（分母变小 → f′ 变大）；远离 → 用 **+**。

> **【结论要点】** 万能判据：**相向 → 接收频率升高；背离 → 接收频率降低**。先用这句话定升降，再回头选符号，比死背公式可靠得多。

两种运动的物理机制不同，别混着记：

- **波源动**：改变的是空间中的波长——波源前方的波峰被“追着挤”在一起，λ′ = (u − v_源)/f。
- **观察者动**：波长没变，变的是观察者“撞上波峰”的频率——迎着走，单位时间撞上更多波峰。
- **介质中的波速 u 始终不变**（由介质决定），变的只是接收频率。

> **【易错提醒】** 光学多普勒必须用相对论公式（只有相对速度，没有“介质”），不能套上面这个声学公式。

**3. 反射：抓住“端点性质”**

- 反射点为波节（固定端 / 波阻变大）→ 反射波相对入射波在该点**反相**（多出 π，即“半波损失”）。
- 反射点为波腹（自由端 / 波阻变小）→ **同相**反射。
- 反射波的频率、波速、波长都与入射波相同（同一介质），唯一可能的变化就是那一个 π 的相位突变。

> **【口诀 · 对应题目】** 本单元的一条主线：不管是绳上的波还是光，**从“轻”到“重”（光疏到光密）反射就多半个波长**。把这句话记牢，第十三次的薄膜判据直接就通了。

## 第 13 次　波动光学 1：干涉

**本次考点：**相干性 · 双缝 · 薄膜 · 劈尖 · 牛顿环 · 迈克尔逊

### 一、相干条件与相干性（选择题高频概念题）

下面按“零基础”来讲，尽量少堆公式，先把物理图像说清楚。

**1. 干涉到底在干什么？**

把光想成水波。两列水波相遇，有的地方波峰叠波峰，水就更高；有的地方波峰叠波谷，水就抵消。光也是这样：两束光叠加后，有的地方更亮，有的地方更暗，形成**稳定的亮暗条纹**，这叫干涉。

但关键是：不是随便两束光相遇都能形成稳定条纹。必须让两束光**步调关系稳定**，也就是相干。

**2. 相干三条件**

理想情况下，两束光要相干，必须**同时**满足三条：

**① 频率相同**

频率就是每秒振动多少次。频率相同，波峰波谷的节拍才一样，才能形成固定的加强、减弱位置。

如果频率不同，两束光的相位差会不断变化：这一时刻波峰对波峰，下一时刻波峰对波谷，条纹会快速移动。人眼（以及任何有响应时间的探测器）看到的是平均效果，就看不到稳定干涉。

**② 振动方向相同**

光波是横波，振动方向垂直于传播方向。如果一束光上下振动，另一束光左右振动，它们不能在同一方向上很好地叠加出强弱分布。

- 振动方向**不完全相同**：只有共同方向的分量能干涉，干涉效果变差（对比度下降）。
- 振动方向**完全垂直**：干涉项恒为零，完全不干涉。

**③ 相位差恒定**

“相位”可以理解为波走到哪个位置：波峰、波谷、上升阶段、下降阶段。

> **【结论要点】** “相位差恒定”**不是**要求两束光相位相同，而是要求它们之间的**先后关系固定**。

比如一束光总比另一束光晚半个周期，这也是相位差恒定，仍然可以干涉，只是条纹位置会移动（原来最亮的地方变成最暗）。

如果相位差随机变化，亮暗位置就随机变化，时间平均后是一片均匀亮度，看不到条纹。

> **【结论要点】** 相干条件记成：**频率相同、振动方向相同、相位差恒定**。三个条件缺一不可。

> **【易错提醒】** 选择题常考：**频率相同不一定相干**，还要振动方向相同、相位差恒定。看到“两束光频率相同所以一定干涉”直接判错。

**3. 为什么两个独立钠灯不能干涉？**

两个钠灯都发黄光，频率很接近，甚至看起来完全一样。但它们不能形成稳定干涉。

原因是：普通光源发光是**大量原子各自独立、随机、断续地发光**。每个原子发的光是一小段一小段的波列，段与段之间相位毫无关系。

两个钠灯之间没有固定相位关系，它们的相位差在极短时间内（10⁻⁸ s 量级）随机跳变。所以不满足“相位差恒定”，因此不相干。

> **【结论要点】** 两个独立钠灯不能干涉：因为**相位差随机**，**不是**因为频率不同。

> **【口诀 · 对应题目】** 对应作业第 2 题：两只钠灯发出的黄光相遇观察不到干涉，选“不是相干光”。

**4. 时间相干性：看“单色性”和“相干长度”**

实际光源不是无限长的纯正弦波，而是**一段一段的波列**（每个原子发一段，然后停掉，另一个原子再发一段）。

光源的单色性越好，波列越长，时间相干性越好。

时间相干性关心的是这样一个问题：

> **【结论要点】** 同一束光分成两路后，一路走远一点、另一路走近一点，它们到达相遇点时**还能不能来自同一段波列**？

两路光走的路程差叫**光程差**。光程不是单纯的几何距离，而是光在介质中传播折算成真空中的距离：

> **光程 = 折射率 n × 几何路程**

两路光的光程差记作 δ。

- 光程差**不大**：两路光到达时还来自同一段波列 → 相位关系稳定 → 能干涉。
- 光程差**太大**：两路光到达时已经来自不同波列 → 相位关系随机 → 不能干涉。

允许的最大光程差叫**相干长度**，记作 L_c。

> **【结论要点】** δ < L_c 能干涉；δ > L_c 观察不到干涉。

> **L_c = λ² / Δλ　　（Δλ 为光谱宽度）**

- Δλ 越小 → 单色性越好 → 相干长度越长 → 时间相干性越好。
- **白光**：Δλ 很大，相干长度只有几个波长（微米量级），所以肥皂膜要很薄才能看到彩色干涉。
- **钠灯**：Δλ 较小，相干长度约 0.1~1 mm 量级。
- **激光**：Δλ 极小，相干长度可达米、千米甚至更长，时间相干性极好。

> **【口诀 · 对应题目】** 对应作业第 1 题：决定“最大光程差”的是**光源的相干长度**（时间相干性），与光源尺寸、强度、频率本身无关。

**5. 空间相干性：看“光源线度”和“光源大小”**

空间相干性关心的是另一个问题：

> **【结论要点】** 同一时刻，从**同一个扩展光源的不同位置**发出的光，能不能当作相干光来用？

普通扩展光源可以看成许多**独立的小点光源**的集合。每个小点光源都各自随机发光，彼此相位不固定。

- 光源**很小**（接近点光源）：各点发出的光相位关系比较一致 → 空间相干性**好**。
- 光源**很大**（大灯丝、大面光源）：不同点发出的光互相独立 → 空间相干性**差**。

典型例子：杨氏双缝实验。如果双缝前面的光源太大，光源上不同点各自产生一套干涉条纹，这些条纹在屏上**位置互相错开**，叠加后亮暗互相填平，条纹就看不见了。

> **【结论要点】** 光源越小，空间相干性越好；光源越大，空间相干性越差。

定量关系（双缝间距 d、光源线度 a、光源到双缝距离 R、波长 λ）：

> **d < λR / a　　（即光源对双缝的张角 a/R 小于 λ/d）**

这个公式不用死背，记住趋势即可：**光源越小、双缝越近，越容易看到干涉**。

> **【口诀 · 对应题目】** 对应作业第 3 题：空间相干性取决于光源的**线度**。强度、单色性、光谱宽度分别对应别的概念，别选错。

> **【易错提醒】** 两个独立钠灯不相干，是因为它们**不是同一个光源分出来的**，相位差随机；空间相干性则讨论**同一个扩展光源的不同部分**。两者都归到“相位差不稳定”，但成因不同，答题时要说清楚。

**6. 获得相干光的两种方法**

普通光源各原子独立发光，不能直接拿两个灯去干涉。必须把**同一束光**分开，再让它们相遇。方法有两类：

**方法一：波阵面分割法**

取同一个波阵面上的两部分作为两个新光源。

“波阵面”就是波传播时相位相同的点组成的面（比如点光源发出的一圈圈球面）。同一波阵面上的光来自同一光源、同一时刻，相位关系稳定。

- 典型例子：**杨氏双缝干涉**、**菲涅耳双面镜**、**洛埃镜**。
- 特点：从同一波前取两部分，初相关系稳定；**主要受空间相干性限制**（光源要小）。

**方法二：振幅分割法**

用反射、透射把同一束光分成两路（把一份振幅劈成两份）。

比如一束光遇到薄膜，一部分在上表面反射，一部分进入薄膜在下表面反射后再出来。这两束光来自同一入射光，只是振幅被分开了。

- 典型例子：**薄膜干涉**、**迈克尔逊干涉仪**、**牛顿环**、**劈尖干涉**。
- 特点：同一束光被分束，相位关系稳定；**主要受时间相干性限制**（光程差不能超过相干长度）。

> **【易错提醒】** 易混点：标准分类中**双缝干涉属于波阵面分割法，薄膜干涉属于振幅分割法**。旧版笔记把“双缝、薄膜”都写进波阵面分割里，这是错的，本版已改正（见附录勘误）。

总结成表：

- **波阵面分割法**：同一波前取两部分 → 双缝、菲涅耳双镜、洛埃镜 → 限制是光源要小（空间相干性）。
- **振幅分割法**：同一束光反射/透射分两路 → 薄膜、迈克尔逊、牛顿环、劈尖 → 限制是光程差小于相干长度（时间相干性）。

> **【口诀 · 对应题目】** 对应作业填空题第 14 题：波阵面分割法是从同一波面上取**两个（部分）子波阵面**作为**两个相干光源**。

**7. 选择题速记与易错点**

- (1) 相干三条件：频率相同、振动方向相同、相位差恒定。
- (2) 两个独立钠灯不能干涉：因为相位差随机，不是频率不同。
- (3) 频率相同不一定相干。
- (4) 相位差恒定 ≠ 相位相同：一个总比另一个慢半拍也可以干涉。
- (5) 时间相干性由单色性、相干长度决定；单色性越好，相干长度越长。
- (6) 光程差 > 相干长度 → 观察不到干涉。
- (7) 空间相干性由光源线度决定；光源越小，空间相干性越好。
- (8) 双缝干涉 = 波阵面分割法。
- (9) 薄膜干涉、迈克尔逊干涉 = 振幅分割法。
- (10) 白光相干长度短 → 薄膜要薄才能看到彩色条纹。
- (11) 激光：单色性好，时间相干性与空间相干性都好。

> **【口诀 · 对应题目】** 一句话总结：干涉的本质是两束光“来自同一源、步调关系稳定”。**时间相干性管“光程差能有多大还能认亲”；空间相干性管“光源能有多大还能认亲”。双缝是分波阵面，薄膜是分振幅。**


### 二、杨氏双缝与光程差计算

**1. 光程：把“路”统一折算成真空里的长度**

> **光程 = n × 几何路程　　光程差 δ = (各段 n·r 之和的差)**

为什么这么定义？光进入介质后频率不变、波速变慢，波长变短为 λ_n = λ/n。走过几何距离 d 造成的相位变化是 2πd/λ_n = 2πnd/λ。把 nd 当作“等效真空路程”，相位公式就统一成下面这一条：

> **【结论要点】** Δφ = 2πδ/λ　（λ 一律用**真空波长**，δ 是光程差）

- 一条光路里插入折射率 n、厚度 e 的透明片：这一段原来是空气（n≈1），现在变成 n → 光程**增加 (n − 1)e**。

**2. 双缝的几何：光程差从哪儿来**

两缝 S₁、S₂ 相距 d，缝到屏距离 D ≫ d，屏上点 P 距中心 O 为 x，P 相对双缝中点的方位角 θ。

> **δ = d·sinθ ≈ d·tanθ = d·x/D**

- 近似成立的条件：D ≫ d、x ≪ D（近轴），此时 sinθ ≈ tanθ ≈ θ。
- **明纹**：δ = kλ → x_k = k·λD/d（k = 0, ±1, ±2…）。
- **暗纹**：δ = (2k + 1)λ/2 → x = (2k + 1)·λD/(2d)。

> **条纹间距 Δx = λD/d**

> **【结论要点】** Δx 与级次 k 无关 → 双缝条纹**等间距**（这是双缝与牛顿环、光栅的重要区别之一）。

**3. 条纹间距由什么决定**

- d 越小（两缝靠得越近）→ Δx 越大，条纹越疏。
- D 越大（屏放得越远）→ 越疏。
- λ 越长（红光比蓝光）→ 越疏。
- 白光照明：中央 k = 0 处各波长的明纹重合 → 白色；两侧各波长错开 → 彩色条纹，级次高了会重叠成一片模糊的白。

**4. 插介质片 / 改变一条光路**

- 在 S₁ 后插入折射率 n、厚 e 的薄片 → S₁ 一路光程增加 (n − 1)e。

> **整组条纹平移量：Δx_移 = (n − 1)e·D/d = [(n − 1)e / λ] × Δx**

- 条纹**间距不变**，只是整体平移；平移方向**朝向盖片那一侧**——盖片让这一路的光程变长，只有跑到“离这一缝更近、离另一缝更远”的位置，几何程差才能把多出来的光程抵消掉。

> **【易错提醒】** 若 (n − 1)e 恰好等于整数倍波长 mλ → 平移整数个条纹间距 → 原来的中央明纹处**仍是明纹**（作业第 6 题：(1.5−1)×10λ = 5λ）。看到“厚度是波长的多少倍”先算这个倍数是否为整数。

**5. 光强分布：别把 4 倍记成 2 倍**

> **I = I₁ + I₂ + 2√(I₁·I₂)·cos Δφ　　等幅时：I = 4I₀·cos²(Δφ/2)**

- 等幅：I_max = 4I₀（振幅加倍 → 强度 4 倍），I_min = 0。
- 空间平均值 = 2I₀ = I₁ + I₂ → **能量守恒**：暗处少掉的能量都跑到亮处去了，干涉不创造也不消灭能量。
- 两缝**振幅不等**（一缝变窄）：I_min = (√I₁ − √I₂)² > 0 → 极小处不再全黑，但**条纹间距仍只由 d 决定**，条纹照样在。

> **【口诀 · 对应题目】** 对应作业第 4 题：一缝变窄 → 间距不变、原极小处强度不再为零；第 5 题：等幅相干光叠加，最小光强为零。

**6. 一缝加宽 / 缝有宽度时的包络**

- 实际的缝有宽度 a → 每条缝自己还要做单缝衍射 → 双缝条纹被单缝衍射的“包络”调幅。
- 包络的零点（单缝暗纹方向）上，主极大被抹掉 → 出现**缺级**（详见第十四次知识精讲）。

**7. 易错清单**

- (1) 相位差公式里用**真空波长**，光程差里已经把 n 折进去了，不要再除一次 n。
- (2) 条纹平移 ≠ 条纹间距变化：插片只平移，改 d 才改间距。
- (3) 等幅相干叠加 I_max = 4I₀ 不是 2I₀；极小不为零不代表没有干涉。

### 三、等倾干涉（平面平行膜、迈克尔逊干涉仪）

**1. 平行膜的两束反射光**

一束光打到厚度均匀的薄膜上：一部分在**上表面**直接反射，另一部分折射进入膜内、在**下表面**反射、再折射出来。这两束来自同一束入射光（振幅分割法），所以相干，出射后相遇叠加。

> **δ = 2n·d·cos r　（再加半波损失修正）**

> **【易错提醒】** 公式里是 **r（膜内的折射角）**，不是空气中的入射角 i。题目若给 i，先用折射定律 sin i = n·sin r 换算。

- 半波损失：上表面 空气→膜（光疏→光密）有 π；下表面 膜→空气 无 → **净半波损失 λ/2**。
- 反射明纹：2nd·cos r + λ/2 = kλ；反射暗纹：2nd·cos r + λ/2 = (2k+1)λ/2，即 **2nd·cos r = kλ**。
- 透射光与反射光**互补**（此明彼暗），能量守恒的必然结果。

**2. 为什么叫“等倾”**

膜厚 d 处处相同 → 光程差只由**倾角**决定 → 倾角相同的光线（哪怕来自扩展光源的不同点）光程差一样 → 干涉结果一样。

- 用透镜把同一方向（同一倾角）的平行光聚到焦平面上同一点 → 屏上出现**同心圆环**。
- i 增大 → r 增大 → cos r 减小 → δ 减小 → 级次 k 变小 → **中心（i = 0）级次最高**，越往外级次越低。
- 条纹是“等倾线”，所以叫**等倾干涉**；与劈尖、牛顿环的“等厚干涉”相对。

> **【口诀 · 对应题目】** 对应作业第 10 题：等倾干涉可以用**扩展光源**——不同点发出的光彼此不相干，但同倾角的光聚到同一圆环上，非相干叠加后总光强提高而对比度不下降。

**3. 迈克尔逊干涉仪**

结构：分束板把一束光分成两路，分别被反射镜 M₁、M₂ 反射回来再合束。**补偿板**的作用是让两路在玻璃中走过的光程相等（用白光等低相干光源时必须）。

等效图像：M₂ 与 M₁ 在 M₂ 附近所成的虚像 M₁′ 之间，形成一层“空气膜”。看懂这个等效，迈克尔逊就退化成平行膜问题了。

> **动镜移动 Δd → 光程差改变 2Δd → 条纹移过 N 条 → λ = 2Δd / N**

- M₁′ 与 M₂ **严格平行** → 等效平行空气膜 → **等倾圆环**。
- M₁′ 与 M₂ 成**小夹角** → 等效劈尖 → **等厚直条纹**。
- 中心（i = 0）处光程差 = 2d（再加半波损失修正）。两臂严格等光程（d = 0）时，两束在分束板上经历的反射次数奇偶不同、多出一个 π → 观察端口的中心为**暗**，视场全暗（另一端口则全亮）。

> **【易错提醒】** 动镜移动 Δd，光程差改的是 **2Δd**（光来回走了两趟）。算波长时漏掉因子 2 是最经典的错误（作业填空第 12 题）。

**4. 速记**

- (1) 平行膜 → 等倾 → 同心圆环，中心级次最高。
- (2) 公式用膜内角 r，不是入射角 i。
- (3) 迈克尔逊：等效空气膜，动镜 Δd ↔ 光程差 2Δd ↔ 条纹数 N。

### 四、等厚干涉（劈尖、牛顿环）与半波损失判据

**1. 等厚 vs 等倾：一眼分清**

- 膜**厚度均匀** → 光程差只由倾角定 → **等倾**干涉（平行膜、圆环）。
- 膜**厚度不均匀**、且用平行光垂直入射（倾角固定）→ 光程差只由厚度定 → **等厚**干涉（劈尖直条纹、牛顿环圆环）。

> **【结论要点】** 同一条条纹 = 光程差相同的一批点的轨迹。等倾条纹追的是“角度相同”，等厚条纹追的是“厚度相同”。

**2. 半波损失：唯一可靠的判据**

光在界面上反射时，若从**光疏（n 小）射向光密（n 大）**，反射光的电矢量相位会突变 π，等效于多走 λ/2 的光程；从光密射向光疏则**没有**这个突变。

> **【结论要点】** 口诀：**光疏到光密，反射加半波**。薄膜的两个界面**各判一次**，把两次的结果相加，得到净半波损失（λ/2 或 0）。

- 两次都是光疏→光密（或两次都不是）→ 净半波损失为 **0**（两次相变抵消）。
- 只有一次是光疏→光密 → 净半波损失为 **λ/2**。

> **【易错提醒】** 不要背“牛顿环中央一定是暗斑”。中央的明暗完全由两界面折射率决定，作业填空第 19 题那种 n 递增或递减的夹层，必须逐界面数。

**3. 劈尖（楔形空气膜）**

> **厚度 δ(x) = θ·x　（θ 为楔角，极小）**

- 典型空气劈尖（玻璃—空气—玻璃）：上界面 玻璃→空气 无半波损失，下界面 空气→玻璃 有 → 净 λ/2。
- 反射**暗纹**：2δ + λ/2 = (2k+1)λ/2 → **2δ = kλ**（k = 0, 1, 2…）。
- 反射**明纹**：2δ + λ/2 = kλ → 2δ = (2k−1)λ/2（k = 1, 2…）。
- 尖端 δ = 0 处，2δ = 0 = 0·λ → 是 **k = 0 的暗纹**（空气劈尖尖端是暗的）。

> **相邻明（暗）纹对应的膜厚差 Δδ = λ/2　　条纹间距 Δx = λ/(2θ)**

- 测微小厚度：h = θ·L = [λ/(2Δx)]·L（纸片、细丝直径都这么测，作业填空第 17 题）。
- **工件缺陷判断**：条纹弯向**尖端（膜薄端）** → 该处要走到更薄的位置才能找到同一厚度 → 说明该处膜比正常**厚** → 工件**凹陷**；弯向厚端 → **凸起**。弯曲一个条纹间距 ↔ 深度（高度）= **λ/2**。

**4. 牛顿环**

平凸透镜凸面放在平板玻璃上，中间是一层厚度随半径变化的空气膜：

> **δ(r) ≈ r² / (2R)　（R 为凸面曲率半径，r ≪ R）**

- 反射观察（空气膜，净半波损失 λ/2）：

> **暗环：r_k = √(k λ R)，k = 0, 1, 2…（k = 0 即中央暗斑）　　明环：r_k = √((2k+1)λR/2)**

- **测曲率半径**的黄金公式（与“中央算不算第 1 环”的编号争议无关）：

> **r_{k+m}² − r_k² = m·λ·R**

- 浸液体（折射率 n）：2nδ = kλ → r_k = √(kλR/n) → 半径 ∝ 1/√n，条纹**整体缩小**（作业填空第 16 题：n = r₁²/r₂²）。
- 透镜缓慢上移 Δ：δ(r) = Δ + r²/(2R) → 固定级次的环半径减小 → 环**向中心收缩**；中心处膜厚从 0 连续增大 → 环心**明暗交替**（作业选择第 8 题）。

**5. 白光薄膜的颜色**

- 反射加强（有净半波损失时）：2nd + λ/2 = kλ → λ = 2nd/(k − 1/2)。
- 透射加强：2nd = kλ → λ = 2nd/k。
- 把 2nd 代进去，筛出落在 **400~760 nm** 的波长，剩下的就是看到的颜色；反射色与透射色**互补**（作业计算第 23 题：反射紫红、透射绿）。

**6. 易错清单**

- (1) 先数半波损失，再写明暗条件，顺序不能反。
- (2) 劈尖尖端的明暗由净半波损失决定：空气劈尖（玻璃夹空气）尖端是暗纹。
- (3) 条纹弯曲方向 → 先想“同一条纹 = 同一厚度”，再推工件是凹是凸。
- (4) 浸液后半径按 1/√n 缩小，不是 1/n。
- (5) 环向中心收缩 ≠ 条纹间隔变小，别把半径和间距混为一谈。

## 第 14 次　波动光学 2：衍射与光栅

**本次考点：**单缝衍射 · 光栅缺级 · 光谱重叠 · 分辨本领

### 一、单缝夫琅禾费衍射

**1. 衍射是什么，和干涉什么关系**

波遇到障碍物会“绕弯”，不严格沿直线走，这叫衍射。惠更斯—菲涅耳原理给出算法：**波前上每一点都是新的子波源**，把所有子波按相位叠加起来，就是衍射图样。

- **干涉**：可数的几束相干光叠加（双缝 = 2 束，光栅 = N 束）。
- **衍射**：同一个波前上**无穷多个**子波源叠加（单缝 = 无穷多条窄带）。

> **【结论要点】** 两者本质完全相同——都是相干叠加，工具也一样：算光程差 → 算相位差 → 把振幅（矢量）加起来。区别只在“是几束”。

- **夫琅禾费衍射**（远场衍射）：入射光和衍射光都当作平行光，用透镜把同一方向的光聚到焦平面上观察。近距离观察叫菲涅耳衍射，本学期不作要求。

**2. 半波带法：不积分也能得到暗纹**

把缝宽 a 沿宽度方向切成 N 条等宽窄带。相邻窄带发出的光射向 φ 方向时，光程差都是 (a sinφ)/N，相位差也一样。

- 若 **a·sinφ = λ**：可把缝分成 **2 个**半波带，两带上对应点的光程差正好 λ/2 → 一一配对相消 → **暗纹**。
- 若 **a·sinφ = 2λ**：分成 **4 个**半波带，两两相消 → **暗纹**。
- 若 **a·sinφ = 3λ/2**：分成 **3 个**半波带，其中两个相消，剩下一个 → **明纹**（但比中央暗得多）。

> **暗纹：a·sinφ = kλ　(k = ±1, ±2, ±3…，不含 0)　　明纹（近似）：a·sinφ = (2k+1)λ/2**

- **中央明纹**在 φ = 0：所有子波到该方向光程相同、完全同相 → 最亮最宽。

**3. 屏上的尺度**

> **第一级暗纹 x₁ = λf/a　　中央明纹宽度 Δx₀ = 2λf/a　　其余明纹宽度 = λf/a**

- **中央明纹是其他明纹的 2 倍宽**，亮度也集中在这里（约占总能量的 90%）。
- 缝宽 a **减小** → 图样**展宽**（Δx ∝ 1/a）——缝越窄，反而散得越开，这是衍射最反直觉也最常考的一点。
- 波长 λ **变长**（红光）→ 展宽。
- 焦距 f **变大** → 屏上尺度变大（角度分布不变）。
- 极限：a ≫ λ → 中央明纹极窄 → 看起来就是直线传播 → 回到几何光学。

**4. 透镜在这里起什么作用**

- 会聚透镜把**同一方向（同一衍射角 φ）**的平行光聚到焦平面上同一点：x = f·tanφ。
- 透镜**平移** → 光轴平移 → 中央明纹（φ = 0 的方向）**跟着平移**；但图样的**角分布 ∝ λ/a 与 f 无关**，所以大小不变。

> **【易错提醒】** 屏上尺度 ∝ f，角度分布 ∝ λ/a。问“图样大小变不变”先看问的是哪一个。

**5. 斜入射**

> **暗纹：a·(sinφ − sinθ₀) = kλ　（θ₀ 为入射方向与缝法线的夹角）**

- 正入射 θ₀ = 0 时退化回 a·sinφ = kλ。斜入射会让整个图样**平移**（中央明纹移到 φ = θ₀ 方向），但角宽度基本不变。

**6. 强度分布（了解即可）**

> **I = I₀·(sin β / β)²，　β = πa·sinφ/λ**

- 次极大（第一、第二亮纹）约为主极大的 **4.7%、1.6%** ——所以单缝衍射看起来就是“中间一条粗亮的，两边几条很淡的”。

**7. 速记**

- (1) 暗纹条件 a·sinφ = kλ，k 从 1 开始数，中间没有 0 级暗纹。
- (2) 中央明纹宽度 = 2λf/a，是其他明纹的两倍。
- (3) 缝越窄、波长越长 → 散得越开。

### 二、光栅 · 缺级 · 分辨本领

**1. 从双缝到光栅：N 束同相叠加**

光栅 = 大量等宽、等间距的平行狭缝。缝宽 a，不透光部分宽 b，**光栅常数 d = a + b**（相邻缝的间距）。

相邻两条缝发出的光射向 φ 方向时，光程差都是 d·sinφ，相位差都是 2πd sinφ/λ。

> **主极大（光栅方程）：d·sinφ = kλ　(k = 0, ±1, ±2…)**

- 为什么叫**主极大**：此时 N 条缝的光**完全同相** → 合振幅 = N 倍 → 强度 = **N²** 倍（比双缝亮得多、窄得多）。
- 稍微偏离主极大方向一点点，N 个相位就排成一个完整的圆 → 合振幅 ≈ 0。所以相邻主极大之间有 **N − 1 个极小**、**N − 2 个很弱的次极大**。

> **【结论要点】** N 决定主极大的**亮度与尖锐程度**（N 越大越亮越细）；d 决定主极大的**位置**（角度）。两者各管一摊，别混。

**2. 最大级次**

> **|sinφ| = |kλ/d| ≤ 1　→　|k| ≤ d/λ　→　k_max = ⌊d/λ⌋**

- 若 d/λ 恰好是整数，该级落在 90° 方向（贴着光栅面出射），实际观察不到，要再退一级。

**3. 缺级：单缝包络把主极大“吃掉”**

每条缝自己有宽度 a，所以它自己还要做单缝衍射。单缝衍射的强度曲线像一个“包络”，把 N² 倍的主极大**调幅**。

如果某个主极大的方向，恰好是单缝衍射的暗纹方向（a·sinφ = mλ），那么这个方向上**每条缝自己什么都不发**，主极大自然就消失了。

> **联立 d·sinφ = kλ 与 a·sinφ = mλ　→　k = m·(d/a)　(m = 1, 2, 3…)**

- **d = 2a**（缝宽与不透光部分等宽）→ k = 2, 4, 6… → **偶数级全部缺级**。
- 一般地，d/a = p/q（最简分数）→ **k 为 p 的整数倍**的那些级缺级。

> **【口诀 · 对应题目】** 一句话：缺级 = 光栅主极大踩在单缝暗纹上。算的时候就是两个方程除一下。

**4. 光栅光谱与谱线重叠**

- 复色光入射：除 0 级（各波长重合、呈白色）外，不同波长的主极大角度不同 → **分光**，这就是光谱仪的原理。
- 第 k 级主极大的位置：sinφ = kλ/d → λ 越长偏得越远（红光在外）。
- **重叠条件**：k₁λ₁ = k₂λ₂（不同级次之间撞车）。同级不同波长的**不会**重叠，因为它们本来就是被分开的。
- 第 k 级光谱不与第 k+1 级重叠的条件：k·λ_max < (k+1)·λ_min。

**5. 斜入射**

> **d·(sinφ ± sinθ₀) = kλ　（θ₀ 为入射角；正入射时退化为 d·sinφ = kλ）**

- 题目说“原中央明纹位置变成第 k 级”，意思是 φ = 0 方向上的光程差等于 kλ。

**6. 分辨本领：多近才算“分得开”**

点光源经过有限孔径后，成的像不是点，而是一个衍射斑（圆孔是**艾里斑**）。两个点靠得太近，两个斑糊在一起就分不清了。

**瑞利判据**：一个斑的**中心**恰好落在另一个斑的**第一级暗环**上时，算“刚能分辨”。

> **圆孔：θ_min = 1.22·λ/D　　单缝：θ_min = λ/a**

- D（或 a）越大、λ 越短 → θ_min 越小 → 分辨能力越强（所以天文望远镜越做越大，电子显微镜用波长极短的电子）。
- 对应的**最小可分辨线距离** = L·θ_min（L 为到物体的距离）。

> **光栅色分辨本领：R = λ/Δλ = k·N　（N 为被照亮的总刻线数）**

- 级次越高、刻线越多 → 分得越细。注意 R 与光栅常数 d **无关**，只与 N 和级次有关。

> **【易错提醒】** **1.22 只用于圆孔**（望远镜、眼睛、显微镜物镜）。单缝的瑞利判据是 λ/a，没有 1.22。看到“单缝”“狭缝”就别套 1.22。

**7. 易错清单**

- (1) 光栅方程里 d 是**光栅常数**（缝距），不是缝宽 a；给“每毫米 n 条刻线”时 d = 1/n mm，注意单位。
- (2) 缺级时该级“消失”，其余级的相对亮度不变。
- (3) 主极大位置由 d 定，宽度由 N 定——不要把 N 塞进光栅方程。
- (4) 分辨本领 R = kN，与 d 无关。

## 第 15 次　波动光学 3：偏振

**本次考点：**偏振态 · 马吕斯定律 · 布儒斯特定律 · 双折射与波片

### 一、偏振态与马吕斯定律

**1. 偏振：横波才有的问题**

横波的振动方向**垂直于**传播方向，于是就多出一个问题：它到底朝哪个方向振？这个“振动方向相对传播方向的不对称性”就叫**偏振**。

- 纵波（比如声波）振动方向就在传播方向上，没有选择余地 → **没有偏振现象**。所以“有偏振”是光是横波的直接证据。

**2. 五种偏振态，一层层加条件**

- **自然光**：大量原子各自独立随机发光，垂直于传播方向的平面内**各个方向都振**，且彼此相位随机。偏振度 P = 0。
- **线偏振光**：只沿一个固定方向振动（电矢量端点画一条直线）。P = 1。
- **部分偏振光**：某个方向占优，可看作“自然光 + 一束线偏振光”的混合。0 < P < 1。
- **圆偏振光**：两个互相垂直的分量**等幅**、相位差 **±π/2** → 电矢量端点画圆。P = 1（完全偏振）。
- **椭圆偏振光**：两个正交分量不等幅，或相位差不是 0、π、±π/2 → 端点画椭圆。P = 1（完全偏振）。

> **偏振度 P = (I_max − I_min) / (I_max + I_min)**

**3. 马吕斯定律：本质就是一次投影**

偏振片（起偏器/检偏器）只允许沿它的**透振方向**的分量通过。线偏振光振幅 A₀，与透振方向夹 θ：

- 通过的分量 A = A₀·cosθ；
- 强度 I ∝ A² → I = I₀·cos²θ。

> **I = I₀·cos²θ　（马吕斯定律）**

- θ = 0° → 全通过；θ = 90° → **消光**；θ = 60° → 1/4；θ = 45° → 1/2。
- **自然光过偏振片**：各方向平均下来 ⟨cos²θ⟩ = 1/2 → **I = I₀/2**，而且出射光变成**线偏振光**（这就是“起偏”）。

> **【易错提醒】** 马吕斯定律只对**线偏振光**成立。自然光过偏振片一律减半，不要拿角度去乘。

**4. 多片串联：一片一片来**

- 前一片的出射就是后一片的入射（除非中间插了波片），逐片套马吕斯定律即可。

> **两正交偏振片中间插第三片（与第一片夹 θ）：I = (I₀/2)·cos²θ·cos²(90° − θ) = (I₀/8)·sin²2θ**

- θ = 45° 时最大，I = I₀/8。

这个结论常让人意外：夹在两片**正交**（本来完全不透光）的偏振片之间再插一片，居然有光出来了。原因是中间那片把偏振方向**转**了一下，让第三片不再对着消光方向。

**5. 怎么鉴别各种偏振态（高频实验题）**

第一步：只用一块偏振片，转动一周，看透射光强怎么变。

- 出现**完全消光** → **线偏振光**。
- 强度**完全不变** → **自然光 或 圆偏振光**（二者此时无法区分）。
- 强度**变化但不消光** → **部分偏振光 或 椭圆偏振光**（同样无法区分）。

第二步：在偏振片前加一块 **λ/4 波片**（光轴对准第一步中强度最大的方向），再转偏振片。

- 变成能**消光** → 原来是**圆偏振光**（波片把 ±π/2 的相位差补成了 0 或 π）。
- 仍然**强度不变** → 原来是**自然光**（随机相位差再加上 π/2 还是随机，波片救不了）。
- 椭圆偏振与部分偏振用同样的思路区分（椭圆能消光，部分偏振不能）。

> **【易错提醒】** **圆偏振光过偏振片：强度减半，且转动偏振片强度不变**——光强表现和自然光一模一样。想区分必须上 λ/4 波片。这是选择题最爱挖的坑（作业第 4、6 题）。

**6. 速记**

- (1) 自然光过偏振片：减半 + 变成线偏振。
- (2) 线偏振过偏振片：乘 cos²θ。
- (3) 两片正交 → 全黑；中间插一片 → 有光（45° 时最大 I₀/8）。
- (4) 转一周有消光 = 线偏振；强度不变 = 自然光或圆偏振。

### 二、布儒斯特定律

**1. 现象：反射和折射都会“筛”偏振**

自然光射到两种介质的界面上，反射光与折射光都会变成**部分偏振光**：

- 反射光中**垂直于入射面**的分量（s 分量）占优；
- 折射光中**平行于入射面**的分量（p 分量）占优。

**2. 布儒斯特角：反射光变成纯线偏振的那一瞬间**

随着入射角变化，反射光里 p 分量的比例一直在变。存在一个特殊角度 **i_B**，此时 p 分量**完全不反射**（反射系数为零），于是反射光只剩 s 分量 → 成为**振动方向垂直于入射面的线偏振光**。

- 此时的几何特征：**反射光线与折射光线互相垂直**，即 i_B + r = 90°。

> **tan i_B = n₂ / n₁　（光从介质 1 射向介质 2）**

推导就两行：由折射定律 n₁ sin i_B = n₂ sin r，又 r = 90° − i_B → n₁ sin i_B = n₂ cos i_B → tan i_B = n₂/n₁。

**3. 三条常用推论**

- **反射光是线偏振光，振动方向 ⊥ 入射面**（s）。
- 若入射线偏振光的振动方向 **∥ 入射面**（p）且以 i_B 入射 → **无反射，全部透射**。
- **玻璃片堆**：让光以 i_B 反复透过许多片玻璃，s 分量每次都被反射掉一部分 → 透射光越来越接近纯 p 方向的线偏振光（可做起偏器）。
- 平行玻璃板有**两个**界面：以 i_B 从空气射入时，折射角 r 恰好等于“玻璃→空气”界面的布儒斯特角 → 内表面的反射光也是**同方向**的线偏振光。

> **【易错提醒】** 布儒斯特角只对**反射光**给出完全偏振；**折射光永远是部分偏振光**（p 占优），无论什么角度都不会变成完全偏振。

> **【结论要点】** 记牢这一对：**反射掉的是垂直入射面的（⊥，s）；不反射、全透射的是平行入射面的（∥，p）。**

> **【口诀 · 对应题目】** 对应作业选择第 7 题（反射光为振动方向垂直于入射面的线偏振）与填空第 12 题（无反射的是 p 分量，电矢量平行入射面）。


### 三、双折射与波片

**1. 双折射：一束光进去，两束光出来**

光进入**各向异性晶体**（方解石、石英等）会分裂成两束，这叫双折射：

- **o 光（寻常光）**：遵守普通折射定律，各个方向传播速度相同 → 波阵面是**球面**。
- **e 光（非常光）**：传播速度随方向改变，一般不遵守折射定律（甚至可以不在入射面内）→ 波阵面是**旋转椭球面**。
- **光轴**：晶体中 o、e 两光速度**相同**的特殊方向。沿光轴传播时不发生双折射。
- **主截面**：光轴与光线构成的平面。o 光振动 **⊥ 主截面**，e 光振动 **∥ 主截面** → 两束光的振动方向**互相垂直**。

> **【口诀 · 对应题目】** 对应作业选择第 8 题：o 光波阵面是球面，e 光是旋转椭球面，二者在光轴方向上相切。

**2. 主折射率与正、负晶体**

> **n_o = c/v_o，　n_e = c/v_e（e 光取垂直于光轴传播时的折射率）**

- **正晶体**（如石英）：n_e > n_o（v_e < v_o），椭球被球面套在**里面**。
- **负晶体**（如方解石）：n_e < n_o（v_e > v_o），椭球把球面套在**里面**。

**3. 波片：给两个分量制造相位差**

把晶体磨成薄片，**光轴平行于表面**。光垂直入射时，分解成沿光轴（e）与垂直光轴（o）的两个分量，它们走**同样的几何路程**，但速度不同 → 出射时产生相位差。

> **光程差 Δ = |n_e − n_o|·d　　相位差 δ = 2π·|n_e − n_o|·d / λ**

- **λ/4 波片**：Δ = λ/4 → δ = π/2，厚度 d = λ/[4|n_e − n_o|]。
- **λ/2 波片**：Δ = λ/2 → δ = π，厚度 d = λ/[2|n_e − n_o|]。
- 严格地说还要加整数个波长：d = (m + 1/4)·λ/|n_e − n_o| 之类；题目问“**最薄**”才取 m = 0（作业填空第 19 题）。
- **快轴**：折射率**小**（光走得快）的那个主轴；另一个叫慢轴。

**4. 波片怎么改变偏振态（线偏振入射，振动方向与光轴夹 α）**

- **α = 0° 或 90°**：只有一个分量被激发 → 出射**仍是线偏振光**（波片只加了一个整体相位，不改变状态）。
- **α = 45° 过 λ/4 波片**：两分量等幅 + 相位差 π/2 → **圆偏振光**。
- **其他 α 过 λ/4 波片**：→ **椭圆偏振光**，椭圆的轴沿光轴与垂直光轴方向。
- **过 λ/2 波片**：相位差加 π → 出射**仍是线偏振光**，但振动方向相对光轴**镜像翻转**（相当于整体转过 2α）。
- **旋向反转**：右旋圆偏振过 λ/2 波片 → 两分量相位差由 +π/2 变成 +3π/2 ≡ −π/2 → 变成**左旋**。所以 λ/2 波片可以实现旋向反转（作业填空第 20 题）。

**5. 波片夹在正交偏振片之间（定量）**

> **I = I_in·sin²(2α)·sin²(δ/2)　（起偏器与检偏器正交，波片光轴与起偏器透振方向夹 α）**

- α = 45° 时：1/4 波片（δ = π/2）→ I = I_in/2；λ/2 波片（δ = π）→ 偏振方向被转过 90° → **完全通过**，I = I_in。
- 不放波片（δ = 0）→ I = 0，就是普通的正交消光。

这个装置的意义：本来全黑的正交偏振片之间，插一片晶体就有光了 → 可以用来**观察**晶体、测量应力分布（光弹性）、做电光开关。

**6. 易错清单**

- (1) o 光 ⊥ 主截面、e 光 ∥ 主截面 → 两束光振动方向互相垂直，所以它们**不相干**，不会自己干涉（要拿偏振片把它们投影到同一方向才会干涉）。
- (2) 波片只对**有偏振的光**起作用：自然光过 λ/4 波片**还是自然光**（相位本来就随机，加 π/2 仍随机）。
- (3) 波片的“快轴”是 n 小的方向，别记反。
- (4) λ/2 波片**不改变**线偏振的“线”性，只改变方向；λ/4 波片才可能把线偏振变成圆/椭圆偏振。

## 附录　本版更正的旧版错误

- 第十二次知识框架：相邻波节（或相邻波腹）间距是 **λ/2**，不是 λ/4；λ/4 是波节到相邻波腹的距离。
- 第十三次知识框架：**薄膜干涉属于振幅分割法**，不属于波阵面分割法（双缝、菲涅耳双面镜、洛埃镜才是）。
- 第十三次选择第 7 题：透射光相长的最小非零厚度为 **λ/(2n)**；λ/(4n) 对应反射相长/透射相消。
