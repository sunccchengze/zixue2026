## 记账规则（与概率论项目一致）

- 卡片表：`| # | concept | S(days) | D(1-5) | last | due | flags | history |`；
  新卡 Again 1.0 / Hard 1.5 / Good 3.0 / Easy 6.0，初始 D=3；复习 S×(Hard1.4/Good2.2/Easy3.0)；
  Again → S=max(1,S×0.3) 且 D+1；flags：cw=自信错、leech=累计4次Again（换角度重教不重考）；
- 到期卡优先于新内容；单次新卡 ≤7；history 记最近8档；会话内 Again/Hard 隔约3轮换形式重考；
- 每轮结束三件事：更新 topicNN 卡片 → 更新 HANDOFF（含下一句+判卷预案）→ git commit+push；
- 记忆熵降噪：LEARNINGS/ERRORS 单文件超约150行做同根因合并；只记可迁移模式不记流水账。
