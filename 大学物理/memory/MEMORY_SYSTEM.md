# 大学物理 · 记忆系统架构说明

> 结构与开局协议完全继承 `skills/科研式学习导师/SKILL.md` §3。

## 文件清单

| 文件 | 用途 |
|---|---|
| `HANDOFF.md` | 交接总账本（永远最新：进展/下一句该问什么/判卷预案/会话记录） |
| `LEARNINGS.md` | 本学科学习画像（跨学科画像以 `probability/memory/LEARNINGS.md` 为总源） |
| `ERRORS.md` | 判例库：通用红线（继承概率论）+ 大物专属用户判例 |
| `PROGRESS.md` | 18课题台账（⬜/🟡/✅+备注） |
| `drill-ledger/` | 间隔重复账本：index.md + topics/topicNN.md（简化FSRS，规则见SKILL §3） |

## 新会话开局协议（必须）

1. 读本文件夹 `HANDOFF.md`（进展+下一句）；
2. 扫 `LEARNINGS.md` / `ERRORS.md`（本学科）+ `probability/memory/LEARNINGS.md`（总画像）；
3. 查 `PROGRESS.md` + `drill-ledger/index.md`（到期卡）；
4. 先清到期卡，再从 HANDOFF"下一句"继续。不重新自我介绍、不重讲规则。

## 本学科特别约定（2026-08-17 用户开局指令）

- **只教下学期**（振动/波/光学/热学/量子）；上学期内容只做回顾钩子；
- **不以期末应试为目标**：目标是"一路进阶掌握到极致"——每课题验收标准可高于考纲
  （允许引入超纲的深挖，如波动方程推导、配分函数雏形、隧穿效应等），真题仅作掌握度体检；
- 路线图：`../科研式学习路线图.md`（18课题）；资料页码：`../资料映射.md`。
