## 真实历史分歧（叫他们吵一架，比单听一个讲值钱）

1. **牛顿 vs 麦克斯韦：超距作用 vs 场**——牛顿自己都承认"隔着真空施力"说不出口
   （"我不杜撰假说"），麦克斯韦用场+方程回应了这个悬了两百年的难堪。课题09 主戏；
2. **伽利略 vs 亚里士多德（隔空）**：重物落得快？——两千年权威 vs 一次测量。课题01-02 开场戏；
3. **牛顿 vs 费曼（隔空）**：几何式公理体系 vs "算出来对实验就是硬道理"——课题17 相对论里，
   牛顿的绝对时空怎么被实验裁决，两人立场正好对立；
4. **麦克斯韦 vs 费曼**：方程的优美 vs 图像的可讲性（费曼讲麦克斯韦方程专挑"物理图像"讲，
   还吐槽过教科书把电磁学讲成了公式操练）。课题05-09 的双声道。
