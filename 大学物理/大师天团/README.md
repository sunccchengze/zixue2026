## 历史真实分歧（可"让他们吵一架"的点）

- **玻尔兹曼 vs 当时的能量学派（马赫/奥斯特瓦尔德）**：原子到底存不存在？熵是统计的还是纯宏观的？
  ——讲课题15（熵的统计意义）时开吵最有价值。
- **麦克斯韦妖 vs 热二律**：麦克斯韦亲手造了挑战热二律的思想实验，玻尔兹曼-西拉德-兰道尔一路接招。
- **费曼 vs "光到底是波还是粒子"**：波动光学（杨/麦克斯韦阵营）与光量子（爱因斯坦/费曼QED）
