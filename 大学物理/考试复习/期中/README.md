## 每轮的闭环

先独立做题→标出卡点→只查相关V4/教材小节→自己对答案并记录错因→24–48小时后闭卷重做。
常规每轮约45分钟：做题30分钟、按需回查5分钟、核对复盘10分钟；没有卡点时回查时间可继续做题。完整模拟另给90分钟。若考试临近，按总计划7轮压缩，不省掉范围筛选和复盘。

状态说明：`未开始`→`进行中`→`已核对`→`已闭卷重做`；“已核对”不等于已掌握。
