# 课题01 · 机械振动 —— 开题简报

> 为什么千差万别的系统都在做"同一种运动"？本课题开工前已做微积分摸底（见 HANDOFF 批4题）。

## 研究背景（谁卡过）

伽利略在比萨大教堂吊灯下用自己的脉搏计时，发现摆"摆幅大小不同，来回时间却相同"
（等时性，两门新科学记载）。惠更斯据此造出摆钟，把航海经度误差从几百公里压到几十公里——
但人们随后发现**大摆角时等时性是假的**，这个"近似失效"逼出了简谐运动的严格定义。
更深的谜在后面：弹簧-物块、单摆、浮标、LC 电路、分子振动、晶体格点——材料完全不同，
方程却一模一样。这种运动的"指纹"是什么，是本课题的研究问题。

## 研究问题（一句话）

**为什么弹簧、摆、乃至一切"被拉离平衡就想回去"的系统，都在做同一种运动？
这种运动的通用身份证（方程）长什么样，证件上的三个字段 A、ω、φ 各归谁管？**

## 攻关线索（五站，路标不是答案）

1. **从胡克定律到方程**（回顾锚点：牛顿第二定律）：F=-kx + F=ma 怎么变成 x''=-(k/m)x？
   回复力的"回复"二字藏在哪里？
2. **猜解与验证**：什么样的函数二次求导后等于自己的负常数倍？（cos/sin 现身；
   微积分摸底在此上岗）验证一个解比背一个解可靠。
3. **A、ω、φ 的管辖权**：哪个由系统决定（k、m/g、L），哪些由初条件决定（怎么拉、怎么放）？
   ★本课题最大考点：ω 与 A 无关——摆幅砍半，周期不变（伽利略的脉搏发现的正是这个）。
4. **旋转矢量**：为什么画一个逆时针转的矢量就能代替三角函数运算？（2022期中T1-2 的提速工具）
5. **叠加的世界**：同频合成（相位差决定加强/减弱）、不同频（拍——调音师的耳朵）、
   2022期中真题 T1-2 实战。

## 里程碑（验收五项）

- [ ] **解释**：大白话讲清"回复力→简谐运动"和"A、ω、φ 各归谁管"（费曼检验）；
- [ ] **推导**：由 F=-kx 独立走到 x(t)=A cos(ωt+φ) 全链条，并用能量观点（E=½kA²）复验；
- [ ] **反例**：造两个"不是简谐运动"的情形（大摆角单摆 / 阻尼振动），说出简谐的边界在哪；
- [ ] **联系**：①说出振动是波的原材料（课题02 预告）；②能量观点=上学期机械能守恒的翻译；
      ③跨学科：LC 电路同方程（如有兴趣延伸）；
- [ ] **一页报告**：四段结构，存疑至少一条。
