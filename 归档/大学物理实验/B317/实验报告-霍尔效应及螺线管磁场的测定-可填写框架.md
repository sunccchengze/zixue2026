## 一、实验目的

1. 理解霍尔效应及霍尔电压的形成机制。
2. 验证霍尔电压 U_H 与霍尔控制电流 I_CH 的线性关系。
3. 验证霍尔电压 U_H 与励磁电流 I_M 的线性关系。
4. 用霍尔效应测量螺线管轴线上磁感应强度及其空间分布。
5. 通过电流与磁场换向的对称测量，减弱不等势电势差、温度不均匀等因素造成的系统影响。

## 二、实验原理（简述）

### 1. 霍尔效应与霍尔电压

霍尔元件中有工作电流 I_CH，磁感应强度 B 垂直于电流方向。载流子受洛伦兹力偏转，在元件横向积累电荷，形成霍尔电场 E_H。稳态时电场力与洛伦兹力平衡：

`e v B = e E_H`，且 `E_H = U_H/L_H`　（3.2.1）

其中 v 为载流子漂移速率，L_H 为霍尔电压两端的距离。设霍尔元件沿磁场方向的有效厚度为 d、载流子浓度为 n_c，则 `I_CH = n_c e v L_H d`。消去 v 得：

`U_H = R_H I_CH B/d = K_H I_CH B`　（3.2.5）–（3.2.6）

`R_H = 1/(n_c e)`，`K_H = R_H/d`。

R_H 为霍尔系数，K_H 为霍尔元件灵敏度。由 R_H 的符号可判断主要载流子类型；载流子浓度按系数的绝对值计算：`n_c = 1/(e |R_H|) = 1/(e |K_H| d)`。单位换算须使用 SI 制：I_CH 用 A、B 用 T、U_H 用 V、d 用 m。

### 2. 四极性反向测量

霍尔电压测量电极可能不在同一等势面，产生不等势电势差 U₀。依次改变工作电流和磁场方向，四种状态下的读数为：

`U₁ = U_H + U₀`（+I_CH，+B）；`U₂ = −U_H − U₀`（−I_CH，+B）；
`U₃ = −U_H + U₀`（+I_CH，−B）；`U₄ = U_H − U₀`（−I_CH，−B）。

因此：

`U_H = (U₁ − U₂ − U₃ + U₄)/4`　（3.2.8）

该组合可消除四次读数期间近似不变的 U₀。若 U₀ 在测量过程中漂移，或换向后电流未稳定，抵消不完全；故应记录原始 U₁–U₄，不只抄写计算后的 U_H。

### 3. 有限长螺线管轴向磁场

长度为 L_s、单位长度匝数为 n_s、通以励磁电流 I_M 的有限长螺线管，轴线上某点的磁感应强度可写为：

`B = μ₀ n_s I_M (cos β₂ − cos β₁)/2`　（3.2.9）

其中 β₁、β₂ 为该点与螺线管两端连线相对轴线的夹角。螺线管中心处：

`B₀ = μ₀ n_s I_M L_s/√(L_s² + D²) = μ₀ N I_M/√(L_s² + D²)`　（3.2.10）

μ₀=4π×10⁻⁷ H/m，D 为螺线管直径。若线圈尺寸参数未能从实物或实验室材料中确认，不得据此填造 B₀；应先补录 N、L_s、D 及其定义。

### 4. 数据关系与待求量

在霍尔元件位置固定时，B 与 I_M 成正比，因此 U_H 对 I_CH 和 I_M 均应近似线性。表 3-2-1 中固定 I_M=600 mA，通过 U_H−I_CH 拟合斜率 S_CH，并用螺线管中心场 B₀ 求 K_H：`K_H = S_CH/B₀`。之后计算 R_H 与 n_c。表 3-2-2 在 I_CH=6.00 mA 时改变 I_M，用作线性关系的独立验证。表 3-2-3 将四极性测得的 U_H 按 `B(x)=U_H(x)/(K_H I_CH)` 换算为磁场分布，并比较从左、右两侧扫描的结果。

## 四、数据处理与作图

### 1. 四极性计算

逐行代入：`U_H=(U₁−U₂−U₃+U₄)/4`。示例计算栏（须用本组第一行实测值替换）：

`U_H = (待填 − 待填 − 待填 + 待填)/4 = 待填 mV`

### 2. U_H−I_CH 拟合与 K_H

将表 3-2-1 的 I_CH 换算为 A、U_H 换算为 V，作 U_H−I_CH 图并作线性回归：

`U_H = S_CH I_CH + b_CH`，其中 `S_CH = 待填 V/A`，`b_CH = 待填 V`，`R² = 待填`。

螺线管中心场按实测/确认的参数计算。表格中的 `I_M=600 mA=0.600 A`：

`B₀,600 = μ₀ N × 0.600 / √(L_s² + D²) = 待填 T`

`K_H = S_CH/B₀,600 = 待填 m²/C`

若 U_H 以 mV、I_CH 以 mA 作图，斜率的数值单位为 mV/mA；该数值在转换为 V/A 后相同，但计算 B 和 K_H 时仍应明确单位。

### 3. U_H−I_M 拟合与线性验证

将表 3-2-2 的 I_M 换算为 A、U_H 换算为 V，作线性回归：

`U_H = S_M I_M + b_M`，其中 `S_M = 待填 V/A`，`b_M = 待填 V`，`R² = 待填`。

比较实测斜率 S_M 与 `K_H I_CH μ₀N/√(L_s²+D²)`（中心场模型预期斜率）；填写差异或相对偏差：`待填 %`。同时报告截距和拟合残差，不要仅凭曲线“看起来直”判断通过。

### 4. 霍尔系数与载流子浓度

记录霍尔元件厚度 `d=待填 m`。按教材定义：

`R_H = K_H d = 待填 m³/C`

`n_c = 1/(e |R_H|) = 1/(e |K_H| d) = 待填 m⁻³`

载流子类型根据四极性读数、接线方向和磁场方向的符号约定判断；报告中须写清采用的方向约定。若不能确认霍尔片有效厚度 d 或极性定义，应将相应结果标为“待确认”，不能用外形尺寸或猜测代替。

### 5. B−x 分布与左右扫描比较

对每个 x，先分别用四极性公式得到 U_H,left 与 U_H,right，再用同一 K_H 与 I_CH=5.00 mA 换算：

先将 `U_H` 从 mV 换为 V，再计算 `B_left(x)=U_H,left(x)/(K_H × 0.00500 A)`、`B_right(x)=U_H,right(x)/(K_H × 0.00500 A)`。

依仪器坐标与极性约定将左右扫描转换到一致的磁场方向后作 B−x 图。表格数据补齐后填写：最大场位置 `待填`；中心/参考点场 `待填 mT`；左右扫描最大相对差 `待填 %`。同一镜像位置的相对差可按 `δ_B=2|B_left−B_right|/(|B_left|+|B_right|)×100%` 计算（分母为零时不使用该式，单独报告绝对差）。

### 7. 不确定度与误差分析

仪器分辨率和几何参数不确定度需根据本次实际仪器标牌或实验室给定值填写，不在无依据时设定数值。若四次电压读数的不确定度相互独立，则：

`u(U_H)=√[u(U₁)²+u(U₂)²+u(U₃)²+u(U₄)²]/4`。

若四次读数具有相同标准不确定度 u(U)，则 `u(U_H)=u(U)/2`。由线性回归取得斜率不确定度 u(S_CH)，独立量近似下：

`u(K_H)/|K_H|=√[(u(S_CH)/S_CH)²+(u(B₀)/B₀)²]`

`u(R_H)/|R_H|=√[(u(K_H)/K_H)²+(u(d)/d)²]`，`u(n_c)/n_c=u(R_H)/|R_H|`。

中心场的不确定度可按独立参数传播：

`u(B₀)/B₀ = √[(u(N)/N)²+(u(I_M)/I_M)²+(L_s u(L_s)/(L_s²+D²))²+(D u(D)/(L_s²+D²))²]`。

B(x) 由 U_H、K_H、I_CH 传播；在三者相互独立的近似下，`u(B)/|B|=√[(u(U_H)/U_H)²+(u(K_H)/K_H)²+(u(I_CH)/I_CH)²]`。实际计算时应说明回归斜率、同一校准参数等共享量造成的相关性；若缺少仪器分辨率，报告数值不确定度为“待补”，不得臆造。

主要可能影响包括：霍尔片与螺线管轴线未对准、位置零点与读数误差、换向后读数未稳定、不等势电势差随时间漂移、工作电流/励磁电流波动、线圈温升、霍尔片有效厚度或线圈几何参数误差。讨论时应依据本组读数、拟合残差和左右扫描差异指出最主要的实际误差，而不是罗列后即当作已发生事实。
