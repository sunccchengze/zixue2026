# 待核工作区快照（不是当前版本）

本目录保存本轮同步分支前发现的未提交工作区快照。它不是已核实的旧稿，也不是当前交付依据，**状态：待逐项核对**；不得因为置于归档目录就认为文件无用、已过时或可删除。

- [清单.tsv](清单.tsv)列出 38 个文件的原路径、快照路径及 SHA-256：其中 5 个是当时已跟踪文件的未提交内容，33 个是未跟踪文件。
- 恢复来源是本地 `stash@{0}`（对象 `70e9492`）；以 `git show` 按原字节分别提取，目录结构保留在 `已修改/` 和 `未跟踪/` 中，不会覆盖现行文件。
- 当前仓库已从旧目录迁移至按课程分类的结构，部分文件可能与现行稿重复或存在差异；应先比较当前资产登记、Git 历史、哈希及内容，再决定是否迁移、合并、保留或删除。不能盲目 `stash pop`。
- 当前实验报告和预习报告以 `课程资产登记.json` 及各包生成的“当前版本”为准。本快照不覆盖它们；原始 stash 尚保留。
