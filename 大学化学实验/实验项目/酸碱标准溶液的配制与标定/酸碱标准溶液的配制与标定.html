OVERVIEW · 实验速览

今天这节课，到底要做什么？

一句话：先把 HCl 和 NaOH 配成"大概 0.1 mol/L"，再用基准物质把浓度"校准"到准确。这就是滴定分析的第一课，也是后面 EDTA 滴定、食醋总酸度测定等实验的地基。

1️⃣

粗配 HCl

由 6 mol/L 浓盐酸稀释出 500 mL 0.1 mol/L，装酸式滴定管对应的试剂瓶。

2️⃣

粗配 NaOH

托盘天平快速称约 2.0 g NaOH，用新煮沸放冷的水配 500 mL。

3️⃣

标定 NaOH

精确称 KHP ≈0.45 g ×3 份，酚酞指示，滴至粉红 30 s 不褪色。

4️⃣

标定 HCl

移取 NaOH 25.00 mL ×3 份，甲基橙指示，滴至黄变橙 30 s 不褪色。

🔑 一条主线贯穿全实验

物质的量才是滴定的主角：无论加多少水稀释锥形瓶里的溶液，n(酸) 与 n(碱) 的化学计量关系不变。所有误差分析，最后都归结为一句话——"这个操作让 n 或 V 往哪边偏了？"

为什么必须是这个顺序？KHP 是基准物质，能直接确定物质的量；NaOH 不能。所以先把 KHP 当"砝码"校准 NaOH（第一步），NaOH 拿到准确浓度后才有资格当"标准"去校准 HCl（第二步）。链条一环扣一环：第一步 V 读歪了，第二步全部跟着歪。
对应讲义「四、实验内容」第 3 条（NaOH 标定）→ 第 4 条（HCl 标定）；也对应下方步骤 3、4 和排序游戏的标准答案。
PART 01 · 背后的化学

为什么 HCl 和 NaOH 不能"直接配"标准溶液？

能直接法配标准溶液的物质叫基准物质，要求极苛刻。而 NaOH 和浓 HCl 恰好每条都不达标——不是它们"不够纯"这么简单，而是化学性质本身会和空气做生意。

🧱

NaOH 固体：又吸水、又吃 CO₂

① 吸湿性极强：表面很快糊一层 NaOH 溶液，你称到的是"NaOH + 水"；
② 吸收 CO₂：2NaOH + CO₂ → Na₂CO₃ + H₂O，固体里混入 Na₂CO₃，有效 NaOH 变少；
③ 因此 NaOH 的物质的量无法由称量值确定，只能先粗配、再标定。浓碱还会腐蚀玻璃活塞（生成硅酸钠使活塞粘连），所以碱液必须用碱式滴定管/橡皮塞。

💨

浓盐酸：氯化氢会"逃跑"

① 浓 HCl 有挥发性，开瓶后 HCl 不断逸出，浓度随时间下降；
② 它本身是混合物（恒沸组成约 20.2%），标签浓度只是"大概值"；
③ 所以只能用量筒按比例稀释成近似浓度，再用基准物质或已标定的 NaOH 反过来确定准确浓度。

直接法 vs 间接法（点一点，看看差别）

✅ 直接法 基准物质专属

流程：准确称量 → 溶解 → 定量转移 → 容量瓶定容 → 浓度直接算出。

公式： c = m / (M·V)
例子：称 0.4512 g KHP 于容量瓶定容 250.00 mL，c = 0.4512/(204.22×0.2500) 可直接算准。
前提：纯度 ≥99.9%、组成与化学式完全相符、性质稳定、定量反应、摩尔质量大。

🔧 间接法（标定法） 今天用的

流程：粗配近似浓度 → 用基准物质（或另一标准溶液）标定 → 算出准确浓度。

本实验两步标定：
① KHP（基准）→ 标定 NaOH 的准确浓度；
② 再用 NaOH（已知准确浓度）→ 标定 HCl。
关键：粗配时用托盘天平、量筒即可；标定时必须换万分之一天平、移液管、滴定管。

📖 讲义原文（实验原理 · 第一句）

"NaOH 易吸收空气中的水分和 CO₂，浓 HCl 易挥发，所以不能直接配制标准溶液，只能用间接法配制成近似浓度的溶液。然后用一级标准物质或另一已知准确浓度的标准溶液对其进行标定，计算出准确浓度。"

PART 02 · 核心原理

标定反应、计算公式、滴定突跃与指示剂

2.1 标定 NaOH：邻苯二甲酸氢钾（KHP）登场

邻苯二甲酸氢钾，化学式 KHC₈H₄O₄（也写作 KHP，摩尔质量 204.22 g/mol），分子中只有一个可被 NaOH 滴定的酸性氢，反应按 1:1 定量进行：

滴定反应（1 : 1）
KHC8H4O4 + NaOH → KNaC8H4O4 + H2O
n(NaOH) = n(KHP)  ⟹  c(NaOH) = m(KHP) / [ M(KHP) × V(NaOH) ]

为什么计量点选酚酞？产物 KNaC₈H₄O₄ 是强碱弱酸盐，A²⁻ 水解使计量点溶液显碱性（0.1 mol/L 体系约 pH ≈ 8.7~9.0），而酚酞变色范围 8.0~9.6 恰好落在突跃内——变色时离计量点只差半滴。

2.2 标定 HCl：酸碱"互相标定"

NaOH 浓度确定后，它就成了"已知准确浓度的标准溶液"，反过来滴定 HCl：

互相滴定
H+ + OH− → H2O
c(HCl) × V(HCl) = c(NaOH) × V(NaOH)  ⟹  c(HCl) = c(NaOH)·V(NaOH) / V(HCl)

操作上：移液管准确移取 25.00 mL NaOH 于锥形瓶，加甲基橙 1~2 滴，用 HCl 滴定至黄色变为橙色且 30 s 不褪色。

2.3 滴定突跃：终点敢"半滴定生死"的底气

讲义数据：用 0.1000 mol/L NaOH 滴定 20.00 mL 0.1000 mol/L HCl，化学计量点 pH = 7.0；计量点前后 ±0.1%（即 19.98~20.02 mL）pH 由 4.30 猛增到 9.70——这个几乎垂直的 pH 突变就是滴定突跃（范围 pH 4.30~9.70）。变色范围落在突跃范围内的指示剂都能用：甲基橙(3.1~4.4)、甲基红(4.4~6.2)、酚酞(8.0~9.6)。

PART 03 · 基准物质

为什么偏偏是邻苯二甲酸氢钾？

讲义给出基准物质的 5 项要求。先把标准立起来，再看 KHP 如何"全科满分"。

3.1 基准物质五大铁律

① 高纯度

质量分数 ≥ 99.9%，杂质不干扰滴定。

② 组成确定

组成与化学式完全相符；含结晶水时结晶水数目必须严格一致。

③ 性质稳定

不吸水、不失水、不被空气氧化，不与 O₂/CO₂ 反应。

④ 定量反应

按反应式定量进行、无副反应，反应速率快。

⑤ 摩尔质量大

M 越大，称量相对误差越小（Δm/m 被"稀释"）。

🏆 KHP 战绩

纯度高易提纯 · 不吸湿稳定 · M = 204.22 已算大 · 一元酸性氢 1:1 反应 · 水中溶解度好。附表6 标注：干燥 110~120 ℃，标定对象"碱"。

⚠️ KHP 使用前必须"干燥至恒量"

讲义要求：基准 KHP 先在烘箱 105~110 ℃ 烘干至恒量，保存于干燥器中冷却后称量。恒量＝连续两次烘干、冷却、称量，质量差不超过 0.2~0.3 mg。若 KHP 含水，称得的 m 偏大？不——含水时"m(KHP)"里有水，实际 n(酸)偏少，滴定耗 V(NaOH) 偏小，算出的 c(NaOH) 偏高。细节见【误差分析】。

4.4 酸式 vs 碱式滴定管：一眼分辨

🔵 酸式滴定管（装 HCl）

  • 下端是玻璃活塞：用凡士林涂油、橡皮圈固定活塞
  • 检漏：装水夹持 10 min，活塞转 180° 再试
  • 赶气泡：迅速开大活塞，溶液冲出带走气泡
  • 握法：左手拇指、食指、中指控活塞，手心向内凹，防顶出活塞

🟢 碱式滴定管（装 NaOH）

  • 下端是乳胶管 + 玻璃珠（碱会粘死玻璃活塞）
  • 操控：拇指与食指挤玻璃珠旁乳胶管，留缝隙出液
  • 赶气泡：乳胶管向上弯曲，捏起使溶液从尖嘴喷出
  • 禁忌：不能捏玻璃珠下部乳胶管（会产生气泡）

🧠 记忆钩子

"酸塞碱珠"——酸式用活塞（酸不腐蚀玻璃），碱式用玻璃珠+胶管（碱会咬死活塞）。今天两根滴定管都要用：NaOH 进碱管，HCl 进酸管。

实验步骤超详解：一步一步跟着做

四大步骤与讲义「四、实验内容」逐字对应。每一步都展开：做什么 → 为什么 → 易错点。先算后做，数据要当场记录。

🧮 交互 ⑤ 配液计算器（动手前先算准）

酸液稀释：算量取多少 6 mol/L HCl

c₁V₁ = c₂V₂
V₁ = 8.33 mL → 用量筒量取，倒入试剂瓶再加水至 500 mL

碱液粗配：算称多少 NaOH 固体

m = c·V·M
m(NaOH) = 2.00 g → 托盘天平迅速称取（NaOH 吸湿吸 CO₂）
💬 讲义口径：HCl 用量筒量取后"倒入试剂瓶中，加去离子水稀释至 500 mL"；NaOH 在烧杯中用 50 mL 新煮沸放冷的水溶解，冷却后再转移稀释。
1
0.1 mol/L HCl 溶液的配制▼

操作

  1. 计算所需 6 mol/L HCl 体积：V = 0.1×500/6 ≈ 8.3 mL。
  2. 用 5 mL/10 mL 量筒（或讲义的量筒规格）量取 8.3 mL 浓 HCl，沿瓶壁倒入 500 mL 试剂瓶。
  3. 加去离子水稀释至 500 mL，盖塞摇匀，贴标签（名称、浓度 0.1 mol/L、日期、配制人）。

为什么

浓 HCl 挥发、浓度不确知，所以只能配"近似 0.1 mol/L"，准确值留给后面标定。稀释计算 c₁V₁=c₂V₂ 只需量筒级精度。

易错点

  • 浓 HCl 有刺激性挥发气体——在通风处量取，量筒量后尽快倒入。
  • 标签必须当场贴：无标签溶液=废液。
  • 玻璃塞试剂瓶可用于酸液；但注意瓶塞与瓶口配套。
2
0.1 mol/L NaOH 溶液的配制▼

操作

  1. 计算：m = 0.1×0.5×40.00 = 2.0 g。
  2. 托盘天平迅速称取 2.0 g NaOH 于 100 mL 烧杯（暴露越短越好）。
  3. 加 新煮沸放冷的去离子水约 50 mL，搅拌溶解（放热！）。
  4. 冷却至室温后转移到 500 mL 试剂瓶，加水稀释至 500 mL。
  5. 塞橡皮塞（不能用玻璃磨口塞），摇匀，贴标签。

为什么水要"新煮沸放冷"？

去离子水中溶有 CO₂，会与 NaOH 生成 Na₂CO₃：2NaOH + CO₂ → Na₂CO₃ + H₂O，使溶液含碱性杂质、标定结果失真。煮沸驱逐 CO₂，放冷避免热溶液造成体积误差与容器炸裂风险。

易错点

  • NaOH 溶解放热，必须冷却后再转移/稀释（热液体积不准）。
  • 用玻璃塞长期存放→生成硅酸钠把塞子"焊死"。橡皮塞！
  • 称量动作慢吞吞→固体吸水+吸 CO₂，称量值失去意义（粗配虽容忍，也别离谱）。
3
0.1 mol/L NaOH 的标定（KHP，酚酞）★ 今日核心▼

操作（平行 3 次）

  1. 万分之一电子天平，差减法准确称取已干燥至恒量的 KHP 约 0.45 g（0.44~0.46 g），置于 250 mL 锥形瓶。记录质量到 0.0001 g！三份样品在三只锥形瓶中编号 Ⅰ、Ⅱ、Ⅲ。
  2. 加新煮沸放冷的去离子水 50 mL，轻摇至完全溶解（KHP 溶解稍慢，务必全溶）。
  3. 加酚酞 1~2 滴（0.1% 乙醇溶液），此时溶液无色。
  4. 用 NaOH 溶液（碱式滴定管）滴定：先快后慢，接近终点时一滴一滴、必要时半滴，摇匀。
  5. 终点：溶液呈粉红色，30 s 内不褪色。记录 V(NaOH) 终读数。
  6. 每次滴定结束把液面补到零点附近再做下一份（减少读数系统误差）。
  7. 3 份完成后计算 c(NaOH)ᵢ、平均值 c̄ 与相对平均偏差。

为什么

KHP 是基准物质，n 已由称量精确确定；滴定消耗的 V 由滴定管读出（0.01 mL）。c = m/(204.22×V)。计量点生成 KNaC₈H₄O₄，水解显碱性（pH≈8.7~9.0）→ 选酚酞。"粉红 30 s 不褪色"= 终点后空气 CO₂ 中和过量碱的速度判定，标准的"30 s 规则"。

易错点

  • KHP 没全溶就滴→结果无意义；水少加了可以补，不必重称。
  • 酚酞加 3~4 滴→指示剂本身耗碱+颜色过深难判终点（思考题③）。
  • 终点滴成"深桃红"→过了，V 偏大，c 偏低。理想：淡粉红。
  • 读数前等 1 min 让挂壁液流下；视线与弯月面最低点同高。
4
0.1 mol/L HCl 的标定（甲基橙，互相标定）▼

操作（平行 3 次）

  1. 洗净的 25 mL 移液管用待取 NaOH 润洗 2~3 次（每次 5 mL 左右），洗耳球吸液。
  2. 准确移取 NaOH 溶液 25.00 mL 于 250 mL 锥形瓶（尖嘴靠壁、放液 3 s、残尖不吹）。
  3. 加甲基橙 1~2 滴，此时溶液黄色（NaOH 碱性）。
  4. 用 HCl（酸式滴定管）滴定，边滴边摇；黄色变为橙色且 30 s 不褪色即终点。
  5. 记录 V(HCl)，平行 3 次；计算 c(HCl) = c(NaOH)×25.00/V(HCl)，求平均值与相对平均偏差。

为什么

NaOH 已被 KHP 标定，浓度准确已知→成为"标准溶液"去标定 HCl。强酸强碱滴定突跃 4.30~9.70，甲基橙变色范围 3.1~4.4 刚好擦进突跃下沿：颜色由黄经橙转红，以"橙色 30 s 不褪"为终点（不要滴到红！）。

易错点

  • 移液管没润洗→取出的 NaOH 被管内水稀释，n 偏小。
  • 锥形瓶不能用 NaOH 润洗！只用自来水+去离子水洗净即可（瓶内残留水无影响）。
  • 甲基橙终点从黄→橙，若变红说明 HCl 过量，读数偏大。
  • 移液管放液后尖嘴残留液不吹（移液管标定已考虑残液）。

PART 06 · 手上功夫

滴定操作精讲：让 0.01 mL 都算数

6.1 滴定管使用七步曲（讲义 2.7 节浓缩）

准备阶段

  1. 检漏：装水夹持 10 min，活塞转 180° 再试；滤纸试活塞处。
  2. 润洗：待装液润洗 2~3 次，每次 5~10 mL，润洗液从尖嘴放出（防稀释标准液）。
  3. 装液赶气泡：酸式猛开活塞冲气；碱式弯胶管喷液。
  4. 调零：补液至 0 刻度以上，逐滴调至 0.00；读初读数。

滴定与读数

  1. 手势：左手控阀/珠，右手腕力旋摇锥形瓶，瓶下垫白瓷板。
  2. 速度："成串不成线"；开始每秒 3~4 滴，近终点逐滴，最后半滴。
  3. 半滴：悬而不滴→靠瓶壁沾下→洗瓶冲内壁→摇匀。
  4. 读数：等 1 min，弯月面最低点与视线同高，读到 0.01 mL（如 24.60）。

6.3 交互 ⑧ 半滴操作动画

半滴 = 终点的最后武器

当一滴就会过量时，改用半滴：

  1. 控制活塞使液滴悬而不滴（挂在尖嘴上）；
  2. 用锥形瓶内壁轻轻一靠，把这"半滴"沾下来；
  3. 用洗瓶少量去离子水冲洗内壁，摇匀；
  4. 颜色 30 s 不褪即终点。
半滴体积约 0.02 mL，正是滴定管读数的最小刻度级别——好终点是"抠"出来的。

⚠️ 操作纪律（讲义注意事项浓缩）

  • 装液前必须润洗滴定管 2~3 次 → 防稀释。
  • 滴定前检查尖嘴气泡并排除 → 防体积虚高。
  • 近终点勤摇、慢滴、看色变"由慢到快"，防滴过。
  • 每次滴定结束将标准液补至零点附近再做下一份。
  • 平行 3 次；原始数据当场记，不能追记、不能涂改（错划一条线）。
PART 07 · 数据处理

从原始数据到报告：算得对，还要算得"好看"

7.1 三组核心公式

① 标定 NaOH（KHP）
c(NaOH)i = mi(KHP) / [ 204.22 g/mol × Vi(NaOH) ]
（m 以 g、V 以 L 计；若 V 用 mL：c = 1000 m / (204.22 V)）

② 标定 HCl（互相滴定）
c(HCl)i = c(NaOH) × V(NaOH) / V(HCl)i ，其中 V(NaOH) = 25.00 mL

③ 精密度：相对平均偏差
d̄ = ( Σ |ci − c̄| ) / n  ;  相对平均偏差 = (d̄ / c̄) × 100% ， n = 3

相对平均偏差反映的是精密度（平行数据之间贴不贴），不是准确度。一般要求 ≤ 0.2%（以任课教师要求为准）；超了要找原因、重做。

PART 08 · 误差分析

交互 ⑩ 误差判断训练营：偏高、偏低，还是无影响？

统一情境：NaOH 标定中 c(NaOH) = m(KHP)/[M·V(NaOH)]（V 在分母），HCl 标定中 c(HCl)=c(NaOH)·25.00/V(HCl)。先想清楚"谁变了、在分子还是分母"，再下结论。

得分 0 / 8

💡 万能分析框架（三步）

① 这个操作改变的是 n（物质的量） 还是 V（读数）？——加水不改 n；润洗不当改浓度/读数。
② 变化量出现在公式分子还是分母？
③ 结论：分子变大→结果偏高；分母变大→结果偏低。同向变化时用"实际 vs 计算"对比最快。

PART 09 · 思考题

讲义思考题 · 附参考答案（点击展开）

Q1
滴定管为什么先要用待装溶液润洗 2~3 次？锥形瓶是否需要预先干燥？是否要用标准溶液润洗？▼

润洗滴定管：滴定管洗净后内壁残留去离子水，会稀释装入的标准溶液，使其浓度低于标签/标定值，滴定时消耗体积偏大，导致结果产生系统误差。用待装液润洗 2~3 次使内壁附着的液体与待装液浓度一致。

锥形瓶不必干燥：滴定按物质的量反应，瓶内残留少量水不改变待测物/样品的 n，只改变浓度，对结果无影响。

锥形瓶绝不能用标准液（或待取液）润洗：润洗会使瓶内壁额外附着 NaOH（或样品），等于悄悄增加了物质的量，滴定结果偏高。

Q2
判断下列情况对实验结果有无影响：①滴定中往锥形瓶加少量水；②终点后立即读数；③滴定后尖嘴有气泡/残留液滴▼

① 加水：无影响。水不改变 n(KHP) 或 n(NaOH)，化学计量关系只看物质的量；稀释反而有利于观察颜色。

② 立即读数：有影响。滴定刚结束时管壁还挂着液膜未流下，液面略高于平衡位置，读数偏小（V 偏小）。应垂直静置约 1 min 再读数。

③ 尖嘴气泡/液滴：有影响。若滴定前尖嘴有气泡、滴定后消失，气泡体积被算进了消耗体积，V 读数偏大；若滴定后尖嘴挂有液滴未计入锥形瓶，这部分体积已离开滴定管却未参与反应，也使 V 相对偏大。两种情况在 NaOH 标定中都使 c = m/(M·V) 偏低。

Q3
酸碱滴定中指示剂用量能否多加？为什么？▼

不能多加。指示剂本身多是有机弱酸或弱碱（酚酞是弱酸），会参与质子转移、消耗滴定剂；用量过多会带来额外的终点误差。同时指示剂过量会使颜色过深，终点变色不敏锐、难以判断"刚好变色"。一般 1~2 滴足矣。
