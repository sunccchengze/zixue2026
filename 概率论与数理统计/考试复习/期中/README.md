## 每轮的闭环

先闭卷说出本模块知识→只翻卡住的PPT页→做原题/模拟→自己对答案→记录错因→24–48小时后重做。
常规每轮约45分钟；完整模拟另给90分钟。若考试临近，按总计划7轮压缩，不省掉范围筛选和复盘。

状态说明：`未开始`→`进行中`→`已核对`→`已闭卷重做`；“已核对”不等于已掌握。
