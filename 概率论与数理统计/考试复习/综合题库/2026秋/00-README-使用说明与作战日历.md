## 四、满分路线：这套卷子的分是怎么构成的（先看结论）

按 2010–2020 十一年 + 2023 真卷共 12 套统计（详见 01）：

| 板块 | 典型分值 | 难度 | 你要做到 |
|---|---|---|---|
| 第1章 事件与概率（含贝叶斯大题） | 10–15 | ★★ | 全对（模板 M1–M3） |
| 第2章 一维随机变量与函数分布 | 10–15 | ★★★ | 全对（M5–M7） |
| 第3章 随机向量（联合/边缘/条件/函数） | 15–20 | ★★★★ | 只允许丢 2–3 分（M9–M11） |
| 第4章 数字特征（含协方差） | 10–15 | ★★★ | 全对（M8、M12） |
| 第5章 大数定律与 CLT | 8–10 | ★★ | 全对（M18） |
| 第6章 抽样分布 | 6–15 | ★★★★ | 全对（M13，纯套路） |
| 第7章 参数估计（点+区间） | 15–20 | ★★★ | 全对（M14–M16，纯套路） |
| 第8章 假设检验 | 10–15 | ★★★ | 全对（M17，纯套路） |

**结论一句话**：统计部分（第6–8章）≈ 40 分、几乎全是**可背诵的套路**，是"满分保险区"；
概率部分的二维综合题（14 分）是唯一的"高难单人题"，其余都是模板题。
**丢分从来不是因为不会，而是因为**：区间长度忘取整、自由度用错、分位数方向反、不相关当成独立、检验结论写成"证明了"。

## 五、包里三处"只有这份文件里有"的发现

1. **三套真题被三重收录**：`2019年秋` = MOOC 模拟题（四）2020.6；`2019年春` = MOOC 模拟题（一）2019.1；`2020年秋` = MOOC 模拟题（五）2021.1。
   这三套在真题集、答案集、MOOC 集里各出现一次——命题人自己最顺手的三副骨架（见 01 §5）。
2. **2021 年 4 班模拟卷是"考研改编卷"**：第 1 题（2018 数一#7）、第 2 题（2019 数三#7）、第 3 题（2020 数一#7）、第 4 题（2021 数一#8）、第 5 题（2018 数三#5）……
   它**不代表本校风格**，但里面的 8 道大题（较短一段/长一段、Z=XY、条件密度、成对数据…）是"拔高题源"，冲刺用（见 02B/02C 标注）。
3. **真题与你自己的作业同源**：真题 2016 单选 4"0–9 抽 4 个排成首尾非 0 的奇数 = 41/90"，
   正是你 9.22 作业第 20 题（4 位偶数排列穷举 41/90）的镜像——**老题就是会换个方向再考一次**（见 01 §6）。
4. **期末的"平时 10% 必须项"就是仓库里那两本 MOOC 卷**：课堂 PPT 写明平时成绩含「MOOC 课程测试（**必须**）」，
   而《概率论期末考试题（mooc）（2019-2023）》与《概率论期中考试题（mooc）（2018-2024）》正是该 MOOC 的真题/模拟题集合——
   **刷它们不只是备考，同时也在保平时分**（2023 真卷就是 MOOC 模拟（九）2023.2 的同构卷，本包已核）。
5. **官方答案册勘误清单（逐条回原卷复核，2026-10-15）**——考场一律"按卷面数据、把式子写全"：
   | 条目 | 官方答案 | 按数据复算 |
   |---|---|---|
   | 2011 填空 2（X=有球杯数，P{X=2}） | 2/9（其实是 P{X=3} 的计数） | **2/3** |
   | 2011 填空 6（X~N(3,4), n=4） | 0.4772（把 σ 当 2，忘了 ÷√n） | **0.5** |
   | 2010 填空 1 | 1/2（卷面数据缺条件） | 按其解法（P(AB)=0.4、P(B̄\|A)=0.2）**1/2** |
   | 2010 解答 7(3) 区间 | (−0.2052, 2.052) | **(−0.2052, 2.0052)** |
   | 2014 解答 10（座位数 n） | 12073（与自列公式矛盾） | **12114** |
   | 2014 解答 12(2) F 值 | 1.228 | **1.2418**（= 11.3/9.1） |
   两条"看着像错、其实官方对"的（别自己改）：**2011 填空 4** E(2^X−1) = (0.9+0.2)³−1 = **0.331** ✓；
