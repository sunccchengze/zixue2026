# 课题 05 · 随机变量的函数：变换之后的世界（卷积） · 研究报告

> 作者：自学生 · 2026-08-17 · 导师批注版（批注见文末）

---

## 1. 我研究的问题

**两个独立随机变量之和，等于两个分布做一次"卷积"——离散数格子，连续量线段。**

---

## 2. 我的核心思路

我的起点是一次"超额交卷"：导师问"两个骰子和为 7 有几种拆法"，我答出了 6 种，
然后顺手把和 2~12 的**全表**都列了出来：

> 1, 2, 3, 4, 5, 6, 5, 4, 3, 2, 1（各除以 36）

后来才知道，这张表有个大名：**三角形分布**，它就是两个均匀分布的**离散卷积**。
"超额"不是浪费——那正是卷积的定义自己从手里长出来的样子。

这条线串起了全程：

- **离散数格子**：P(X₁+X₂ = k) = Σᵢ P(X₁=i)·P(X₂=k−i)——把所有拆法扫一遍，每步连乘再相加；
- **连续量线段**：f_Z(z) = ∫ f_X(x)·f_Y(z−x) dx——同一个动作换成密度；
- **变换揉捏空间**：Y = X² 把 0 附近的小数压成超小数，密度 1/(2√y) 在 0 处**爆炸**；
  Y = √X 反过来把小数拉开，密度 2y 在 0 处**归零**。X=0.5 被压到 Y=0.25 那一刻，
  我亲眼看见"均匀"在函数手术下变形；
- **连乘的来历**：独立时，特定拆法 (x, z−x) 同时发生的密度 = f_X(x)·f_Y(z−x)——
  拆法本身也要付概率，这就是连乘的出处；
- **两个积分分家**：∫f_Z(z)dz 对 z 扫，得累积 F（帐篷总面积=1，公理二）；
  ∫f_X(x)f_Y(z−x)dx 对 x 扫，得一个点的高度 f_Z(z)。**f 是高度，F 是面积。**

---

## 3. 我的结论

### 三件套：一个计算引擎的三面

**（一）累积事件法——函数手术的标准流程**

Y = g(X) 的分布，先写累积、再求导（先 F 后 f）：

- Y = X²（X~U[0,1]）：F_Y(y) = P(X² ≤ y) = P(X ≤ √y) = √y → f_Y(y) = 1/(2√y)；
- Y = √X：F_Y(y) = P(√X ≤ y) = P(X ≤ y²) = y² → f_Y(y) = 2y。

平方压缩 → 0 处密度爆炸；开方拉伸 → 0 处密度归零。**变换揉捏概率空间，密度跟着变形。**

**（二）卷积——独立和的双重奏**

- 离散：P(X₁+X₂ = k) = Σᵢ P(X₁=i)·P(X₂=k−i)；
- 连续：f_Z(z) = ∫ f_X(x)·f_Y(z−x) dx；
- U[0,1] 两个独立和：f_Z(z) = z（z≤1）、2−z（z≥1）——**帐篷（三角分布）**，峰值 z=1；
- 骰子全表 1,2,3,4,5,6,5,4,3,2,1 就是帐篷的台阶版：离散数格子、连续量线段，同一个动作。

**（三）密度与概率的分家**

- f 是**高度**，F 是**面积**，F′ = f（课题04 自产的关系）；
- 密度可以 >1（U[0,0.5] 的 f=2），可以在一点爆炸——密度是浓度，不是概率；
- 两个积分各有其职：∫f_Z dz 对 z 扫 → 累积 F；∫f_X·f_Y dx 对 x 扫 → 单点高度 f_Z(z)。

### 实验证据（数字，全部可重算）

- 双骰全表：1,2,3,4,5,6,5,4,3,2,1 / 36；和=7 → 6/36 = 1/6；
- 帐篷高度：f_Z(0.2)=0.2、f_Z(1.0)=1.0、f_Z(1.7)=0.3；
- 帐篷面积：F_Z(0.2)=0.02、F_Z(1.0)=0.5、F_Z(1.7)=1−(0.3²)/2=0.955；
- 双向变换：Y=X² 的 f=1/(2√y)；Y=√X 的 f=2y；
- 总面积验算：∫₀¹ z dz + ∫₁² (2−z) dz = 1（公理二）。

## 4. 我还存疑的地方

1. **密度在一点"爆炸"**：1/(2√y) 在 y→0 时趋于无穷。无穷大的浓度，到底该怎么理解？
   概率论允许函数在一点是无穷大，却要求它积出来还是 1——这两者怎么调和？
2. **卷积为什么要求独立**：连乘 P(A∩B)=P(A)P(B) 是独立才有的特权。如果 X₁、X₂ 不独立，
   "和的分布"还能不能求？会变成什么？
3. **帐篷什么时候变成钟形**：两个均匀和的形状是帐篷，不是正态。那要多少个独立和、
   什么样条件下，形状才会长成钟形？——听说这就是课题10 的中心极限定理。
