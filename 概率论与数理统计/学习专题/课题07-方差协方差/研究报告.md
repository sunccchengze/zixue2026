# 课题 07 · 方差与协方差：怎么量化"分散"和"相关"？ · 研究报告

> 作者：自学生 · 2026-08-17 · 导师批注版（批注见文末）

---

## 1. 我研究的问题

**怎么给"分散"和"相关"这两个日常词装上数学的刻度尺：方差、标准差、协方差、相关系数。**

---

## 2. 我的核心思路

我的起点是课题06 留下的那道裂缝：E(X²) = 91/6 ≠ (EX)² = 12.25，差 35/12。
这个差就是**方差**——而它的真身是"到重心的平均平方距离"。

两条线索串起全程：

- **(x+y)² 的类比就是真相**：Var(X+Y) = Var(X) + Var(Y) + 2Cov(X,Y) 的展开，
  和完全平方公式逐项对应——方差是二阶矩，协方差就是交叉项 2xy。
- **亲手拆掉一个流传最广的错觉**：X ~ U[−1,1]、Y = X²。E(X³)=0（奇对称），
  所以 Cov(X,Y) = 0、ρ = 0；但 Y 由 X 完全决定——**不相关 ≠ 独立**。
  讲义易错点第 6 条，在我手里过了三遍（E(XY)、E(X³)、0÷(σXσY)）才钉死。

---

## 3. 我的结论

**（一）方差：平均平方距离**

- Var(X) = E[(X−μ)²] = E(X²) − μ²（线性性一拆就通）；
- 标准差 σ = √Var——回到原单位；
- 骰子：Var = 35/12 ≈ 2.917，σ ≈ 1.71 点；U[0,1]：Var = 1/3 − 1/4 = 1/12；
- U[−1,1]：Var = 1/3（注意：E(X)=0 不等于 σ=0——重心在原点 ≠ 没有波动；σ=0 只发生在常数）。

**（二）线性变换与独立和——分散化的数学**

- Var(aX+b) = a²·Var(X)：平移不散，放大散 a² 倍；
- Var(X+Y) = Var(X) + Var(Y) + 2Cov(X,Y)；独立 ⟹ Cov=0 ⟹ 直接相加；
- 对照实验：两个独立骰子和 Var = 35/6 ≈ 5.83；同一个骰子 2X 的 Var = 35/3 ≈ 11.67。
  **同步的波动互相放大，独立的波动互相抵消**——"不把鸡蛋放一个篮子"的原理。

**（三）协方差与相关系数——只测"线性"的尺子**

- Cov(X,Y) = E(XY) − E(X)E(Y) = E[(X−μX)(Y−μY)]；
- ρ = Cov(X,Y)/(σX·σY) ∈ [−1, 1]（|Cov| ≤ σXσY，柯西-施瓦茨）——按各自尺寸归一化的纯比例；
- ρ 的几何：点云在四个象限的分布。一三象限居多（大配大、小配小）→ 正；二四象限居多 → 负；
  摊平 → 0。ρ=±1 ⟺ 完美直线关系；
- **术语红线**：数学里"不相关"的定义就是 Cov=0（ρ=0）。日常说的"还是有关系"在数学里叫
  "不独立"。正确链条：独立 ⟹ 不相关；不相关 ⇏ 独立（Y=X² 反例）。
  ρ 只能感知**线性**关系，感知不到抛物线、圆这类高阶关系。

### 实验证据（数字，全部可重算）

- 骰子：Var = 35/12，σ ≈ 1.71；
- U[0,1]：Var = 1/12；
- U[−1,1]：E(X²)=1/3、E(X³)=0、E(X⁴)=1/5 → Var(X)=1/3、Var(X²)=4/45、Cov=0、ρ=0；
- 独立骰子和：Var = 35/6；2X：Var = 35/3；
- Var(3X−2) = 9×(35/12) = 105/4 = 26.25；
- Var(X)+Var(Y) = 4+9 = 13（独立时），ρ = 0/6 = 0。

---

## 4. 我还存疑的地方

1. ρ=0 之外，"非线性相关"怎么量化？Y=X² 和 X 的关系明明铁一样硬，ρ 却给 0——
   有没有别的尺子能测出这种关系？
2. 方差要求 E(X²) 有限——柯西分布连期望都没有，"分散程度"对它就说不出口。
   这种分布真的存在吗？长什么样？

## 导师审稿意见（2026-08-17，归档备终审）

**① 柯尔莫哥洛夫（下次必考）**：Var(X) 的定义依赖 E(X²)<∞。柯西分布 f(x)=1/(π(1+x²))
连 E|X| 都不收敛——你存疑②的答案是"存在，且是重尾家族的族长"。必考：写出
E|X| = ∫|x|f(x)dx = ∞ 的发散理由（提示：|x|/(1+x²) ~ 1/|x|，对数发散）。

**② 费勒（要你记住）**：你被 E(X²)≠(EX)² 咬的那一口和今天的 Y=X² 反例是同一件事的
两面——**函数和平均的交换只在线性时免费**。这条缝会陪你走到课题15（条件期望）。

（马科维茨组合理论）。记住那句话：**同步的波动相加，独立的波动相消。**

**④ 杰恩斯（预告）**：你的存疑①在统计学里有专名——"相关性不意味着线性"。更高阶的尺子
