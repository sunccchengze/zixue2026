# 课题 08 · 矩生成函数 / 特征函数：概率论的计算引擎 · 研究报告

> 作者：自学生 · 2026-08-17 · 导师批注版（批注见文末）

---

## 1. 我研究的问题

**怎么把"分布"整个打包成一个函数，让求矩、求和分布变成机械操作：M(t) 与 φ(t)。**

---

## 2. 我的核心思路

我的起点是物理借来的词：**矩**。一阶矩 E(X) 是重心（骰子 3.5），二阶矩 E(X²)
是转动惯量（骰子 91/6）——而方差 = 绕重心的转动惯量，正是物理的平行轴定理。

两个函数登场：

- **M(t) = E[e^{tX}]**：投币取矩的自动售货机——M′(0)=E(X)，M″(0)=E(X²)，
  一般 M⁽ᵏ⁾(0) = E(Xᵏ)（求导代 0，e^{tX} 的导数 Xᵏe^{tX} 代 0 剩 Xᵏ）；
- **φ(t) = E[e^{itX}]**：M 的孪生兄弟，但 |e^{itX}|=1 恒有界，**任何分布都存在**。

**三位一体**（课题05-08 的会师）：分布做**卷积**（05）、期望做**加法**（06）、
**M(t)/φ(t) 做乘法**（08）——独立和的三步链：

> M_{X+Y}(t) = E[e^{t(X+Y)}] = E[e^{tX}·e^{tY}] = E[e^{tX}]·E[e^{tY}] = M_X(t)·M_Y(t)

指数律 + 独立的期望可拆，把"分布层面"的复杂问题变成"函数层面"的乘法。

---

## 3. 我的结论

**（一）矩族**

- 一阶矩 = 重心 = E(X)；二阶矩 = 惯性 = E(X²)；方差 = 绕重心的惯量；
- 柯西分布 f(x)=1/(π(1+x²))：尾巴如 1/x² 般肥，E|X| = ∫|x|f(x)dx 对数发散
  → 期望不存在，"公平价格"定不出来，矩族全线失守。

**（二）M(t)——矩的自动售货机**

- M(t) = E[e^{tX}]；M⁽ᵏ⁾(0) = E(Xᵏ)；
- 验算：骰子 M(t) = (eᵗ+…+e⁶ᵗ)/6，M′(0) = 21/6 = 3.5 ✓；
- 伯努利 M(t) = peᵗ+(1−p)，M′(0) = p ✓；
- 独立和：M_{X+Y} = M_X·M_Y（卷积变乘法）；
- **局限**：柯西分布 M(t)（t≠0）不存在——e^{tx} 指数爆炸快过 1/x² 尾巴衰减。

**（三）φ(t)——永远能上桌的那个**

- φ(t) = E[e^{itX}]；|e^{itX}| = 1 恒成立 → 期望永远收敛 → **所有分布都有 φ**；
- 这就是课题10（中心极限定理）请 φ 出场的根本原因：证明要对"任意分布"操作，
  只有 φ 保证存在。它把独立和变成乘积：φ_{X+Y} = φ_X·φ_Y。

### 实验证据（数字，全部可重算）

- 骰子 M′(0) = 3.5（六项导数代 0 求和）；
- 伯努利 M′(0) = p；
- 柯西：∫₀^∞ x/(1+x²)dx = ∞（对数发散）。

## 导师审稿意见（2026-08-17，归档备终审）

**① 柯尔莫哥洛夫（下次必考）**：M 和 φ 的互换关系：φ(t) = M(it)。且 M 在 0 附近
（t 的邻域内）有限 ⟺ 分布的尾巴以指数速度衰减；柯西是反例。必考：为什么
e^{itX} 有界保证 φ 存在（一句话：|e^{itX}|=1 ⟹ |φ(t)| ≤ E(1) = 1）。

**② 费勒（要你记住）**：你第二次差点把"和"写成"积"（六项塌成 (eᵗ)⁶）——这是
"指数律"和"和的期望"两个操作在脑子里打架。记住操作顺序：**先指数律（乘），
再独立（拆期望），最后才是求和**。

**③ 戴科尼斯（要你记住）**：M⁽ᵏ⁾(0) 是"机器吐矩"，但别把自动售货机当饭票——
柯西证明了机器会卡壳。任何公式先问一句"它需要什么条件才能跑"。

**④ 杰恩斯（预告）**：课题09 大数定律会用第①站你亲手建的三层表述正式升级；
课题10 中心极限定理的正主就是 φ——你现在手里的牌，正是下一幕的入场券。
