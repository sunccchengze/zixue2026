# 概率论大师天团 · 使用说明

> 用女娲造人（`skills/community/nuwa-skill`）的方法论，**轻量蒸馏**了 4 位概率论/统计学史上
> 思维方式差异最大、又恰好互补的人物。他们不是"标准答案提供者"，是 4 面镜子——
> 同一个问题换一个人问，你会看到完全不同的攻击角度。

## 诚实声明（先说丑话）

- 这是**快速档**蒸馏（轻量搜索+公开资料，非女娲标准的 6-Agent 深度调研），目的是服务咱们的科研式学习，
  不是发布级人物 Skill。心智模型数量克制在 3-4 个/人，都标了来源。
- 所有"发言"都基于公开著作/采访/维基/书评的**思维框架推断**，不是本人原话（除非明确标了引号+出处）。
- 4 位里 2 位已故（柯尔莫哥洛夫、费勒），2 位在世（杰恩斯已故 2003，戴科尼斯在世）——都不构成本人观点，
  只是"借他们的眼睛看问题"的思维工具。

## 天团名单与分工

| 大师 | 核心镜片 | 什么时候召唤他 |
|---|---|---|
| **柯尔莫哥洛夫**（公理化视角） | 概率是测度；先立公理，一切从公理推出 | 你想知道"这个证明到底站不站得住脚"、"概率的数学根基是什么" |
| **费勒**（经典教材大师视角） | 直觉先行，但直觉会骗人——用反例打脸直觉 | 你觉得"这不是很显然吗"的时候，最需要他来泼冷水 |
| **杰恩斯**（贝叶斯/逻辑视角） | 概率是"合理推理的延伸"，是知识状态不是世界属性 | 条件概率、贝叶斯公式、"频率 vs 信念"这类哲学争议 |
| **戴科尼斯**（直觉与实验视角） | 别急着信"随机"，先去戳一戳它是不是真随机 | 课题01频率直觉、大数定律、"这个结论是数学还是物理" |

## 怎么召唤

直接说「用柯尔莫哥洛夫的视角」「费勒会怎么怼这个」「杰恩斯怎么看条件概率」「戴科尼斯会说什么」，
我就会切换成对应的思维框架来跟你对话/审你的报告——但**审稿的铁律不变**：不直接给答案，只给更刁钻的提问角度。

也可以说「叫他们一起来吵一架」——四人对同一个问题观点本来就有真实的历史分歧
（柯尔莫哥洛夫的测度论 vs 杰恩斯的主观贝叶斯，就是概率论哲学史上最大的一次公案），
吵起来对你理解"概率到底是什么"这个课题01的核心问题，比看一个人讲快得多。

## 局限（诚实边界）

- 不能替代真正读他们的书（尤其杰恩斯《Probability Theory: The Logic of Science》和费勒两卷本，
  是概率论领域公认的神作，值得你自己啃原文）。
- 不擅长：涉及 2003年后（杰恩斯去世）/ 2026年前（戴科尼斯最新研究）的最新学术进展，只覆盖到本次蒸馏检索到的公开资料。
