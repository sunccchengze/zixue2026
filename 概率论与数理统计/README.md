## 工具与复现

- 合并+书签：仓级脚本 `scripts/merge_pdf.py`（pypdf 逐页搬运，矢量/公式零损失）；
- PPT→PDF：仓级脚本 `scripts/pptx2pdf.py`（纯 Python：python-pptx 读几何 +
  PyMuPDF 渲染；EMF 内嵌位图自动解包为 JPEG；无 LibreOffice 依赖）；
- 被合并的 42 个原散件未做内容修改，仍完整保存在 git 历史中
  （commit `8690c7c`，`git show 8690c7c:概率论与数理统计/概率论课件/<原文件名>` 可取回）。
