# 9.22 概率论作业题质量分析报告

分析对象：第二版《概率论与数理统计》习题1 的 A、B 两部分奇数题（A1,3,…,29 与 B1,3,5，共18题）。旧版第一章奇数题1至39不能直接套用。

## 一、总体结论

题组覆盖事件运算、古典/几何概型、条件概率、全概率与贝叶斯、独立性证明和系统可靠性。18道题由集合语言过渡到综合计算与网络可靠性，覆盖面完整，适合作为第一章作业。与旧版20道奇数题相比，题号体系与选题结果差别明显：仅A5、A7、A9、A19、A21、A23、A27七题可迁移思路，且题号均已改变。

## 二、知识点与难度结构

| 模块 | 对应题号 | 难度 |
|---|---|---|
| 事件运算与区间 | A1, A3 | 基础 |
| 古典/几何概型与组合 | A5, A7, A13, A15, B1 | 中等 |
| 取球、条件概率 | A9, A11, A17, A19 | 中等 |
| 全概率与贝叶斯 | A21, A23, B3 | 中等 |
| 独立性 | A25, A27 | 中等 |
| 系统可靠性 | A29, B5 | 中等—较难 |

## 三、优点

1. A/B分组把基础运算与综合应用分开，B组三题分别训练排列、全概率和桥式网络。
2. A11用同一组事件对比放回/不放回，能直接暴露“第二次仍是4/10”的对称性。
3. A25、A29、B5把定义、归纳比较和条件化证明串起来，概念诊断价值高。

## 四、主要风险与易错点

A3的 \(B=(2,4]\) 在 \(2\) 处左开，差集必须含 \(2\)；A7必须说明线性24小时模型，带宽末端是半个三角形；A15“4位偶数”应排除首位为0；A25须声明 \(0<P(B)<1\) 以保证条件概率有定义；A29在 \(n=1\) 时两系统相等，不能笼统写“II更大”；B5桥式网络应对元件5条件化，并用32种状态复核。

## 五、工作量与建议

预计熟练学生完成题面约120至180分钟，完整规范书写约180至240分钟。四面答题纸只提供关键过程空间，A29、B1、B5建议先在草稿纸上画图再誊写。图1.9、1.10、1.11已按原图重绘，评分时以结构（串并联/桥）为准。
