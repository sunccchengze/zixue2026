## 第 1 题（判断）——中心极限定理的正确表述 ★答案 对

林德伯格–列维 CLT 的结论是关于**标准化和**的：
(Σ_{k=1}^{n}Xₖ − nμ)/(σ√n) → N(0,1)（分布收敛）。
若不标准化，ΣXₖ 的均值 nμ、方差 nσ² 都随 n 增长，谈"近似服从正态分布"必须先说清是哪个正态（或先标准化）。题干批评"未标准化"这一疏漏，说法正确。对。
（表述规范：对标准化和，n 很大时近似 N(0,1)；等价地 ΣXₖ 近似 N(nμ, nσ²)。）

## 第 2 题（单选）——切比雪夫不等式 ★答案 D

切比雪夫不等式：P{|X−E(X)|≥ε} ≤ D(X)/ε² = (2/9)/ε² = 2/(9ε²)。选 D。

## 第 3 题（单选）——大数定律的条件 ★答案 A

选项 A 的序列 D(Xₙ)=n² 型（如 P{Xₙ=±n²}=1/(2n²)，则 D(Xₙ)=n⁴·(1/n²)=n²）：
切比雪夫大数定律要求 (1/n²)Σ_{k=1}^{n}D(Xₖ)→0；此处 (1/n²)Σk² ≈ n/3 → ∞，条件破坏，不能由切比雪夫方法得到大数定律。选 A。

## 第 4 题（单选）——切比雪夫大数定律适用条件 ★答案 A

切比雪夫大数定律：{Xₙ} 独立（或两两独立），期望、方差都存在，且方差一致有界（sup D(Xₙ)<∞）⇒ (1/n)ΣXₖ − (1/n)ΣE(Xₖ) →P 0。
选项 A 违背该条件（期望/方差条件不齐），其余选项满足同分布、方差存在等条件。选 A。

## 第 5 题（单选）——中心极限定理条件 ★答案 D

林德伯格–列维 CLT：{Xₙ} 独立同分布、期望方差都存在（0<σ²<∞）。
指数分布 Exp(λ)：E(X)=1/λ，D(X)=1/λ² 均存在有限 ⇒ 同分布独立序列满足 CLT。选 D。

## 第 6 题（填空）——二项 + 中心极限定理 ★答案 537

X~B(1000, 1/2)：E(X)=500，D(X)=250。
要求 P{X≤N}≥0.99。由中心极限定理 (X−500)/√250 ≈ N(0,1)：
(N−500)/√250 ≥ u_{0.01} = 2.33 ⇒ N ≥ 500+2.33×15.8114 = 536.84。
最小整数 N = 537。
（自查：N=536 时 (536−500)/15.8114 = 2.277 < 2.33，不满足；N=537 时 2.340 ≥ 2.33 ✓。）

## 第 9 题（填空）——频率的中心极限定理 ★答案 0.01239

n=6000 粒中良种数 X~B(6000, 1/6)，频率 f_n=X/6000。
D(f_n) = (1/6)(5/6)/6000 = 5/216000。
P{|f_n − 1/6| ≤ ε} ≈ 2Φ(ε/√(5/216000)) − 1 = 0.99 ⇒ ε/√(5/216000) = u_{0.005} = 2.576。
ε = 2.576×√(5/216000) = 2.576×0.0048113 = 0.012394。
保留四位有效数字：ε = 0.01239。（若按四舍五入到万分位为 0.0124；以"四位有效数字"为准取 0.01239。）

## 第 10 题（填空）——方差公式逆用 ★答案 3

E(X²) = D(X) + (E(X))² = 2 + 1² = 3。

**(a) 瑞利型密度的数字特征**：设 X 的密度 f(x)=(x/σ²)e^{−x²/(2σ²)}（x>0），求 E(X)、D(X)。
- E(X)=∫₀∞(x²/σ²)e^{−x²/(2σ²)}dx=σ√(π/2)（作换元 u=x²/(2σ²)，用 Γ(3/2)=√π/2）。
- E(X²)=∫₀∞(x³/σ²)e^{−x²/(2σ²)}dx=2σ²（Γ(2)=1）。
- D(X)=2σ²−(π/2)σ²=σ²(2−π/2)=σ²(4−π)/2。
- 答案：选数值组为 (σ√(π/2), σ²(2−π/2)) 的选项。

**(b) 由二维分布函数读概率**：F(x,y)=(1/π²)(π/2+arctan x)(π/2+arctan y)，求 P{X>0,Y>0}。
- 独立柯西型、各自对称：P{X>0,Y>0}=(1/2)(1/2)=1/4。选项含 {1/2, 3/4, 1/4, 3/16}，选 **1/4**。
