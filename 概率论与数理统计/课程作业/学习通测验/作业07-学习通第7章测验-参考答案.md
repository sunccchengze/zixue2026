估计量 θ̂=θ̂(X₁,⋯,Xₙ) 是样本的函数 ⇒ 随机变量；估计值是代入具体样本后的取值（数）。选 B。

## 第 2 题（单选）——矩估计 ★答案 A

E(X)=∫₀¹x·θx^{θ−1}dx = θ/(θ+1)。令 θ/(θ+1)=X̄ ⇒ θ̂=X̄/(1−X̄)。选 A。

## 第 3 题（单选）——最大似然估计 ★答案 D

L(θ)=θⁿ(X₁⋯Xₙ)^{θ−1}（0<Xᵢ<1）⇒ lnL = nlnθ+(θ−1)ΣlnXᵢ。
d/dθ lnL = n/θ + ΣlnXᵢ = 0 ⇒ θ̂ = −n/ΣlnXᵢ = −1/((1/n)ΣlnXᵢ)。选 D。
（d²/dθ² = −n/θ² < 0 ⇒ 极大 ✓。）

## 第 6 题（单选）——有效性（方差最小）★答案 C

Xᵢ~U(0,θ)：E(Xᵢ)=θ/2，D(Xᵢ)=θ²/12。
- (2/3)(X₁+X₂+X₃)：E=(2/3)(3θ/2)=θ ✓ 无偏；D=(4/9)(3θ²/12)=θ²/9。
