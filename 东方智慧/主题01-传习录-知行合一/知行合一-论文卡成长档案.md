## 0. 为什么这张卡属于《知行合一》

《传习录》这一主题的核心不是“知道王阳明说了什么”，而是：

> **知而不行，只是未知。**

所以本次任务不是普通读论文，而是把“我知道科研要读论文、我知道 Zotero 很重要、我知道 AI/ML 能做科研”变成一个真实输出。

这张档案记录的是完整闭环：

> 知识输入 → 第一次行动 V1 → 被打脸 → 修正 V2 → 最终版沉淀。

## 2. V1 原始论文卡

### 基本信息

- 标题：机器学习在空气动力学形状优化中的应用
- 作者：李志超等
- 年份：2022
- 标签：不会读，上面没写

### 摘要后的感悟

这篇论文与自己方向很契合。机器学习的应用很广泛，但自己以前只是对机器学习、强化学习、深度学习等懂一点皮毛，说不清楚。希望看完这篇文章后，也能成为一个“小专家”。

### 三个关键词

1. Aerodynamic Shape Optimization
2. Artificial Neural Network
3. Machine Learning

### 论文三句卡 V1

1. **研究问题**：Machine Learning in ASO。
2. **方法/路径**：用机器学习可以解决很多传统 ASO 中的挑战，包括监督学习、无监督学习、半监督学习、深度学习、强化学习等；还有多样的人工神经网络形式，最后还针对实际问题具体分析。
3. **打脸点**：原来 ML 不只可以在 LLM 中发挥作用，它是对整个人类社会都可以起巨大作用的大杀器。

## 3. V1 判卷：第一次行动的价值

V1 评分：**7.2/10**。

### V1 的价值

1. **真正行动了**：完成 Zotero 入库和第一张手写论文卡，不再停留在“我应该读论文”。
2. **选题方向正确**：论文与 CFD、代理模型、气动优化、设计空间、多目标优化高度相关。
3. **抓到大方向**：ASO、ML、ANN 三个词说明已经抓到论文主题。
4. **有真实打脸点**：从“ML≈LLM/热门工具”扩展到“ML 能进入真实工程优化”。

### V1 的问题

1. **研究问题像标题**：`Machine Learning in ASO` 只是题目压缩，还不是“作者要解决的矛盾”。
2. **方法/路径像名词堆叠**：监督学习、强化学习等是算法类别，不是这篇综述的组织结构。
3. **打脸点偏宏观**：很有冲击力，但还没完全落回用户自己的 CFD/代理模型研究方向。

这正是知行合一里的关键：

> V1 不完美，但没有 V1，就没有可被修正的对象。

## 4. V2 修正版论文卡

### 研究问题

机器学习如何帮助 ASO 方向的研究，解决成本高、计算贵等问题。具体包括：CFD 昂贵、空间高维难分析、成本高等问题。

### 方法/路径

首先像老师一样讲授 ML 和 ASO 的基础知识；再在紧凑几何设计空间、快速气动分析、高效优化架构等应用层面，梳理已有研究中 ML 和 ASO 的结合；后续也有对现状问题的剖析和对未来的展望。

### 打脸点

我本以为 ML 在气动优化里只能训练模型起作用，也就是训练 surrogate model 替代 CFD 昂贵的过程。但今天我看到，ML 不只可以做快速预测，还是设计变量降维、优化流程、交互设计等问题的解决方法。

## 6. 最终版论文三句卡

### 1. 研究问题

这篇综述研究的是：**机器学习如何帮助空气动力学形状优化解决 CFD 仿真昂贵、设计空间高维、优化迭代成本高的问题。**

### 2. 方法 / 路径

作者先介绍传统 ASO 和 ML 基础，再按三个应用层面综述已有研究：

- 紧凑几何设计空间；
- 快速气动分析；
- 高效优化架构。

最后分析当前方法的实际局限和未来方向。

### 3. 打脸点

我原以为 ML 在气动优化里主要是训练 surrogate model 来替代昂贵 CFD；但这篇论文让我看到，ML 还可以参与设计变量降维、优化流程组织、交互式设计，以及物理先验融合。  
所以，ML 不是单点替代工具，而是可以嵌入整个 ASO 工作流的方法族。

## 8. 以后读论文的固定模板

每篇论文先问四件事：

1. **矛盾**：它要解决什么问题？
2. **方法**：它用什么路径解决？
3. **结论**：它得到了什么判断？
4. **局限**：它还没解决什么？

压缩成论文三句卡时，至少保留：

> 研究问题 + 方法路径 + 打脸点。
