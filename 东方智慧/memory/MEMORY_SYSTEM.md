# MEMORY_SYSTEM.md · 东方智慧（Track 5）记忆架构说明

> 这套记忆系统与概率论项目同构，供本轨道使用。各文件职责：

| 文件 | 职责 | 何时更新 |
|------|------|---------|
| `MEMORY.md` | **当前理解库**：你对这个轨道的核心理解、关键洞察、疑问与矛盾、学习日志、跨轨道联结 | 每次学完一个主题后更新 |
| `HANDOFF.md` | **交接总账本**：轨道状态、用户风格、当前理解、遗留问题、下一句该问什么、开场白 | 每次会话结束/换新前更新 |
| `PROGRESS.md` | **进度台账**：20 主题的 ⬜🔄✅🔶 状态 + 统计 + 复习队列 | 学完一个主题标 ✅ |
| `LEARNINGS.md` | **学习画像**：偏好/卡点/有效讲法/知识背景（共享，与概率论一致） | 发现新偏好才写回 |
| `ERRORS.md` | **判例库**：通用红线（导师纪律）+ 本轨道/用户判例 | 用户或导师犯错时记录 |
| `CONVERSATION_TEMPLATE.md` | **沟通范本**：提问/判卷/教学格式照抄（共享） | 只读 |
| `drill-ledger/` | **间隔重复账本**：`index.md` + `topics/topicNN-*.md` | 每主题学完更新卡片 |

## 开局协议（SKILL §0）

1. 读 `HANDOFF.md`（永远最新：进展到哪、下一句该问什么）；
2. 扫 `LEARNINGS.md`（偏好/卡点/有效讲法）与 `ERRORS.md`（判例红线）；
3. 查 `PROGRESS.md`（台账）与 `drill-ledger/index.md`（到期卡片）；
4. **先清到期卡片，再从 HANDOFF 的"下一句"继续**，不重新自我介绍、不重讲规则、不重复问已答过的问题。

## 账本卡片表（简化 FSRS）

`| # | concept | S(days) | D(1-5) | last | due | flags | history |`
- 新卡：Again S=1.0 / Hard 1.5 / Good 3.0 / Easy 6.0，初始 D=3；
- 复习：S' = S × 系数（Hard 1.4 / Good 2.2 / Easy 3.0，再按难度 D 和准点率微调）;
  Again → S'=max(1.0, S×0.3) 且 D+1；flags：cw=自信错、leech=累计4次Again（换角度重教不重考）；
- **到期卡优先于新内容**；单次新卡 ≤7；history 记最近8档；
- 会话内重考：Again/Hard 的卡隔约3轮换表面形式再问，只写最终档。
