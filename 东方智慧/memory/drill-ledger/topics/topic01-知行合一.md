## 概念（记忆锚三件套）

- **故事锚**：王阳明格竹病倒 → 龙场悟道知即行。知而不行，只是未知。
- **口诀**：知是行之始，行是知之成；知而不行，只是未知。
- **位置法**：圆心是"知=行"，不是"知→行"（一体，非两段）。

## 关联

- 打脸链路 = 知行合一（贝叶斯修正 = 事上磨练）
- 现在偏好/伤害贴现（为什么当下无动力）
- "知"分两档：知识（能背不动）vs 真知（能行/会改）

## 主题01收口补充

- **新结论：输出即验知**：真正的知识必须能输出、能应用、能经受验证。论文、比赛、项目成果是“验知”的外部证据。
- **三天小实验方向**：从宏大愿望里切一件最小行动，例如 Zotero 入库 1 篇论文并写 3 句摘要，或用 Agent 搭一个科研工作台雏形。
