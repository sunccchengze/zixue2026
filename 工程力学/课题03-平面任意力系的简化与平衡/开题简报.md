## 研究问题

任何一个平面力系，能不能归结为"两个数"（主矢 + 主矩）？这两个数各有什么脾气？
物体平衡的完整条件是什么？怎么用三个方程解出支座反力？

## 攻关线索（路标）

1. 力的平移定理（悬念正式版）：力可平移到任意点，但要补一个力偶 M=F·d；
   反过来"单力+力偶（R≠0）"合成单力，作用线偏 a=M/R。
2. 力系简化：向 O 点简化 → 主矢 R'（与简化中心无关）+ 主矩 M_O（与简化中心有关）；
   四种最终情形（单力偏 d=M_O/R' / 过 O 单力 / 纯力偶 / 平衡）。
3. 平衡方程：R'=0 且 M_O=0 → 平面 3 方程（ΣFx=ΣFy=ΣM_O=0），解 3 个未知数；
   力矩约定"逆时针为正"；三力矩形式（三点不共线）。
4. 真题接轨：A 计算 2（1）销钉 B 对杆 BCE 的作用力（二力杆 CD + 三力平衡）。
