## 2-1 三力合成（第 2 章 平面力系）

**已知**：三人拉力均 500 N；由题图量得三力相对物体轴线的夹角为
P₁ 在轴线上方 40°、P₂ 在轴线下方 10°、P₃ 在 **P₂ 下方再偏 35°**（即与轴线成 45°）。

> 读图关键：题图的 35° 是**从 P₂ 的作用线量起**的（不是从轴线量起）——这是本题唯一容易看错的地方。
> 检验：只有取 45°，结果才与该书答案 1235 N / 5.53° 吻合。

**解**（取轴线为 x 轴、垂直方向为 y 轴，向上为正；各力向两轴投影）：

| 力 | 与轴线夹角 | Fx / N | Fy / N |
|---|---|---|---|
| P₁ | +40° | 500 cos40° = 383.0 | 500 sin40° = 321.4 |
| P₂ | −10° | 500 cos10° = 492.4 | −500 sin10° = −86.8 |
| P₃ | −45° | 500 cos45° = 353.6 | −500 sin45° = −353.6 |

ΣFx = 1229.0 N，ΣFy = −119.0 N

R = √(ΣFx² + ΣFy²) = √(1229.0² + 119.0²) = **1235 N ≈ 1.24 kN**

tanφ = 119.0 / 1229.0 = 0.0968 → φ = **5.53°**，偏在轴线**下方**（即偏 P₂、P₃ 那一侧）

**答**：三人合力约 **1.24 kN**，方向与物体轴线成 **5.53°**，偏向 P₂、P₃ 一侧。

## 3-1 力对 z 轴之矩（第 3 章 空间力系）

**已知**：F = 2 kN，作用于直角折杆末端；题图把 F 沿一长方体对角线分解，三边 30 : 40 : 50（水平两向 + 竖直 z 向）。
由折杆尺寸（两段 100 mm 沿一个水平方向、一段 150 mm 沿另一个水平方向）得力作用点在水平面内相对 z 轴的偏置：
**x 向 −150 mm、y 向 +200 mm**。

**解**（先把 F 沿三个方向分解，再对 z 轴取矩；z 向分量与 z 轴平行，对 z 轴无矩）：

对角线长 √(30² + 40² + 50²) = √5000 = 70.71 （按比例单位）

F_x = 2 kN × 30/70.71 = **848.5 N**
F_y = 2 kN × 40/70.71 = **1131.4 N**
F_z = 2 kN × 50/70.71 = **1414.2 N**（对 z 轴无矩）

用解析式 M_z(F) = x·F_y − y·F_x：

M_z = (−0.150 m)(1131.4 N) − (0.200 m)(848.5 N)
   = −169.7 − 169.7 = **−339.4 N·m**

（两项恰好相等，因为 150×40 = 200×30；负号表示从 z 轴正向俯视为顺时针转向）

**答**：M_z(F) = **−339.4 N·m**（大小 339.4 N·m，绕 z 轴顺时针、自 z 轴正向俯视）。

## 3-2 力对 x、y、z 三轴之矩（第 3 章 空间力系）

**已知**：直角曲柄 ABCD 位于水平面 Axy 内；OA = l（沿 y），BC = b（沿 x），CD = a（沿 y）；
力 F 在垂直于 y 轴的平面（xOz 面）内，与竖直方向成 θ，F 的作用点 D 坐标为 (−b, l+a, 0)。

**解**：把 F 分解——它在垂直于 y 轴的平面内，故 F_y = 0，而 F_x = F sinθ，F_z = −F cosθ。
代入力对轴之矩的解析式（M_x = y F_z − z F_y，M_y = z F_x − x F_z，M_z = x F_y − y F_x）：

- M_x(F) = (l+a)(−F cosθ) − 0 = **−F(l + a)cosθ**
- M_y(F) = 0 − (−b)(−F cosθ) = **−bF cosθ**
- M_z(F) = 0 − (l+a)(F sinθ) = **−F(l + a)sinθ**

**答**：M_x(F) = −F(l+a)cosθ，M_y(F) = −bF cosθ，M_z(F) = −F(l+a)sinθ（负号表示力矩矢指向轴的负向）。

## 三题的方法骨架（一句话版）

1. **2-1**：平面汇交力系合成——建直角坐标、逐力投影、代数求和、再算模与方位角（符号定象限）。
2. **3-1**：空间力对轴之矩——先把力沿三方向分解，再"垂直于轴的平面内的分量 × 力臂"；与轴平行的分量无矩。
3. **3-2**：空间力对轴之矩的解析式 M_x = yF_z − zF_y（循环）——先写作用点坐标，再写力分量，最后代入，一步不跳。
