## 2-1 三力合成（第 2 章 平面力系）

**已知**：三人在水平面上拖拽重物，每人拉力 P = 500 N。由题图（书页 52）：
P₁ 在轴线上方 40°，P₂ 在轴线下方 10°，P₃ 在 **P₂ 作用线下方再偏 35°**（即与轴线成 45°）。
> 读图关键：35° 是**从 P₂ 作用线量起**的（弧线两端分别接 P₂、P₃ 两杆），不是从轴线量起。

**解**：

1. **建系**：取物体轴线为 x 轴（右为正），竖直方向为 y 轴（上为正）。

2. **逐力投影**（先写三角式，再代入）：

   | 力 | 与 x 轴夹角 | x 投影 / N | y 投影 / N |
   |---|---|---|---|
   | P₁ | +40° | 500cos40° = 383.0 | +500sin40° = 321.4 |
   | P₂ | −10° | 500cos10° = 492.4 | −500sin10° = −86.8 |
   | P₃ | −45° | 500cos45° = 500×(√2/2) = 250√2 = 353.6 | −500sin45° = −250√2 = −353.6 |

   （表中投影取一位小数；下面的和用未舍入值算。）

3. **代数求和**（公因子 500 提出，保留四位小数）：

   ΣFx = 500×(cos40° + cos10° + cos45°) = 500×2.4580 = **1228.98 N**
   ΣFy = 500×(sin40° − sin10° − sin45°) = 500×(−0.2380) = **−118.98 N**

4. **合力大小**：

   R = √(ΣFx² + ΣFy²) = √(1228.98² + 118.98²) = √1524547.7 = **1234.73 N**
   精确链：R = 500·√[(cos40°+cos10°+√2/2)² + (sin40°−sin10°−√2/2)²] = 500×2.4695 N
   → 按 4 位有效数字：**R = 1235 N ≈ 1.24 kN**

5. **方向**（符号定象限）：

   tanφ = |ΣFy|/ΣFx = 118.98/1228.98 = 0.09681 → φ = arctan(0.09681) = 5.5299° ≈ **5.53°**
   因 ΣFx > 0、ΣFy < 0，合力在轴线**下方**，偏向 P₂、P₃ 一侧。

**答**：R ≈ **1235 N（1.24 kN）**，与物体轴线成 **5.53°**，偏向 P₂、P₃ 一侧。

## 3-1 力对 z 轴之矩（第 3 章 空间力系）

**已知**：F = 2 kN = 2000 N，作用于直角折杆末端。由题图（书页 72，原件高清扫描直接确认）：
- F 方向按长方体三边比例 **x : y : z = 30 : 40 : 50**；
- 折杆水平段依次为 **100 mm（沿 +y）→ 150 mm（沿 −x）→ 100 mm（沿 +y）**。

> 读图关键：① 图中三个尺寸依次是 100、150、100（不是只有两个）；
> ② F 箭头偏向竖直线的 +y 一侧，与 F_y(40) > F_x(30) 自洽（若 30/40 互换，
> 结果 −353.6 N·m 与教材答案 −339.4 不符，故 40 对 y、30 对 x 被唯一确定）。

**解**：

1. **分解力**（方向余弦法；对角线 d = √(30²+40²+50²) = √5000 = 50√2 ≈ 70.71）：

   F_x = 2000×30/(50√2) = 1200/√2 = **600√2 ≈ 848.5 N**
   F_y = 2000×40/(50√2) = 1600/√2 = **800√2 ≈ 1131.4 N**
   F_z = 2000×50/(50√2) = 2000/√2 = **1000√2 ≈ 1414.2 N**（与 z 轴平行，对 z 轴无矩）

2. **作用点坐标**（单位换算 mm → m，这是得分点）：

   x = −150 mm = **−0.150 m**，y = +(100+100) mm = **+0.200 m**（z 向偏置不影响 M_z）

3. **代公式**（力对轴之矩解析式；F_z 与 z 轴平行不贡献）：

   M_z(F) = x·F_y − y·F_x

4. **代入计算**：

   M_z = (−0.150)×(800√2) − (0.200)×(600√2)
       = −120√2 − 120√2 = **−240√2 N·m**
   （两项相等并非巧合：150×40 = 200×30 = 6000，出题设计）

5. **小数化**：M_z = −240×1.41421 = −339.41 ≈ **−339.4 N·m**

**答**：M_z(F) = **−240√2 ≈ −339.4 N·m**（大小 339.4 N·m；负号 = 自 z 轴正向俯视为顺时针，力矩矢指向 −z）。

## 3-2 力对 x、y、z 轴之矩（第 3 章 空间力系）

**已知**：直角曲柄 ABCD 在水平面 Axy 内：AB = l（沿 +y）、BC = b（沿 −x）、CD = a（沿 +y）；
力 F 在垂直于 y 轴的平面（xOz 平行面）内，与竖直方向成 θ，指向 +x 且向下；作用点 D 为曲柄末端。

**解**：

1. **作用点坐标**：D = (−b, l+a, 0)，即 x_D = −b，y_D = l+a，z_D = 0。

2. **力分量**（F 在垂直 y 轴平面内 → F_y = 0；与竖直成 θ，指向 +x、向下）：

   F_x = F sinθ，F_y = 0，F_z = −F cosθ

3. **力对轴之矩解析式**（对原点矩投到轴上）：

   M_x(F) = y·F_z − z·F_y ；M_y(F) = z·F_x − x·F_z ；M_z(F) = x·F_y − y·F_x

4. **逐项代入**（一步不跳）：

   M_x = (l+a)·(−Fcosθ) − 0·0 = **−F(l+a)cosθ**
   M_y = 0·(Fsinθ) − (−b)·(−Fcosθ) = **−bFcosθ**
   M_z = (−b)·0 − (l+a)·(Fsinθ) = **−F(l+a)sinθ**

5. **力臂法复核**（物理直观，一行一个）：
   - 对 x 轴：只有竖直分量 F_z = −Fcosθ 有力臂，力臂 = y_D = l+a → M_x = −F(l+a)cosθ ✔
   - 对 y 轴：只有竖直分量 F_z = −Fcosθ 有力臂，力臂 = |x_D| = b → M_y = −bFcosθ ✔
   - 对 z 轴：只有水平分量 F_x = Fsinθ 有力臂，力臂 = y_D = l+a → M_z = −F(l+a)sinθ ✔
   （各分量中与轴平行的分量对轴无矩——这是全部符号来源。）

**答**：M_x(F) = **−F(l+a)cosθ**；M_y(F) = **−bFcosθ**；M_z(F) = **−F(l+a)sinθ**。
负号表示力矩矢指向对应轴的**负向**。
