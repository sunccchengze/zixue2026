## 再做一份（换一批题）

```bash
cd /home/user/zixue2026
# 1) 改（或复制）spec：题号、题面原文、配图路径、留白行数
# 2) 生成（自动审计是否一页）
/home/user/opt/.venv/bin/python scripts/generate_homework_sheet_docx.py 工程力学/作业/<spec>.json "<输出>.docx"
# 3) 出打印预览（顺便再确认一次页数）
/home/user/opt/.venv/bin/python scripts/docx_preview_pdf.py "<输出>.docx" "<输出>.preview.pdf"
```

两个工具都在仓级 `scripts/`（通用，别的学科同样可用）：

- `generate_homework_sheet_docx.py`：题面 + 配图 + 留白 → 一页 docx；
  全部用 exact 行距与精确图片尺寸，**Word 的排版结果 = 脚本算出的高度**
- `docx_page_audit.py`：读回 docx 的 XML，按 Word 规则累加高度，判定是否真的一页
- `docx_preview_pdf.py`：沙箱没有 LibreOffice（apt 源不可达），自己按 docx 里的量把版面画成 PDF，供肉眼验收

## 踩过的坑（改排版前必读）

1. **相邻同边框段落会被 Word 合并**：用 N 个带下边框的段落画横线，只会画出 1 条。
   答案：用**表格**画线（insideH 画 n−1 条 + bottom 画最后 1 条 = n 条），并写 `w:trHeight` exact 行高。
2. **带边框的段落高度会超出「字号×行距」**：手写横线行一律 exact 行距 + 表格行高，别指望自动行距。
3. **`\hskip` 式对齐救不了中文**：中文全角字符按 1 em 估宽，预览器的折行才准。
4. 图片显示尺寸由 `wp:extent`（EMU）决定，插图和表格行高都要按它算，否则首末行会被撑开。
