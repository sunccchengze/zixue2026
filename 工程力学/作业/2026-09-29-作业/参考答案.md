## 习题 1-4 · 受力图（逐物体说明）

约定：光滑铰链反力用两正交分量表示；二力杆两端力等大、反向、共线（沿杆轴）；
理想绳/滑轮张力处处相等记 T；作用与反作用在不同物体上、等值反向。

### (a) 对象：AB、BC、销钉B、整体

- **杆 AB**：仅 A、B 两处受力，杆上无载荷 → **二力杆**。受力：A 端 `N_AB`、B 端 `N_AB'`，等大反向、沿直线 AB。
- **杆 BC**：仅 B、C 两处受力 → **二力杆**。受力：B 端、C 端各一力，等大反向、沿直线 BC。
- **销钉 B**：三个力——外载 `P`（竖直向下）；杆 AB 通过销传来的力（沿 AB，与 AB 的 B 端力反作用）；杆 BC 通过销传来的力（沿 BC）。三力汇交于 B、平衡。
- **整体**：外力只有——A 处反力（沿 AB，因 AB 二力）、C 处反力（沿 BC）、B 处 `P`。三力平衡必汇交。

### (b) 对象：AB、CD、轮H、销钉和轮D、整体

绳张力全绳相等记 T；轮 H 为动滑轮吊重 P，两绳段近似竖直 → `2T = P`，`T = P/2`。

- **杆 AB**：A 铰支 → 两分量 `(A_x, A_y)`；E 点绳拉力 `T`（水平、指向 D 一侧）；B 铰（与 CD 连）→ 两分量 `(B_x, B_y)`。非二力杆。
- **杆 CD**：C 铰支 → 两分量 `(C_x, C_y)`；B 铰 → 两分量（与 AB 的 `(B_x,B_y)` 等值反向）；D 处销对杆的反力 → 两分量 `(D_x, D_y)`。
- **轮 H（动滑轮）**：左、右两绳段张力各 `T`（向上），吊重 `P`（向下）；平衡得 `T=P/2`。
- **销钉和轮 D（合取）**：绳对轮的作用——顶部水平段 `T`（指向 E，即水平向左）、右侧下行段 `T`（向下）、系于轴上的绳端 `T`（向下）；以及杆 CD 通过销传来的两分量（与杆 CD 的 `(D_x,D_y)` 反作用）。
- **整体**：外力——A 铰两分量、C 铰两分量、吊重 `P`（向下）。绳与销均为内力，不画。

### (c) 对象：AB和销钉B、CE和滑轮、整体

斜杆 EB 两端铰接、中间无载 → **二力杆**，其作用力沿 EB。B 处为辊轴支座 → 反力竖直 `N_B`。

- **AB和销钉B**：A 铰支 → 两分量 `(A_x, A_y)`；B 处辊轴反力 `N_B`（竖直）；B 处斜杆 EB 传来的力 `F_EB`（沿 EB）。
- **CE和滑轮**：E 处斜杆 EB 传来的力 `F_EB`（沿 EB，与上反作用）；D 铰（与 AB 连）→ 两分量 `(D_x, D_y)`；C 处滑轮绳——水平段 `T`（指向墙，水平）、竖直段 `P`（吊重向下）。
- **整体**：外力——A 铰两分量、B 辊轴反力 `N_B`（竖直）、C 处系墙绳的水平张力 `T`、吊重 `P`（向下）。斜杆 EB 为内力。

## 习题 3-6 · 求 F 与轴承约束力

**建系**：轴沿 y（A→D 为正）；x、z 如图，z 竖直向上。轴承 A、B 为径向轴承，反力只有 `X、Z` 两分量。
**位置**（mm）：A=0，C=400，B=1000，D=1400。
**主动力**：C 处 `F` 沿 +z，对轴(y)力臂 200；D 处 `P`=800N 沿 +x，对轴(y)力臂 200。

**(1) 对轴 y 取矩（扭矩平衡）求 F：**
ΣM_y = 0：200·F − 200·P = 0 → **F = P = 800 N**。

**(2) ΣM_x（对 A）求 Z_B：** 400·F + 1000·Z_B = 0 → Z_B = −400·800/1000 = **−320 N**。

**(3) ΣF_z 求 Z_A：** Z_A + Z_B + F = 0 → Z_A = −800 + 320 = **−480 N**。

**(4) ΣM_z（对 A）求 X_B：** −1400·P − 1000·X_B = 0 → X_B = −1400·800/1000 = **−1120 N**。

**(5) ΣF_x 求 X_A：** X_A + X_B + P = 0 → X_A = −800 + 1120 = **320 N**。

### 结果（与教材答案页逐位一致）

| 量 | 值 (N) |
|---|---|
| F | 800 |
| X_A | 320 |
| Z_A | −480 |
| X_B | −1120 |
| Z_B | −320 |

负号表示实际方向与所设坐标正向相反。大小：|X_A|=320、|Z_A|=480、|X_B|=1120、|Z_B|=320。
