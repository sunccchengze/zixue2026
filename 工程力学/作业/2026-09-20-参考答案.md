## 2-2 桥墩力系向 O 点简化（第 2 章 平面力系，书页 52）

**已知**（题面照录）：桥墩受力 F=2740kN，M=552.5kN·m，G=5280kN，P1=193kN，P2=140kN，如题 2-2 图。
由题图（渲染读图确认）：
- F 竖直向下，作用于墩顶中线（高 21m 处）；
- M 为顶部位力偶，**逆时针**（附录一有反证）；
- G 竖直向下，作用于中线 10.7m 高处（重心）；
- P1 水平向左，作用于顶（21m 高）；P2 水平向左，作用于 10.7m 高处；
- O 为墩底中点（地面）。

**解**：

1. **主矢**（建系：x 右正、y 上正，O 为原点）：

   ΣFx = −(193 + 140) = **−333 kN**（向左）
   ΣFy = −(2740 + 5280) = **−8020 kN**（向下）

2. **主矢大小**：

   R = √(333² + 8020²) = √(110889 + 64320400) = √64431289 = **8026.91 kN → 8027 kN**（4 位有效数字）

3. **方向**：

   与水平夹角 = arctan(8020/333) = arctan(24.0841) = **87.62° = 87°37′**
   即合力指向**左下**，几乎竖直（偏离竖直向下仅 2.38°）。
   （教材答案页作 87°54′，差 17′——主矢由题给数据唯一确定，判为答案页笔误，见附录一。）

4. **对 O 点主矩**（逆时针取正；F、G 沿中线过 O，力臂为 0）：

   M_O = P1×21 + P2×10.7 + M
       = 193×21 + 140×10.7 + 552.5
       = 4053 + 1498 + 552.5
       = **6103.5 kN·m（逆时针）**

   （向左的力作用在 O 上方：力臂 = 高度，转向 = 逆时针，逐项 +。）

5. **合力作用线位置**（R ≠ 0 → 力系简化为一个合力）：

   到 O 的垂直距离 d = M_O / R = 6103.5 / 8026.91 = **0.7604 m**
   在 O 的**左侧**（向下的力要产生逆时针主矩，作用线必偏在 O 左边）。

   两个等价的定位描述（作业写其一即可，建议都写）：
   - 与**基线**交点：x₀ = −M_O/8020 = −6103.5/8020 = **−0.761 m**（O 左 0.76m）；
   - 与**墩中轴线**交点：y₀ = M_O/333 = 6103.5/333 = **18.33 m**（O 上方，教材答案页作 18.31m，差 2cm，见附录一）。

**答**：向 O 点简化结果为主矢 **R = 8027 kN**（指向左下，与水平成 87.6°、即与竖直成 2.4°）
与主矩 **M_O = 6103.5 kN·m（逆时针）**；因主矢不为零，力系合力为一，
其作用线在 O 左侧 d = 0.76m 处——交基线于 O 左 0.76m，交墩中轴线于 O 上方约 18.33m。

## 2-7 四滑轮板两力偶合成（第 2 章 平面力系，书页 52–53）

**已知**（题面照录）：矩形板上装四个滑轮 A、B、C、D，绕过 B、D 的绳拉力 F1=F2=400N，
绕过 A、C 的绳拉力 F3=F4=300N，滑轮大小不计，未注单位 mm。
由题图（渲染读图确认）：
- 滑轮位置（以板中心为原点）：A(−240, +100)、B(+240, +100)、C(+240, −100)、D(−240, −100) mm
  （240+240 为两滑轮列间距 480mm，200 为两行滑轮间距）；
- F1 在 B 处指向左上、与水平成 60°；F2 在 D 处指向右下、与水平成 60°；
- F3 在 A 处指向左下、与水平成 30°；F4 在 C 处指向右上、与水平成 30°。

**解**：

1. **写分量（先验证"两个力偶"）**：

   F1 = (−400cos60°, +400sin60°) = (−200, +346.41) N
   F2 = (+400cos60°, −400sin60°) = (+200, −346.41) N = **−F1** ✔（等值反向平行 → 力偶）
   F3 = (−300cos30°, −300sin30°) = (−259.81, −150) N
   F4 = (+300cos30°, +300sin30°) = (+259.81, +150) N = **−F3** ✔（力偶）

   （每根绳两端拉力等值、方向相反且平行，正是题设"两个力偶"的来源；
   图中角度按此读法自洽——若把 30° 改读成从竖直量起，F4 ≠ −F3，不成力偶，舍去。）

2. **力偶矩**（逆时针取正；M = Σ(x·Fy − y·Fx)，单位 N·mm）：

   M1 = (240×346.41 − 100×(−200)) + ((−240)×(−346.41) − (−100)×200)
      = (83138.4 + 20000) × 2 = **206276.9 N·mm = 206.28 N·m（逆时针）**

      力偶臂法复核：d1 = 480sin60° + 200cos60° = 415.69 + 100 = 515.69 mm
      M1 = 400 × 515.69 = 206276.9 N·mm ✔

   M2 = ((−240)×(−150) − 100×(−259.81)) + (240×150 − (−100)×259.81)
      = (36000 + 25980.8) × 2 = **123961.5 N·mm = 123.96 N·m（逆时针）**

      力偶臂法复核：d2 = 480sin30° + 200cos30° = 240 + 173.21 = 413.21 mm
      M2 = 300 × 413.21 = 123961.5 N·mm ✔

3. **合力偶矩**（力偶矩为自由矢量，代数相加）：

   M = M1 + M2 = 206276.9 + 123961.5 = **330238.4 N·mm = 330.2 N·m，逆时针**

**答**：两个力偶的合力偶矩 **M = 330.2 N·m，方向逆时针**。

> ⚠️ 教材答案页（书页 368）作 **247.1 N·m，逆时针**——方向一致、数值与本版图不符，
> 排查记录与判定见附录二（按本版图任何自洽读法都得 330.2；247.1 判为旧版数据的遗留答案）。

## 题3 四面体空间力系向 O 点简化（照片题，第 3 章 空间力系）

**已知**（照用户照片誊录）：四面体的三条棱 OA、OB、OC 相互垂直，且 OA=OB=OC=a，
在三角形 ABC 平面内的三条边上分别作用力 F1、F2 和 F3，且 F1=F2=√2F、F3=2√2F，
在 OAC 和 OBC 平面内分别作用力偶 M1 和 M2，且 M1=M2=Fa。
试将该力系向 O 点简化，并给出最终合成结果。

**读图（照片）**：以 O 为原点，OA、OB、OC 分别为 x、y、z 轴正向：
A(a,0,0)、B(0,a,0)、C(0,0,a)。
- F1 在边 CA 上，方向 **C→A**（箭头朝 A）；F2 在边 CB 上，方向 **C→B**（箭头朝 B）；
  F3 在边 AB 上，方向 **A→B**（箭头朝 B）；
- M1 在 OAC（xOz）面内，弧线箭头由 C 侧转向 A 侧（+z→+x）→ 力偶矢沿 **+y**；
- M2 在 OBC（yOz）面内，弧线箭头由 B 侧转向 C 侧（+y→+z）→ 力偶矢沿 **+x**。

**解**：

1. **三个力的矢量式**（|CA|=|CB|=|AB|=√2·a，边方向单位化后代入）：

   F1 = √2F·(A−C)/|A−C| = √2F·(1/√2, 0, −1/√2) = **(F, 0, −F)**
   F2 = √2F·(B−C)/|B−C| = √2F·(0, 1/√2, −1/√2) = **(0, F, −F)**
   F3 = 2√2F·(B−A)/|B−A| = 2√2F·(−1/√2, 1/√2, 0) = **(−2F, 2F, 0)**

2. **主矢**（与简化中心无关）：

   R = F1+F2+F3 = **(−F, 3F, −2F)**
   |R| = F·√(1+9+4) = **√14 F ≈ 3.74F**
   方向余弦：(−1/√14, 3/√14, −2/√14)（与 x、y、z 轴夹角 105.5°、36.7°、122.3°）

3. **各力对 O 之矩**（取作用线上任一点，如顶点；力对点之矩与取点无关，已换点复核）：

   C×F1 = (0,0,a)×(F,0,−F) = (0, +aF, 0)
   C×F2 = (0,0,a)×(0,F,−F) = (−aF, 0, 0)
   A×F3 = (a,0,0)×(−2F,2F,0) = (0, 0, +2aF)
   力的部分 Σ = **(−aF, aF, 2aF)**

4. **两个力偶**（力偶矩是自由矢量，直接加入）：

   M1 = (0, +Fa, 0)；M2 = (+Fa, 0, 0)

5. **对 O 点主矩**：

   M_O = (−aF+aF, aF+Fa, 2aF+0) = **(0, 2aF, 2aF)**
   |M_O| = 2√2 aF ≈ 2.83aF（方向 (0,1,1)/√2，与 y、z 轴各成 45°）

6. **最终合成判定**（关键一步）：

   R·M_O = (−F)·0 + 3F·2aF + (−2F)·2aF = **2aF² ≠ 0**

   → 主矢与主矩**不垂直**，力系不能简化为单一合力，最终结果为**力螺旋（螺旋力系）**：
   - **轴向力偶**（M_O 沿 R 方向的分量）：
     M∥ = (M_O·R)/|R|² · R = (2aF²/14F²)·(−F,3F,−2F) = **(aF/7)(−1, 3, −2)**
     |M∥| = (aF/7)·√14 = **(√14/7)aF ≈ 0.534aF**，与 R **同向**；
   - **螺旋轴（中心轴）**：过点 r0 = (R×M_O)/|R|² = (10a/14, 2a/14, −2a/14)
     = **(5a/7, a/7, −a/7)**（以 O 为原点），方向沿 R；
     验证：对 r0 取矩 M_O − r0×R = M∥（纯轴向）✔ —— 轴上只剩下那个轴向力偶；
   - 于是最终合成 = **螺旋轴上的单力 R = √14F（方向 (−1,3,−2)/√14）+ 同向轴向力偶 (√14/7)aF**。

**答**：向 O 点简化的结果：主矢 **R = F(−1, 3, −2)**，|R| = √14F ≈ 3.74F；
主矩 **M_O = aF(0, 2, 2)**，|M_O| = 2√2aF ≈ 2.83aF。
因 R·M_O = 2aF² ≠ 0，力系最终合成为**力螺旋**：螺旋轴过点 (5a/7, a/7, −a/7)、
方向 (−1,3,−2)；轴上为单力 √14F（方向余弦 (−1,3,−2)/√14）加同向轴向力偶 (√14/7)aF。

> 核对说明：照片题，无教材答案页可对照；自检三重——① 三个力矩换点（顶点 A/B/C
> 与边中点）复核一致；② r0 处取矩 = 轴向分量 M∥ 的解析恒等式数值验证通过；
> ③ 全部断言写入 `制作解答图-题3.py`（R、M_O、r0、|M∥| 逐项 assert）。

## 附录三 · 方法骨架（一句话版）

1. **2-2 一般平面力系向点简化**：主矢 = 各力投影代数和（与简化中心无关）；
   主矩 = 各力对 O 之矩代数和 + 力偶矩（力偶对任何点矩相同）；
   R ≠ 0 时合力作用线 d = M_O/R，位于 M_O 转向所"需要"的一侧（本例：向下的力、逆时针主矩 → 偏左）；
   作用线方程 x·Ry − y·Rx = M_O，代 x=0 或 y=0 即得与轴/基线交点。
2. **2-7 力偶合成**：每根绳两端等值反向平行 → 各自成力偶；
   力偶矩 = F×d（d = 两平行作用线间垂直距离，用 (r₁−r₂)×û 一行算出）；
   力偶矩是自由矢量，直接代数相加，转向按逆时针正。
3. **题3 空间力系向点简化**：先建系、把每个力写成矢量式（单位向量×大小）；
   主矢 = 矢量求和；主矩 = Σ(r×F)（取点可换）+ 力偶矢直接加（自由矢量）；
   最后判 **R·M_O**：=0 → 单一合力（作用线 d=M_O/R）；≠0 → **力螺旋**
   （轴向力偶 M∥=(M_O·R)/|R|²·R，螺旋轴过 r0=(R×M_O)/|R|²，用"对 r0 取矩=M∥"闭环验证）。
