# 大师天团 · 工程力学

> 4 位思维方式差异最大的真实人物，用作"借他的眼睛看问题"的思维工具。
> **诚实声明**：以下均非本人原话，思维框架为基于公开资料的推断，仅作多视角提问/审稿之用。

| # | 人物 | 镜片（一句话视角） | 分工 |
|---|---|---|---|
| 01 | 牛顿 | 静力学根基：三大定律 / 作用与反作用 | 查受力分析、查平衡方程（"∑F=0 是谁的定律？"） |
| 02 | 胡克 | 弹性：应力∝应变（ut tensio, sic vis） | 查变形、查刚度 vs 强度、材料性能试验 |
| 03 | 欧拉 | 压杆稳定：细长杆失稳与欧拉公式 | 查屈曲、查临界载荷、查有效长度 |
| 04 | 圣维南 | 局部效应：边界细节只在局部作乱 | 查截面法凭什么成立、查应力集中、查公式适用范围 |

**用途**：①攻关中换视角提问（"胡克会问什么"）；②报告起草时每人一题面试你；
③审稿意见署名分派（牛顿查受力图、胡克查变形、欧拉查失稳、圣维南查局部效应）。
**历史真实分歧优先**：牛顿（刚体、无变形）与胡克（一切皆可变形）本就是两条路线——
"让他们吵一架"（"这根杆到底该看成刚体还是弹簧？"）比单人讲授更有价值。
