## 二、补篇II 内容定位

原书运动学两章无"点的合成运动"，而本课程考试单考一道大计算题（2024 A/B 卷计算5，均 12 分）。补写 7 页：一点两系三运动与牵连点（B2.1）→ 速度合成定理及证明（B2.2）→ 加速度合成定理（动系平动 / 转动 + 科氏加速度，B2.3）→ 例题 4 道 → 小结 / 思考题 6 道 / 习题 6 道（附答案）。

- 例B2-1 / B2-4（曲柄摇杆套筒求 ω、α）≈ 2024A 计算5 题型：牵连转动 + 科氏项
- 例B2-2（半圆凸轮顶杆）＝ 牵连平动、相对圆周
- 例B2-3（转盘旋弧槽）＝ 科氏加速度最简情形
- 全部例题数值先经 Python 矢量核算（坐标投影逐一复算），再入排版

## 四、工艺记录

- **页码偏移勘定**：扫描件前部（扉页~篇扉页区）PDF 页 = 书页 + 9；正文起 PDF 页 = 书页 + 8。全部选段边界渲染抽验（17 处首末页）无误后方才拼装
- **补写页排版**：自写引擎（PyMuPDF），字体：中文 Droid Sans Fallback（`china-ss`）、数字拉丁 FiraGO（`figo/figit/figbo/figbi`）、专用符号 Noto Sans Math；CJK 粗体以微错位双描实现；两端对齐含 CJK 拉伸与句首标点规避
- **去 AI 味**：按 humanizer-zh（op7418/Humanizer-zh 24 模式）对补写文稿做编辑纪律自检（去填充词、破折号限量、无空泛结论、术语贴合原书语体）
- **拼装**：`insert_pdf` 选页 + `garbage=3, deflate=True, deflate_images=False` 保存（注意：不省 `deflate_images` 会膨胀至 ~216 MB）
