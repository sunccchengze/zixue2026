# 课题02 · 平面汇交力系与力偶系 — 一页研究报告

> 状态：✅ 已验收（2026-08-24）· 模式：新学快讲

## 研究问题

多个力作用在同一点，怎么合并成一个"等效力"？两个等大反向但不共线的力（力偶），
合力明明是 0，为什么还会转——用什么量度"转"的强弱？

## 我的思路（过程）

1. **开题批 4 题**：K1（√2F 合成）、K2（正交分解）、K3（转，用 ΣM 量度）均独立答对
   （高中向量底子）；K4❌ 标"我猜"答"d 随矩心变"，并自问"力偶是啥"。
2. **力偶概念 + 力矩/力偶对比表 + 符号位置法**（M_O(F) 带下标=跟点走，M 无下标=自由）；
   用户自写定义卡："力偶：一对力，一个力系；M=F·d；d 为两力作用线垂直距离，与矩心
   位置无关"（达考试口径）。
3. **验证批 3/3**：K4 重做（d 只由两力决定）✅、方向盘 M=F·2r=30 N·m（未踩 r/d 坑）✅、
   共线边界（ΣF=0、ΣM=0、不是力偶、不平动不转动）✅。
4. **小测**：T1 3-4-5（50 N/53°）✅；T2 等效力偶（150×0.2=50×0.6=30 N·m 不变）✅
   并自猜名称"等效力偶原理"（正式名：力偶的等效原理）；T3(a) 20√3 N 沿角平分线 ✅；
   T3(b)❌ 以为合力与力偶的转动相互抵消 → "两账不抵"补丁（力归移动、偶归转动）→
   重做✅（"移动且转动，两账不互抵"）。
5. **悬念抢答**：合力+力偶"可以简化，用等效力偶原理把力偶矩变成单个力的力矩"——
   方向正确，正式名=**力的平移定理**（a=M/R），课题03 推导。

## 结论

- 汇交力系合成：平行四边形/力多边形/分量法（正交分解是计算捷径）；两等力 F 夹角 θ
  → 2F·cos(θ/2)，沿角平分线。
- 力偶：两个等大、反向、不共线的力；合力恒 0（不移动）、纯转动；力偶矩 M=F·d，
  与矩心无关（自由矢量）；共线则不是力偶（ΣF=0 且 ΣM=0）。
- 力偶的等效原理：同平面内力偶等效 ⇔ 力偶矩相等（F、d 可互换，可任意搬动）。
- 移动与转动是两本账：ΣF 管移动、ΣM 管转动，单个力不能抵消力偶（"力归移动、
  偶归转动、两账不抵"；图像：直着开+打方向盘）。

## 我还存疑的地方

   平移定理开题就收。
2. 单力之矩随矩心怎么变（M_P 与 M_O 的关系）还没形式化——课题03 力系简化时收。

   "逆时针为正"，与多数教材/真题一致）。
