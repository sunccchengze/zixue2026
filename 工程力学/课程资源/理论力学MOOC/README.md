## 2. 会话全过程纪要

### 阶段一 · 课件批量下载

用户给出课程链接，要求「把里面的文档全部下载到工作区」。

- 页面本身只有课程介绍，实际内容走接口；匿名访问 `/learn/` 会被 **302 跳回课程首页**。
- 用无头 Chromium 实测确认：未登录抓取不到任何内容接口 → 需要登录态。
- 用户提供浏览器 Cookie 后，逆向出完整调用链，**23 份 PDF 全部下载成功，0 失败**，
  每个文件校验 `%PDF` 文件头，无损坏。
- 目录结构：`downloads/理论力学/NN 章名/NN 课时名/文件名.pdf`

> ⚠️ 课程进行至第 4 周，仅发布 5 章（绪论、第 1~3 章、动力学专题）。
> 其余 6 章（刚体平面运动、质点运动微分方程、动量/动量矩/动能定理、达朗贝尔原理、虚位移原理）
> 按课程大纲预置了占位，讲义发布后可增量下载。

### 阶段二 · 讲义文本抽取

- 用 `pypdf` 抽取 339 页文本，得 40,604 字符，按「文档 → 页」结构化落盘。
- 清除每页重复的页眉（航天航空学院 / 主讲人 / 示范中心）并去重，得 31,956 字符的干净语料。
- 结论：讲义为 PPT 导出，**文字可提取但公式多为图片**，因此知识地图中的公式按
  理论力学标准体系用 LaTeX/Unicode 重排，再从讲义原文校订，而非依赖 OCR。

### 阶段三 · 交互式知识地图（`理论力学知识地图.html`）

- 内容**逐页读完全部 339 页讲义后编写**，非通用大纲。
- 每个知识点四段式：**要点 → 公式 → ⚠ 易错点 → 📄 出处（精确到文件名与页数）**。
- 支持全文检索（如「科氏」「自锁」「零杆」「力螺旋」）、已发布/待发布筛选、
  逐级展开折叠、章节概览卡。
- **单文件、全内联、零外部依赖**，离线双击即用。

（10 题，满分 100，可提交 3 次）。

用户先后三次请求获取标准答案（含「暗示 / 偷偷核对」的形式），AI **均予拒绝**，理由：

1. 测验处于计时中且尚未提交，且计入课程成绩；
2. 接口返回 `showAnalysis = false`、`viewedAnswer = null` —— 教师主动锁定了答案与解析；
3. 在仍有提交机会时提供答案，无论以何种形式包装，实质都是替答。

## 3. 技术要点：icourse163 接口逆向

这部分是本次工作最花时间的环节，留存备查。

| 关卡 | 现象 | 解法 |
|---|---|---|
| 跨域拦截 | 返回 `非法跨域请求` | 从 2.2 MB 的 `core.js` 中定位到：<br>`edu-script-token` 请求头 = **`NTESSTUDYSI` Cookie 的值** |
| 匿名访问 | `/learn/` 302 跳回首页；接口 `系统异常` | 必须携带已登录且**已参加课程**的 Cookie |
| 接口改名 | 网传的 `courseBean.getMocTermDto` 返回 `-1 系统异常` | 带 Cookie 开无头 Chromium 进学习页抓真实 XHR →<br>实际是 **`courseBean.getLastLearnedMocTermDto.rpc`**，参数仅 `{termId}` |
| PDF 直链 | 前端 PDF 阅读器懒加载，抓不到请求 | 用老接口 `CourseBean.getLessonUnitLearnVo`（DWR），<br>取响应中的 **`textOrigUrl`** |
| 文件名乱码 | 服务器文件名藏在 URL 参数里 | 解析 `download=` 参数并 URL-decode，比用目录里的单元名更准 |
| 视频 | `getResourceToken` 返回「没有权限」 | 视频走移动端 `mob-token` 体系，Web Cookie 换不到，**未攻克** |

**关键细节**：PDF 直链带 NOS 签名，`Expires` 约为签发后 15 分钟，
所以必须「取一个链接、立刻下一个」，不能先把链接全取完再批量下载。

**接口签名探测技巧**：向 `/web/j/{Bean}.{method}.rpc` 发请求，
返回 `-1007 不含有该参数 :xxx` 说明 Bean 存在但参数名不对；
返回 `-1003 类名出错` / `-1004 方法名出错` 说明 Bean/方法不存在。
据此可低成本枚举出真实签名。

## 5. 复现 / 复用指南

### 环境

```bash
pip install requests pypdf
# 仅当需要用无头浏览器抓接口时才装：
pip install playwright && python3 -m playwright install chromium
```

### 增量下载新课件

后续 6 章讲义发布后：

```bash
echo '你的 Cookie 整行' > cookies.txt   # 见下方"获取 Cookie"
python3 dl.py                          # 已存在的文件自动跳过，只下新增
```

常用参数：

```bash
python3 dl.py --list-only          # 只导出清单不下载
python3 dl.py --types 3,4          # contentType：1视频 2测验 3PDF 4附件 5富文本
python3 dl.py --overwrite          # 强制覆盖
```

### 重新生成合订本

新章节下载后重新合并（脚本会增量覆盖同名文件）：

```bash
python3 merge_by_chapter.py                 # 输出 按章节合并/
python3 merge_by_chapter.py --out 别的目录    # 自定义输出
```

### 重新生成知识地图

编辑 `mindmap_data.py` 增删知识点后：

```bash
python3 build_mindmap.py           # 输出 理论力学知识地图.html
```

### 获取 Cookie

1. 浏览器登录 <https://www.icourse163.org/>，并确认**已参加**该课程
2. 打开任意课程页 → F12 → Network → 选中 `icourse163.org` 请求
3. Request Headers → `cookie:` → 右键 Copy value
4. 整行粘贴到 `cookies.txt`

> Cookie 有时效，过期后重取。**切勿提交到版本库**（`.gitignore` 已屏蔽）。
