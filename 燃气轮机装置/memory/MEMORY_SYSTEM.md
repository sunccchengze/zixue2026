# MEMORY_SYSTEM · 燃气轮机装置

- 架构：`HANDOFF.md`（交接总账本，永远最新）/ `LEARNINGS.md`（学习画像）/ `ERRORS.md`（判例库）/ `PROGRESS.md`（课题台账）/ `drill-ledger/`（间隔重复账本，简化 FSFS 卡片表）。
- 开局协议：新会话先 HANDOFF → LEARNINGS/ERRORS → PROGRESS/drill-ledger → README 导游图（见《_开局指令-给新会话Agent.md》）。
- 漂移防护：搬动本目录指向的子目录时，同日同步 HANDOFF 与 PROGRESS（《仓库使用手册》§四.3）。
