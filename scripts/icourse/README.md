# MOOC资料采集会话归档

来自2026-10-05本地上传，原目录 `数物+复变/icourse/`。这是历史采集工具和探测证据，不是经完整运行验证的通用下载产品。

- 复变资料现位于 `复变函数与积分变换/资料原件/复变函数_课件_前五章/`（21份分节+5份合并）。
- 数物资料现位于 `数理方程/资料原件/数学物理方程_课程课件/`（45份分节+6份合并）。
- `common.py` 仅从环境变量 `ICOURSE_COOKIE` 读取本机已授权登录态；禁止将真实值写入源码、日志或聊天。未提供即拒绝运行。
- `download_all.py` / `download_xjtu.py` 为历史下载入口，需以本目录为cwd读取索引，输出隔离到仓库 `build/icourse/`。未用真实会话执行联网测试。
- `merge_pdfs.py` 合并归档资料，`fix_order.py` 输出排序计划；原始下载索引含当时绝对路径，仅作为历史证据，不保证当前路径有效。
- `browser_*` / `explore*` / `iface_*` / JS / HTML / JSON / 截图为当时探测记录，不是学习资料；暂保留而不凭文件名删证据。
- 旧会话Cookie和匹配的会话标识已从当前树清除；`pdf_net.json` 中脱敏占位不能用于请求。历史仍含泄露，须先撤销登录态，再另行协调历史重写。
- 只能访问自己已获授权的课程。资料版权归课程提供方；当前仓库公开，分享范围需由仓库所有者核实。
