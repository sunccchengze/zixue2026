# MEMORY_SYSTEM · 大学化学记忆系统

## 开局协议

1. 读 `HANDOFF.md`；2. 扫 `LEARNINGS.md` 与 `ERRORS.md`；3. 查 `PROGRESS.md` 与 `drill-ledger/index.md`；4. 先清到期卡，再从 HANDOFF 的“下一句”继续。

## 文件职责

- HANDOFF：唯一接力入口，永远最新。
- LEARNINGS：只记可迁移的学习模式，不写流水账。
- ERRORS：导师红线与用户典型判例。
- PROGRESS：15 课题状态。
- drill-ledger：简化 FSRS 卡片账本。

## 卡片规则

新卡 Again/Hard/Good/Easy 的 S 分别为 1/1.5/3/6 天；复习乘 0.3/1.4/2.2/3.0（Again/Hard/Good/Easy），再按难度与准点率微调。单次新卡不超过 7；到期卡优先；cw=自信错；累计 4 次 Again 标 leech 并换角度重教。

## 图像与报告

重要公式制作手写课堂笔记风 PNG；结构、能级、相图禁 ASCII。每课题报告照常归档并写审稿意见，但不等待逐篇确认，全部课题结束后统一回顾。
