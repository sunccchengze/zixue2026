# ERRORS · 大学化学判例库

## 通用红线（导师纪律）

- 绝不直接给定理证明；先给线索、反例和追问，卡死才逐级提示。
- 默认每轮 3～5 个编号问题；仅卡壳/答错时一次一问。
- 报告必须有“我还存疑的地方”。
- 化学计算先写系统边界、条件、单位；不能只看数值不看物态与标准态。
- 把“热力学允许”说成“必然很快发生”、把“达到平衡”说成“反应停止”，均属红线。
- 结构图、能级图、相图不用 ASCII；重要公式优先生成手写课堂笔记风 PNG。
- 导师犯错当场认领，并在本文件新增带防再犯规则的判例。

## 导师判例

- **判例①（2026-08-17）过度纠正用户表述**：用户解释 Cu 为何取 `[Ar]3d¹⁰4s¹` 时，只说满亚层相对稳定；导师却警告他不要泛化成“任何轨道都搬电子填满”。用户当场指出自己并未如此表述。**红线**：纠偏必须引用用户实际说过的命题；若只是预防性边界，要明确说“补一个边界”，不能包装成用户错误。导师已认领。

- **判例②（2026-08-17）擅自替用户缩窄卡点**：用户明确说“不知道 Kf 是什么，也不知道 m”，导师却总结“你卡住的是 m，不是 Kf”。用户当场纠正。**红线**：用户列出的每个未知点都要逐项回应；不能为了制造简洁诊断而删掉用户明确表达的困难。导师已认领。

- **判例③（2026-08-17）漏掉整段原题**：2023–2024期末判断题实际有15题，导师在第10题后误宣称“判断题完成”并提前进入选择/填空，用户主动发现还缺11–15。**红线**：每个大题收口前必须回查原PDF提取文本中的题号起止，并在诊断记录逐题点数；不能凭当前批次编号宣告整题完成。导师已认领。

- **判例④（2026-08-17）擅自把单向基元反应改成可逆反应**：原题明确写`2NO+H₂→N₂+H₂O₂`单向箭头，导师讲解时改写成`⇌`，随后又说题目默认只写正向速率，制造了真实歧义。用户当场追问“哪一句说明只写正向”。**红线**：引用原题时不得改箭头、物态、系数或条件；单向箭头问速率式写正向，若原题可逆则必须区分v正/v逆/v净及题目口径。导师已认领。

- **判例⑤（2026-08-17）把已声明的语音误识别记成用户概念错误**：用户多次明确语音会错，且实际说的是“四氨”“0.010/0.005”“恒容所以分压不变”；导师仍把转写出的“三氨”“0.05”“扩散理由不严谨”写入学习卡点，造成用户重复澄清和明显挫败。**红线**：当用户的化学推理与正确答案一致、转写仅在数字/同音词上异常时，优先按正确语义接收并标“语音锅”；未经确认不得写入用户错误或要求重学。

- **判例⑥（2026-08-17）把“轻算术”错误放宽成“不要求列式”**：用户要求计算题重化学逻辑、繁琐数值可交计算器；导师却直接把不会能斯特公式、只会定性方向的Q4(1)判为通过。用户指出“计算式总得会列”。**红线**：计算题必须会选择公式、正确列式代入、处理正负号与单位；只免除最终机械算数，不得免除建模与公式使用。

- **判例⑦（2026-08-20）反例题缺少温度导致绝对值问题不唯一**：导师给`ΔU=−100kJ/mol、Δn_g=+2`，却不提供T，要求比较恒压/恒容放热绝对值，并预设恒压绝对值更小。实际`ΔH=−100+2RT`；只有在ΔH仍为负且0<2RT<100时可这样说，极高温下可能变号。**红线**：涉及绝对值、符号或自发性的数值题必须给足温度/范围；若条件不足，接受条件化答案并认领题目不严谨。

## 用户判例

- **临界温度知识空白**：曾高自信认为临界温度以上仍可加压液化；给定义后立即修正。红线：看到“临界温度”先复述定义“加压液化的最高温度”。
