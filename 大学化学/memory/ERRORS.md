# ERRORS · 大学化学判例库

## 通用红线（导师纪律）

- 绝不直接给定理证明；先给线索、反例和追问，卡死才逐级提示。
- 默认每轮 3～5 个编号问题；仅卡壳/答错时一次一问。
- 报告必须有“我还存疑的地方”。
- 化学计算先写系统边界、条件、单位；不能只看数值不看物态与标准态。
- 把“热力学允许”说成“必然很快发生”、把“达到平衡”说成“反应停止”，均属红线。
- 结构图、能级图、相图不用 ASCII；重要公式优先生成手写课堂笔记风 PNG。
- 导师犯错当场认领，并在本文件新增带防再犯规则的判例。
- 提问时不得把答案写进题干，题干只给条件，答案由用户产出。
- **配位数绝不再考（用户点名）**：属于初中级概念；今后任何题目不得要求配位数。配位命名只少量验证，用户自称“只是命名不熟练”，不做大题考察。

## 导师判例

- **判例①（2026-08-17）过度纠正用户表述**：用户解释 Cu 为何取 `[Ar]3d¹⁰4s¹` 时，只说满亚层相对稳定；导师却警告他不要泛化成“任何轨道都搬电子填满”。用户当场指出自己并未如此表述。**红线**：纠偏必须引用用户实际说过的命题；若只是预防性边界，要明确说“补一个边界”，不能包装成用户错误。导师已认领。

- **判例②（2026-08-17）擅自替用户缩窄卡点**：用户明确说“不知道 Kf 是什么，也不知道 m”，导师却总结“你卡住的是 m，不是 Kf”。用户当场纠正。**红线**：用户列出的每个未知点都要逐项回应；不能为了制造简洁诊断而删掉用户明确表达的困难。导师已认领。

- **判例③（2026-08-17）漏掉整段原题**：2023–2024期末判断题实际有15题，导师在第10题后误宣称“判断题完成”并提前进入选择/填空，用户主动发现还缺11–15。**红线**：每个大题收口前必须回查原PDF提取文本中的题号起止，并在诊断记录逐题点数；不能凭当前批次编号宣告整题完成。导师已认领。

- **判例④（2026-08-17）擅自把单向基元反应改成可逆反应**：原题明确写`2NO+H₂→N₂+H₂O₂`单向箭头，导师讲解时改写成`⇌`，随后又说题目默认只写正向速率，制造了真实歧义。用户当场追问“哪一句说明只写正向”。**红线**：引用原题时不得改箭头、物态、系数或条件；单向箭头问速率式写正向，若原题可逆则必须区分v正/v逆/v净及题目口径。导师已认领。

- **判例⑤（2026-08-17）把已声明的语音误识别记成用户概念错误**：用户多次明确语音会错，且实际说的是“四氨”“0.010/0.005”“恒容所以分压不变”；导师仍把转写出的“三氨”“0.05”“扩散理由不严谨”写入学习卡点，造成用户重复澄清和明显挫败。**红线**：当用户的化学推理与正确答案一致、转写仅在数字/同音词上异常时，优先按正确语义接收并标“语音锅”；未经确认不得写入用户错误或要求重学。

- **判例⑥（2026-08-17）把“轻算术”错误放宽成“不要求列式”**：用户要求计算题重化学逻辑、繁琐数值可交计算器；导师却直接把不会能斯特公式、只会定性方向的Q4(1)判为通过。用户指出“计算式总得会列”。**红线**：计算题必须会选择公式、正确列式代入、处理正负号与单位；只免除最终机械算数，不得免除建模与公式使用。

- **判例⑦（2026-08-20）反例题缺少温度导致绝对值问题不唯一**：导师给`ΔU=−100kJ/mol、Δn_g=+2`，却不提供T，要求比较恒压/恒容放热绝对值，并预设恒压绝对值更小。实际`ΔH=−100+2RT`；只有在ΔH仍为负且0<2RT<100时可这样说，极高温下可能变号。**红线**：涉及绝对值、符号或自发性的数值题必须给足温度/范围；若条件不足，接受条件化答案并认领题目不严谨。

- **判例⑧（2026-08-21）把用户合法的估算写法误判为“中间数乱了”**：课题04 Q5，用户写 pH = 9.7 − lg5.6，导师评“数值上碰巧≈8.95，中间数乱了，记住正路”。用户坚持并给出完整推导链：pKa = −lg(5.6×10⁻¹⁰) = 10 − lg5.6；pH = pKa + lg(1/2) = 10 − lg5.6 − 0.3 = 9.7 − lg5.6，数学完全合法，且避免了手算 lg5.6，是聪明的写法。**红线**：判卷前必须沿代数规则完整还原用户算式再下结论；写法与“正路”不同不等于错，只有数值或符号错误才标错；用户坚持推导链时先复算再回应。导师已认领。

- **判例⑨（2026-08-24）误读手写图片并虚构总反应末尾的4H⁺**：用户在Na₂SO₄水溶液电解题中，总反应正确写为`2H₂O→2H₂+O₂`，导师却把上一行阳极半反应末尾的`+4H⁺`串读到下一行，错误判成“总反应未消去H⁺”，还据此安排重复修复。用户上传更清晰图片并指出导师胡说。**红线**：手写图片判卷必须逐行区分题号、半反应与总反应，不能把相邻行内容拼接；若视觉上真有歧义，应明确说“我不确定这一处”并只确认该位置，不得用确定语气虚构用户笔迹。导师已当场认领并撤销错判。

- **判例⑩（2026-08-30）生图模型把d轨道盒子数画错**：课题09八面体高低自旋图卡中，导师生成的第一版把t2g画成4盒、eg画成3盒，导致Co³⁺低自旋t2g⁶画成4盒、高自旋eg²画成3盒，用户指出“你画图没有画对吧！”。**红线**：d轨道固定5盒，分裂后t2g恒3盒、eg恒2盒，低自旋t2g⁶ eg⁰为3满+2空，高自旋t2g⁴ eg²为t2g 1双2单+eg 2单共4单电子；生图后必须数盒子、数电子再发图，错图当场认领重画并记判例。导师已认领，已重画v2、v3、v4中文修正版，v4最终正确。

- **判例⑪（2026-08-30）能量账图卡电子数与盒子数不匹配**：第二次重画的高低自旋能量账图卡中，左侧高自旋eg只画1个电子，t2g只画3个电子，总数不足d⁶，用户再次指出“你刚才的图画的又出问题了”。**红线**：高低自旋图必须同时满足盒子数（t2g 3、eg 2）和电子数（d⁶），高自旋t2g⁴ eg²共6电子4单，低自旋t2g⁶ eg⁰共6电子0单，E高=4Et2g+2Eeg+1P，E低=6Et2g+3P，ΔE=2(P-Δ₀)，图后必须双检。导师已认领，已重画最终修正v4版正确。

- **判例⑫（2026-08-30）配位命名判松**：用户写“K3[Fe(CN)6] 六氰合铁化钾(III)”和“[Co(NH3)5Cl]Cl2 氯化一氯五氨合钴(III)”，导师却判✓，用户当场指出“第一题答错了你还判对？”。实际K3[Fe(CN)6]规范应为六氰合铁(III)酸钾（铁氰化钾），“铁化钾”缺“酸”；[Co(NH3)5Cl]Cl2规范应为一氯·五氨合钴(III)氯化物，配阴离子“氯化物”在最后，不能把“氯化”放最前。**红线**：配位命名必须严格按“配体数+配体名+合+中心名(氧化数)+酸/化物”顺序，酸根/化物在最后，氧化数括号紧跟中心；“铁酸钾”不能写“铁化钾”，“氯化物”不能前置；错名必须判✗并针对性加练3～5题，不以“接近”放宽。导师已认领。

- **判例⑬（2026-09-01）提问时把答案写进题干**：大排查批3/4中，导师写“VSEPR符号：A中心 X成键原子数 E孤对数 电子域m+n 举SF4 AX4E1”“杂化守恒：参与杂化的AO数=杂化轨道数 例1s+3p→4 sp³”等，题干直接包含答案，用户指出“你在直接给我答案吗”。**红线**：题干只给条件和待求，不写结论和例子；答案由用户产出，导师只在判卷时补。已认领，重出批3/4。

- **判例⑭（2026-09-03）把用户括号式旁白口误定性成“概念张冠李戴”**：批3第1题 ClF₃，用户答案 5 电子域 / AX₃E₂ / T 形 / 孤对在赤道位全对；但旁边写了一句“忘记 F 是强场还是弱场；强场对应低自旋 d²sp³”，导师据此判“VSEPR 与晶体场两套模型混用”并记入卡点。用户当场纠正：“我就是手滑了！我五个电子域都答对了怎么可能写那两个 d 轨？”**红线**：用户写在“思考/旁白/括号”里的即兴联想不等于答案内容；判卷只看其最终给出的结论与论证。若该句只是旁白、未作为结论输出，不得按概念错扣分或写入卡点。导师已认领，已将 LEARNINGS 条目改为“高分全对 + 旁白口误，不扣分”。

- **判例⑮（2026-09-05）误读手写图上标，把全对判成“漏指数”**：批4第5题用户写 `v=k[A]²[B]`、总级数 2+1=3、A加倍B减半→2倍，全部正确；导师初判误以为写的是 `k[A][B]` 而判“漏 A 的指数”。用户核对原图纠正：“第五题你仔细看图，我没漏。”**红线**：涉及指数/上下标/角标时必须逐字符放大核对再判；手写小上标不能凭印象判“漏”。若不确定，应明确说“我不确定这一处，请指认”并只确认该位置，不得用确定语气误判。导师已认领，判卷改为“全部正确”。

- **判例⑯（2026-09-05）仓库级结构性事故：自出“温和版”三卷降智 + 用 20 题抽查潦草宣布“大排查收口”**：旧 `期中检测/卷一二三.docx` 客观题砍半、填空覆盖仅为真题 1/5、计算全是单步标准态套用；且卷二简答与卷三简答整题重复、Zn-Cu 素材连用三次（卷内查重失效）；更严重的是用批1–4 约 20 道自编温和题就写“大排查已收口、开课题11”。用户批评：“思考不拐弯、门槛极低、改对一遍就放行、离真题差得远”。**红线（后果最严重的判例，优先级最高）**：
  1. 出题一律从“学校真题原型 + 坑法编号”出发（见《真题解剖/命题DNA-陷阱清单与三套C档卷设计矩阵.md》），禁止从卡面文字出发编题；
  2. 结构参数对齐真题：10 判断级概念坑（可并入选择）+15~20 选择 +25~35 分填空 +25~40 分计算；每卷 A 档题量 ≤20%；选ABCD/判√×打散均衡；
  3. 组卷必须维护“考点×坑法”选题矩阵并查重——同素材三卷不得连用，同坑法编号三卷至多一次；
  4. 每卷须含数值审美配额：10⁻ⁿ 级、≥10²⁰ 级、负数答案、ln/e 运算各至少一处；烟雾弹数据、反推题、条件限定词题须各有席位；
  5. 所有计算数值须经独立脚本双核算后再发卷（2026-09-05 终审即逮住卷二算3 根号内漏乘 4 的笔误）；
  6. **任何“收口/过关/通过”类结论，必须有题库级覆盖证据 + 真题级卷面成绩（C 档正确率 ≥70%）支撑**；20 题抽查充其量是侦察，永远不构成收口；掌握=当次对+隔 1~3 天无提示再对+能讲清，改对一遍绝不等于掌握；
  7. 发现题目过易时主动自首降级重出，不得等用户发现。判例全文证据版见《真题解剖/解剖-旧期中检测卷123-温和版自检.md》（51 题逐题档位终审）。
