## 下一句该问什么

先完整反馈20题摘要，然后修复A组5个模块：
1. 第一电离能：用户定义正确但选D；标准C。周期总体左→右增，Mg为3s²满亚层，失电子比Al(3p¹)难，故I₁(Mg)>I₁(Al)。
2. ΔH/ΔU：条件并不少。`ΔH=ΔU+Δn_gRT`；该反应气体产物2mol、反应物1mol，Δn_g=1；298K时RT≈2.48kJ/mol，所以ΔU=ΔH−2.48，选C。
3. MO遗忘：O₂两个π*单占→顺磁；B₂在B/C/N次序下，价层6e填`σ2s²σ*2s²π2p_x¹π2p_y¹`，也顺磁，键级1。N₂抗磁键级3，F₂抗磁键级1。
4. 作用力：取向看永久偶极矩，H₂O最大、CO最小；色散看极化率，HBr最大。原解析说CO最小疑似错误，科学口径H₂O最小，已记`资料勘误.md`，此题不作为硬扣分依据。
5. 元素：n=3,ℓ=2说明3d电子；总3价电子→3d¹4s²，为Sc，Z=21。V是3d³4s²、Z=23。

发修复A组5题：
1. 为什么Mg第一电离能高于Al？
2. 对`C(s)+CO₂(g)→2CO(g)`，写ΔH与ΔU关系并算Δn_g，不要求乘RT。
3. 写出B₂最后两个电子落在哪里、未成对数、磁性、键级。
4. 用“偶极矩/极化率”分别给CO、HBr、H₂O的取向力最大最小、色散力最大最小；同时指出原解析争议。
5. 为什么量子数n=3,ℓ=2指向Sc而不是V？写两者价电子排布。
