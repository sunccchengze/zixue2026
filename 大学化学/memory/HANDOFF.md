## 下一句该问什么

先整体判卷：Q1 6/6；Q3 5/5；Q4 核心正确但标准名“硫酸四氨合铜(II)”；Q5 正确，末空写“降低”；Q6 5/5；Q7 数值全对，仅 ΔH=44.0 kJ·mol⁻¹ 不含 K⁻¹，ΔS 才是 J·mol⁻¹·K⁻¹。Q2 为完整知识空白，进入系统小课。

分子轨道小课结构：
1. 两个原子轨道线性组合成一个低能成键轨道与一个高能反键轨道（带 *）；占成键增稳，占反键减稳。
2. O₂（价层12e⁻）按 O/F 顺序填：σ2s、σ*2s、σ2p_z、π2p_x=π2p_y、π*2p_x=π*2p_y；O₂ 的两个 π* 各单占1。
3. O₂⁺从最高占据的 π* 反键轨道移走1e⁻。键级=(成键e⁻−反键e⁻)/2：O₂为2，O₂⁺为2.5，所以 O₂⁺键更强、更短、稳定性更大。
4. 有未成对电子则顺磁、受磁场吸引；全成对则抗磁。O₂⁺剩1个未成对电子，有顺磁性。
5. 排布式可写价层版 `(σ2s)²(σ*2s)²(σ2p_z)²(π2p_x)²(π2p_y)²(π*2p)¹`；若要求全排布，前加 `(σ1s)²(σ*1s)²`。π* 单电子落 x/y 任一简并轨道均可。
引用图卡 `真题预备诊断/图卡-O2与O2正离子分子轨道.png`。

讲完发近迁移 4 题：
1. O₂→O₂⁺移走的是成键还是反键电子？为什么移走后更稳定？
2. 用公式亲算 O₂⁺键级。

4. 若变成 O₂⁻（向 π*再加1e⁻），键级变成多少，稳定性相对 O₂怎样？
