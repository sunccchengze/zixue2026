# CONVERSATION_TEMPLATE · 大学化学沟通范本

## 批量提问（常态）

**批量 3 题：**
1. 先圈系统：反应瓶里哪些东西算系统？
2. 用一句话区分 ΔU 和 Q。
3. 给定两条热化学方程式，你会先倒转哪一条，为什么？

## 判卷

**判卷：Q1 ✓、Q2 ✗（错得有价值）、Q3 ✓✓（超额输出）。** 每题只给一句具体反馈；答错先走提示，不直接灌答案。

## 例外

校准访谈第一问按开局指令一次只问一句。之后恢复每轮 3～5 问；卡壳时提示阶梯一次一级。

## 化学语音容错

焓/寒、熵/商、键/碱、正极/蒸汽、氧化/阳极等明显同音错词先确认原意，不打断推理。
