## 逐题判卷

### 第1题 · ClF₃ 的 VSEPR
- **用户答案**：AX₃E₂，总电子域数 5，T 形，孤对电子在 2 个赤道位。（另有一句旁白“忘记 F 是强场还是弱场、强场对应低自旋 d²sp³”，已确认是口误/即兴联想，不是答案内容。）
- **判定**：✅ **全对（5 电子域 / AX₃E₂ / T 形 / 孤对在赤道位）**。旁白口误不扣分（判例⑭）。
- **关键式**：电子域 5 → sp³d → AX₃E₂ → T 形；2 个孤对必占**赤道位**（减少 90° 排斥）。

### 第2题 · 乙烯 C₂H₄
- **用户答案**：两个 C 都是 sp²；参与 AO 为 2s、2p；2p_z 肩并肩电子云重叠。
- **判定**：✅ **正确**。
- **补齐**：每个 C 用 `2s + 2p_x + 2p_y → 3个sp²`，用于 σ 骨架；剩余 **2p_z** 不参与杂化，两个 C 的 2p_z 肩并肩（侧面）重叠形成 π 键，π 电子云在分子面上下。

### 第3题 · CO₂ 非极性 vs H₂O 极性
- **用户答案**：CO₂ 直线形，正负电荷中心重合，键偶极矢量和为 0，键角 180°；H₂O 角形，2 个孤电子对，矢量不为 0，键角略小于 109°28′。
- **判定**：✅ **正确**。
- **微调口径**：H₂O 实测键角约 **104.5°**（小于 109.5° 的原因：孤对-成键对排斥 > 成键-成键对排斥），表述为“略小于 109°28′”无误。

### 第4题 · 乙醇 vs 二甲醚沸点
- **用户答案**：乙醇有羟基，可形成分子间氢键，沸点升高；乙醚有醚键，无氢键。
- **判定**：✅ **方向正确**。
- **精确化**：乙醇 O–H 既能**给**氢键又能**接受**氢键，可形成强分子间氢键网络；二甲醚只有 C–O–C，虽 O 可接受氢键，但无 O–H **给体**，**分子自身之间不能形成强氢键网络**，主要靠偶极-偶极 + 色散力 → 沸点低得多。

### 第5题 · 配合物命名 + 氧化数 + 配位数
- **用户答案**：六氨合钴(III)氯化物；六氰合亚铁(II)酸钾。
- **判定**：🟡 **名称基本对，但题问的氧化数/配位数没写；命名建议改标准写法**。
- **标准命名**：
  - `[Co(NH₃)₆]Cl₃` → **三氯化六氨合钴(III)**；中心 Co **+3**；配位数 **6**；配离子 `[Co(NH₃)₆]³⁺`。
  - `K₄[Fe(CN)₆]` → **六氰合铁(II)酸钾**（俗名亚铁氰化钾；“铁(II)”已含亚铁，不需要再写“亚铁(II)”）；中心 Fe **+2**；配位数 **6**；配离子 `[Fe(CN)₆]⁴⁻`。

## 教学附录（2026-09-03 追加：F⁻ 强弱场 + d²sp³ vs sp³d² + 亚铁口径）

### A. F⁻ 是弱场配体
- 光谱化学序（近似）：`I⁻ < Br⁻ < S²⁻ < Cl⁻ < F⁻ < OH⁻ < C₂O₄²⁻ < H₂O < NH₃ < en < NO₂⁻ < CN⁻ < CO`
- F⁻：电负性大、几乎只做弱 σ 给体、不反吸电子 → Δ₀ 小 → **弱场**；CN⁻/CO → Δ₀ 大 → 强场。
- 判别：**Δ₀ > P → 低自旋（强场）；Δ₀ < P → 高自旋（弱场）**。

### B. 先看主语再选模型
| 主语 | 模型 | 写法 |
|---|---|---|
| 主族分子（ClF₃、PCl₅、SF₆…） | VSEPR/价层电子对 | 电子域 5→sp³d，6→sp³d² |
| 配合物（八面体） | 晶体场+杂化 | 强场/低自旋→d²sp³；弱场/高自旋→sp³d² |

- `d²sp³`：内轨，用内层 (n−1)d 两个轨道。
- `sp³d²`：外轨，用外层 nd 两个轨道。
- `dsp²`（一个 d）是**平面正方形**（[Cu(NH₃)₄]²⁺ 类），勿与上面混。

### C. 口决
> 主族数电子域，配合物看场；场强配内轨 d²，场弱走外轨 sp³d²。

### D. 用户命名口径（已记偏好）
- `K₄[Fe(CN)₆]` → **六氰合亚铁酸钾**（常用名，用户固定写“亚铁”，不加 (II)）。
- `K₃[Fe(CN)₆]` → **铁氰化钾 / 六氰合铁(III)酸钾**（Fe³⁺为“铁”，Fe²⁺为“亚铁”）。
- 一般题用户写“亚铁/铁/正铁”不扣分；仅当题目明确要求 IUPAC 系统命名时提示带 (II)/(III)。
- **用户点名红线：配位数绝不再考；配位命名只做少量验证。**
