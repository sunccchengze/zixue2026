# 课题 01 · 守恒、反应热与焓 · 开题简报

## 研究背景

燃烧看似让东西“消失”，金属锈蚀却让东西“增加”。拉瓦锡用封闭容器和称量把争论从故事变成数字；随后热力学又要求我们同时给能量记账。

## 研究问题

**化学变化中，物质与能量究竟以什么意义守恒；为什么反应热可以绕路计算？**

## 攻关线索

1. 先画系统边界：蜡烛、铁、空气、产物哪些被算进来？
2. “质量守恒”究竟守的是整套系统、元素种类，还是某一件物体？
3. 热、功、内能和焓中，谁是状态函数，谁依赖过程？
4. 恒压反应热为什么常用 ΔH 表示？
5. 如果起点和终点相同，热量为什么能沿不同反应路线相加？

## 里程碑

- [x] 能用系统边界统一解释蜡烛变轻与铁生锈变重
- [x] 能区分热 Q、功 W、内能 U、焓 H
- [x] 能在给定条件下判断 qv=ΔU、qp=ΔH
- [x] 能独立完成一条盖斯定律路线
- [x] 能提出至少一个守恒表述的边界或存疑
