# 第二讲 · 方程尺度账、pH项与浓差电池

> 提速档：先连续讲完，再集中手写4题。

## 一、方程倍乘时，四个量为什么变化不同

假设原反应转移n mol电子：

`ΔG°=−nFE°`

总反应整体乘2时，物质的量和电子转移都翻倍，因此`n'=2n`、`ΔG°'=2ΔG°`。代回：

`E°'=−(2ΔG°)/(2nF)=E°`

所以E°像“每单位电荷的下坡高度”，是强度量，不随方程倍乘。

又因：

`ΔG°=−RTlnK`

反应乘2后ΔG°翻倍：

`lnK'=2lnK=ln(K²)`，故`K'=K²`。

记忆表：

| 量 | 方程×2 |
|---|---|
| E° | 不变 |
| n | ×2 |
| ΔG° | ×2 |
| K | K² |

## 二、写Nernst方程的固定四步

1. 写并配平实际总反应；
2. 按“产物活度幂/反应物活度幂”写Q，纯固体纯液体删掉；
3. 数总反应电子转移数n；
4. 代`E=E°−(0.05916/n)lgQ`（25 ℃）。

Q增大，电池按所写方向的推动力减弱，E降低；Q减小，E升高。

## 三、pH为什么会被计量数放大

重铬酸根的还原半反应：

`Cr₂O₇²⁻+14H⁺+6e⁻⇌2Cr³⁺+7H₂O`

电子不写入Q，水为纯液体也不写：

`Q=[Cr³⁺]²/([Cr₂O₇²⁻][H⁺]¹⁴)`

pH升高1，`[H⁺]`缩小10倍；因为有14次方，Q放大`10¹⁴`倍。因此：

`ΔE=−(0.05916/6)lg(10¹⁴)=−(0.05916/6)×14≈−0.138 V`

记忆：H⁺在反应物侧，升pH会削弱该还原反应的电势。

## 四、浓差电池：E°=0也能有电压

电极材料相同、仅浓度不同，例如：

`Cu|Cu²⁺(0.010 M)||Cu²⁺(1.0 M)|Cu`

高浓度Cu²⁺一侧更想还原，是阴极；低浓度一侧Cu更容易氧化补充Cu²⁺，是阳极。电子从稀侧流向浓侧，最终趋向浓度相等。

两边标准电势相同，所以`E°电池=0`；实际电势来自浓度差：

`E=(0.05916/2)lg([Cu²⁺]浓/[Cu²⁺]稀)`

本例比值100，所以`E=0.05916 V`。
