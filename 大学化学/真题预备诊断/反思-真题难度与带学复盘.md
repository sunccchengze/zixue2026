**2024–2025 真题的"转弯"（更狠）：**

## 二、我认领的四个错误（不是借口）

1. **做卷子没对照真题**：我声称"仿 2023–2024 期中风格"，实际只仿了"题型名字"，没仿"题量、陷阱密度、多步数值"。这是最根本的失职——**我没有把仓库里现成的真题文本当唯一难度基准**。

2. **把"大排查"当成"20 题就能收口"**：账本 topic00 就有 **100 条卡**，全科约 **150+ 条卡**。而我用自己编的 4×5=20 题就宣布收口，且**根本没更新 drill-ledger 的状态与到期日**（index 还停在 2026-08-24）。这等于**把"做了 20 道练习"冒充"覆盖了 150 条知识"**。

3. **把"改对一遍"当成"掌握"**：你在最后那一题把 d⁶ 改对了，我就说通过并开下一章。这违背了本项目的间隔重复规则（Again/Hard 后要隔约 3 轮、换表面形式重考；leech=4 次 Again；掌握 = 下次到期**不看答案**还能对+能解释）。我用"你已经会了"掩盖了"长期记忆尚未建立"。

4. **把"你自评不扎实"当成"我再出点易题安慰"**：你明明在反馈"基础地动山摇"，我却出了更平的卷子去"检测"，这是在**回避真正的难度**，不是帮你。

## 三、新方案（提议，先不动手出新的，等你看过）

### 1. 收回"大排查收口"

- drill-ledger 全量到期卡**必须逐卡重测**，不再只抽查 3 张。

### 2. 难度三档（按学校真题定义）
- **A 档（识别）**：能说出概念、写对符号——**不到此档不能进 B**。
- **B 档（单步迁移）**：把概念放到一个稍改的情境（如电子亲合能 F vs Cl、n=2,m=−1 轨道数）。——**学校判断/选择题主要是 B**。
- **C 档（综合+陷阱+数值）**：多因素判断、反例狙击、多步计算（ΔU=ΔH−2.48、分压两步、盖斯组合、CaCO₃ 分解温度、从量子数反推元素）。——**学校填空/计算主要是 C**。

### 3. 判定标准（不再"一遍而过"）
- **及格线**：一套真题目 85 分制，按真题难度出，**C 档正确率 ≥70%**；
- **掌握定义**：当次对 + **间隔 1~3 天后不看重做还能对 + 能讲为什么**（尤其 B/C 档）；
- **leech**：同一卡 B/C 档错 3 次以上 → 换角度重教，不允许只"提醒一句"。
- **通过后**：再拿**真题原卷/改编**做一次"真实考场级"（限时、无提示），而不是再让我编一套我自己的题。
