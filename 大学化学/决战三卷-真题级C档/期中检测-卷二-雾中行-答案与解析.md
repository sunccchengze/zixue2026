## 二、选择逐题解析

**1. B**（X2 考古坑，档位 C−）。
 钢桶：Q=0、体积功 W=0 → 按第一定律 ΔU（体系总内能）=0；
 但反应焓变按定义核算 ΔH = ΔU + Δ(pV)，恒容放热反应使温度、压力剧升，
 Δ(pV)>0，而体系化学内能转化为热能的"反应份量"项为负——
 结论为：热力学第一定律计算对象区分（本体系 ΔU=0）与反应自身的
 ΔrHmθ（放热 <0）是两回事；选项 B 的正确读法：ΔU=0、ΔH > 0 用于
 "绝热钢桶"（产物处于高温终态的表观摩尔焓差）。本卷与学校原型保持一致。
 翻车点：A/C（Q=0 ⇒ ΔH=0，混淆 Q 的概念对象）；
 D（"放热反应 ⇒ ΔU<0"混淆了反应的焓与体系总内能）。
 原型：2016 期中选9（0.72% 温存考点）。账本：00-33 钢桶家族。

**2. A**（G1 现象反推，档位 C−）。
 变冷 ⇒ 吸热 ΔH>0；自发 ⇒ ΔG<0；两式联立 ⇒ ΔS>0（−TΔS 攻入）。
 且后空与"晶体溶解→粒子弥散"的热力学解释互相印证。
 翻车点："变冷 = 放热"的体感反读；D（变冷≠破冰点）。
 原型：2024–25 期中判9（NH₄NO₃）→ 期末选7（同年双考基因）。

**3. D**（档位 B）。s→l 小增；l→g 剧增（Sθ 水液 69.9 → 气 188.7 J/(mol·K)）；
 石墨→金刚石 ΔS<0；H₂+Cl₂→2HCl 摩尔数相同但复杂度略增，远小于气化。
 原型：2016 期中填4/期末选1 家族。

**4. B**（P15 计算性配方）。H–Cl Δχ=0.9 ∈ (0.4, 1.7)。
 Mg–O/Cs–F > 1.7 范离子键；Cl–Cl Δχ=0 非极性共价。
 翻车点：把 0.9 与 1.7 相比然后"接近离子"误选 A。
 原型：宝典 P16 第 7 讲公式双界。

**5. D**（T4 反例需求）。en 有两配位原子 N，多齿；其余单齿（NH₃ 有一对
 孤电子、一个配位点）。翻车点：B 把"氯的四个孤电子对"误当多配位。
 原型：2024–25 期中判8 转选。账本：09-16。

**6. A**（T2 装备矩阵）。HCl、HBr 都是极性分子 → 两者间有取向力+诱导力+色散力。
 B 双双非极（CCl₄ 尽管每个 C–Cl 键极，分子对称总和为零）；
 C 跨极对只有色散+诱导；D 双双非极。
 翻车点：B（极性键当极性分子）。原型：2023–24 期中选6 + 期末选13 家族。

**7. B**（库存坑 K7 首次动用，档位 B+）。
 盐效应：无共同离子的电解质通过活度系数使微溶盐溶解度**略增**
 （治学集所给量级千分之几）。A 是同离子效应的反射。
 翻车点：A（一概"加盐退溶"）。原型：治学集 3.3 星标 + 宝典生存区公式。

**8. C**（档位 B）。原子晶体 SiO₂ 1710 ℃ > 离子晶体 NaCl 801 > KI 681
 （同晶型按晶格能：Na⁺ 半径小 > K⁺）> 分子晶体 S₈(119 ℃) > CO₂(−78.5 ℃)。
 翻车点：把 NaCl/KI 序颠倒（晶格能随阳离子半径递减）。
 原型：2024–25 期中选7 扩大军（五个排序）。

**9. C**（档位 B）。键角由电子对排布（杂化）与孤对决定，与
 "中心半径"不成唯一关系。D 关键：偶极矩=键矩矢量和（解释 CO₂ 分子极性为零）。
 原型：2016 期末选2。

**10. B**（X1 考古坑，档位 C−）。同种 Ag|Ag⁺ 电极两极浓度不同：Nernst
 表明浓侧 E 更正为正极（"浓差电池高浓侧为正极"）。
 翻车点：C（"同材料"即零压）；D（反向记忆）。
 原型：2016 期末判18 的 holiday——"退役十年，复活回枪"。
 备注：阳极溶出、阴极析出，Ag⁺ 从浓侧迁移到稀侧。

**11. C**（档位 B）。催化剂改历程、降 Ea、加速率常数 k 而非 K。

**12. D**（T5 摘条件款）。ΔrGmθ 是温度函数；只判标准态方向。
 A 错：判断任意状态需等温方程 ΔrGm = ΔrGmθ + RTlnJ；
 B 错：ΔG 与速率无关（热/动分家）。
 原型：2016 期末判7 + 16 期末选20 家族。

**13. C**（K 系库存+四象限，档位 B）。ΔH>0、ΔS<0 → ΔGθ = ΔHθ−TΔSθ =
 95+0.150T > 0 恒成立 → 永不自发。设置的"633 K"为幻觉转换温度
 （ΔHθ/ΔSθ 此时带负号无意义——分母为负，T转 无物理对应）。
 原型：2024–25 期中算3(3) 的同型考位。

**14. C**（10-12 leech 目标题）。阴极：H₂O 得电子（因 Na⁺ 活性极差难还原）：
 2H₂O + 2e⁻ → H₂ + 2OH⁻（阴极区 pH 升高）；
 阳极：2Cl⁻ − 2e⁻ → Cl₂。
 翻车点：B/D（极性颠倒）；A（Na 气相观）。
 原型：2024–25 期中填10 + 2016 期末选12。账本：10-12。

**15. B**（库存坑 K5 邻近位，档位 C−）。
 拉平效应：水中所有比 H₃O⁺ 强的酸都被拉平到 H₃O⁺（HCl 与 HClO₄ 在水中
 强度看无差）；区分效应：在冰醋酸中，HCl 与 HClO₄ 显示差别。
 原型：治学集 3.3 引用教材 P167。B 级证据+教科书概念框架性正确，
 首次动用后须观察学校是否真考（回填接口）。

**16. A**（档位 B−）。负-正组合全程自发；B（正-负）全程不自发；
 C/D 温敏（本卷选择13 即是 D 象限的姊妹反面）。
 原型：2024–25 期中选15 同族（△/△ 组合的镜像考）。

**17. D**（档位 B+）。同离子效应：解离度↓、pH↑（加的是共轭碱），Ka 是
 温度专属常数不变。
 翻车点：A/B 把"加酸"当"加碱"反射；C（Ka 当变量）。
 原型：2023–24 期末判13（Zn 与 ppt）旁系 + 2016 期中判6（氨水加酚酞）。

**18. A**（G3 考古原型）。M²⁺3d⁵ ⇒ M 基态 3d⁵4s²（失的总是 4s 先）→ Mn。
 翻车点：D（记 3d⁶=Fe²⁺ 的记忆串线）；C（3d⁷=Co²⁺ 也错配）。
 原型：2016 期中填3。

**19. D**（档位 B）。乙二醇两个 −OH、Mn 最大（197 ℃），氢键最盛；乙醇 78；
 丙酮 56（无 H 键可供氢）；乙醚 34.5。
 与其他题的关系：课 10 的沸点比较 purlin。
 原型：期末选8（沸点系列）泛用版。

**20. C**（档位 B）。多电子体系：n 同 l 不同 → E 随 l 增（ns<np<nd<nf）。
 A（3d 是 5 条简并）；B（能级组差）；D（H 原子单电子：能量只与 n 有关，
 恰与本句相反——一条"反向也得记住"的冷理）。
 原型：2016 期末判1（简并 5）+ 2024–25 期中判9（l 越大越高）的复合版。

## 三、填空答案

**1.** Fe；3d⁶4s²；（原子序数）26；4s。
评注：失电子顺序 4s 先于 3d（与填充顺序不同——填充是 4s 先填、
失去也是 4s 先，别背反）。账本 08-24/00 区邻域。

**2.** Ksp = [Ca²⁺][F⁻]² = s×(2s)² = 4s³；4×(2.0×10⁻⁴)³ = **3.2×10⁻¹¹**。
翻车点：写成 s³（漏系数 2）或 4s²。

**3.** 理论 ΔTf = 2×1.86×(6.80/136)/(0.250 kg)
 = 2×1.86×0.200 = **0.744 ℃**（即凝固点 −0.744 ℃）；
 i实测 = 0.62/(1.86×0.200) = 0.62/0.372 = **1.67**；
 解释：i<2 ⇒ 完全电离假设高估粒子数 —— 实际体系存在
 **离子缔合/活度<1**（"表观电离不完全"的检测结果而非本意有问题）。
翻车点：把"凝固点 −0.744"当 ΔTf 数值代入与零点混淆。

**4.** Kθ = Ksp(AgCl)/Ksp(AgI) = 1.8×10⁻¹⁰/8.3×10⁻¹⁷ = **2.2×10⁶**；
趋势 **很大（可视为完全）**；
烟雾弹：6.1 mol/L 是无关数据，埋给"不拿来用就会心慌"的同学。
翻车点：把 K 写反成 Ksp(AgI)/Ksp(AgCl) 得 4.6×10⁻⁷。
原型：2015 期末填10 家族 + 宝典 S1 教导。

**5.** 减小；基本不变但微增（盐效应）。

**6.** 1；pKa；1。（"±1"现成考点，2016 期末选18 家族。）

**7.** H₂O；H₂S；水分子间存在大量氢键而其余两者只有分子间力
 （"H 键是超纲小助手"注）。账目：氢键家族复测。

**8.** lnKθ = −ΔrGmθ/(RT) = 57 000/(8.314×298) = **23.0**；
 Kθ = e²³ ≈ **1.0×10¹⁰**。
翻车点：用 lg 与 ln 混用（lgKθ = 10 验算：23.0/2.303 ≈ 10 ✓）。

**9.** 阴极：2H₂O + 2e⁻ → H₂↑ + 2OH⁻（或写作 2H⁺ + 2e⁻ → H₂，给分；
 推荐前者——课程水电解口径）；阳极：2Cl⁻ − 2e⁻ → Cl₂↑。

**10.** 溶质质点（粒子）的数目（浓度）；溶质的本性（种类）。

## 四、计算题标准解

### 算1（8 分）
(1) Qp = ΔrHmθ × ξ = −1266 × 1.0 = **−1266 kJ**（放热 1266 kJ）。
(2) Δn(g) = 2 −(4+3) = −5；
 QV = ΔrUθ = ΔrHmθ − Δn(g)RT
 = −1266 − (−5)(8.314)(298)/1000 = −1266 + 12.4 = **−1253.6 kJ**。
 【采分点：Δn 只数气体；Qp–QV 差 12.4 kJ。】
(3) Ⅰ ✓（绝热+Q=0 定义）；
 Ⅱ ×（ΔrHmθ 是反应自身的性质/定义量，与环境绝不绝热无关——
 注意区分"反应焓变"与"体系该款的 Q"）；
 Ⅲ ✓（化学能转热，体系内温度上升）。
原型：2024–25 期中选13 数据本尊 + 2016 期中选9 概念混搭。

### 算2（8 分）
(1) n = 3.00/60 = 0.0500 mol；b = 0.0500/0.100 = 0.500 mol/kg；
 完全电离 i=2：ΔTf = 2×1.86×0.500 = **1.86 ℃**（凝固点 −1.86 ℃）。
(2) i实测 = 1.67/(1.86×0.500) = 1.67/0.930 = **1.80**。
(3) i = 1 + α(ν − 1)，ν=2 → α = i − 1 = **0.80（表观电离度 80%）**。
(4) 离子间静电相互作用 / 离子缔合（离子对）使活度小于浓度 ——
 依数性只数"真正自由的粒子"（这正是 D–H 活度概念的指针味）。
原型：16 期中简5（HgCl₂）的翻面——"反过来问会不会太小"的身份证。

### 算3（8 分）
(1) c/Ka = 0.050/2.0×10⁻⁵ = 2500 > 500 ✓ 近似合法；
 [H⁺] = √(2.0×10⁻⁵×0.050) = √1.0×10⁻⁶ = 1.0×10⁻³ → **pH = 3.00**。
(2) c/Ka = 5.0×10⁻⁴/2.0×10⁻⁵ = 25 < 500 ✗ 必须用精确式：
 x² + Ka·x − Ka·c = 0 → x = [−2.0×10⁻⁵ + √(4.0×10⁻¹⁰ + 4.0×10⁻⁸)]/2
 = [−2.0×10⁻⁵ + 2.01×10⁻⁴]/2 = **9.0×10⁻⁵ mol/L** → **pH = 4.04**。
 （验算真实解离度 α = 9.0×10⁻⁵/5.0×10⁻⁴ ≈ 18%，远超 5% 的近似门槛。）
(3) 强行用近似式：[H⁺] = √(2.0×10⁻⁵×5.0×10⁻⁴) = √1.0×10⁻⁸
 = 1.0×10⁻⁴ → pH = 4.00——[H⁺] 相对误差约 +10%（pH 只差 0.04 是个"温柔的假象"）。
 教训（写一句即可得分）：近似式不是天然合法——先查 c/Ka 再决定算式；
 "稀"不等于"稀到可以忽略解离"；本题 pH 蒙对、[H⁺] 错 10%，
 凡后续要拿 [H⁺] 进别的计算（缓冲比、电导）都会连环炸。
原型：治学集 3.5 例 3-4 同型 + K14 库存坑二次动用。

### 算4（8 分）
(1) K = [CrO₄²⁻]/[Cl⁻]² = Ksp(Ag₂CrO₄)/Ksp(AgCl)²
 = 9.0×10⁻¹² / (1.8×10⁻¹⁰)² = 9.0×10⁻¹² / 3.24×10⁻²⁰ = **2.8×10⁸**。
(2) [CrO₄²⁻] = K×[Cl⁻]² = 2.8×10⁸×0.10² = **2.8×10⁶ mol/L**——
 该数值物理上不可能达到（任何溶液溶不下这么多），含义是：
 该转化反应进行得**极其完全**（平衡前沿产物极端被拉过去），
 实践中 Ag₂CrO₄ 将被 Cl⁻ 几乎完全转化为 AgCl（固体量被消耗尽为止）。
 【此问正是南卷汇 14/15 期末算3"104 mol/L 彩蛋"的教育版——
 承认数学结果、拒绝接受物理结果、给出转化解释。】
(3) AgCl 开始析出：[Ag⁺] = Ksp/[Cl⁻] = 1.8×10⁻¹⁰/0.010 = **1.8×10⁻⁸ mol/L**；
 Ag₂CrO₄ 开始析出：[Ag⁺] = √(Ksp/[CrO₄²⁻]) = √(9.0×10⁻¹²/0.001)
 = **9.5×10⁻⁵ mol/L**；
 判定：**AgCl 先沉淀**（1.8×10⁻⁸ ≪ 9.5×10⁻⁵）。
 用莫尔法语境再说一句：铬酸钾指示剂的原理恰是"后出彩砖"。
原型：23-24 期末算3 骨架 + 16 期末算二分级沉淀。

### 算5（8 分）
(1) ΔrHmθ = [2×0 + 2×(−241.8)] − [4×(−92.3) + 0]
 = −483.6 + 369.2 = **−114.4 kJ/mol**；
 ΔrSmθ = [2×223.0 + 2×188.7] − [4×186.9 + 205.0]
 = 823.4 − 952.6 = **−129.2 J/(mol·K)**；
 ΔrGmθ(298) = −114.4 − 298×(−0.1292) = −114.4 + 38.5 = **−75.9 kJ/mol**。
 【注意 0.1292 是 kJ 化的 ΔS——单位检验采分点。】
(2) J = [(0.50)²×(0.10)²] / [(0.20)⁴×0.10] = 0.0025/0.00016 = **15.6**；
 ΔrGm = −75.9 + 8.314×298×ln 15.6/1000 = −75.9 + 6.82 = **−69.1 kJ/mol < 0**；
 反应向**正方向**进行。（Kθ = e^(75900/2477)≈e^30.6 ≈ 2×10¹³ ≫ J=15.6，双路验证。）
(3) ΔrGmθ(500) = −114.4 − 500×(−0.1292) = −114.4 + 64.6 = −49.8 < 0，
 500 K 标准态下仍自发（放热主导区未过——T转 = 114400/129.2 ≈ 885 K）。
原型：2023–24 期末算1 流程全套 + 等温方程的判向（卷三还要再上范特霍夫）。
