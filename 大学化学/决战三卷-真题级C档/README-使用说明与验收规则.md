每卷：选择 20×2 = 40；填空 10×2 = 20；计算 5×8 = 40；合计 100 分；建议 120 分钟。
设计依据：《../真题解剖/命题DNA-陷阱清单与三套C档卷设计矩阵.md》。

## 使用顺序

1. 卷一（真题原型换皮）→ 卷二（烟雾弹/条件帽）→ 卷三（冷知识/考古/讨论）。
   不要跳卷；每卷一次性限时完成。
2. 手写拍照提交；关键化学式/电子排布会被回显核对后才判分
   （指数、上下标放大核对——判例⑮）。
3. 判卷按答案册的“采分点”表执行；判断式选择题选对 1 分 +
   写出任一错误选项的错因再 1 分（训练加严，学校卷无此要求）。

## 验收（对“决战复习”通过的定义）

- 每套卷单独出判卷报告（仓库内成文）。
- 通过线：**整套 C 档题正确率 ≥ 70%**（不是总分 ≥70）。
- 任一课题映射区（答案册"考点/账本"列）错 ≥3 次 → 该课题升级为 leech，
  换角度重教，间隔 1–3 天重测变体，仍按"当次对+无提示再对+能讲清"算掌握。
- 三卷全部判完后产出《决战三卷-复盘与leech清算.md》。
