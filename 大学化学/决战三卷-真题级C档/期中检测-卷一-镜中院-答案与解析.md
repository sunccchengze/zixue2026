## 二、选择逐题解析

**1. D** 633 kJ。进度 ξ = 3.0/6 = 0.5 mol → 1266×0.5 = 633 kJ。
考点：计量进度折算（N1）。档位 C−。翻车点：选 A（把"每摩尔进度"当成"每摩尔
水"）；选 B（3 mol 水当反应数）；选 C（1.5 反除）。
原型：2023–24 期中选14（44.8→89.6）同族——账本卡（新编号 00-105）。
 
**2. B**。(3,2,−2,+1/2)：n=3，l=2<n，|m|=2≤l，m_s=±1/2 → 合法。
A l≥n 非法；C |m|>l 非法；D m_s 只能 ±1/2。
考点：量子数三条规则。档位 B。原型：2023–24 期中选择1 换皮（选项重排）。

**3. D**。E(4d) = 4+0.7×2 = 5.4 > E(5s) = 5+0 = 5.0 —— 应为 E(4d) > E(5s)。
考点：n+0.7l 公式应用 ×4 连比。档位 B。翻车点：不记得公式时"同周期 d 亚层
靠内所以低"的错误直觉。
原型：2016 期中选择3 ↔ 2024–25 选10 的题族（基因 E=n+0.7l）。

**4. B**。3d⁵4s¹（半满稳定性）。A 是诱导选项（按顺序斜填而不记特例）。
考点：Cr 特例。档位 B。翻车点：A（"未充满前 4s 必满"幻觉）。
原型：2023–24 期中选择3（Cu）的镜像——本题考 Cr。账本 leech 复测区（08 排布卡）。

**5. C**。3d⁵4s²：最高能级 4s → 第四周期；族 = d+s 电子数 = 5+2 = 7 → ⅦB；
该元素是 Mn。错误诱导：B（看 4s 就归 A 族）；A/D（多算一周期）。
考点：周期=最大 n；d 区族数 = (n−1)d+ns 和（≤7 时）。
档位 B。原型：2023–24 期中选择5 ↔ 2014 期末填2 的 Mn 基因。

**6. C**。I₁: N(1402) > O(1314) > C(1086) kJ/mol —— ⅤA 半满高于 ⅥA。
考点：反常。档位 B。翻车点：D（照周期律单调递增排）。
原型：2014 期末填4（N>O）→ 2023–24 选4 的题族。
账本：00-17 周边（电负性与电离能分家）。

**7. A**。HF（氢键，b.p. 19.5 ℃）> H₂S(−60 ℃) > PH₃(−87 ℃) > SiH₄(−112 ℃)。
后三个非氢键分子按色散力（Mr）排：H₂S(34) > PH₃(34) ≈ 同级，但 H₂S 有取向力
（μ≠0，角形）故 >PH₃；SiH₄ 非极性球形 Mr=32 → 最低。
考点：沸点 ≠ 键强；氢键 > 三力；三力内部分配。档位 B+。翻车点：C（纯 Mr 记忆）；
B（把 PH₃ 排在 H₂S 前）。
原型：2023–24 期中选择9 的弱化镜像版（那题考"分子间力最弱"）。

**8. D**。SiO₂ 原子晶体（共价网）熔点 1700 ℃；CO₂ 分子晶体升华 −78.5 ℃。
考点：键型定晶体类型，晶体类型定熔点量级。档位 B。翻车点：C 同族幻觉；A
把 Si–O 高极性误读为离子键。
原型：2016 期末选6（CO₂ vs SiO₂ 熔点）改设问。

**9. A**。键级：O₂⁺ 2.5，O₂ 2.0，O₂⁻ 1.5 → 键长反向：O₂⁺ < O₂ < O₂⁻。
考点：键级-键长反序链条。档位 B+。翻车点：C（把"加电子"误解为"键变强"）。
原型：2023–24 期末选10 骨架 + 仲英小助手例（O₂/O₂⁺/N₂/N₂⁺）。
账本：01-40 键级链复测。

**10. B**。晶体三特征：自发多面体外形、固定熔点、各向异性；非晶体恰好相反。
C 错（非晶体无固定熔点，有软化区间）；D 错（玻璃是典型非晶体）；A 错（一字坑：
晶体力学性质 = 各向异性）。
考点：一字坑 T6。档位 B。翻车点：A 的"异性/同性"眼滑。
原型：2023–24 期中选择11。

**11. A**。NaCl 801 ℃ > MgCl₂ 714 ℃ > AlCl₃ 180 ℃(升华) > SiCl₄ −70 ℃。
链条：离子晶体(1:1 型) > 过渡向 > 层状/分子 > 分子。
考点：离子极化加深使晶格向分子退化。档位 B。翻车点：D（Mr 幻觉的又一次攻击）。
原型：2023–24 期中选择13 换皮（NaF/CaO 是晶格能；本题考熔点排序）。
账本：00-86（NaCl vs CaO 直觉错误的孪生位）。

**12. C**。H、S、G 均为广度状态函数。U 虽为状态函数且加和，但 W、Q 为过程量；
T 是状态函数但为强度量无加和性 → A/B/D 各被一票否决。
考点：双条件双筛（R5）。档位 B+。翻车点：漏看加和性这一半筛子 → 把 T 组选入。
原型：2023–24 期中选择12（S、H、G 组）的扩展版。

**13. A**。目标 = ①−②：ΔH = −393.5 −(−395.4) = +1.9 kJ/mol（吸热、
金刚石在石墨之上）。考点：Hess 换算+方向。档位 B。翻车点：B（减反方向）；
C/D（直接相加）。原型：2023–24 期中选择14 换燃烧底物。
账本：00-31 的顺堂测位。

**14. B**。绝热 Q=0；真空外压=0 → W=0；ΔU=0；理想气体 ΔU 只随 T → T 不变；
H=U+pV，理想气体 pV=nRT、T 不变 → ΔH=0。
考点：自由膨胀"三零"+第四零。档位 B。翻车点：D（把"膨胀必然吸热"的直觉
用到真空膨胀——没人可吸！）；C 的 ΔH≠0 幻想。
原型：2016 期中选10/判11 绝热自由膨胀家族（账 00-53）。

**15. C**。两相平衡处 ΔrGm = 0；此时 Kθ = c液/c固 形态下活度均为 1 → Kθ=1。
A 错：标准态与非标准混同（ΔrGmθ 在 Kθ=1 时等于 −RTln1 = 0——等等，
Kθ=1 代入得 ΔrGmθ = −RT ln Kθ = 0？典坑：对本题纯固↔纯液体系，活度各为 1，
故 J=1=Kθ，确实 ΔrGmθ=0——但命题采分点只要求"ΔrGm=0（两相平衡）与 Kθ=1"，
A 项"ΔrGmθ=0"在本特例亦成立。经复核：A 与 C 在本特例下都成立。
**本题按"最完备描述"判 C 为唯一标准答案；若学生选 A 并自洽，给 1 分（半分）
并在答案旁注明'纯固液体系 ΔrGmθ=0 是特例而非通法'。**（出题端诚实勘误一条，
已记入台账。）
考点：平衡条件 vs 标准函数。档位 B+。翻车点：B（Kθ=0 的轴对称误感）。
原型：2024–25 期中选12（液-气平衡）转固-液版。

**16. A**。亨利定律：p = kH·xB —— 分压↑溶解度↑（气体可乐原理）。
B 错：亨利定律适用稀溶液中的气体溶质；C 错：拉乌尔定律适用稀溶液中的**溶剂**；
D 错：电解质不按理想处理。
考点：两定律适用对象对调陷阱（T2）。档位 B。
原型：2024–25 期中判7 + 选16（对象文换）。账本：00-54。

**17. D**。c/Ka = 0.10/1.0×10⁻⁵ = 10⁴ > 500，近似式合法；验证：[H⁺]近似
= √(10⁻⁶)=10⁻³；精确解 −x²/(0.1−x)=10⁻⁵，x≈9.995×10⁻⁴，偏差 0.05%。
考点：近似条件 c/Ka > 500（库存坑 K14 首次动用）。档位 B+。
翻车点：B（"浓度大才精确"的错误直觉——方向恰好相反）。
原型：南卷汇 2016 期中简2 稀释定律 + 治学集 3.x；首次在全真题解剖之外
开采 K14。

**18. B**。目标 = ① − ②（减反应）→ K = Kθ₁/Kθ₂。
考点：多重平衡"加乘减除"口诀的逆向版（P24 反例位的常规形态——
先考口诀正向，卷三另考反例位）。档位 B。
翻车点：C（减反顺序）。原型：2014 期末填空6、2016 期末选5 题族。

**19. D**。铜电极是活性电极：阳极 Cu − 2e⁻ → Cu²⁺ 溶解；阴极 Cu²⁺ + 2e⁻ → Cu
析出；一溶一析，液中 Cu²⁺ 近似不变（电解精炼原型）。
A 错（Cu²⁺ Eθ 高优先于 H⁺ 还原）；B 错（Cu 比 SO₄²⁻/OH⁻ 更容易失电子）；
C 错（夹在 1：阳极溶解应减重，阴极才增重）。
考点：电极材质改变电解结论的暗门。档位 B+。
翻车点：比照"惰性电极电解 CuSO₄（阴 Cu 阳 O₂）"的经验作答 → 撞 B。
原型：2023–24 期末判5 转选 + 2016 期末选12 电解序列。

**20. C**。T转 = ΔHθ/ΔSθ = 88 000/110 = 800 K（注意 kJ→J 的重要换算，
本卷第二次考单位换算，计入 N3）。
ΔH<0、ΔS<0 → 低温自发（"自发放热又减熵，冷了才肯动"）。
考点：四象限下象限 + T转 数值。档位 B。
翻车点：D（遇 ΔS<0 就否定）；A（遇 ΔH<0 就全程放行）。
原型：2024–25 期中算3 的定量化改选择题 + 2016 期末判21 家族。

## 四、计算题标准解

### 算1（8 分）
(1) 目标 = ② − ①：
 ΔrHmθ = (+96.2) − (−74.8) = **+171.0 kJ/mol**（吸热）。
 依据原理：**Hess 定律**（或"状态函数与途径无关"）。【数值 2 分+原理名 1 分】
(2) ΔrGmθ = ΔrHmθ − TΔrSmθ = 171.0 − 298×0.150
 = 171.0 − 44.7 = **+126.3 kJ/mol**（>0，298 K 标准态下非自发）。
 【单位换算 J→kJ 一致性是隐藏采分点 0.5】
(3) T转 = ΔrHmθ/ΔrSmθ = 171 000/150 = **1140 K**。
 298 K < T转 → 非自发（与(2)互证）；1200 K > T转 → 自发。
 【方向判断两档各 1 分 + T转 1.5 分】
翻车点：ΔS 的 J/kJ 不换 → T转 会算出 1.14 K 的荒诞值（此时量纲自检立现）。
原型：2024–25 期中算3 换底物 + 2023–24 期中算4 的等式群。

### 算2（8 分）
(1) n(He) = 2.0/4.0 = 0.50 mol；n(H₂) = 2.0/2.0 = 1.00 mol；n总 = 1.50 mol。
 p总 = nRT/V = 1.50×8.314×300/20.0 = **187 kPa**（取 3 位：187.1 kPa）。
 p(He) = 187.1×(0.5/1.5) = **62.4 kPa**；p(H₂) = **124.7 kPa**。
 【关键：等质量 2 g 与等物质的量幻觉对冲——He 的物质的量是 H₂ 的一半，
 而不是一样。账本 00-28 的正面教材版。】
(2) b = ΔTf/Kf = 1.55/1.86 = **0.833 mol/kg**；
 n = b×0.0600 kg = **0.0500 mol**；M = 4.50/0.0500 = **90.0 g/mol**。
(3) 实测 |ΔTf| 只有一半 → 有效粒子数减半 → 合理解：**该物质在水溶液中
 发生二聚（缔合）**（如羧酸型氢键二聚体）。
 M表观 = 4.50/[(0.78/1.86)×0.060] = 4.50/0.0252 = **178.6 → 约 179 g/mol**，
 恰为 2×90 → 与二聚互洽。
 【讨论位：依数性测 M 无法自选"电离/缔合"身份——方向相反歧义，
 只能靠化学知识定夺。这就是第 6 空烟雾弹的姊妹位。】

### 算3（8 分；每格 0.4 分）

| 微粒 | 电子对数 | 杂化 | 电子对构型 | 微粒构型 | 极性 |
|---|---|---|---|---|---|
| CO₂ | 2 | 等性 sp | 直线形 | 直线形 | 非极性 |
| NO₃⁻ | 3 | 等性 sp² | 平面三角形 | 平面三角形 | 非极性 |
| SF₄ | 5 | 不等性 sp³d | 三角双锥 | 变形四面体(跷跷板) | 极性 |
| XeF₄ | 6 | 不等性 sp³d² | 八面体 | 平面四方形 | 非极性 |

翻车点：SF₄ 和 XeF₄ 的"电子对构型 vs 微粒构型"两列互换（高频混淆）；
NO₃⁻ 极性栏写"谈极性无意义"也接受，但推荐按对称性给"非极性"。
原型：2023–24 期中算1 的扩展版（4 物质×5 列=20 点）。

### 算4（8 分）
(1) c酸=c盐 → pH = pKa + lg(0.020/0.020) = **4.75**。
(2) 加 0.005 mol NaOH（先反应脚本）：
 HAc − OH⁻ → Ac⁻ + H₂O；
 反应后：HAc 0.015 mol，Ac⁻ 0.025 mol；
 pH = 4.75 + lg(0.025/0.015) = 4.75 + lg 1.667 = 4.75 + 0.222 = **4.97**。
 【采分点：先写中和脚本再套公式——把 0.005 直接并进分母者最多得 1 分。】
(3) 加 0.020 mol NaOH 恰好把 HAc 全部中和 → 体系变为 0.040 mol NaAc/0.100 L
 = 0.400 mol/L 的弱碱溶液——**缓冲对解体**，pH 由阴离子水解决定：
 [OH⁻] = √(Kw/Ka × c) = √(10⁻¹⁴/(1.78×10⁻⁵) × 0.400)
 = √(2.25×10⁻¹⁰) = 1.50×10⁻⁵ → pOH = 4.82 → **pH = 9.18**。
 【采分点：①指出"缓冲被击穿"1 分；②改用弱碱水解公式 1 分；③数值 1 分。】
原型：卷二算2 遗产升级 + 2016 期末算二（NaAc+HCl 版）的姊妹；
账本：00-84 深度复测。

### 算5（8 分）
(1) 负极（Fe）：Fe → Fe²⁺ + 2e⁻；正极（Cu）：Cu²⁺ + 2e⁻ → Cu；
 总：Fe + Cu²⁺ → Fe²⁺ + Cu。
(2) E(Cu) = 0.34 + (0.0592/2)lg 0.10 = 0.34 − 0.0296 = **+0.310 V**；
 E(Fe) = −0.44 + 0.0296 lg(10⁻⁴) = −0.44 − 0.1184 = **−0.558 V**；
 E = 0.310 −(−0.558) = **0.868 V ≈ 0.87 V**。
 【采分点：分项电极电势先算——跳过直接写总式的最多拿半分。】
(3) lg Kθ = nEθ/0.0592 = 2×(0.34+0.44)/0.0592 = 1.56/0.0592 = 26.35
 → **Kθ ≈ 2.2×10²⁶**。
 【大数体验位：接受 10²⁶ 量级的任意规范写法。】
(4) 放电中 [Cu²⁺] 降、[Fe²⁺] 升 → E(Cu) 降、E(Fe) 升 →
 **电动势逐渐减小**（趋于平衡即 E→0，此时 J=Kθ）。
原型：2016 期末算三（Zn-Cu 双非标+K）+ 2006 期末填17 lg 版。
账本：09-18 全族复测（Fe/Cu 次序已是老友）。
