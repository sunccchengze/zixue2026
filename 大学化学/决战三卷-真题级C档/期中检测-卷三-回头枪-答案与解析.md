## 二、选择逐题解析

**1. C**（A1 冷知识正面确认）。2014–25 期中判2 的正面版——杂化轨道数守恒、
能量介于其间。出题提醒：凡含"均、一定、只能"听起来很冷但成立的正确说法，
要在题库里常备不动摇。账本：08-09 家族。

**2. D**（K1 库存坑首次动用）。范德华半径 > 金属半径 > 共价半径。
机理：范德华半径量的是非成键接触（最外）；共价半径量是成键接触（最内，
因电子云重叠拉近）；金属半径介于其间。原型：治学集 2.x"原子半径三种口径"。

**3. D**（Cl 为最大——F/O 反常的"两连坑"第二连）。
Eea 数值：F 322 < Cl 348（O 141 < S 200，同理）。
这一题本身就是 O/F 反常解释（小半径电子云拥挤）的量化版本。
原型：2023–24 期中选4/填5 的另一极（那边考"O<F"的同周期反常、
本卷考"F<Cl"的同族反常）。账本：00-17 邻域 ×3 首次完整展布。

**4. C**（R2 诱导的反面）。3d⁴4s²：按最低原理 + 特例应为 3d⁵4s¹ → 该
排布既非"序排"（序排为 3d⁵4s¹ 或 3d⁶）A/B/D 合法。
翻车点：把"特例"当"异常"→ 误选 A 或 B。**特例本身才是正解**。
原型：2023–24 期中选3 R2 家族（Cu/Cr 双侧）。

**5. A**（A1 钻穿冷理）。ns 钻穿最强 → 屏蔽最弱 → Z* 最高 → 能量最低，
这就是 n+0.7l 公式的"人物小传"。翻车点：B（想着单电子原子）、C（恰好相反）。
原型：治学集 1.2 屏障/钻穿；间接出处：2023–24 期中判10 序位。

**6. D**（A1，24-25 判5 的完整版）。铵离子四条 N–H 完全等同，
配位键的身世在成键后泯灭。与 24-25 判5（四键能相等 ✓）构成话面互证。
翻车点：A（"配位键就应当不一样"的执念）。

**7. B**（等性/不等性判据：有无孤对——NH₃ 1 孤对等 4 电子域 → 不等性 sp³。
CH₄/BF₃/CO₂ 均无孤对 → 等性）。
翻车点：A 把"线形"当不等性；D 未把孤对当判据。原型：治学集 2.3.3 重点位。

**8. A**（I₂ / CCl₄：24-25 判1 ✓ 的正面版，"相似相溶"的机理语言=同类分子间力）。
翻车点：C（"极"字崇拜）。

**9. B**（AX₃E₂ → 电子对构型三角双锥、分子构型 T 形）。
原型：2024–25 填5（ClF₃ 变形T形）。账本：09-13/09-20 邻域。

**10. C**（s-p 混杂——课程讲过的"小周期特殊性"）。
O₂/F₂ 2s 与 2p 差距较大、混杂弱 → σ(2p) 低于 π(2p)；
B₂/C₂/N₂ 则相反 - σ(2p) 被推到 π(2p) 之上。
翻车点：D（把一切归罪于氢键）；A（分子量与轨道无能级对应）。
原型：2024–25 填2 + 治学集 2.5。
 
**11. B**（分子内氢键选项全景）。
A 错：分子内氢键不搭给了邻居 → 熔沸点降（邻羟基苯甲醛 b.p. 比间/对位低）。
B 对。
C 错：氢键可分分子间与分子内。
D 错：邻羟基苯甲酸的**共轭碱**被分子内氢键稳定 → 酸性比对位**更强**
（水杨酸 Ka1 ≈ 10⁻³·⁰ vs 对位 ≈ 10⁻⁴·⁶）——这正是"氢键对酸性的影响"的
合理解（与治学集"氢键使酸性降低"的库存备忘构成参照系：
**内/外氢键与电离部位的关系不同，方向要分情况**。）。
原型：K3 库存坑（已按科学口径修正）；16 期中简4。

**12. A**（B7 吸氧腐蚀正极）。中性体系：O₂ + 2H₂O + 4e⁻ → 4OH⁻；
负极（阳极）：Fe → Fe²⁺ + 2e⁻。
翻车点：B/D（记了析氢腐蚀的正极把条件帽丢掉）。原型：宝典第 7 讲公式线。

**13. C**（B6 银电极三值——计算型选择）。
0.7996 + 0.0592 lg(1.8×10⁻¹⁰) = 0.7996 + 0.0592×(−9.745)
 = 0.7996 − 0.577 = 0.222 V。
翻车点：B 拿 0.577 半成品（那是一级中间量：Eθ 变化幅度）；
D 弄反符号。原型：宝典坑题/卷三算2 的先导位。

**14. B**（分级沉淀换底物：CuS 的 Ksp 小 13 个数量级、必先行）。
翻车点："Zn²⁺ 在过渡金属中通常不愿沉淀"的错偏印象。
原型：16 期末算二（AgCl/Ag₂CrO₄）元胞移位。
——登记豁免：与卷二算4 同考族（分级沉淀），坑法不同（那卷考幂比换算
与分级判序结合，本卷只考"谁先"的快断）。防查重豁免登记号 3-14。

**15. D**（B5/K9 缓冲范围）。pH = pKa 时 c盐/c酸 = 1，容量最大；
"缓冲范围 pKa ± 1"的端点上，容量 ≃ 最大值的 1/3。
翻车点：A/C（记得±1却不记得中间最大）。原型：16 期末选18。

**16. A**（K5 库存坑首次动用）。指示剂选用 = 变色范围 ⊂ 滴定突跃
（化学计量点附近）。B/D 均为"看着像对"的料。
原型：治学集 3.x 指示剂段、教材 P178 锚点。

**17. C**（R4 三真一假：CO₂ 是 O=C=O 直线形、Δμ 矢量和为零）。
其余三项皆真：记 SF₄/XeF₄ 那类"有孤对的分子才可谈论极性时小心"。
原型：18 期中不定项高密基因 + 16 期中判16/判18 家族。

**18. B**（稀释双效应的完整版）。α↑、c(OH⁻)↓（非 1/10）、pH↓、Kb 不变。
翻车点：A（忘了 α 变）；D（Kb 是 T 的专属常数）。
原型：2023–24 期末判4+选14 的合流版。

**19. A**（临界温度正面定义）。
B 错：临界温度越高**越易**液化（常温加压即可）；C 太绝；D 配错条件帽。
原型：2016 期中判14 转选。

**20. D**（N8 姊妹数：104×500 = 5.2×10⁴ g/mol）。
翻车点：A 把序数 2 当聚合度；C（"多分散就没数"的放弃式作答——
渗透压给数均值，并非"无法确定"）。
原型：16 期中算1 的姊妹位（那题反推，本卷正算）。

## 三、填空答案

**1.** >；>；<；是。（与卷二选2 构成 A2 互证对——同一现象在两卷以
不同题面复测，登记豁免号 3-F1。）

**2.** 范德华半径 > 金属半径 > 共价半径；
原因：范德华半径按非键接触计、共价半径按成键接触计（电子云重叠拉近），
金属半径居中——**计量口径不同**。

**3.** 等性；不等性；NH₃ 中氮原子还有一对孤电子占据一条 sp³ 杂化轨道，
故四条杂化轨道不完全等同（成键-孤对分配差异）。
 
**4.** K = [CrO₄²⁻]/[S²⁻] = Ksp(PbCrO₄)/Ksp(PbS)
 = 2.8×10⁻¹³/8.0×10⁻²⁸ = **3.5×10¹⁴**；趋势**极大（可视为完全）**。
翻车点：幂比方向写反得 2.9×10⁻¹⁵。

**5.** 浓侧；负极半反应：Ag → Ag⁺(稀) + e⁻。
原型：2016 期末判18 的"复活回枪"。账本：09 区的考古邻域。

**6.** 酸；碱；NH₄⁺ + H₂O ⇌ NH₃·H₂O + H⁺（写 NH₃ 给分）。

**7.** 3；抗磁（无未成对电子）；短于（键级 3 > 2 → N≡N 比 O=O 短）。
账本：01-40 MO 链复测（卷一考了 O₂ 族，本卷考 N₂——三族分工兑现）。

**8.** ① +；② −；③ −。（"气生则+"与"气灭则−"与"离子成固体则−"，都在
脾性快答口径内。）

**9.** pA = 50×0.40 = **20 kPa**；第二空换了一个体系（非挥发溶质的稀溶液，
xB = 0.10，同一溶剂 p* = 50 kPa）：Δp = p*·xB = 50×0.10 = **5 kPa**。
翻车点：把两个空串到一个体系里算（Δp 误取 50×(1−0.40)=30 kPa 者，
是"没看到换了溶液"的读题车窗事故）；本题正是"条件帽子"训练位。
 
**10.** 最大：Br₂(g)；最小：C(金刚石)。
（金刚石 Smθ ≈ 2.4 J/(mol·K)，是"高度有序"的极端。
翻车点：选 H₂O(l) 为最大的"生活熵"幻觉。）

## 四、计算题标准解

### 算1（8 分）
(1) ΔrHmθ = ΔfHθ(C₂H₆) − [ΔfHθ(C₂H₄) + 0] = −84.0 − 52.4 = **−136.4 kJ/mol**。
(2) ΔrHmθ = ΣΔcHθ(反) − ΣΔcHθ(产)
 = [−1411.0 + (−285.8)] − [−1559.8] = −1696.8 + 1559.8 = **−137.0 kJ/mol**。
 【采分点：燃烧法是"反−产"方向的反向和（B1）——方向颠倒当场丢 1 分。】
(3) 键能法：断 C=C 612 + H–H 436 = 1048；成 C–C 348 + 2×C–H 826 = 1174；
 ΔrHmθ ≈ 1048 − 1174 = **−126 kJ/mol**。
 【断键吸热为正、成键放热为负——方向掼错者得 +126，是最常见翻车点。】
(4) 燃烧法/生成法互洽（差 <1 kJ，数据精度所致），键能法偏差约 10 kJ ——
 原因：**平均键能是统计平均值**，并不针对 C₂H₄/C₂H₆ 的具体结构；
 另反应热各项里还含有结构/应力等细微项。
原型：宝典 B1（烯加氢三算法），数值经全部重算。

### 算2（8 分）
(1) 0.222 = 0.799 + 0.0592 lg(Ksp/1)
 → lg Ksp = (0.222 − 0.799)/0.0592 = −9.75 → **Ksp ≈ 1.8×10⁻¹⁰**。
(2) E = 0.799 + 0.0592 lg 0.010 = 0.799 − 0.118 = **+0.681 V**。
(3) 加 Cl⁻ 至 [Cl⁻] = 0.010：[Ag⁺] = Ksp/[Cl⁻] = 1.8×10⁻⁸ mol/L；
 E = 0.799 + 0.0592 lg(1.8×10⁻⁸) = 0.799 − 0.458 = **+0.341 V**。
 影响（写一句即得分）：加入沉淀剂使银电极电势大幅降低——
 "电极电势的条件帽子挂在活度上"，这也是络合/沉淀滴定用电势法
 指示的理论基础（Eθ 与 Ksp 互相反演）。
原型：2016 期末算四 + 宝典 B6/G5 族——本卷与卷二算4（幂比）构成
电化学-沉淀两端的完整闭环。

### 算3（8 分）
(1) ln Kθ = −ΔrGmθ/(RT) = 141 800/(8.314×298) = 57.2
 → lg Kθ = 57.2/2.303 = 24.85 → **Kθ ≈ 7×10²⁴**。
 【大数现身——这是三套卷 10²⁰ 级配额的责任点。】
(2) ln(K₂/K₁) = −ΔrHmθ/R × (1/T₂ − 1/T₁)
 = (198 000/8.314)×(1/873 − 1/298)
 = 23 815×(0.001145 − 0.003356) = −52.6；
 ln K₂ = 57.2 − 52.6 = 4.6 → **K₂ ≈ 1×10²**。
 【放热反应升温 K 骤降 22 个数量级——"肉眼可见的勒夏特列"。】
(3) 热力学句：Kθ(298) 巨大说明**反应限度**极高、SO₂ 转化率近 100%
 在热力学上可能；
 动力学句：298 K 下**速率太慢**（活化能高）——所以需要高温提 k、
 催化剂降 Ea；温度又不得不让步于平衡：450–500 ℃ 是限度与速率的折中。
原型：2024–25 期末/期中算3 的姊妹 + 2016 期中算二的姊妹版。

### 算4（8 分）
(1) ln Kθ = 33 000/(8.314×298) = 13.32 → lg = 5.78 → **Kθ ≈ 6×10⁵**。
(2) J = p(NH₃)²/[p(N₂)·p(H₂)³] = 0.50²/(2.0×6.0³) = 0.25/432
 = **5.8×10⁻⁴**；
 J ≪ Kθ → ΔrGm = ΔrGmθ + RTlnJ < 0 → 反应沿**正方向**进行
 （ΔrGm = −33.0 + 2.48×ln(5.8×10⁻⁴) = −33.0 − 18.6 ≈ −51.6 kJ/mol）。
(3) 体积缩到 1/4 → 各分压 ×4：J′ = (2.0)²/(8.0×24.0³)
 = 4/(8.0×13 824) = **3.6×10⁻⁵**；
 J′ < J ——加压**使反应商变小**、离平衡更远于"正向走"的一侧——
 定量证据：向气体分子数减小的方向（2 < 4）移动是勒夏特列的数学像。
原型：16 期中选7（H₂S 分解平衡移动）+"分压商"实操版。

### 算5（8 分）
(1) c = Π/RT = 77.4/(8.314×298) = 3.12×10⁻⁵ mol/L；
 100 mL 中 n = 3.12×10⁻⁶ mol → M = 1.00/3.12×10⁻⁶
 = **3.2×10⁵ g/mol**。
(2) 小分子单体 1%（质量）贡献的摩尔数很大（M=104 的 0.01 g 即
 9.6×10⁻⁵ mol，是同质量高分子的 ~30 倍量级）→ **粒子数大增 →
 Π 明显偏大 → 反推 M 被严重低估**。
 机理句：依数性只数"粒子数"，小分子是"粒子数老鼠"。
 【这正是"104 mol/L 彩蛋"的教育形态——数学算得动、物理必自洽。】
(3) 凝固点降低：ΔTf 与溶质摩尔浓度线性（Kf = 1.86 K·kg/mol 量级，
 摩尔质量 10⁵ 的 1% 溶液 ΔTf 一般为 10⁻⁵–10⁻⁴ K——**信号太小不可测**；
 渗透压在大分子体系反而给出**可测的毫米水柱信号**（依数性的量级对比）。
原型：16 期中算1 + X3 超物理结果的物理解读；账本 10-01 家族。
