## 第二部分 · 是非题（1×8）逐题解剖

**是1**「以 Ψ² 表示的空间图像即为电子云，越浓密处电子出现的概率必然越大」
- 解剖：|Ψ|² 的严格身份是**概率密度**；"概率"= |Ψ|²·dV（密度×体积元）。
  教材通俗说法是"电子云越密处概率越大"——若按通俗口径判 √，按严格口径判 ×。
- ⚠️**本题自带歧义**，歧义本身就是考点：它测试你是否知道"密度≠概率"这层窗户纸。
  治学集第一章强调的原话是"其平方 |Ψ|² 表示电子在某一点出现的概率密度"。
- 判定：按命题人语境判 **√**（通俗口径），但要在解析里讲清密度/概率之别。
- 档位：C（歧义型）。这类题在新 C 档卷中会改造为：明确考"概率密度"术语。

**是2**「[AlF₆]³⁻ 中的 Al 原子采用 sp³d² 杂化，则配离子空间构型为正八面体」→ **√**
- 解剖：Al³⁺ 与 6 个 F⁻，6 配位，sp³d² → 八面体。命题为真。
- 坑法：双层包装——先设一个杂化前提（考生要验证前提合理），再由前提推构型
  （考生要完成第二步）。**前提为真且推论为真**，学生若只会背对应表而验证不了前提，
  反而不敢判 √。
- 对照：2024–25 判断2（杂化能量守恒 √）同款"前提–推论"双层包装。
- 档位：C。

**是3**「对氢原子来说，其原子能级顺序为 1s<2s<2p<3s<3p<4s<3d」（按提取文本尽力还原）→ **×**
- 解剖：氢原子（单电子）无屏蔽效应，能级只由 n 决定：
  2s = 2p，3s = 3p = 3d。题面把多电子原子的顺序（含能级交错）按到氢头上。
- 坑法：**"氢原子"三个字是开关**——一旦漏看，多电子规则背得越熟错得越干脆。
- 档位：C。**这是 2016 的特色坑：限定词决定全题。**
- 2023–24 期末判断6（"仅由 n 决定"×）是本题的镜像——同一对概念两面考。

**是4**「共价键都具有饱和性和方向性，而离子键没有饱和性与方向性」→ **√**
- 解剖：教材标准表述。
- 与 2024–25 选择7 的 (A)(B) 选项同源——**一句话在两个年份以判断/选项两种形态出现**。
- 档位：A。

**是5**「溶液的蒸气压下降值与溶液中溶质的摩尔分数成正比」→ **√（有限定口径）**
- 解剖：Δp = p*·x_溶质 ——对**难挥发非电解质稀溶液**成立。
  题面只写"溶液"未写限定，但本章教学默认该语境；按教学口径判 √。
- 坑法：命题的成立依附默认语境——训练"知道公式的适用边界"。
- 档位：B。

**是6**「在同重量的两份水中，分别加入等物质的量的甘油和蔗糖形成两份稀溶液，
则这两份溶液的沸点一定相同」→ **√**
- 解剖：同质量水 + 等物质的量非电解质 ⇒ 质量摩尔浓度 b 相同 ⇒ ΔT_b = K_b·b 相同。
- 坑法：**甘油 vs 蔗糖的分子量差异是烟雾弹**（2016 就用烟雾弹了，比 2024–25 填7 更早）。
  学生会忍不住比"哪个分子大"。
- 档位：C（烟雾弹历史原型）。注意"同重量水"指的是**溶剂**而非溶液——分母选对才对。

**是7**「稳定单质在 100 kPa、298.15 K 时的标准摩尔生成焓和标准摩尔熵均为 0」→ **×**
- 解剖：ΔfHmθ(指定单质) = 0 ✓；但 Smθ(298K) ≠ 0 ——标准摩尔熵是绝对量
  （热力学第三定律：只在 0 K 的完美晶体为 0）。
- 坑法：T3 半对半错 + **两个"零"的拼盘**。这是期末级别考点进期中。
- 档位：C。2023–24 期末判断7（石墨燃烧焓=CO₂生成焓 √）是本题同族。

**是8**「等温等压条件下，用 ΔrGmθ 可以判断任何化学反应自发进行的方向」→ **×**
- 解剖：ΔrGmθ 只对应**标准态**的判据；任意状态须用 ΔrGm（等温方程）。
  "任何"+"θ" 的组合自相矛盾。
- 坑法：**θ 符号本身就是陷阱**。搬 2016 期末判断11（ΔGθ大 K 小 √）对照：
  命题人反复考"θ 只管标准态"这一层。
- 档位：C。

### 是非题小结
- √× 分布约 4:4（是1√、是2√、是3×、是4√、是5√/争议、是6√、是7×、是8×
  → 5√3×，若 是1 从严则 4:4）。
- 八年前的判断题坑深已不低于现行卷：**"θ 符号""氢原子""密度/概率"三个限定词坑**
  至今仍在 2023–25 复用。风格的连续性 → 旧卷仍有极高训练价值。

## 第三部分 · 选择题（2×11，不定项）逐题解剖

> 不定项规则："每小题有一个或多个答案"——多选少选错选均无分（2015 期末注明：
> 全对 2 分，选对不全 1 分）。**不定项把 4 个选项变成 16 种真伪组合，是已被现行
> 学校卷淘汰、但仍是 C 档训练的最佳模具**。我们的新卷虽用单选，但会保留
> "逐选项判真伪"的评分要求。

**选1** VSEPR：SF₄ 的空间构型 → **A（变形四面体）**
- 解剖：S 价层 5 电对（6+4)/2=5，1 孤对 → AX₄E → 跷跷板/变形四面体。
- 选项解剖：(B) 三角锥 = NH₃ 型（AX₃E）；(C) 平面三角 = BF₃ 型；(D) 正四面体 = CH₄ 型。
  **四个选项对应四种 AX 原型，缺一个 AX 知识就锁不死答案**。
- 档位：B。用户账本 00-47（SF₄ 曾 Hard）。

**选2** 按 MO 理论不可能存在的是：B₂ / He₂⁺ / Be₂ / O₂²⁺ → **C（Be₂）**
- 解剖：键级判存亡——B₂ 键级 1、He₂⁺ 键级 0.5、O₂²⁺ 键级 3 均可存在；
  Be₂：KK(σ2s)²(σ*2s)² 键级 0 → 不存在。
- 坑法：**"离子可以、中性不行"的反直觉**——学生常以为带电的更不稳定。
- 档位：C。除 O₂²⁺ 外全部是用户账本 00-28/29 leech 的近亲。

**选3** 量子数对应能量最低的电子：A(3,1,0,+½) B(3,1,1,−½) C(3,0,0,+½) D(3,2,1,−½) → **C**
- 解剖：n+0.7l：A/B = 3.7（同为 3p，简并）；C(3s)=3.0 最低；D(3d)=4.4。
- 坑法：同组内含简并对（A=B）——**简并意味着既不能选 A 也不能选 B**，
  用不定项规则反向排除。
- 档位：B/C。与 2024–25 选择10（比最高）镜像：**比高与比低成对考**。

**选4** 下列叙述正确的是 → **A、B 双对**
- 选项解剖：
  (A) CCl₄、CO₂ 非极性；NH₃、PCl₃ 极性 ——✓（对称四面体/直线 vs 三角锥）。
  (B) PCl₅、BeCl₂ 非极性（三角双锥、直线，对称）；H₂S、NH₃ 极性 ——✓。
  (C) CO₂、CCl₄ 非极性 ✓，但把 PCl₃、BeCl₂ 标为极性 ——BeCl₂ 直线非极性 ✗。
  (D) CO₂、BCl₃ 非极性 ✓，BF₃、BeCl₂ 标极性 ✗。
- 坑法：**八分子四句话，每句换一对分子。必须把 8 个分子的构型-极性全部
  判一遍**（每个分子都要走 VSEPR→对称性→μ=0? 三步）。
- 档位：C（不定项形态下是全卷最狠选择）。新卷将拆两题保留此强度。

**选5** NH₃ 与 CCl₄ 分子之间存在哪些作用力 → **B（色散力 + 诱导力）**
- 解剖：极性 × 非极性 → 色散（一切）+ 诱导（极性分子诱导非极性）；无取向力
  （取向力需双方永久偶极）。
- 选项解剖：(A) 取向+诱导（缺色散——色散**永远存在**，漏色散是最常见错）；
  (C) 取向+色散（取向力越界）；(D) 三力全家（取向力越界）。
- 档位：C。三力适用矩阵的活用，与 2023–24 判断5 同源同函数。

**选6** 同质量 H₂/O₂/N₂/CO₂ 混合，分压最小 → **D（CO₂）**
- 解剖：同 m，M 越大 n 越小，x 越小，p_i 越小。CO₂ M=44 最大。
- 档位：B（2016 已有"等质量不等摩尔"的 P1 配方雏形! 2024–25 选择9 是它的量化版）。

**选7** 0.1 mol/L 的 MgCl₂ / NaCl / AlCl₃ / 蔗糖中沸点最高 → **C（AlCl₃）**
- 解剖：比 i·c：AlCl₃ i≈4 > MgCl₂ i≈3 > NaCl i≈2 > 蔗糖 i=1。
- 档位：B。**0.1 mol/L 四兄弟排序是十年常客**，我旧卷同位置是"渗透压比"（只有 2 项），
  信息量砍半。

**选8** 下列叙述正确的是 → **A、C**
- 选项解剖：
  (A) 离子化合物可能含共价键 ——✓（NaOH、Na₂SO₄）。
  (B) 构成晶体的分子一定含共价键 ——✗（稀有气体单原子分子）。
  (C) 共价化合物中也可能含离子键成分 ——✓（极性键有部分离子性；Δχ 居中即"过渡型"）。
  (D) 非极性分子中一定含非极性键 ——✗（CO₂、CCl₄：极性键组成非极性分子）。
- 坑法：**"可能/一定"量词对打**——每句话都在量词上做文章。
- 档位：C。（A、C 的"可能"为真，（B、D 的"一定"为假——帮助学生建立
  "化学里含'一定/均/任何'的命题优先打问号"的元规则。）

**选9** 2 mol H₂ + 2 mol Cl₂ 在绝热钢桶内反应生成 HCl(g)：对 ΔrU、ΔrH_p、ΔrS、ΔrG
的符号判断（选项文本有损，四种组合）→ **ΔU=0、ΔH>0、ΔS>0、ΔG<0** 的那组
- 解剖：钢桶恒容 + 绝热 ⇒ Q=0、W=0 ⇒ **ΔU=0**；
  反应放热全用于升温 ⇒ ΔH=ΔU+Δ(p·V)=V·Δp>0（温度升 → p 升）；
  反应自发 ⇒ 孤立系 ΔS>0；ΔG<0（等温等压判据外推至该混合物的自发性方向）。
- 坑法：**绝热恒容容器是"ΔU=0 但 ΔH≠0"的专用场景**——把"ΔH=Qp"的条件
  （等压）悄悄换掉。这是判断9（2023–24 状态函数）与选择13（自由膨胀）之外的
  第三种热力学场景坑。
- 档位：C++。**此类题是我旧卷从未覆盖的热力学深水区。**

**选10** 水煤气 C(s)+H₂O(g)→CO(g)+H₂(g)，ΔrH=+131.3 kJ/mol，自发性 → **A（高温正向自发、低温正向非自发）**
- 解剖：ΔH>0 + 气体 1→2 mol（ΔS>0）→ 高温自发。
- 档位：B（隐步：自己判 ΔS>0）。2023–24 选择15、2024–25 计算3 的同一内核。

**选11**「下列属于状态函数的一组是」（选项文本提取丢失）
- 可由同年期末判断6、2023–24 期末判断14 与 2023–24 期中选择12 反推：
  考的是 state function 清单 + 广度/强度甄别。
- 坑法推测：选项里必混 Q、W 或 T 中的一个。
- 档位：B。**同时这也是提取残缺的实证——2016 年期中卷在文本流中本就有缺页风险，
  学习时不能依赖单一文件。**

### 选择题小结
- 11 题中不定项多解至少 3 题（选3/4/8 都可能双解），逐选项判真伪成为强制动作。
- 与现行卷题型映射：选9（绝热钢桶）→ 现行卷没有对应题，是新卷可首发的 C 档素材。

## 第四部分 · 填空题（1×10 空，5 题）解剖

**填1** HBr 分子中形成 σ 键的原子轨道是 **H 的 1s** 和 **Br 的 4p（4p_x/沿键轴那条）**。
- 解剖：VB 理论基本动作：半充满轨道沿键轴最大重叠。
- 陷阱：写"Br 的 4s"或"杂化轨道"都不准确——主族卤素单质卤化氢的成键按
  p_x 直接重叠处理（教材口径）。
- 档位：B。

**填2** 配合物命名题（提取文本残缺为 [Co(NO₂)?(NH₃)?]?SO₄ 形式，按残片结构
最可能为 [Co(NO₂)(NH₃)₅]SO₄ 一系）：中心原子 Co³⁺；配体 NO₂⁻ 与 NH₃；
配位原子 N（硝基写法）/ 若为 ONO⁻ 则为 O。
- ⚠️提取残缺说明：该题是中文化命名 + 四连问的经典格式，
  与 2023–24 填空4 / 2024–25 填空11 完全同构——**命名题八年年年见**。
  用户红线：新卷对此仅保留 1 题轻量版。
- 档位：B。

**填3** M²⁺ 的 3d 轨道有 6 个电子 → M 原子的核外电子排布 **[Ar]3d⁶4s²**；第**四**周期。
- 解剖：**从离子反推原子**——失电子先失 4s。M²⁺ 3d⁶ ⇒ M 3d⁶4s² ⇒ Fe（26）。
- 坑法：正推 3d⁶ → 写 [Ar]3d⁶4s² 的人要在 M²⁺ 上加回电子时容易错加成 3d⁸。
  （先失 4s 的充放规则是反推题的双向关键。）
- 档位：C。是 2024–25 填空6（量子数反推）的前身——**反推题在期中卷有 8 年传统**。

**填4** 由三个反应 Hess 求 ΔfHθ(C₂H₂)：
(1) C₂H₂(g)+5/2O₂(g)→2CO₂(g)+H₂O(g) ΔH=−1246.2
(2) C(s)+2H₂O(g)→CO₂(g)+2H₂(g) ΔH=+90.9
(3) 2H₂O(g)→2H₂(g)+O₂(g) ΔH=+483.6
- 解：目标 2C(s)+H₂(g)→C₂H₂(g)。
  2×(2)：2C+4H₂O→2CO₂+4H₂（+181.8）
  −(1)：2CO₂+H₂O→C₂H₂+5/2O₂（+1246.2）
  −(3)×5/4：5H₂+5/2O₂→5H₂O（−604.5）
  相加：2C+H₂→C₂H₂，ΔfHθ=181.8+1246.2−604.5=**+823.5 kJ/mol**……
  ……这个数值明显不合理（真实 ΔfH(C₂H₂)≈+226.7），
  ⚠️**原卷提取文本中三个方程的系数/物种很可能有错漏**（例如 (3) 实为 H₂O 分解的
  ½ 倍、或 (2) 为 C+H₂O→CO+H₂ 之类）。
- **教学含义①（对命题）：Hess 题可以在 3 方程 4 物种下做 5 分钟级计算，是期中常客。**
- **教学含义②（对考生）：Hess 题也要量纲/数量级自检。**
- 档位：C（计算 5 分钟级）。

**填5** 由 2 mol 量级的"3 mol NH₄Cl 加成放热"反推写 1 mol 的热化学方程式：
按文本残片 2NH₃(g)+2HCl(g)→2NH₄Cl(s) 放 352.2 kJ ⇒
**NH₃(g)+HCl(g)→NH₄Cl(s) ΔrHmθ=−176.1 kJ/mol**。
- 解剖：热化学方程式的标准写法（系数=1 mol 进度 + 状态 + ΔH 符号）。
- 档位：B。与 2023–24 选择14 互为正逆（那题给 1 mol 求 2 mol 进度）。

## 第五部分 · 简答题（34 分）解剖——2016 独有的"说理题"题型

**简答1**（6 分）(1) 3s、3p_x/y/z、3d 系列中哪些简并？(2) 五组量子数比能量大小。
- 解：(1) 多电子原子中同一亚层内简并：3p_x=3p_y=3p_z（三简并）；
  3d 五条（xy, yz, xz, z², x²−y²）五简并；但 **3s 与 3p 不简并、3p 与 3d 不简并**
  （能级分裂）。
  (2) 按 n+0.7l：E(1,0,0,−½)=1.0 < C(2,0,0,+½)=2.0 < A(3,2,1,+½)=D(3,2,0,+½)=4.4
  < B(4,3,2,−½)=6.1。A 与 D 同为 3d 简并 ⇒ **A = D**。
- 坑法：要求写">、="——**"="的正确使用"才是考点**（学生只会写 >）。
- 档位：C。

**简答2**（8 分）MO 三原则 + O₂ 的电子排布 + 键级与磁性。
- 解：三原则（能量最低、泡利、洪特）+ 对称性匹配/最大重叠前提；
  O₂：KK(σ2s)²(σ*2s)²(σ2p_x)²(π2p_y)²(π2p_z)²(π*2p_y)¹(π*2p_z)¹；
  键级=(8−4)/2=2；π* 轨两个单电子 ⇒ 顺磁。
- 档位：B（OS高频，账本 00-28/29 经此题原形强化过）。
- **教学含义：MO 题在简答中出现=要求写出完整排布式，不给分缩写。**

**简答3**（6 分）PCl₃ 分子与 NO₃⁻ 离子：杂化类型 + 空间构型。
- 解：PCl₃：P 3s²3p³，(5+3)/2=4 电对 1 孤对 → 不等性 sp³，三角锥；
  NO₃⁻：N (5+0+1)/2=3 电对 0 孤对 → sp²，平面三角形（另有 π₄⁶ 大π键）。
- 坑法：分子 vs 离子同考——**离子的电荷要计入电对数公式（±电荷）**；
  NO₃⁻ 若忘记 +1 电子就算成 2.5 电对崩盘。
- 档位：C。2023–24 计算1 的数据表格版即由此演化。

**简答4**（6 分）红细胞在纯水和 1.0 mol/L NaCl 中分别发生什么？（血液溶质总浓度≈0.6 mol/L）
- 解：纯水（≈0）< 0.6 → 水向细胞内渗透 → **膨胀甚至溶血**；
  1.0 mol/L NaCl > 0.6 → 细胞失水 → **皱缩**。
  解释核心：半透膜 + 水从低渗向高渗净迁移。
- 档位：B（应用型）。体现了 2016 卷"生活-体液"应用面的传统
  （延续为 2024–25 选择4 融雪剂）。

**简答5**（8 分）9.14 g（提取作 29.14 g）HgCl₂ 溶于 32.75 g 乙醇，沸点升高 1.27℃，
K_b(乙醇)=1.20，M(HgCl₂)=271.59 ——HgCl₂ 在乙醇中是电解质吗？
- 解：以提取数字计：n=29.14/271.59=0.1073 mol；b=0.1073/0.03275 kg=3.28 mol/kg；
  若为非电解质 ΔT_b=1.20×3.28=3.93 K ≫ 实测 1.27 K——实测/理论≈0.32<1，
  物理上不可能 ⇒ **提取文本中的质量必有误**（若 m=9.26 g：b=1.04，ΔT=1.25≈1.27 ✓，
  即真实数据应为约 9.26 g，HgCl₂ 表现为非电解质 i≈1）。
- 结论：**HgCl₂ 是共价化合物，在乙醇中不电离（i≈1），不是电解质**。
- 坑法："用 i 值判电解质身份"——依数性反解实验题，是依数性考点里最贵的题型。
- ⚠️再次实证提取噪音（29.14→疑为 9.26/9.14），与新卷的"考生须量纲自检"训练目标一致。
- 档位：C++。

## 第六部分 · 计算题（26 分）解剖

**计算1**（6 分）蛋白质摩尔质量：5.18 g/L，Π=0.413 kPa @298.15 K → M≈3.11×10⁴
- 链：M = mRT/(ΠV) = (5.18×8.314×298.15)/(413 Pa×10⁻³ m³) ≈ 3.109×10⁴ g/mol。
- 坑法：kPa→Pa、L→m³ 双单位换算（账本 00-52/53 的原形——30 年前真题数据
  至今未变！我温和版没出过一点渗透反推 M 的数）。
- 档位：C。

**计算2**（10 分）由燃烧热求 ΔfH(CH₄)：(1) 等压 (2) 等容
- ΔcHθ：C(石墨) −394；CH₄ −890；H₂ −285.8 kJ/mol。
- Q_p：ΔfHθ(CH₄) = [−394 + 2×(−285.8)] − (−890) = −75.6 kJ/mol。
- Q_v：ΔU = ΔH − Δn_g·RT；C+2H₂→CH₄ 的 Δn_g = 0−2 = −2：
  ΔU = −75.6 − (−2)×8.314×298×10⁻³ = −70.6 kJ/mol。
- 坑法：①燃烧热符号使用（生成物−反应物 vs 反应物−生成物的两套口径）；
  ②等容版要 Δn_g（**氢气是气体、甲烷是气体、碳是固体**）；
  ③28 年前就考 ΔH↔ΔU 换算（选择题小而难的前身）。
- 档位：C++。

**计算3**（10 分）CH₄(g)+CO₂(g)→2CO(g)+2H₂(g)：求 ΔrGθ(298) 并判自发性 + 正向自发条件
- 缺表的提取情境下按教材数据（ΔfHθ：CH₄ −74.8；CO₂ −393.5；CO −110.5；H₂ 0；
  Sθ：CH₄ 186.3；CO₂ 213.7；CO 197.7；H₂ 130.7 J/mol·K）：
  ΔrHθ = [2(−110.5)+0] − [(−74.8)+(−393.5)] = +247.3 kJ/mol
  ΔrSθ = [2×197.7+2×130.7] − [186.3+213.7] = +256.8 J/mol·K
  ΔrGθ(298) = 247.3 − 298.15×0.2568 ≈ +170.7 kJ/mol > 0 → 不自发；
  T > ΔH/ΔS ≈ 963 K 则正向自发。
- 档位：C++（与 2023–24 期末计算1 的 Fe₂O₃ 还原完全同构——**Fe₂O₃ 题是从这里来的**）。
