## 三条铁规（搬动文件时的纪律）

1. 源材料位置变更后必须更新本图 + `开局指令 §3 资料清单`；
2. 章程类文件名以"书名号引用"散落在各学科文档中（如《资料勘误.md》）——
   只有**路径形态**的引用（`../资料勘误.md`）需要跟随搬动修改，书名引用不用；
3. memory/ 内部文件（HANDOFF/PROGRESS/drill-ledger）记录的是"现状指针"，
   搬动其指向的目录时须同日同步两表（参见判例⑯阶段的漂移教训）。
