# 课题04 · 酸碱与缓冲 · 开题简报

> 2026-08-21 · 深讲档

## 研究问题

pH 是什么账？缓冲液为什么“扛得住”少量酸碱？Ka/Kb/Kw 与课题03 的 K 是什么关系？

## 深讲档依据

双卷显示只掌握等量 NH₃/NH₄⁺ 个例；需完整学 Ka/Kb、解离度、盐水解、缓冲容量与 pH 计算。本课题按“K 的特例”主线：Ka/Kb/Kw 全部是化学平衡常数，缓冲公式从 Q=K 推出。

## 里程碑

- [x] Kw 与水的自电离；pH 定义与中性边界（温度依赖）
- [x] 强酸/弱酸 [H⁺] 计算：Ka=x²/(c−x) 近似与条件
- [x] 缓冲原理：Henderson–Hasselbalch 推导与应用（NH₃/NH₄⁺ 三步法已教，待验）
- [ ] 盐类水解与酸碱性判断
- [ ] 缓冲容量与稀释效应
- [ ] 完成含存疑的一页报告

## 首批问题（2026-08-21）

1. 25 ℃ 时 Kw=1.0×10⁻¹⁴，纯水的 pH 是多少？水的电离吸热，升温后 Kw 变大还是变小？pH=7 是不是永远等于“中性”？
2. 0.10 mol/L HCl 与 0.10 mol/L HAc（Ka=1.8×10⁻⁵），[H⁺] 各约多少？弱酸[H⁺]怎么列式（提示：Ka=x²/(c−x)，x 是什么）？
3. Henderson–Hasselbalch 公式 pH=pKa+lg([A⁻]/[HA]) 从 Ka 定义式一行推出（自己推）。0.10 mol/L NH₃（Kb=1.8×10⁻⁵）与 0.10 mol/L NH₄Cl 等量混合，pH≈？（提示：pKa+pKb=14）
4. 缓冲液里加入少量强酸，是哪个组分把 H⁺ 吃掉？pH 为什么几乎不变？0.1 mol/L 与 1 mol/L 的缓冲液哪个“更能扛”？为什么？
