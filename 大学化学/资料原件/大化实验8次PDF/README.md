1. **邻页共享**：原书相邻实验在同一页面收尾/开场，归位规则是"每个实验从自己的标题页起、到下一个实验标题页止"，
   因此相邻实验会在交界页重叠（第1/2 次共 PDF p84；第2 次与 EDTA 实验共 p86；第6/7 次共 p123），属有意保留，内容不缺页。

   课表「PbCl2」教材写作「PbCl₂」（文件名按用户指定用 `PbCl2` 纯文本）。

   教材对应「实验三十四」（p150），未抽取——若日后确有需要再补。
