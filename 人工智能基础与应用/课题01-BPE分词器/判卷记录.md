## 本课题的判分环境坑（已解决，记录备查）

| 坑 | 现象 | 处置 |
|---|---|---|
| 官方 conftest 需 Python ≥3.12 | 官方 `pyproject.toml`: `requires-python = ">=3.12,<3.14"`；conftest 用 PEP 695 泛型语法，3.11 无法解析 | 3.11 下自动改用**等价轻量 conftest**（同一 `snapshot` 夹具语义），并在日志头部如实声明；升到 3.12+ 后自动切回官方原文 |
| tiktoken 需联网下载 GPT-2 词表 | 无外网时 `SSLError` 挂掉 12 项对齐测试 | 新增 `环境/judge/prefetch_tiktoken.py`：用官方 fixture **离线构造** tiktoken 缓存（encoder.json 哈希与 tiktoken 内置期望一致，已验证 n_vocab=50257） |
| PyTorch CPU 专用源不可达 | `download.pytorch.org` SSL 被拦 | bootstrap 改为：默认不装 torch（课题01 不需要）；`--with-torch` 时先试 CPU 源、失败退回 PyPI |
