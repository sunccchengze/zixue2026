# 判分与验收标准

> 立标 2026-09-17。继承仓库总纲 `skills/科研式学习导师/SKILL.md` §5a《命题与判卷纪律》，
> 并按本学科"可执行判分"的特性做加法。**与总纲冲突处，以本文件的更严条款为准。**

## 一、三层判分（每一层都必须留下原始输出）

| 层 | 谁判 | 判据 | 归档 |
|---|---|---|---|
| **L1 自动判分** | 判分器（pytest / 自建 script） | 通过 / 失败 / 覆盖率 / 指标数字 | `判卷记录.md` 贴**原始输出**（不许转述） |
| **L2 导师审稿** | 我 | 3–5 条：必考项 / 要记住 / 预告项（含"哪里可能在自欺"） | `判卷记录.md` |
| **L3 费曼收口** | 你讲 + 我追问 | 三条硬标准（讲清 / 指代码 / 改坏修好） | `判卷记录.md` + `知识卡` |

**L1 不通过 → 不进 L2/L3**；L3 不通过 → 课题不标 ✅，写进 HANDOFF 的"下一句"。

## 二、通用红线（继承总纲 + 本学科加严）

1. **结果对 ≠ 满分**：本学科分数按"证据链"给，逻辑链完整才满分（总纲 §5a 第 5 条）。
2. **没有预测的实验不算实验**：跑之前必须先写"预期现象"（见实验卡），否则 L1 直接判不合格。
3. **无证据的结论不采纳**：曲线要原始日志/repro 命令；截图要能追溯到 run.yaml。
4. **no-go 不擦除**：失败的实验、被推翻的假设全部留在 `证据/`，并在报告里如实呈现。
5. **口径统一**：跨模型比较必须同数据集、同 token 化、同评测脚本；指标优先用**词表无关**的 bpb。
6. **不许自创指标**：新增指标必须给出定义 + 为什么已有的不管用 + 与已有指标的相关性。
7. **误差棒是必填项**：任何"变好了"的结论都要给多次运行的范围（至少 2 个种子）。
8. **不许把测试集当验证集反复调**（M7 常见自欺）。
9. **掌握的定义**（总纲 §5a 第 8 条原文）：当次对 + **隔 1–3 天无提示再对** + 能讲清为什么。
10. **宣布"通过"必须附证据引用**：哪份判分输出、哪个数字、哪些 leech 已清零。

## 五、自欺自查清单（结项前必过）

1. 我报的每个数字，**能在 `证据/` 里找到原始日志**吗？
2. 我的"变好了"，有没有可能是评测口径变了 / 提示词变了 / 只挑了好种子？
3. 我有没有把**训练集上的表现**当成了能力？
4. 我写下的每个"因为…所以…"，有没有**反事实检验**（去掉这个因素会怎样）？
5. 我的图，**坐标轴和误差棒**都标了吗？有没有截断坐标轴让差距显得很大？
6. 我的结论，**最强的反方论点**是什么？写进报告了吗？
