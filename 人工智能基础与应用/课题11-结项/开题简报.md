# 课题11 开题简报 · 结项（NeurIPS 报告 + 现场 demo）

> 模块：**M9** ｜ 周次：**W15–W16（12-21→2027-01-03）** ｜ 算力：**弹性 ≤4 GPU·小时**
> 唐杰作业对应：**⑥ 英文 NeurIPS 格式 + W16 现场 demo**、**⑦ 作业 40% / 大项目 60%** ｜ 判分来源：**报告协议 + 导师审稿 + 自我攻击**

## 一、研究背景

唐杰的原话是"**问题、动机、方法、结果，一项都不能糊**"。
这恰好也是本学科九份章程反复强调的：**没有证据的结论不采纳、no-go 不擦除、误差棒必填**。
结项不是"写一篇总结"，而是**把 11 个课题的证据链组装成一份可被审稿的作品**。

## 二、研究问题（结项版）

> **我能不能用一份英文技术报告 + 一个可运行的 demo，证明我独立完成了大模型全链路，并且知道自己的结论在哪里不成立？**

## 三、攻关线索

1. **报告骨架**（NeurIPS 风格，8–10 页）：Abstract / Introduction / Related Work / Method / Experiments / Results / Discussion & Limitations / Conclusion
2. **只写有证据的结论**：每个数字都能指回 `证据/` 中的原始日志
3. **Limitations 必须诚实**：规模受限（0.1B vs 前沿）、算力受限（免费档）、评测口径的局限
4. **Demo 设计**：现场演示要**可在 3 分钟内跑完**（预生成 checkpoint，不现场训练）
5. **自我攻击 3 条**：主动写出"我的结论最可能错在哪"
6. **一稿多用**：这份报告同时作为课程大论文（70%）与唐杰作业⑦的交付物

## 七、自检清单（结项前必过，抄自《判分与验收标准》§五）

1. 每个数字都能在 `证据/` 找到原始日志吗？
2. "变好了"有没有可能是口径变了 / 只挑了好种子？
3. 有没有把**训练集表现**当能力？
4. 每个"因为…所以…"有没有反事实检验？
5. 图表的坐标轴与误差棒都标了吗？
6. 我写下的最强反方论点是什么？

## 八、风险与提醒

- ⚠️ 报告最易犯的错是**夸大**：规模受限就要说受限，这反而是可信度来源。
- ⚠️ 不要为了"好看"删掉 no-go 记录——用户明确要求"负结果不许擦除"。
- ⚠️ W16 现场 demo 必须有**失败预案**（预生成结果 + 录屏），不依赖现场网络与算力。
