## 一、注意力：加权检索 + 为什么缩放 $1/\sqrt{d_k}$

**计算式**（先记住形状，再看含义）：
$$\mathrm{Attn}(Q,K,V) = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}} + M\right)V$$
其中 $Q,K,V \in \mathbb{R}^{L\times d_k}$，$M$ 是因果掩码（下三角为 0、其余 $-\infty$）。

**含义**：每个位置发出一个查询 $q$，去和所有位置的键 $k$ 做**内积**（相似度），
softmax 归一化成权重，再对值 $v$ 做加权平均。**它就是"按相似度检索并汇总"**。

**为什么除以 $\sqrt{d_k}$**：设 $q,k$ 各分量独立、均值 0 方差 1，则内积 $q\cdot k = \sum_{i=1}^{d_k} q_i k_i$ 的
方差是 $d_k$（方差可加）。$d_k$ 越大，内积的**取值范围越宽** → softmax 越容易"饱和"
（一个位置拿走几乎全部权重）→ 梯度趋近 0 → 训练不动。
除以 $\sqrt{d_k}$ 把内积的方差重新拉回 1 量级。**这是"训练稳定性"的第一课。**

**因果掩码**：语言模型不能看未来。做法是**在 softmax 之前**给未来位置加 $-\infty$（实现上常用 $-10^9$ 之类的大负数，
而不是 0）——因为在 softmax 之后置零会**改变概率归一化**（等价于把已分配的概率丢掉，剩下的位置没有重新归一）。

**在代码里长什么样**：`手写/` 里会有 `scaled_dot_product_attention` 与
`multihead_self_attention`（含 causal 与 RoPE 两个变体）；上游对照 `nanochat/gpt.py` 的
`CausalSelfAttention`。**注意接口而非实现**：CS336 的 `tests/adapters.py` 规定了你要暴露的函数签名。

## 二、多头：拆开看不同关系，但总算力不变

**做法**：把 $d$ 维拆成 $h$ 份、每份 $d_k = d/h$，各自独立做注意力，再拼回来过一个输出投影 $W_O$。

**关键理解（常被误解）**：多头**不增加**注意力的总计算量——
单个头用满 $d$ 维时，$QK^\top$ 是 $L^2 d$；$h$ 个头各 $d/h$ 维合计仍是 $L^2 d$。
多头的收益在于**归纳偏置**：不同的头可以在不同子空间里学不同的关系
（有的学"上一个词是谁"，有的学"括号配对"，有的学"句子边界"），比单一头更灵活。

**变体（现代模型常用）**：
| 变体 | 做法 | 动机 |
|---|---|---|
| MQA | 所有头**共享一份** K/V | KV cache 减小 h 倍，但质量略降 |
| **GQA** | 头分组，组内共享 K/V（如 8 组） | 折中：cache 减小、质量几乎不掉 ← 现代主流 |
| MLA | 把 K/V 压成低维潜变量再解压 | 更激进，DeepSeek 系 | 

> **为什么都在动 K/V**：推理时的瓶颈是 **KV cache 的显存**（见 §五），
> 它随 `层数 × 序列长度 × 头数` 线性增长，与"生成速度"直接相关。这是"架构为推理服务"的典型例子。

## 三、位置编码：从"贴标签"到"转角度"

**问题**：注意力的内积是**置换不变**的——把 token 顺序打乱，结果不变。所以必须注入位置信息。

**三代方案**：
| 方案 | 做法 | 缺陷 |
|---|---|---|
| 可学习绝对嵌入 | 学一个 $L_{\max}\times d$ 的查表 | **不能外推**：训练 2048，推理 4096 时后一半没学过 |
| 正弦绝对编码（原论文） | $\sin/\cos$ 固定频率 | 可外推性弱，实践中被 RoPE 取代 |
| **RoPE（旋转位置编码）** | 把 $q,k$ 按**二维子空间**旋转角度 $\theta\cdot m$ | 内积只依赖**相对距离** $m-n$；外推性好 |

**RoPE 的核心恒等式**（这是它存在的全部理由）：
$$\langle R_m q,\ R_n k\rangle = \langle q,\ R_{n-m} k\rangle$$
即：**在内积里只出现"位置差"**，绝对位置被"旋转"吸收掉了。
推导要点：旋转矩阵是正交阵，$R_m^\top R_n = R_{n-m}$。

**频率分配**：第 $i$ 对维度的角频率 $\theta_i = 10000^{-2i/d}$——
低维（$i$ 小）转得快（管近距离），高维转得慢（管远距离）。
**"10000"这个底数是"能覆盖多长上下文"的旋钮**，这就是所谓 YaRN / NTK 插值等长上下文外推技巧的入口。

**在代码里长什么样**：`手写/` 的 `rope` 与前缀 `rope` 的多头注意力；
CS336 有单独的 `run_rope` 测试点。

## 四、归一化与残差：让 100 层能训起来的两件套

**LayerNorm**：对每个 token 的 $d$ 维向量做 $(x-\mu)/\sqrt{\sigma^2+\epsilon}$，再缩放和平移。
**RMSNorm**：只做 $x/\sqrt{\mathrm{mean}(x^2)+\epsilon}$，再乘一个可学缩放 $g$。
- 省掉了**减均值**与**平移**：更便宜（少一次归约、少一组参数）
- 效果相当：真正起作用的是**尺度不变性**（分母归一化），而中心化贡献有限
- 现代模型（LLaMA/Qwen/GLM 系）默认 RMSNorm

**残差连接**：$x \leftarrow x + f(\mathrm{norm}(x))$（pre-norm）。
**它防的是梯度消失**：反向传播时，加法的 Jacobian 是单位阵，
于是梯度有一条**恒等通路**可以直达浅层。没有它，几十层的网络基本训不动。

**pre-norm vs post-norm**（原论文是 post-norm）：
| | 形式 | 性质 |
|---|---|---|
| post-norm | $\mathrm{norm}(x + f(x))$ | 原版；深了需要小心 warmup，容易发散 |
| **pre-norm** | $x + f(\mathrm{norm}(x))$ | 训练稳，是现代默认；代价是"深度"的表示能力稍弱 |

> 课题02 会做"去掉残差"的改坏实验：你会亲眼看到 loss 从"平稳下降"变成"几乎不动"。

## 五、FFN、参数量与 KV cache（**把结构换算成资源**）

**FFN 的演化**：两层线性 + 激活。原版 $d_{ff} = 4d$ 配 ReLU。
**SwiGLU** 用三个矩阵：$\mathrm{Swish}(xW_1)\odot(xW_3)$ 再过 $W_2$；
为保持参数量不变，取 $d_{ff} \approx \tfrac{8}{3}d$（3 个矩阵 × 8/3 ≈ 4 个矩阵 × d 的等价参数量）。

**单层参数量**（$d$ 宽，标准 MHA）：
- 注意力：$W_Q,W_K,W_V,W_O$ 各 $d\times d$ → $4d^2$
- MLP（SwiGLU，$d_{ff}=\tfrac{8}{3}d$）：$3\cdot d\cdot \tfrac{8}{3}d = 8d^2$
- 两处 RMSNorm 缩放：$2d$（可忽略）
- **合计 ≈ $12d^2$ 每层** → 全模型 ≈ $12\,L\,d^2 + Vd$（权重共享时）

**验算习惯**：拿到任何模型的配置（如 `d=768, L=12, V=50257`），
先心算 $12\times12\times768^2 \approx 85\text{M}$，加嵌入 $50257\times768\approx39\text{M}$（共享则算 1 份）
≈ 124M —— **与 GPT-2 的 124M 吻合**。这种"能不能心算"是 M3 的验收标志之一。

**KV cache 显存**（推理，重点）：
$$\text{bytes} = 2 \times L_{\text{layers}} \times L_{\text{seq}} \times n_{kv} \times d_k \times \text{bytes/elem}$$
（乘 2 是因为 K 和 V）。用 GQA 后 $n_{kv}$ 从 $h$ 降到组数，
**cache 直接按比例缩小**——这就是 GQA 流行的真正原因。
课题05 会实测这个数字。

## 六、常见误解（每条配反例）

| 误解 | 反例 / 更正 |
|---|---|
| "注意力=可解释的检索" | 注意力权重高 ≠ 因果重要（已有大量反例）；它是**加权平均的权重**，别过度解读 |
| "多头=多算" | 总 FLOPs 不变（§二），只是分成子空间 |
| "位置编码只是加个向量" | RoPE 是**旋转 Q/K**，不是加到输入上；且它只影响内积的相位 |
| "RMSNorm 是 LayerNorm 的近似" | 它**省略**了中心化，不是近似；在很多模型上效果更好且更省 |
| "参数量大就一定强" | 同样算力下，参数与数据要按 scaling law 配比（课题03 的正题） |
| "因果 mask 随便加个大负数就行" | 必须**在 softmax 之前**；加在之后会破坏归一化 |

## 九、记忆锚

- **隐喻**：注意力 = **"会议室里的自由讨论"**——每人（query）挑自己关心的话题（key），
  按关心程度（softmax 权重）听别人（value）说话；因果 mask = "不许听后面发言的人"；
  多头 = 同时开 h 个并行分会场；RoPE = 每个人的座位号刻在**朝向**上，所以只关心"相隔几个座位"。
- **口诀**：**"缩放防饱和、掩码在软前、多头不减算、旋转只认距、残差是命脉、归一挑 RMS"**
- **符号位置法**：$\dfrac{QK^\top}{\sqrt{d_k}}$ —— 把 $\sqrt{d_k}$ 写在分数线下方，
  心里念"**维度越高，内积越炸，除以根号拉回来**"。
