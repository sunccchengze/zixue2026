## 一、研究背景

预训练给"知识"，后训练给"行为"。三条主流路线：
| 方法 | 需要什么 | 优化什么 |
|---|---|---|
| **SFT** | (指令, 回答) 对 | 最大似然（只对回答部分算 loss） |
| **DPO** | (指令, 好回答, 坏回答) 偏好对 | 隐式奖励差（无需显式 reward model） |
| **RLVR** | 可判对错的答案 + 验证器 | 期望可验证奖励（GRPO 用组内相对优势） |

**本课题的教学价值极高**：它是课程大纲"机器学习（强化学习）"与唐杰作业④的交点，
也是"知识讲解"最能发挥的地方——**GRPO 的每一项都能在概率论里找到根**（期望、方差、条件期望）。

## 二、研究问题

> **同一个基座、同一套评测，SFT / DPO / RLVR 各自把什么能力提升了、把什么能力损害了？训练奖励的上升，有多少是真的能力提升？**

## 三、攻关线索

1. **基座与数据**：基座用课题04 的模型（或 0.1B 级开源小模型）；任务是**可验证**的（数学题/格式约束/单元测试）
2. **SFT 的损失掩码**：**只对回答部分算 loss**，指令部分不算 —— 这是个高频错误点
3. **DPO 的推导**：为什么 $\sigma(\beta \log\frac{\pi(y_w)}{\pi_{ref}(y_w)} - \beta\log\frac{\pi(y_l)}{\pi_{ref}(y_l)})$ 能等价于"隐式奖励"？
4. **GRPO 的四步**：采样一组输出 $G$ 个 → 打分 → **组内归一化得优势** $A_i = \frac{r_i - \mathrm{mean}(r)}{\mathrm{std}(r)}$ → 加权策略梯度 + KL 惩罚
5. **KL 惩罚的作用**：防止策略跑离参考模型太远（对应 RLHF Book 的"过度优化"章）
6. **评测口径**：**训练奖励 ≠ 能力**。必须在 held-out 题集上评，并且给误差棒
7. **制造一次 reward hacking**：例如让模型学到"输出格式对了但答案是瞎猜"，记录现象（这是本课题最好的素材）

## 七、代码级提问示例

1. 为什么 SFT 只对回答部分算 loss？若指令部分也算，会发生什么？
2. GRPO 里为什么要除以组内标准差？如果一组所有奖励**完全相同**，优势是多少？这时梯度会怎样？
3. DPO 不需要 reward model，那它的"奖励"藏在哪？（用对数比写出来）
4. 训练奖励从 0.3 涨到 0.8，held-out 准确率却从 40% 掉到 35%。列出三个可能原因。
