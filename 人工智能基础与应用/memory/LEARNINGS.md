## 偏好（全仓通用，直接继承）

- [2026-08-16] **批量提问**：每条消息 3–5 个编号问题，一口气答完；一次一问只在卡壳时退回使用。
- [2026-08-24] **手写答题 + 拍照**：Agent 直接读图、回显关键式后判卷；指数/上下标逐字符放大核对。
- [2026-08-24] **你多讲、我多写**：减少碎片化追问，先给完整连续讲解，再集中发 3–5 个关键问题。
- [2026-08-17] **跳过逐课题审阅**：报告照写归档，不再逐篇等用户确认；全部结束后统一回顾。
- [2026-08-16] **记忆锚必需**：新术语必须自带"隐喻 + 口诀 + 符号位置"，用户会主动要求强化记忆。
- [2026-08-17] **生图偏好**：重要公式/概念图用生图模型出"手写课堂笔记风"PNG，不用 ASCII 图。
- 重视**证据分级**与**反例/可证伪**（来自 MBTI 仓库提炼的画像）：不给假精确，预测→打脸→修正是核心链路。

## 本学科新增观察（2026-09-17 起）

- [2026-09-17] **用户主动要求"知识讲解"这条腿加重**：明确说"实操性够强，但知识讲解偏少"，
  并要求"知行合一贯穿全流程"。→ **讲课不是配菜**：每课题必须先讲透对应模块，再上手写；
  首次回应需附《知识地图》与《对标资源清单》让用户看到"学什么、跟谁学"。
- [2026-09-17] 用户选择了**零预算 + 全量对标**这个最难的组合 → 说明其风险偏好是
  "用方法和纪律换资源"，**不是"砍需求"**。因此遇到资源不足时，第一反应应是"降规模保链路"，
  而不是"砍掉某一环"。
- [2026-09-17] 用户选择"分层双轨"而非"严格红线" → 说明其目标是**16 周内真正跑完全链路**，
  愿意用"手写学习目标 + 代写脚手架"换取时间；但**学习目标的边界必须由我守住**，
  因为用户自己可能忍不住"看一下实现"。
