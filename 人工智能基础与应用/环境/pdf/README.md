# 环境 / pdf · 讲义排版链（Markdown → PDF）

> 私有目录（已在学科 README 登记）。用途：把 `讲义/*.md` 与 `章程与地图/*.md`
> 排成**可以直接下载、阅读、打印**的中文 PDF。母版永远是 Markdown，PDF 是派生物。

## 一、怎么用（三条命令）

```bash
cd 人工智能基础与应用

环境/pdf/生成讲义PDF.sh                  # 每讲各一份 + 全书（封面/目录/版权页）
环境/pdf/生成讲义PDF.sh --charter        # 另出《章程与地图》分册（九份合订）
环境/pdf/生成讲义PDF.sh --one M2         # 只重做 M2（改完某一讲后最快）
环境/pdf/生成讲义PDF.sh --check          # 只体检：公式逐条编译，不产出文件
环境/pdf/生成讲义PDF.sh --book --preview 3   # 出全书并导出第 3 页 PNG 供肉眼验收
```

产物：

| 文件 | 页数 | 内容 |
|---|---|---|
| `讲义/pdf/大模型实训讲义-全书.pdf` | 23 | ⭐ **下载这一个就够了**：封面 + 版权说明 + 目录 + M0–M3 + 大纲 |
| `讲义/pdf/M0…M3、README、M4-M9-.pdf` | 2–5 | 单讲分册（手机上看、单讲打印、发给同学） |
| `章程与地图/pdf/章程与地图-全书.pdf` | 28 | 九份章程合订（宪法层：学什么/跟谁学/什么叫学过/何时学/谁写代码） |

## 二、这一套是怎么搭起来的（可复现）

执行 `环境/pdf/bootstrap.sh` 一次性准备（约 1 分钟），之后**编译全程离线**。

| 部件 | 来源 | 为什么这么选 |
|---|---|---|
| 排版引擎 | PyPI `typst`（0.15） | 沙箱**无 LaTeX**（xelatex/pdflatex 全无），typst 是静态链接的预编译二进制，`pip install` 即得；编译一份 5 页中文讲义 ≈ 0.2 秒 |
| 正文/标题字体 | npm `@expo-google-fonts/noto-serif-sc` `-sans-sc` | 沙箱**一个中文字体都没有**（`fc-list :lang=zh` 返回 0），且**中国镜像全部不可达**（清华/中科大/阿里 DNS 不通）；npm 是实测可达的通道 |
| 符号字体 | npm `@expo-google-fonts/noto-emoji` | 讲义里有少量 emoji 与方块字符，思源宋体没有这些字形，缺了会出豆腐块 |
| 拉丁兜底 | 系统 `DejaVu Sans / Mono` | 等宽代码块与数学拉丁字母的兜底 |
| 验收工具 | PyPI `pymupdf` + `fonttools` | 自动核对页数、抽文本核对标题齐备性、导出预览图、**字形覆盖自检** |
| 转换器 | 本目录 `md2typst.py`（自研，约 600 行） | 见下节：**没有用 pandoc** |
| 字体瘦身 | 本目录 `subset_fonts.py` | 四个中文字重 48 MB → **12 MB**（-75%），渲染零差异 |

字体与 Python 环境都放在仓库外的 `/home/user/opt/`，不进 git、不污染仓库：

```
/home/user/opt/.venv/    排版用的 Python 环境（**隐藏目录**：不进平台快照，可由 bootstrap.sh 重建）
/home/user/opt/fonts/    字体（15 MB，已子集化；含在快照里，下次会话不必重下）
```

> **为什么 venv 用隐藏名**：平台快照会跳过 `.venv` 一类目录（含 `node_modules`、`__pycache__` 等），
> 而 193 MB 的排版 venv 里 **155 MB 是用不上的 pandoc**——留着既拖慢快照又没收益。
> 隐藏它的代价是"若沙箱重建要跑一次 bootstrap.sh"（约 40 秒，已实测）。

## 三、为什么不用 pandoc（实测结论）

初版试过 `pypandoc_binary`（pandoc 3.9 内置 typst writer），实测三个硬伤：

1. **数学转写有损**：`\langle x,y \rangle` 被改写成 `(x, y)`（尖括号语义丢失）；
2. **表格/emoji/代码块样式不可控**，而讲义是"读"的材料，排版即内容；
3. 报错信息定位差，出问题只能猜。

所以改成自研转换器，并立了一条铁律：**未知 LaTeX 命令直接报错，绝不静默丢公式**——
公式是讲义里的知识锚点，坏一条就是教错一处。

## 四、自研转换器踩过的坑（都写在这里，免得下次重踩）

| 坑 | 现象 | 处理 |
|---|---|---|
| `//` 与 `/*` 是注释 | 路径 `证据/*.yaml`、`讲义/*.md`、URL `https://…` 后面的正文**被静默吞掉**；结尾还有未闭合块注释 → `unclosed delimiter` | `esc()` 里把 `/` 后紧跟 `*` 或 `/` 的斜杠转义成 `\/`；URL 本身安全（第二个 `/` 不紧跟 `*`） |
| `@` 是引用语法 | 版权页里的 `@expo-google-fonts` 被当成文档标签引用 → ``label `<expo-google-fonts>` does not exist`` | 写成 `\@expo-google-fonts` |
| typst 数学里**连写字母 = 一个标识符** | `xy`、`QK`、`argmax`、`times12` 全部报 `unknown variable` | 拼接片段时按「前片尾/后片首都是字母数字就补空格」处理；`QK^\top`→`Q K^⊤` |
| 合并上下标会粘连 | `w_t\mid` 被合并规则粘成 `w_tmid` | `^(x)`/`_(x)` 只在后面不是字母数字时才合并 |
| 符号名随版本变动 | `angle.l`、`dot.circle`、`diff`、`prod` 在 0.15 里**不存在** | 一律改用**字面 Unicode 字符**（`⟨ ⟩ ⊙ × √ ∂ ∏`），实测在数学模式下渲染正确且稳定 |
| `*…*` 强调有边界歧义 | `③*bpb 会变吗？*` 这种「数字字符 + 星号 + 拉丁」组合会报 `unclosed delimiter`（中文文本里极易踩） | 粗体/斜体改写成函数式 `#strong[..]` / `#emph[..]`，无歧义 |
| 封面里 `1fr` 无效 | `#v(1fr)` 在 block 里不撑开高度 | 用固定间距；并把 `#align(center)[` 的开括号补回（一次手改曾误删，导致 `unclosed delimiter` 追查很久） |
| 标题里有引号 | `#set document(title: "…"我"…")` 字符串被截断 | `typst_str()` 统一转义 |

## 五、自动验收（不是"能编译就算过"）

`md2typst.py` 每次编译都做三件事：

1. **逐条公式编译**：把每条公式单独放进一个最小文档编译一遍（M0–M3 共 99 条去重公式）；
0. **字形覆盖自检**：讲义里每个字符都必须在字体链里（正文用宋体链、代码用等宽链分开查）——
   缺字在 PDF 里是豆腐块，肉眼扫 24 页很容易漏；
2. **标题齐备性**：markdown 里每个二/三级标题的中文指纹必须能在 PDF 抽出的文本里找到——
   防的是"排版悄悄吞内容"这种最难肉眼发现的事故（含公式的标题只核对公式前那段中文）；
3. **页数/体积/预览图**：`--preview N` 导出指定页 PNG，人眼抽检。

## 六、维护约定

- 讲义内容只改 `讲义/*.md`；**PDF 是派生物**，改完跑一次 `生成讲义PDF.sh`。
- `.typ` 中间产物保留在仓库里（便于 diff 排版变化与排查），体积很小（7 份共约 236 KB）。
- 讲义更新后，请在 `讲义/README.md` 的状态表里同步"PDF 已重生成"的日期。
- 字体许可：思源宋体/黑体/Noto Emoji 均为 SIL OFL 1.1，DejaVu 为 Bitstream Vera 许可，均可自由再分发。
