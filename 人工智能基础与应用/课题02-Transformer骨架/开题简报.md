## 一、研究背景

2017 年《Attention Is All You Need》删掉 RNN，用自注意力 + 前馈层实现 **O(1) 依赖路径 + 全并行**。
此后所有主流大模型都是它的变体，但**细节已经换了一轮**：正弦位置编码 → RoPE；LayerNorm → RMSNorm；
post-norm → pre-norm；ReLU MLP → SwiGLU；MHA → GQA。**本课题要求你把现代版写出来，而不是复刻 2017 版。**

## 二、研究问题（一句话）

> **一个"能从零训起来"的现代 Transformer 层，最少需要哪几个组件？每个组件去掉之后，训练会以什么方式失败？**

## 三、攻关线索

1. **形状先行**：写下每一步的张量形状（含 batch、序列、头数），**先能在纸上跑通**，再写代码。
2. **注意力的三个动作**：投影出 Q/K/V → 缩放点积 + 因果掩码 → softmax 加权求和并输出投影。哪一步最容易错？为什么？
3. **位置信息**：RoPE 为什么是"旋转 Q/K"而不是"加到输入上"？（讲义 M3 §三给了恒等式）
4. **归一化与残差**：为什么 pre-norm 比 post-norm 好训？残差提供了什么"通路"？
5. **优化器**：AdamW 里"解耦权重衰减"解耦的是什么？为什么它比 L2 正则更常用？
6. **稳定性**：梯度裁剪在什么情况下救命？fp16 vs bf16 的差别如何影响 loss 曲线？
