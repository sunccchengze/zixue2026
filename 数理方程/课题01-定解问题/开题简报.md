# 课题01 开题简报 · 什么是定解问题

## 研究背景

> 历史上卡过谁：18世纪弦振动争论——达朗贝尔（行波） vs 欧拉（任意初始形状可否） vs 伯努利（级数）→最终傅里叶1807年用正弦叠加任意函数解决，催生现代分析；热传导（傅里叶）与位势（拉普拉斯）同样从物理守恒律化为PDE。
> 当年卡点：PDE本身有无穷多解，怎样加条件才唯一确定物理过程？

## 研究问题（一句话）

**一根两端钉死的琴弦，拨一下，它以后怎么动？怎样把"钉死"和"拨一下"翻译成数学等式，让方程有唯一解？**

## 攻关线索（路标，不是答案）

1. **建模**：取小段(x,x+Δx)，牛顿第二定律 T0 u_xx → ρ u_tt，微小假设 sin≈tan≈u_x → u_tt = a² u_xx + f(x,t)，a²=T0/ρ；热传导能量守恒→ u_t = a² u_xx + f；静电平衡→ Δu = -f/ε
2. **定解条件**：初始条件 u(x,0)=φ(x)（拨的形状），u_t(x,0)=ψ(x)（有无初速）；边界条件三类：Dirichlet u=g（位移已知/温度已知，钉死），Neumann -T0 u_x=g 或 u_x=g（受力已知/绝热自由端），Robin u_x ±σu=g（弹性弹簧连接）
3. **适定性**：Hadamard三问：存在？唯一？稳定（初边值微扰→解微扰）？椭圆/抛物/双曲各有何不同；反例：Laplace方程初值问题不适定
4. **分类**：二阶线性PDE：A u_xx +2B u_xy + C u_yy +... =0，判别式 Δ=B²-AC：>0双曲（波动，有限传播），=0抛物（热，无限传播但衰减），<0椭圆（位势，最平），决策树入口
5. **预告**：为什么两端钉死只能某些频率振动？→本征值问题（下课题）；结合真题选择1"线性齐次判定"练分类

## 里程碑

- ☐ 能口述弦/热/位势三方程推导与物理图像（传播/耗散/平衡）
- ☐ 能写出三类边界条件并各举一物理实例（钉死/绝热/连弹簧）
- ☐ 能判断一个二阶PDE类型并说明适定性含义
- ☐ 能完整写出一个定解问题（方程+初始+边界）并判断有界/无界、齐次/非齐次

## 交付物要求

- 手写公式卡：u_tt = a² u_xx + f， u_t = a² u_xx， Δu=0 + 三类边界格式
