# ERRORS · 判例库（数理方程）

## 通用红线（导师纪律，最高优先级，继承自概率论项目）

- 绝不直接给定理证明——只给线索/反例/追问，不给答案；卡死给线索不给答案
- 报告必须有"我还存疑的地方"，缺则不完整
- **批量提问**：每条消息3~5题，不零碎一问一答；仅卡壳/答错时临时一次一问+提示阶梯
- 说"完全可能"前先算量级（波动能量守恒 vs 热传导衰减量级）；杜绝量级误判
- 导师自己出错必须当场认领并写入本文件（示范诚实）
- 图表禁止ASCII，必须生图模型PNG；重要公式必须手写体公式卡PNG
- 公式卡中希腊字母/下标必须清晰可辨，避免电脑字体混淆

## 本学科判例（待积累）

> 格式：判例编号、时间、现象、红线

- **判例00（模板）**：分离变量误用——在非齐次边界直接分离，未齐次化。红线：见边界先问齐次否？Dirichlet/Neumann? → 先选w齐次化模板，再分离。
- **判例01（预测）**：本征值λ漏=0情况。红线：特征值问题三岔路口：λ<0,=0,>0 必须逐一讨论，写成 checklist。
- **判例02（预测）**：正交系数积分把l写成π。红线：系数公式必带区间长度+权重，Bessel带ρ，默写时带权重口诀"ρ别丢"。
- **判例03（预测）**：达朗贝尔半无界奇延拓/偶延拓混淆。红线：Dirichlet→奇延拓（固定端反相），Neumann→偶延拓（自由端同相），口诀"钉死奇，自由偶"。
- **判例04（预测）**：格林函数符号错 +1/2π ln r。红线：格林=-基本解+调和补偿，镜像法"电荷正负"检查。

> 后续真实教学中每出现一次典型错，立即追加一条，审稿必查。

## 继承自概率论项目的通用教训（作参考）

- 验证公理凭感觉不动手——需带数字实算
- 把积分当可数求和——区分有限/可数/不可数/积分
- 基础比率谬误——条件概率先写公式标分子分母
- 蒙提霍尔50/50+读心术——先钉规则（主持人知情+必开羊门）再算
