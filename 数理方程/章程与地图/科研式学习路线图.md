## 阶段一：地基 · 什么是定解问题

### 课题01 · 什么是定解问题：三类典型方程+初始/边界条件+适定性
- **研究问题**：一根琴弦的振动，怎么变成一道"方程+条件"的数学题？为什么要分波动/热传导/拉普拉斯三类？
- **攻关线索**：
  1. 从牛顿第二定律推弦振动：T0, ρ, u_tt = a² u_xx + f 的每项物理意义
  2. 三类边界：Dirichlet(位移已知)/Neumann(受力/绝热)/Robin(弹性连接) ——弹簧故事
  3. 定解条件=初始+边界；适定性 Hadamard 三件套：存在/唯一/稳定
  4. 分类：二阶线性PDE判别式 B²-4AC → 双曲/抛物/椭圆，物理图像：传播/耗散/平衡
- **里程碑**：
  - ☐ 能口述弦/热/位势三方程推导与物理图像
  - ☐ 能写出三类边界条件并举物理实例
  - ☐ 能判断一个PDE类型并说明适定性含义
  - ☐ 完成定解问题建模一页报告
- **交付物**：开题简报 + 手写公式卡：三类方程 + 决策树初版

### 课题02 · 分离变量法（一维波动：弦振动本征值）
- **研究问题**：两端钉死的弦，为什么只能以某些固定频率振动？本征值从哪来？
- **线索**：
  1. 假设 u=X(x)T(t) → X''/X = T''/(a²T) = -λ 的魔法
  2. λ三分叉：<0, =0, >0逐一讨论，X(0)=X(l)=0 → λ_n = (nπ/l)², X_n=sin(nπx/l)
  3. 正交性：∫X_n X_m =0 + 叠加原理 → 级数解
  4. 初始条件定系数：傅里叶正弦系数
- **里程碑**：本征值推导、驻波物理、系数公式
- **真题锚点**：南卷汇2016填空1、2015特征值问题

## 阶段二：核心 · 分离变量家族

### 课题03 · 分离变量法（一维热传导：衰减模态）
- **研究问题**：一根热杆两端冰冻，温度怎么随时间衰减？为什么没有振动？
- **线索**：热方程 u_t = a² u_xx → T'/a²T = X''/X = -λ → T~exp(-a²λ t) 指数衰减 vs 波动cos/sin；极值原理预告
- **里程碑**：热vs波对比表，衰减因子物理意义

### 课题04 · 二维拉普拉斯：矩形域与圆域初探
- **研究问题**：稳恒温度场没有时间，怎么分离？圆盘为什么会跑出周期边界和Bessel预告？
- **线索**：
  1. 矩形：u= X(x)Y(y)，双方向本征值
  2. 圆域极坐标：Δ = (1/ρ)∂ρ(ρ∂ρ)+ (1/ρ²)∂θθ → 分离得 θ''+λθ=0 周期条件 → λ=n²
  3. 预告：径向方程就是Bessel方程（课题10展开）
- **里程碑**：矩形泊松公式、圆形周期特征值

### 课题05 · 非齐次边界齐次化：稳态法+平移模板
- **研究问题**：边界不为零（端点有温度/有外力），分离法直接卡死怎么办？
- **线索**：w(x,t)构造模板：Dirichlet w= (g2-g1)/l x + g1；Neumann w=...；Robin；令v=u-w化为齐次边界；若g(t)随时间→w(x,t)同形式
- **里程碑**：三类边界w模板速记，齐次化后新方程多出f*=-w_t + a²w_xx

### 课题06 · 非齐次方程固有函数展开：外力强迫
- **研究问题**：弦上有外力f(x,t)拍打，方程本身不齐次，怎么用"本征函数"当基？
- **线索**：将f和u都按X_n展开 → T_n''+a²λ_n T_n = f_n(t) 常微分非齐次 → 常数变易/待定系数；热方程类似一阶ODE；类比：振动模态像钢琴键，外力逐键敲
- **里程碑**：f_n(t)系数积分，T_n ODE求解

## 阶段三：替代工具 · 当分离法失效

### 课题07 · 行波法与达朗贝尔：无界弦的跑波
- **研究问题**：无限长弦，根本没有边界可分离，波是怎么跑的？
- **线索**：
  1. 特征线法：u_tt = a² u_xx → (∂t ± a∂x) → 令 ξ=x-at, η=x+at → u=F(ξ)+G(η)
  2. 达朗贝尔公式：u= [φ(x+at)+φ(x-at)]/2 + (1/2a)∫_{x-at}^{x+at} ψ(s) ds
  3. 半无界：x>0, Dirichlet→奇延拓，Neumann→偶延拓，Robin更复杂
  4. 物理：前一半是初始位移分裂两半跑，后一半是初速区间贡献
- **里程碑**：行波图像手绘，能默达朗贝尔，奇偶延拓口诀"钉死奇自由偶"

### 课题08 · 积分变换法：傅里叶与拉普拉斯
- **研究问题**：无界热传导/波动，级数变积分怎么办？
- **线索**：
  1. 傅里叶变换：把x→ω，偏微分变常微分；热核：(4πa²t)^(-1/2) exp(-x²/4a²t)
  2. 拉普拉斯变换：把t→p，初值自动进入；适合半无界t>0问题
  3. 逆变换查表+留数（复变预告）
- **里程碑**：热传导无界解，傅里叶正逆变换对

### 课题09 · 格林函数与点源问题
- **研究问题**：点热源/点电荷的温度/电势，是所有解的"乐高积木"吗？
- **线索**：
  1. 基本解：拉普拉斯 -1/2π ln r (2D), 1/4πr (3D)；热方程高斯核
  2. 格林函数定义：ΔG = δ，G|边界 =0（Dirichlet格林）
  3. 镜像法：半平面/四分平面/圆外，电像法故事
  4. 泊松公式：单位圆Dirichlet问题积分表达式
- **里程碑**：会写半平面格林，理解"点源指纹"隐喻

### 课题10 · 特殊函数：贝塞尔与勒让德
- **研究问题**：圆盘膜振动为什么敲出Bessel？球面稳态温度为什么是Legendre多项式？
- **线索**：
  1. Bessel方程：x²y''+xy'+(x²-n²)y=0 → J_n, N_n, 零点 μ_m, 加权正交 ∫ρ J_n(μ_m ρ) J_n(μ_k ρ)
  2. 圆膜振动：u= Σ A_mn J_n(μ_mn ρ/a) cos(nθ) cos(a μ_mn t)
  3. Legendre方程：(1-x²)y''-2xy'+l(l+1)y=0 → P_l(x), Q_l，正交 ∫_{-1}^1 P_l P_k =0
  4. 母函数、递推：第①问"为什么叫多项式"
- **交付物**：Bessel零点表记忆锚，递推公式卡

## 阶段四：综合

### 课题11 · 综合战法与能量法：解题决策树+唯一性
- **研究问题**：考场上3分钟如何选对方法？怎么证明解唯一？
- **线索**：决策树：①看区域有界否→无界行波/变换；②看边界齐次否→w齐次化；③看方程齐次否→固有展开；能量积分 E(t)=∫(u_t²+a²u_x²) → dE/dt ≤0 → 唯一；极值原理：拉普拉斯/热传导最大值在边界
- **里程碑**：手绘决策流程图（mermaid→PNG），能量法证明唯一性骨架
