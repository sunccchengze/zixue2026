## 一、两句话玩法

1. **先自己，后 AI**：闸门题先答、书先读、复算先跑——答案永远在教练手里，不在同一屏里；
2. **过一关交一物**：每单元至少 1 件资产落 `资产/`，资产总账 +1 行；13 单元通关 = 收口四关（U12）。

## 四、训练节奏（每单元默认「标准档 B」）

| 档位 | 结构 | 单次投入 |
| :--- | :--- | :--- |
| A 快档 | 压缩：闸门 + 阅读地图 + 1 个输出任务 | 45–60 分钟 |
| **B 标准档（默认）** | D1 输入日 + D2 输出日（+ D3 落地日） | 2 × 45–90 分钟 |
| C 精档 | B + 挑战日（平台落地 / 6.3 前瞻选题） | 3 × 45–90 分钟 |

每次训练日 45–90 分钟到点收尾，未完成入队不硬拖。每 3 个训练日 1 次**裸奔日**（不对话教练，自己按关卡卡走，次日教练判卷）。每次开场先清复习队到期卡。

## 五、学完标准（替代「读完 + 3 题」）

1. **13 单元 × 每单元 ≥ 1 件硬资产**（资产总账 ≥ 13 行）；
2. **U12 结业四关**：抽问 10 抽 3 / 一页四段报告（本人手写）/ 资产总账盘点 / 存疑台账结转；
3. 产出/输入时间比 ≥ 2；打脸记录 ≥ 13 处。
