# 关卡卡 · U1（教材卷 讲01）XDSM 与六个挑战

## 0. 目标与验收线
读完 + 练完，你能：
① 徒手画出 CFD 驱动 ASO 的五模块 XDSM，并指出哪一格吞时间、你平台缺哪一格；
② 说出六个挑战的 **3 + 3 分组**，每条能讲一句「它为什么贵」，并把它对准你自己平台的一处代码/日志；
③ 讲清「为什么有了伴随方法仍然需要机器学习」。

**过卡线（标准档 B）**：闸门题教练判「对」+ 试卷错 ≤ 3 题 + 1 件资产交进 `资产/`。

  4. 🔮 下注：六个挑战里，几个是「设计空间的病」？（先写数字，教练封存）
