#### 1. 生活与物理直觉引子：一堆叶型，其实只沿几条"脾气"在变

把 1000 个叶型叠在一起看，你会发现它们并不是乱变的：
有的整片变厚、有的中线鼓起来、有的后缘翘一下。**这些"整片的共同变化模式"就是模态（mode）**。
用一句话说：与其记"180 个坐标点"，不如记"第 1 条脾气 ×0.7、第 2 条脾气 ×0.3、第 3 条脾气 ×0.1"。
——**维数从 180 掉到 3，代价是丢掉那些"不常发生的细节"**。

论文对 PCA 的定位就是这件事：PCA 把高维数据变换到低维，同时**保留数据里最大的变化量**
〔原文 P21 "PCA is a mathematical algorithm that transforms high-dimensional data to low dimensions while maintaining the maximum variation in the data s"〕。

#### 2. 工程死穴：为什么"降维"能同时解决 ①②③

**先认词**

| 中文 | 英文 | 一句操作定义 |
| :--- | :--- | :--- |
| 聚类 | clustering | 把样本按"像不像"分堆；**不需要标签**，所以归在无监督学习 |
| k-means | k 均值：k 是堆数、means 是各堆的中心 | 反复做两件事——把点分给最近的中心（E 步）、把中心移到堆内平均（M 步） |
| 高斯混合模型 | GMM = Gaussian Mixture Model | 每堆是一个高斯（有均值、有协方差），每个点以"概率"属于各堆；E/M 同理但更软 |
| 主成分分析 | PCA = Principal Component Analysis | 找一组正交方向使投影方差最大；方向=协方差矩阵的特征向量，"贡献量"=对应特征值 |
| 快照 | snapshot | 一次仿真/某个时刻的整个场（一张压力云图就是一个向量） |
| DMD | Dynamic Mode Decomposition，动态模态分解：Dynamic 动态、Mode 模态、Decomposition 分解 | 对时间序列快照做"一阶算子的低秩近似"，得到一组带增长/振荡率的相干结构 |
| 流形学习 | manifold learning（Isomap / LLE 等） | 假设数据躺在一张弯的低维曲面上；先建近邻图，再沿图走**测地距离**，最后降维 |
| 降维/参数化 | dimensionality reduction | 把 d 维压缩到 k 维（k ≪ d）；在 ASO 里就是"把形状用 k 个数说清" |

**死穴回顾**：讲 01 挑战①——设计变量一多，空间里满是畸形外形，CFD 不收敛、优化低效。
降维一次性解决三件事：**① 维度从几百降到几维（代理模型精度回来，见讲 02 §3 第三步）；
② 畸形形状落在流形外、天然不会被采到；③ 优化变量少了，无梯度法的评估次数从 c^n 掉到 c^8。**

#### 3. 数学从 0 到 1 推导：手推一次 PCA，三行代码就能验

设样本矩阵 X ∈ ℝ^{n×d}（n 个样本、每行是一个 d 维形状坐标）。**三步**：

1. **中心化**：每列减自己的均值 → X̃ = X − μ̄（不做这步，PCA 会被"整体位置"骗走）；
2. **协方差矩阵**：Σ = (1/(n−1)) X̃ᵀ X̃ ∈ ℝ^{d×d}（**对称半正定** → 特征值全 ≥ 0）；
3. **特征分解**：Σ = V Λ Vᵀ，Λ = diag(λ₁ ≥ λ₂ ≥ … ≥ λ_d)，V 的列即主成分方向；
   第 j 个主成分得分 = X̃ v_j；**前 k 个保留的方差比例 = (λ₁+…+λ_k)/(λ₁+…+λ_d)** ← 这就是选 k 的判据。

**手算例（由 `code/pca.py` 逐行复算）**：三个二维样本 (1,1), (2,2), (3,3)。

- 中心化后 (−1,−1), (0,0), (1,1)；Σ = (1/2)·[[2,2],[2,2]] = [[1,1],[1,1]]；
- 特征值 λ₁ = 2（方向 (1/√2)(1,1)ᵀ），λ₂ = 0（方向 (1/√2)(1,−1)ᵀ）；
- 保留 1 个主成分 → 方差保留 **100%**：**一个数就装下了这三个点**。

把例子换成"三个叶型 × 180 个坐标"，λ₁ 就是"最主要的整片变化"（例如整体厚度），
而"方差保留 ≥ 99% 所需的最小 k"就是你该用的模态个数。**这条判据比"论文用了 8 个模态"有用得多。**

**连你学过的两门课**：
① 概率论课题 07——λ_j 就是主成分得分的**方差**，V 的列彼此**不相关**（这是"去相关变换"）；
② 数理方程——"找一组正交方向使方差最大"和"找拉普拉斯算子的本征模态"是同一类瑞利商极值问题，
所以"模态"这个词在这里不是比喻。

#### 4. 操作流：五种工具的输入/输出与选择

| 工具 | 输入形状 | 输出形状 | 中间几步 | 什么时候用 | 丢什么 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| k-means | (n, d) | k 个中心 + 每个点的堆号 | 初始化中心 → E/M 迭代 | 想把设计空间**分块**（混合专家 ME 的第一步，讲 02/07） | 形状假设硬（各堆同尺寸球形），边界硬切 |
| GMM | (n, d) | k 组 (π_c, μ_c, σ_c) + 后验概率 | E 步算归属概率（式 35）、M 步更新（式 36–38） | 要**软**归属、要椭圆形状时 | 仍受"由 k 个高斯拼"限制 |
| PCA | (n, d) 或 (d, n_s) 场 | 载荷 (d, k)、得分 (n, k) | 中心化 → 协方差 → 特征分解 | 线性关系够用、要**可解释**、要能反算回形状 | 只抓线性结构；弯曲流形上会被"平均"糊掉 |
| Isomap / LLE | (n, d) | 低维坐标 (n, k) | 建近邻图 → 最短路算测地距离 → 降维；Isomap 明确要"直接从训练数据构造核矩阵"〔原文 P23 "construct the kernel matrix"〕 | 形状空间明显弯曲（例如"薄 → 厚"绕着走） | 近邻图断裂就整体崩；样本少时更脆 |
| DMD | 快照序列 (d, n_t) | 模态 + 增长率/频率 | 把序列切成两半 → 对前一做 SVD → 求投影算子的特征对 | 时间相关/非定常流动（失速先兆、抖振） | 需要等间隔时间序列；非线性强时失真 |

**线性 vs 非线性模态，叶型上的差别长这样**：论文 Fig. 42（p44）画了 PCA / ASM / InfoGAN 三种模态——
线性的 PCA 与 ASM 模态在系数加倍时呈**线性叠加**效果，而 InfoGAN 模态因为网络里用了非线性激活，
改潜变量会带来**全局性**厚度/弯度变化〔原文 P44 "PCA and ASM modes are linear, so the"〕。
**记住这条区别，讲 06 会用到。**

#### 5. 数据与图表：怎么读 Fig. 21/22（PCA）与 Fig. 24（DMD）

- **Fig. 21（p22）**：流程是"归一化到同一量级 → 协方差矩阵 → 特征分解"。
  **第一格"归一化"是命门**：叶型坐标（米级）和来流马赫数（O(0.5)）混在一起不归一化，PCA 会只看见量纲大的那个。
- **Fig. 22（p23）**：黑箭头=主轴，蓝点被投到"最宽的那个方向"。读图只问一句：**去掉第二维，点序会变吗？**（不会——这就是 100% 方差保留的画面）
- **Fig. 24（p25）**：DMD 的"切两半 + SVD"看着像障眼法，其实是逼你回答"用什么算子描述演化"——**一阶线性近似**；
  这就是为什么它对湍流相干结构有效、对强非线性转捩吃力。

**你的审美挑剔用在这里**：这三张流程图画法是"编号 1:/2:/3: + 箭头"的统一模板，好读；
但 PCA 那张图把"方差最大"这个**目标函数**藏起来了，只画了步骤——一张只讲"怎么做"不讲"为什么这么做"的图，
教不出会挑 k 的人。

![每维摊到几个点：N^(1/d) 的坍缩（手账版）](./images/L01_s5_curse_of_dim_zh.png)

> 上图（`images/L01_s5_curse_of_dim_zh.png`，本白皮书与讲 11 共用）请和 §3 的判据对着看：样本数不变、把 d 从 74 打到 8，每维实际点数 = 1000^(1/8) = **2.37**

#### 6. 审稿人批判

1. **§3.2 讲降维却不给"保留几个主成分"的行业惯例**：全文没写"方差保留 90%/95%/99% 哪个常用"，导致读者照抄别人论文里的 k；
2. **把 PCA 与自编码器分在两节（§3.2.3 与 §3.5.5）却不说它们的关系**：AE 训练时的重构误差最小化在**线性解码器**情形下与 PCA 等价，这个联系不写，学生就把两件事当两件事；
3. **k-means/GMM 在 ASO 里的真实用途（分块建代理，即 ME 的第一步）只在 §4.2.1 才出现**，方法节与应用节相隔 30 页，认知负担大；
4. **DMD 只给了定义没给"能省多少 CFD"**：对流场建模（§4.2.2）才是它的主场，本节里它是"顺带介绍"，篇幅分配与工程重要性不匹配。

#### 9. 自测 10 题（2 选 + 2 填 + 6 答）

1. （选）PCA 第一步做中心化的目的是：A 让数据更好看 B 否则协方差会把"整体均值方向"当成最大变化 C 让特征值变负 D 为了去掉噪声
2. （选）DMD 处理的对象是：A 静态形状矩阵 B 时间序列快照 C 标签数据 D 概率分布
3. （填）PCA 的主成分方向是协方差矩阵的 __________，对应的 __________ 表示该方向上的方差大小。
4. （填）选 k（保留几个模态）的常用判据是 __________ ≥ 95%。
5. （答）用三句话说清 k-means 与 GMM 的差别（从"归属是硬是软"、"簇形状"、"迭代内容"三方面）。
6. （答）为什么线性 PCA 在一圈"弯曲"的叶型分布上会失效？画一张 5 秒能看懂的草图并解释。
7. （答）Isomap 为什么比 PCA 更能对付弯曲流形？它的失败模式是什么？
8. （答）把 1000×74 压到 8 维，"每维实际点数"从 1.10 变成多少？写出算式。
9. （答）如果老板要求"降维后必须能反算回原始几何用于出图"，你会拒绝哪一种降维方法？为什么？
10. （答）批判：为什么说"只讲步骤、不讲目标函数"的流程图会教出不会选 k 的人？

**答案要点**：1-B；2-B；3-特征向量、特征值；4-累计方差保留比例；
5-硬 vs 软（后验概率式 35）、球形 vs 椭圆（各带协方差 σ_c）、更新中心 vs 更新 (π, μ, σ)；
6-弯曲分布的"弦方向"落在流形外（中间是空的），投影会得到不存在的形状；
7-用近邻图上的**最短路/测地距离**替代欧氏距离再降维；图不连通或采样稀疏处即崩；
8-每维点数 = N^(1/k) = 1000^(1/8) = **2.37**，对比 74 维的 1000^(1/74) = **1.10** ⇒ 约 **2.2 倍**；
若想"每维 10 点"，8 维需 10^8、74 维需 10^74 ⇒ 说明 8 维已经可以谈采样，74 维永远不能；
9-AE/VAE 的解码器能反算，但要**训练完冻结**；真正会拒绝的是"只给得分不给载荷"的黑箱降维（无逆映射）；
10-因为没有目标函数，就没有"再降一维损失多少"的量化依据，k 只能靠抄。
