#### 3. 场景引子：一摞作业，四种批法

你最熟的世界是考试。同一摞作业，老师有四种批法：

- 全批，每题都有标准答案 → **监督学习**；
- 完全不批，只让你自己找规律 → **无监督学习**；
- **只有一半作业有答案**：另一半自己先做一遍，
  让模型给个参照答案 → **半监督（伪标签）**；
- **完全没有答案，只有期末成绩**：反复试错、按分数调整策略 → **强化学习**。

气动设计的现实恰好落在后两种：**标签（CFD）又贵又慢**，
而"好坏"往往只剩一个标量。

![一摞作业的四种批法：全批、不批、批一半、只有期末分](./images/L04v2_s1_exam_scene_zh.png)

> 🧭 **呼吸点**：引子的账——四种批法的分水岭只有一个：
> **你付不付得起标签钱**。

#### 4. 工程死穴 + 先认词：标签从哪来

**先认词 · 第一批**（本讲新词都在这里定义，后面不再解释）

| 中文 | 英文 | 一句操作定义 |
| :--- | :--- | :--- |
| 伪标签 | pseudo label | 先用有标签数据训 M₀，再用 M₀ 给无标签数据贴一个假标签 y′ |
| 受限玻尔兹曼机 | RBM = restricted Boltzmann machine（restricted 受限：层内不相连） | 一层可见 v + 一层隐元 h 的二部图，学"哪些配置常一起出现" |
| 对比散度 | CD = contrastive divergence | 不做完整马尔可夫链，只走 k 步就估梯度 |
| 深度信念网络 | DBN = deep belief network | 把 RBM **逐个堆叠**：训好一个冻结一个，输出当下一层输入 |
| 强化学习 | RL = reinforcement learning（reinforcement 强化、learning 学习） | 学一个**策略** π：在状态 s 下出什么动作 a，使**长期累计奖励**最大 |

**先认词 · 第二批**

| 中文 | 英文 | 一句操作定义 |
| :--- | :--- | :--- |
| 状态 / 动作 / 奖励 | state / action / reward | 状态=当前局面；动作=改哪几个模态系数；奖励=改完好坏的变化 |
| Q 值 | Q(s,a) | "在 s 下执行 a，往后一共能拿多少分"的期望，Q-learning 就是把它列表或拟合出来[^L04-12] |
| DQN | Deep Q-Network | 用深度网络代替 Q 表，配合 ε-greedy 在"用已知最好"与"试新的"之间权衡 |
| 策略梯度 | policy gradient（确定性策略梯度 DPG 直接把状态映射到最优动作）[^L04-13] | 不估 Q，直接对 π 的参数求梯度 |

**死穴数据**：一次 CFD 几小时，1000 组样本就是一个课题组一学期的机时。
半监督正是在"标签不完整且获取代价高昂"这个背景下出现的[^L04-1]。

它的正式定义也摆在那儿：用少量有标签数据、
配大量无标签数据一起训[^L04-2]。

#### 5. 数学从 0 到 1：三块，各配一张图

**（a）伪标签的更新式**。

给定有标签集 (X_L, Y_L) 与无标签集 X_U，三步：

1. 只在有标签样本上训一个 M₀；
2. 用 M₀ 给每个 x_j ∈ X_U 贴上伪标签 y′_j；
3. 真标签与伪标签合并，再训一个 M_semi。

第三步里的 λ 是**信任折扣**——伪标签不是事实，只按 λ 的成色计入损失。
论文 Fig. 25 的流程正是"真标签与伪标签合并后再训一个监督模型"[^L04-14]。

<details>
<summary>LaTeX 渲染版</summary>

$$
M_0 = \arg\min \sum_{i\in L}\big(\hat y(x_i)-y_i\big)^2,\qquad y'_j = \hat y_{M_0}(x_j)
$$

$$
M_{\text{semi}} = \arg\min\Big[\sum_{i\in L}\big(\hat y(x_i)-y_i\big)^2
+ \lambda\sum_{j\in U}\big(\hat y(x_j)-y'_j\big)^2\Big]
$$

</details>

![伪标签三步：训 M0、贴伪标签、合并再训，中间挂着 λ 与置信闸门](./images/L04v2_s3_pseudo_three_steps_zh.png)

🔮 **下注**：M₀ 在无标签点 x_u 上预测 C_D = 0.0180，真值 0.0205。
第二轮把这个 0.0180 当事实去拟合，误差会被**稀释**还是被**固化**？先选一个。

👊 **打脸**：**误差被固化**。
第一轮偏低 12% 的预测，第二轮变成训练目标，第三轮再在这个基础上偏。

若 M₀ 对畸形外形系统偏乐观，伪标签会把模型往
"畸形但看似好"的区域再推一把——这就是**自我强化的偏见**。

![预期误差被稀释，实测误差被固化并逐轮放大](./images/L04v2_s3_self_reinforce_zh.png)

**手算一遍**：0.0205 → 0.0180，低了 0.0025，相对偏差 12.2%。
工程上必须加两道闸：

- 闸门①置信度门槛：只接受 |σ| < 1.96σ̂ 的伪标签；
- 闸门②抽查：每 5 轮抽 5% 做真 CFD 校验，若 MAE 增 >10% 就丢掉该批伪标签。

**（b）RBM 的能量直觉**。

先说结论：RBM 学的是一个概率分布，
**数据里的配置能量低，模型自造的配置能量高**。

  E(v,h) = −aᵀv − bᵀh − vᵀWh，  P(v,h) ∝ exp(−E)

![数据配置落在能量谷底，模型自造的配置被压向高处](./images/L04v2_s3_rbm_energy_zh.png)

训练就是两个相位相减：正相位把数据配置的概率顶上去，
负相位把模型自造配置的概率压下来。

负相位要做吉布斯采样走到平衡[^L04-3]，
外积 v′h′ᵀ 就是那个负梯度[^L04-4]——太慢，于是 CD-k 只走 k 步。

![对比散度：长链采到平衡太慢，走 k 步就够用](./images/L04v2_s3_cd_k_steps_zh.png)

为什么叫 restricted：可见层与隐层之间全连[^L04-5]，
而同层内的节点之间没有连线[^L04-6]。
于是**给定一层的值，另一层各神经元条件独立**，整层可以并行采样[^L04-7]。

![两层全连、层内不连：给定一层，另一层各神经元条件独立](./images/L04v2_s3_rbm_bipartite_zh.png)

**（c）RL 的三件套翻译**。把你的优化循环改写成 RL 语言：

- 状态 s_t =（当前设计变量、C_L、C_D、剩余约束裕度、t/总步数）；
- 动作 a_t = Δ 模态系数向量，动作空间连续 → **必须用策略梯度/DPG 而非 Q 表**；
- 奖励 r_t = (C_D,t − C_D,t+1) × 10⁴，用"省下多少阻力计数"当奖励。

目标是让长期累计折扣奖励最大。
奖励这一步的定义很直白：每执行一个动作就算一次[^L04-15]；
而策略本身只是"从状态空间到动作空间的一张映射"[^L04-16]。

![智能体与环境的一圈：动作出去，状态与奖励回来，一格就是几小时](./images/L04v2_s3_rl_loop_zh.png)

**为什么难训**：奖励稀疏（中间步 CFD 不收敛 = 0 分，噪声淹没信号）、
约束不可微（"厚度 ≥ 2 mm"塞不进奖励），
且**策略每改一次都要真实 CFD**。

> 🧭 **呼吸点**：§5 的账——伪标签是借来的标签，RBM 是借来的分布，
> RL 是借来的评价；三笔债都要还，只是还款方式不同。
