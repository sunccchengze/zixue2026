#### 3. 场景引子：老中医与全科体检

- **系数建模**像老中医：你报几个症状（几何参数），他说一个结论（C_D = 0.0173）。
  快、便宜、可导，但**问他"压力峰值在哪"**他答不上来。
- **流场建模**像给你拍一张全科 CT：吐出整张压力云图、马赫数分布。
  信息量大到可以事后算任何指标，但训练贵、显存吃紧，
  而且一旦拍错（激波位置偏了两格），**后面所有指标一起错**。

![左：老中医给一个结论；右：全科体检给一整张图](./images/L07v2_s1_tcm_ct_zh.png)

论文的开篇就是这一取舍的学术版：CFD 能提供全域所有变量的丰富信息，
但 ASO 通常只关心几个气动性能指标（升力系数、阻力系数），
因此**建模气动力系数**极受关注[^L07-1]。

#### 4. 工程死穴 + 先认词：把"贵"拆成两笔账

**先认词 · 第一批**（本讲新词都在这里定义，后面不再解释）

| 中文 | 英文 | 一句操作定义 |
| :--- | :--- | :--- |
| 响应面法 | polynomial response surface | 用低阶多项式拟合系数；1990 年代计算机辅助气动设计初期的主流[^L07-2] |
| 混合专家 | ME = Mixture of Experts | 把设计空间切成块，每块一个小专家，再按后验概率加权（讲 03 的 k-means 在这里上岗） |
| RMTS | regularized minimal-energy tensor-product splines | 张量样条 + 正则，能撑到 10^5 量级训练点，但**高维不行**[^L07-3] |
| 降阶模型 | ROM = reduced-order model | 用 POD/快照把高维场压成几阶坐标系下的动力学 |
| 配点 | collocation points | 没有标签、只要求满足 PDE 的内部点（讲 05 的式 79 第二项） |

**先认词 · 第二批**

| 中文 | 英文 | 一句操作定义 |
| :--- | :--- | :--- |
| 计数 | drag counts | 1 count = 0.0001 的阻力系数增量；"0.9 counts"就是 ΔC_D = 0.00009 |
| 平均绝对误差 | MAE = mean absolute error | 预测与真值差的绝对值平均（比 R² 更诚实，因为它不能被"大方差"骗） |
| 外推 | extrapolation | 查询点在训练分布之外；ML 模型天生是**插值型**的 |

**死穴一：样本与维度互相拉扯。**

传统代理训练耗时，而**不适合处理大数据**（讲 02）；用 ANN 能吞大数据，
但**大多数 ML 预测模型是插值型的，外推预测可能失去精度**[^L07-4]——
所以维度灾难仍是气动力系数建模的根本困难[^L07-5]。

**死穴二：加速 CFD 而不是替代它。**

论文 §4.2.3 明确：高保真 ASO 里，
即使精度被认为很高的代理模型，也可能达不到所需保真度[^L07-6]，
所以仍然需要高保真 CFD[^L07-7]。

**这一句是给你这种"平台作者"的一记直拳：代理不能替代验证，只能替代搜索。**

![两处死穴：样本与维度互相拉扯；代理只能替代搜索，不能替代验证](./images/L07v2_s2_two_deadlocks_zh.png)

> 🧭 **呼吸点**：§4 的账——本讲所有数字都要挂两个标签：
> **什么口径**（E2 代理 / E4 闭环）与**什么误差单位**。

**（a）系数建模的代表数字（全部出自论文）**

其中 Li & Zhang 那一行的样本量与误差，论文在两处各说了一遍：
验证集是 47,967 个未见机翼[^L07-8]，训练样本与误差档位见 p61 的对照表[^L07-9]。

🔮 **下注**：C_D = 0.0173，论文说的"0.4% 平均相对误差"
换算成绝对误差是多少？再换成 counts 是多少？先算，再看下一行。

👊 **打脸**：0.0173 × 0.004 ≈ **6.9 × 10⁻⁵ ≈ 0.7 counts**。

机翼优化里 C_D 的常见量级是 0.008–0.03。

所以"0.4%"这三个字，在不同基准上代表 0.3–0.7 counts 的绝对误差——**不换算就没有可比性**。

**（b）0.4% 到底意味着什么（上一节下注题的正解）**

第一级：相对误差 0.4%（论文口径）。

第二级：绝对误差 ~3×10⁻⁵ ≈ 0.3 counts（按 C_D ≈ 0.008 折算）。

第三级：对你自己的 η = 0.9561——**对照你自己的 η = 0.9561**，
0.9561 是"方差解释比例"，0.4% 是"平均相对误差"，**两者不可直接比大小**。

![0.4% 的三级台阶：相对误差 → 绝对误差 → 你自己效率的量级](./images/L07v2_s3_04pct_ladder_zh.png)

想比，就把 η 换算成 MAE：η ≈ 1 − MSE/Var(y)。

若 Var(η) ≈ (0.011)²（你数据集效率的标准差量级），
则 RMSE ≈ 0.011 × √(1−0.9561) ≈ **0.0023**。

也就是约 0.23 个百分点。

![预期：两个百分数可以直接比；实测：必须先换成同一绝对量纲](./images/L07v2_s3_r2_trap_zh.png)

这在"叶轮机械效率"这门生意里**不是小误差**，
因为整机收益的论断常以 0.2–0.5 个百分点为单位。

（换算口径：本白皮书自算，标注为〔延伸·待核实〕，不许当论文数字引用。）

**（c）流场建模的代表数字**

论文 Table 3（p53）把技术列成三档：POD / 流形学习（Isomap、LLE）/ 自编码器与 GAN。

关键对比是：**Isomap 类模型能把激波处的压力梯度"拉尖"**，比 POD 更接近 CFD[^L07-10]。

Decker 等人也报了激波附近误差更小[^L07-11]。

Thuerey 等用 U-Net（AE 的特例）预测不同翼型、不同 Re 的速度与压力场。

**未见过的翼型上平均相对误差 < 3%**[^L07-12]。

Chen 等用条件 GAN 预测速度场，75 个未见 UIUC 翼型上，
x/y 方向分量平均相对误差 **8.13% / 20.83%**。

![三个数 vs 一整张场：后面所有指标都挂在激波位置对不对上](./images/L07v2_s3_field_vs_coeff_zh.png)

**（d）"替代求解器"与"喂初值"的差别（本讲最实用的分类）**

- **喂初值**：Obiols-Sales 等用 CNN 预测速度、压强、涡黏度作为 CFD 的初场，
  **加速 1.9–7.4×**（层流与湍流、多种几何）[^L07-13]；
  注意：**最后仍是 CFD 收敛出来的数**，所以这是 E3/E4 口径，可以拿去发"效率提升"；
- **改格式**：Bar-Sinai 等的数据驱动离散化，在**粗 4–8× 的网格**上达到标准有限差分同级别的精度[^L07-14]——
  **这是"同等成本换更高保真"，不是"加速"**，写论文时千万别混；
- **替代求解**：POD/DMD 做低维动力学，最便宜，但对强非线性/激波运动最脆。

![系数建模 vs 流场建模：两种世界观的流水线对照](./images/L08_s2_flowfield_pipeline_zh.png)

#### 6. 操作流：选型决策树（把论文散落的判断集中成一张）

```
需要下游用到"分布/梯度场"（载荷、换热、抖振、分离）吗？
├── 不需要（只要 C_L/C_D/η/π）
│    ├── 设计维度 d ≤ 20，样本 ≤ 5k      → Kriging / GEK（讲 02）＋ EGO 加点（讲 09）
│    ├── 样本 ≥ 50k，需要交互式毫秒响应    → ANN 系数模型（残差形式）＋ 最近邻门控（本讲 5）
│    └── 需要跨工况（M、Re 扫描）         → 把 M/Re 当输入 + 依赖采样策略（Du et al.〔原文 P61 "16/10"〕的做法）
└── 需要（全场）
     ├── 网格固定、样本 ≥ 1k 张场         → CNN/U-Net（<3% 是可达线）
     ├── 想给 CFD 省时间                 → CNN 预测初场 + 仍跑 CFD（1.9–7.4×）
     └── 数据极少但方程干净              → PINN（代价：边界一变就重训，讲 05/讲 08）
```

#### 8. 审稿人批判（本讲可攻击的点，含对论文本身的）

1. **"R²/相对误差/counts"三种口径混用**：Table 5 用 counts、正文用平均相对误差、别的论文用 R²，
   综述未提供统一换算表——这是**本讲 §3(b) 存在的理由**，也是你能在组会上挑的第一根刺；
2. **外推风险只被"提出"没有被"度量"**：全文说"多数模型是插值型的、外推可能失准"，
   但没有一篇被引工作给出"外推距离 vs 误差增长"曲线；
3. **§4.2.1 的 ANN 优势叙述隐含"样本多就准"**：没有讨论**样本浪费**（10^5 样本里大量互相冗余），
   这正是"最优采样"（讲 06）该在此出场却被挪到 §4.1 的编排问题；
4. **对"验证集构造方式"零着墨**：留出集是随机切还是按型号/工况切，直接决定 R² 是 0.95 还是 0.60，
   综述没提醒（这是本白皮书判卷红线：**E2 不许冒充 E4**）。
5. **顺带批本白皮书自己**：本讲 §5(b) 那个 0.0023 的换算，
   分母 Var(η) ≈ (0.011)² 是**我替你估的**，不是你数据集的真值。
   你不算出来，这个数就只是个好看的算术练习。

1. （选）流场建模相对系数建模的**唯一**决定性优势是：A 精度更高 B 能直接提供分布量（载荷/换热/分离）供下游约束使用 C 训练更便宜 D 不需要网格

**答案要点**（一题一行，先做再看）：

1. B——能直接提供分布量供下游约束使用，精度不是它的卖点。
2. B——降低迭代到收敛的成本，最后仍是 CFD 收敛出来的数。
3. 135,108；47,967；0.4%。
4. 1 × 10⁻⁴（万分之一）。
5. RMSE = σ_y·√(1−R²)，需知 σ_y（没有 η 的标准差就说不清）；两者量纲与分母不同，必须换成同一绝对量纲才可比。
6. 优化器会**主动飞向模型高估收益的方向**，而那里往往正是样本稀疏处（最优点被伪影吸走）。
7. 随机留出时相邻样本几乎同型号 → 泄漏；分组留出才测真实外推。你的 1,000 组按 Ω（转速）分 5–8 组。
8. 见 §10；d 用 KD-tree 现算、σ̂ 来自 MC Dropout/ensemble、β 是超参（0.5–2 起试）。
9. 先改输出：输入决定表征（几何模态，讲 06），输出决定用途；次序是"几何模态 → 站位分布 → 约束使用"。
10. 例：见论文同类工作样本 10^5 而你是 10^3，若不知样本量就会误以为"我的 R² 更高"，实际上别人的对象更大（3D 机翼、跨 M/高度范围），结论"我更强"会被审稿人当场击穿。
