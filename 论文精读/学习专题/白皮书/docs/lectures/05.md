#### 3. 场景引子：一条流水线上的八个工位

把"从外形到性能"想成一条手工流水线：

- **ANN（Artificial Neural Network，人工神经网络）**：一个"万能表格"，你给它形状参数，它吐气动力系数；
- **CNN（Convolutional Neural Network，卷积神经网络）**：不读参数表，**直接看图**（网格场），用小窗口滑动找局部特征；
- **RNN（Recurrent Neural Network，循环神经网络）**：**沿叶高/沿时间**一格一格读，自带记忆（LSTM 的三门）；
- **AE（Autoencoder，自编码器）**：先把图**压成几个数**再还原，逼自己只留最要紧的信息；
- **VAE（Variational AE，变分自编码器）**：压成的不是数，是**一个分布**（μ 和 σ），于是能"随机生成"新形状；
- **GAN（Generative Adversarial Network，生成对抗网络）**：造假者 vs 鉴定者互相打，最后造出来的以假乱真；
- **SOM（Self-Organizing Map，自组织映射）**：把高维形状摆到一张二维"地图"上，**相邻的形状长得像**；
- **PINN（Physics-Informed NN，物理信息神经网络）**：不许只学数据，**还要满足方程**，不满足就罚。

![一件外形数据走过八个工位，最后吐出气动系数](./images/L05v2_s1_factory_line_zh.png)

论文对 ANN 的定位很直白：ANN 是深度学习的**核心组件**，
近年的 ML-based ASO 进展绝大多数用的都是 ANN[^L05-1]。

八个名字容易记成八件事，其实它们是一棵树：

![家族树：一根主干分出"看结构"与"压缩生成"两支，另有"加物理"一条侧枝](./images/L05v2_s2_family_tree_zh.png)

> 🧭 **呼吸点**：引子的账——八个架构不是八门课，
> 是三种欲望：**更准**、**要流形**、**少付数据**。

#### 4. 工程死穴 + 先认词：为什么"更深"不等于"更好"

**先认词 · 第一批**（本讲新词都在这里定义，后面不再解释）

| 中文 | 英文 | 一句操作定义 |
| :--- | :--- | :--- |
| 前向传播 / 反向传播 | forward pass / backpropagation | 前者：输入 → 输出；后者：从输出把梯度一路送回每层权重（ML 界把自动微分反传称为 backpropagation，现代软件包内置）[^L05-2] |
| 激活函数 | activation function | 给每个神经元加"非线性"，否则多层等于一层（ReLU: r(z) = max(0, z)）[^L05-3] |
| 损失函数 | loss function | 预测与观测的平方和：min_θ Σᵢ (ŷᵢ(θ) − yᵢ)² |
| 梯度消失 | vanishing gradient | 层数深时，梯度在反传中逐层乘小于 1 的因子 → 前面的层几乎学不到 |
| 过拟合 | overfitting | 训练集很好、留出集很差：记住了噪声 |

**先认词 · 第二批**

| 中文 | 英文 | 一句操作定义 |
| :--- | :--- | :--- |
| 转置卷积 | transposed convolution | 反卷积上采样（先补零再卷），把低维特征放大回高维场[^L05-4] |
| 瓶颈层 | bottleneck layer | AE 中间那一小段，潜变量住在这里 |
| 模态崩塌 | mode collapse | GAN 的生成器只造少数几种花样，判别器卡住不再进步[^L05-5] |
| 拓扑保持 | topology preservation | SOM 的要求：输入空间相邻的点，在映射图上仍相邻[^L05-6] |

**死穴**：气动数据是**小样本 + 强相关**（相邻控制点几乎一样），
所以网络容易①过拟合到历史型号、②在流形外乱给数（外推）、
③根本不知道自己在违物理（负压区、质量不守恒）。

这三条分别对应本讲的 VAE/GAN（管①的多样性）、PINN（管③）、
留出集 + 置信带（管②，见讲 07/09）。

> 🧭 **呼吸点**：§4 的账——"更深"从来不是免费的，
> 深度换来的表达力要拿**梯度、样本、物理合理性**三样东西去抵。

#### 5. 数学从 0 到 1：五块，每块一张图

**本讲两个"必须会画"的结构**（左：自编码器的瓶颈；右：PINN 的三项损失）——
它们分别对应"降维"与"讲物理"，
也是你被追问"AE 和 PINN 到底差在哪"时的唯一答法：

![自编码器自己当标准答案；PINN 把方程残差写进损失，于是没有标签也能算](./images/L05_s4_ae_and_pinn_loss_zh.png)

**（a）一层神经网络在算什么。**

  z = W h_prev + b，  h = σ(z)

**参数量算例**（这一手你必须会，因为组会必问）：
Linear(74 → 256) 的参数量 = 74 × 256 + 256 = **19,200**；
Linear(256 → 256) = 256² + 256 = **65,792**。

![两层线性层的参数量算账：74×256+256 与 256²+256](./images/L05v2_s3_param_count_zh.png)

你那台残差代理 523,011 个参数，大致就是
"一个 19,200 的入口 + 若干个 65,792 的块 + 出口"堆出来的。
**数量级对得上，说明它是个"中等身材"的网络**，不是黑魔法。

**（b）训练 = 一次极大似然。**

论文的表述：神经网络训练的核心原则就是极大似然估计，
把参数优化到"在给定输入下使观测输出出现概率最大"[^L05-7]，
于是目标函数写成式 (64) 的平方误差和：

  min_θ Σᵢ (ŷᵢ(θ) − yᵢ)²

**残差代理的妙处**：预测 y = y_CFD_base + f_θ(x)，
即让网络只学"相对基准的增量"。
这在数学上等价于给回归加了一个"先验中心"，小样本时明显更稳。

**（c）为什么需要激活，以及梯度消失从哪来。**

激活函数给网络加非线性，论文的写法是 ReLU 与 Leaky ReLU[^L05-8][^L05-9]。
没有它，多层网络等价于一层线性变换——白堆。

![三种激活：直线、S 形、取正值；导数的大小决定梯度能不能传回去](./images/L05v2_s3_activation_zh.png)

🔮 **下注**：若 σ 取 sigmoid，σ′(z) ≤ 0.25。
十层串联、链式法则一路乘下来，第一层还能收到多少梯度？先猜个数量级。

👊 **打脸**：0.25^9 ≈ 4 × 10⁻⁶，**第一层几乎收不到梯度**。
这就是 vanishing gradient 的算术版本[^L05-10]。

![梯度消失链：每回传一层乘 0.25，九层之后细成一条线](./images/L05v2_s3_backprop_chain_zh.png)

> 图注：链上数字是按 0.25^9 手算的**示意链**，
> 真实网络的每层因子各不相同；结论不变——**连乘会指数衰减**。

ReLU 的导数在 z > 0 处为 1，所以能训深；
代价是 z < 0 时导数为 0（"死 ReLU"），于是有了 Leaky ReLU（式 63）。

**（d）AE / VAE / GAN 的目标函数（三行版，务必背）**

- AE：min ‖D(E(x)) − x‖² —— 重构误差；瓶颈层强制压缩[^L05-11]；
- VAE：min ‖x̂ − x‖² + β · KL(q(z|x) ‖ p(z)) —— 多了一项"把潜分布拉成标准正态"，
  于是**潜空间可以采样生成**；论文明确说 VAE 的编码器输出的是 μ 与 σ[^L05-12]；
- GAN：min_G max_D E[log D(x)] + E[log(1 − D(G(z)))] —— 对抗，
  判别器让"假"的概率趋 0、"真"趋 1。

瓶颈就是那个强制压缩的窄口，少它网络会学出恒等映射：

![沙漏形结构：编码压到瓶颈层，解码再还原，输入输出要尽量一样](./images/L05v2_s3_ae_bottleneck_zh.png)

VAE 把瓶颈里的"一个点"换成"一坨概率"，
这就是它能生成、能插值、能当设计空间的根因[^L05-13]：

![自编码瓶颈是一个点，变分自编码的瓶颈是均值与标准差](./images/L05v2_s3_vae_mu_sigma_zh.png)

**（e）PINN 的损失函数（这是全书的题眼之一）。** 论文式 (79)：

  min_θ  Σ_{i=1}^{N_u} (ŷ_{u,i}(θ) − y_{u,i})² + Σ_{i=1}^{N_f} (r̂_{f,i}(θ))²[^L05-14]

第一项是**数据项**（在有数据的点上要对得上），
第二项是**物理残差项**（在配点上，偏微分方程残差要小）[^L05-15]。
配点就是"没有标签、只要求满足方程"的内部点。

**为什么这样能少要数据**：数据项只约束 N_u 个点，
而物理项把**整条方程**当"无限多条软约束"，
把解空间从"任意光滑函数"缩到"近似满足守恒律的函数族"。

论文对 PINN 的原始定义就是：
既完成监督学习任务、又尊重物理规律的神经网络[^L05-16]。

**手算例（把抽象砸实）**：设一维定常问题 r̂ = dp̂/dx + 0.5，
在 3 个配点上估出残差 r = (0.41, 0.52, 0.49)，则物理损失
= 0.41² + 0.52² + 0.49² = 0.168 + 0.270 + 0.240 = **0.678**。

![损失的两项：有答案的数据项，加没有答案的配点残差项](./images/L05v2_s3_pinn_two_terms_zh.png)

若网络把三处残差都改到 0.05，损失 = 3 × 0.0025 = **0.0075**，降 **91 倍**。
**这就是"把物理写进损失函数"的全部含义：不新增数据，只新增一项可以求导的惩罚。**

> 🧭 **呼吸点**：§5 的账——五个式子其实是一句话：
> **把"我不知道怎么写的规则"翻译成"我能求导的惩罚项"**。

#### 6. 操作流：八个架构在 ASO 流水线里各替代哪一格

| 架构 | 输入 | 输出 | 在 ASO 里替代 | 主要风险 |
| :--- | :--- | :--- | :--- | :--- |
| MLP-ANN | (n, d) 设计变量 | (n, m) 系数（C_L/C_D/C_M） | **替代 CFD 的"评估"格** | 外推不可信（讲 07） |
| CNN | 网格/图像场 | 系数或场 | 免参数化直接读形状；也可做几何合法性判别（讲 06） | 分辨率/网格绑定，换网格就失配 |
| RNN/LSTM | 沿展向/时间的序列 | 序列（沿程载荷、C_p 分布） | 三维叶片/非定常问题 | 训练慢；长序列梯度问题 |
| AE | 高维形状/场 | 潜向量 + 重构 | **替代"人工挑参数"**（模态参数化，讲 06） | 重构看着好、物理不合理 |
| VAE | 形状 | (μ, σ) + 生成 | 设计空间探索、样本生成 | 模糊（均方损失天生糊） |
| GAN/InfoGAN | 潜变量 z | 逼真空形 | 造数据 + 潜变量当设计变量（论文：贝塞尔/B 样条 + GAN 生成光滑真实翼型[^L05-17]） | **模态崩塌**[^L05-5] |
| SOM | 高维设计变量 | 2 维拓扑地图 | 看"设计变量在权衡图上的位置"（Obayashi & Sasaki 用它做设计变量聚类[^L05-18]） | 拓扑与尺度敏感 |
| PINN | 坐标（x, y） | 场变量 | 替代求解器本身（最激进） | 边界条件一变就要重训，工程不友好〔原文 P41 关于固定初边值条件的说法，见 §6〕 |

**三句论文自己的话要记住**。CNN 省参数靠的是滤波器与池化[^L05-19][^L05-20]，
代价是要吃大量数据[^L05-21]。

RNN 的名字来自那个指向自己的反馈环[^L05-22]。

WGAN 那句"权重裁剪是糟糕办法"的坦率评论也别忘了[^L05-25]：
换损失不等于免调参。

> 🧭 **呼吸点**：§6 的账——选架构只问一句：
> **你要替掉的是评估、参数化、还是求解器本身**。

#### 8. 审稿人批判（本讲可攻击的点，含对论文本身的）

1. **§3.5 是"教科书体"，与 §4 应用体写法不统一**：读者读完仍不知道"我该选哪个"；缺一张决策表（我们上面那张就是替他补的）；
2. **没有训练细节**：优化器、学习率、BN、Dropout、早停——一句都没写。这在 2022 年已经不算"可省略"，
   因为气动圈复现失败八成栽在这里；
3. **PINN 的工程障碍只点到为止**：原文明说最初设定在一组固定的初边值条件下，
   对"每轮迭代边界都变的优化"是硬伤〔原文 P41 "the original PINN was set up under a fixed set of initial and boundary conditions"〕，
   但没有量化"重训一次要多久 vs 一次 CFD 要多久"；
4. **GAN 一节把 mode collapse 与 WGAN 的权衡写在一起**却未说明 WGAN 也带来新的调参负担
   （原文 P40 提到 arjovsky 等人批评权重裁剪是"terrible way to enforce a lipschitz constraint"，
   这句是全文少见的坦率，值得表扬但没跟进"所以 ASO 里到底怎么配"）。
5. **顺带批本白皮书自己**：本讲把"参数量对得上"当成"结构合理"的证据，
   这是**量级论证，不是证明**。
   真要证明，得做消融实验（去掉残差块、换宽度各跑一遍）。

**答案要点**（一题一行，先做再看）：

1. B——没有非线性，多层矩阵连乘仍是线性变换。
2. B——瓶颈换成 (μ, σ) 并加 KL 正则，于是能采样生成。
3. 平方误差和（MLE）；数据项（预测误差）+ 物理残差项（配点）。
4. r(z) = max(0, z)。
5. 每层乘 ≤0.25 的因子连乘 → 梯度指数衰减；恒等支路让梯度有一条"不乘权重"的直通路径。
6. 数据项只给 N_u 条约束，物理项在 N_f 个配点上各给一条，等于免费的额外标注，把假设空间缩小。
7. 边界条件每次迭代都变 ⇒ 每次都要重训；缓解：把边界量当**网络输入**（一次训练覆盖一批工况），代价是样本 × 工况数。
8. 表现为生成的叶型集中在少数几种厚度/弯度组合；监测：潜空间采样 1000 次，统计落在训练集凸包内的比例与前 k 个模态的方差占比。
9. 模型绑死分辨率与网格拓扑：SU2 从 140k 换到 3.55M 网格时，CNN 的像素坐标系变了，预测直接失效。
10. 补三项：优化器与学习率调度、早停/正则的具体配置、数据划分方式（是否按型号/工况分组留出）。
