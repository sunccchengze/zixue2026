## 〇、先认词（A3：不许在未定义的词上开讲或出题）

| 中文 | 英文 | 一句操作定义 |
|---|---|---|
| 气动外形优化 | Aerodynamic Shape Optimization, ASO | 给定目标（如阻力系数 C_D 最小）、约束（如升力系数 C_L 固定）、一组能改形状的参数，用算法找出使目标最好的那组参数值 |
| 设计变量 | design variable | 上面那组"能改形状的参数"里的一个。全部设计变量拼成一个向量 x，它的长度就是**设计空间的维数** |
| 设计空间 | design space | 所有 x 取值构成的集合。维数 = 设计变量个数 |
| 计算流体力学 | Computational Fluid Dynamics, CFD | 把流体控制方程离散到网格上用计算机数值求解，得到流场与气动力 |
| 目标函数 | objective function | 要最小化或最大化的那个量，例如 C_D，或升阻比 C_L/C_D |
| 约束 | constraint | 必须满足的条件。分**几何约束**（厚度、面积、体积）与**气动约束**（C_L、力矩系数 C_M） |
| 工况 | flight condition | 一组飞行状态，通常由马赫数 M 与雷诺数 Re 定义 |
| 梯度 | gradient | 目标函数对每个设计变量的偏导数组成的向量，∂f/∂x_1 … ∂f/∂x_n，指向函数上升最快的方向 |
| 伴随方法 | adjoint method | 一种算上面那组偏导数的方法。**关键性质：算全部 n 个偏导数的成本，与 n 的大小无关** |
| 代理模型 | surrogate model / metamodel | 用一个训练好的近似函数 ŷ = g(x) 顶替昂贵的 CFD，输入设计变量、输出气动量，毫秒级出结果 |

> 本轮**不给定义**、后面才讲的词（这里只记名字）：Kriging、GEK（梯度增强 Kriging）、
> Cokriging、PCE（多项式混沌展开）、PINN、XDSM、保真度 fidelity、Pareto 前沿。
> 它们分别在第 03、06、02 会话展开。

## 一、画面（六层阶梯第 1 层，只给画面，不给论文结论）

一个压气机转子叶片要定型，工程上要做的事：

1. 先选一种**参数化方法**，把叶片形状写成一组数字。数字有几个，设计空间就几维。
2. 给一组数字，生成几何 → 生成网格 → 跑一次 CFD → 得到 C_D、C_L、C_M。
   高保真 RANS 一次要几小时到几天。
3. 优化器根据目标与约束，决定下一组数字往哪改。改一步就要重跑第 2 步。
4. 反复几百上千次，直到收敛。

**时间几乎全花在第 2 步。** 这是这一整篇综述存在的物理原因。
