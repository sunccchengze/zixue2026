## 一、总纲（一句话）

**总知识不变，一堵墙拆成台阶 + 扶手 + 镜子；论证尽量搬进图与表。**
只许增加：解释、例子、题目、图、指路。禁止新增事实（新事实 = 0 条预算，S13）。

## 二、密度硬规格（S1–S5，G 项机器核）

| # | 规则 | 阈值 |
| :---: | :--- | :--- |
| S1 | 段落（含引言行） | ≤100 字，目标 50 |
| S2 | 分句（。！？；， 切分，风格核计长：引用标签/脚注链/Markdown 记号不计） | 目标 ≤40，硬上限 80 |
| S3 | 公式块 | 前一句**先说结论**；块内新符号 ≤2 个，超了拆块；块后必有呼吸点 |
| S4 | 图先行 | 论证性公式/结构先放图或表，式内每个项用文字箭头指回图上编号格 |
| S5 | 图/表密度 | 每 400–600 字至少 1 张图或表（G 项按"distinct 图片下限"近似核） |

列表项 ≤140 字；先认词表**单批 ≤5 行**、单格 ≤40 字，超批拆"第二批"。

## 三、装置语法（全书统一标记，G 项点卯）

| 装置 | 标记（原样写） | 用法 | 每讲配额 |
| :--- | :--- | :--- | :---: |
| 呼吸点 | `> 🧭 **呼吸点**：`（blockquote） | 密块之后，1–2 句"刚才发生了什么" | ≥3 |
| 下注 | `🔮 **下注**：`（独立短段） | 先让他写数字/选项，**下一段**再揭底 | ≥1 |
| 打脸 | `👊 **打脸**：`（独立短段） | 预期 vs 实测，数字必须可回溯（原文 or `code/` or 账本） | ≥1 |
| 带走 3 数 | `📌 **带走 3 个数**：`（节标题内） | 一行一个数，每个数带口径 | =1 |
| 上讲的数 | `⏪ **上讲的数**：`（节标题内） | 2 题 + `<details>` 折叠答案 | =1 |
| 修复清单 | `🛠 **修复清单**：`（§平台节内） | 本讲给你的平台加 0–3 项（加 0 项也要明写"本讲不加"） | ≥1 处标记 |

**装置红线**：
- 下注必须**先问后答**（问和答案之间不许插解释）；
- 打脸不许自嗨：实测数字挂〔原文 P##〕或 `code/` 文件，示意值挂牌"示意"；
- 一个装置一个 Emoji，图注/表格里禁用 Emoji（E 项不变）；
- 装置只许用在标记行，正文其他地方不撒 Emoji。

## 四、每讲十三节模板（G/D 项共同依据）

```
#### 0. 本讲元数据          ← 3 行卡片（范围/前置/读完能做什么）+ <details> 审查层（原 7 行表全保留）
#### 1. 你在这里            ← 一行方位（12 讲中的第 N 站：地基/工具箱/战场/收口）+ 你的平台·第 N 站
#### 2. 上讲的数            ← ⏪ 2 题 + 折叠答案
#### 3. 场景引子            ← ≤8 行小故事（列表改场景；原信息一条不删）
#### 4. 工程死穴 + 先认词    ← 认词表 ≤5 行/批；死穴拆块
#### 5. 数学从 0 到 1        ← 图先行 + 先说结论 + 呼吸点（S3/S4）
#### 6. 操作流（含 🔮 👊）   ← 下注与打脸落在此节或 §5 之后
#### 7. 数据与图表          ← 读图三步保留（先看什么/好在哪/可挑剔）
#### 8. 审稿人批判          ← 逐条保留原样（H 项 critique 原子）
#### 9. 承前启后            ← 保留原样
#### 10. 你的平台接哪一步    ← 🛠 修复清单累加
#### 11. 自测 10 题          ← 2+2+6 题干逐字保留（H 项 quiz 原子）；答案一题一行 + 一行推理链
#### 12. 带走 3 个数         ← 📌 一行一个
#### 13. 一句收口           ← ≤2 行
```

文件头第一行写 `<!-- v2 -->`（G 项凭此识别 v2 文件；未重写讲次不写，G 项公开挂牌「待 v2」）。
讲 12 允许少"上讲的数"以外的节（D 项例外规则不变）；第零章无 §2/§10 装置（用"章末下注 + 带走 3 数"）。

## 五、审查层与脚注（S10）

1. **引用降脚注**：正文 `〔原文 P## "串"〕` 一律写成 `[^L01-3]` 形式的脚注链，
   脚注定义行写全标签：`[^L01-3]: 〔原文 P5 "two compounding challenges in ASO"〕`。
   脚注 id 规则：`L01`–`L12` / `CH0` / `P6` / `FM` + 连号；**定义行必须含完整标签**（A/H 项核它）。
2. **元数据折叠**：讲首 7 行元数据表全保留，移入 `<details><summary>审查层（导师验收用）</summary>…</details>`；
   卡片 3 行留在正文（G 项不核 details 内文字长度，但 H 项原子仍须在文件内）。
3. **E0–E4**：首次出现（讲 01）指向第零章 0.5；此后只许"口径 E2（第零章 0.5）"式短引用。

## 六、公式排版（S10/方法论 §9.8 双轨，G 项不核、人工核）

- 行内公式：Unicode 平文本主轨（`R(x, x′) = exp(−Σ((xᵢ−x′ᵢ)/θᵢ)²)`）；
- 独立公式块：Unicode 平文本 + 同块 `<details>` 内给 LaTeX 渲染版（`$$…$$`，禁裸 `$$` 入正文流）；
- 讲 08 是双轨格式范本，其余讲照抄。

## 七、图像规范（S11，沿用配图规矩 + 3 条新增）

1. 一图一义；图内中文标签 ≤12 字；图注 ≤25 字；零 Emoji；示意数字必须图注下挂牌"示意值，勿当论文数据引用"；
2. **新图文件名**：`Lxx_v2_sN_语义_zh.png`（v2 轮新图一律带 `_v2_`，与旧 24 张区分）；
3. **打脸图**必须含"预期 / 实测"两个显式标签（文字，不是 Emoji）；
4. 生成后拼对照表人工质检（AI 画中文会糊：糊了就重画或降图内文字密度）；
5. 每轮生成 ≤10 张（配额）；先写文字占位再填图，图注位置在文字旁边。

## 八、守恒协议（S13，H 项机器核）

- v1 基线冻结在 `docs/archive/v1/`；账本 `docs/knowledge_atoms_v1.{json,md}`（1913 条）；
