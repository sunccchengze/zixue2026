#### 1. 生活与物理直觉引子：地图与国境线

一张好地图的价值在于它**画了什么**；一张综述的价值在于它**引用了什么**；
而一篇综述真正的边界，藏在它**没引用什么**里。
2022 年初截稿的地图，画不出 2023 年之后的城——这不是作者的错，但你必须知道这条国境线在哪，
否则你会以为世界上没有那些城。

#### 2. 工程死穴：三个"看起来不像问题"的问题

**先认词**

| 中文 | 英文 | 一句操作定义 |
| :--- | :--- | :--- |
| 覆盖盲区 | coverage gap | 某技术在领域内已成主流，但综述参考文献里检索不到 |
| 口径 | metric definition | 同一个"精度"可以是 R²、平均相对误差、counts、MAE——四者不可互换 |
| 可复现性 | reproducibility | 别人用你的数据与配方能否复现同一数字（本讲用它来评综述，也用它来防自己） |
| 被引次数 | citation count（本仓特指：在本综述正文 p3–68 内 `[N]` 标记出现次数） | 衡量一篇文献在**这篇综述里**的承重力，不是学术影响力 |

#### 3. 从 0 到 1：四项体检指标与推导

**（a）承重结构：谁在托着这篇综述**
统计方法（可复现）：对正文 p3–68 逐页扫描 `[N]` / `[N, M]` / `[N–M]` 标记，按编号聚合计数。
`tools/scan_corpus.py` 现场跑出的结果摘要见 §5。
**判据**：若某文献被引 ≥ 8 次，说明它承担了**方法主干**（不是"相关举例"）——这类文献必须读原文，不能只读综述。
（这就是本仓 `../章程与地图/12篇论文总规划.md` 按被引次数挑 P02–P12 的全部理由。）

**（b）盲区：用 0 命中证明"不是我不认识，是它没被写"**
在参考文献区（p69–103）对关键词做不区分大小写检索：**命中 0 次**的条目就是盲区。
本白皮书不"引用"这个结论，而是**每次装配前重跑 `tools/scan_corpus.py`** 并把结果写进
`corpus/facts/scan-results.md`，讲稿引用该文件 → 数字随语料变化自动更新（这是把"宣称"绑到"可复现"上的唯一诚实办法）。

**（c）口径混杂度：一篇综述能被"换算"多少**
本白皮书把全文出现过的性能口径归成四类：**R² / 平均相对误差 / counts / MAE**。
一条判断：**只要表格里的误差列没有写口径与分母，那张表就不能用来比较工作好坏**（讲 07 §6 已用过这条）。

**（d）自陈限度：作者自己承认的三件事（这最值钱，务必背）**

1. **大规模实用优化仍没解决**：因为 ML 训练成本高
   〔原文 P1 "practical large-scale design optimizations remain"〕；
2. **建议的方向是把 ML 建模与先验经验/知识耦合**（物理信息 ML）
   〔原文 P1 "such as physics-informed ml, is recommended"〕；
3. **很多 ML 模型只被用在较不难的 ASO 问题上，且没有与传统 ASO 做对比**
   ——这是全篇最锋利的一句自我批评，出现在结论：〔原文 P68 "without comparing to conventional ASO"〕。
   **含义**：领域里存在"和基线比"的缺失，这条你可以直接写成自己论文的 §1 动机。

#### 4. 操作流：如何把"批判"落成产物（三步）

1. **列边界表**：三列——技术 / 在本综述的覆盖情况（命中数）/ 我们领域里是否真的需要；
2. **挑一条做小实验**：选"综述没覆盖、但你能三天做完"的那条（对你的 Rotor 37 数据集而言，
   最优候选是"神经算子做流场预测"或"多保真 Co-Kriging 基线"，因为你的数据形状已经就位）；
3. **写成可复现的对比**：固定留出协议（按工况分组）、双口径报误差（相对 + 绝对）、披露训练成本 ——
   这三条正是本讲对综述的批评，也是你自己的护城河。

#### 9. 自测 10 题（2 选 + 2 填 + 6 答）

1. （选）判断一篇文献是否"必读原文"，最客观的本地判据是：A 期刊影响因子 B 它在本综述正文中被引次数 C 发表年份 D 作者名气
2. （选）综述结论中作者自陈的最大未解问题是：A 精度不够 B ML 训练成本高导致大规模实用优化仍未解决 C 网格太粗 D 缺少实验
3. （填）本白皮书用「______ 命中 0 次」来证明盲区，而不是用「我觉得不重要」。
4. （填）作者指出很多 ML 模型被用于较不难的问题，且**没有与 ______ 做对比**〔原文 P68 "without comparing to conventional ASO"〕。
5. （答）写出"被引次数排序"的算法（三步 + 一句为什么不能用全文 103 页做分母）。
6. （答）Table 2/Table 4 各缺哪一列？如果给你重写，你加什么列？
7. （答）为什么"外推风险"必须用"最近邻距离"而不是 R² 来监控？给出你的阈值设定流程。
8. （答）把本讲六条批评压缩成组会可讲的三条，各配一句"我打算怎么补"。
9. （答）如果扫描脚本因连字/断行漏检了某关键词，会产生什么后果？如何用两条命令自查？
10. （答）批判的批判：为什么"按被引次数选 12 篇"本身也有偏差？说出两种偏差并给出补救读法。

**答案要点**：1-B；2-B；3-关键词（在参考文献区 p69–103 的）；4-传统 ASO；
5-①取正文 p3–68；②正则抓 `[N…]` 展开区间/逗号；③按编号计数并降序 ——
不能用全 103 页做分母是因为**参考文献区自身含大量方括号编号**，会把书目当成"被引"；
6-都缺"样本量/CFD 次数/误差与口径"列；重写就加：N_train、N_eval、误差(mean ± max) + 口径、加速比、是否含外推；
7-R² 只测同分布，测不出"离训练流形多远"；流程：算 d(x) 分布 → 取训练集内部 d 的 95 分位为 d_max → 超过则前端标"外推"；
8-示例：①只和 ML 基线比 → 我补 SLSQP+SU2；②口径混杂 → 我四件套报数；③旗舰图无可读轴 → 我的图先写 caption 再画图；
9-误判"0 命中=没有"→ 结论夸大；自查：`grep -o` 直接扫原文 PDF 提取文本 + `tools/scan_corpus.py --dump <关键词>` 打印命中页；
10-偏差①：本综述的知识结构决定"承重"，会继承它的盲区；偏差②：老文献天然高引（时间累积），新方法吃亏。
   补救：对被引最多的 3 篇读原文，同时**额外**读 2 篇"综述里 0–1 命中但被其他来源强推"的论文（本规划 §二的两篇补编即为此设）。
