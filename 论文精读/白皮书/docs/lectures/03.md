#### 3. 场景引子：一堆叶型，其实只沿几条"脾气"在变

把 1000 个叶型叠在一起看，你会发现它们并不是乱变的：
有的整片变厚、有的中线鼓起来、有的后缘翘一下。
这些"整片的共同变化模式"就是**模态（mode）**。

与其记"180 个坐标点"，不如记"第 1 条脾气 ×0.7、第 2 条脾气 ×0.3、第 3 条脾气 ×0.1"。
**维数从 180 掉到 3，代价是丢掉那些"不常发生的细节"**。

![一千个叶型只沿三条脾气在变：180 个坐标换成 3 个数](./images/L03v2_s1_blade_modes_zh.png)

论文给 PCA 的定位就是这件事：把高维数据变换到低维，
同时**保留数据里最大的变化量**[^L03-1]。

把这句话倒过来读，就是降维的定义：
把高维数据变成低维表示，同时留住原来那份关键信息[^L03-2]。

> 🧭 **呼吸点**：引子的账——叶型不是乱变，是沿几条"脾气"变；
> 降维就是"拿这几条脾气当新坐标轴"。

#### 4. 工程死穴 + 先认词：一次解决三件事

**先认词 · 第一批**（本讲新词都在这里定义，后面不再解释）

| 中文 | 英文 | 一句操作定义 |
| :--- | :--- | :--- |
| 聚类 | clustering | 按"像不像"把样本分堆，**不需要标签**，所以归在无监督学习 |
| k-means | k 均值：k 是堆数、means 是各堆的中心 | 两步循环——把点分给最近的中心（E 步）、中心移到堆内平均（M 步） |
| 高斯混合模型 | GMM = Gaussian Mixture Model | 每堆是一个高斯（有均值、有协方差），每个点以概率属于各堆 |
| 主成分分析 | PCA = Principal Component Analysis | 找一组正交方向使投影方差最大；方向是协方差矩阵的特征向量 |
| 快照 | snapshot | 一次仿真或某个时刻的整个场；一张压力云图拉平就是一个向量 |

**先认词 · 第二批**

| 中文 | 英文 | 一句操作定义 |
| :--- | :--- | :--- |
| DMD | Dynamic Mode Decomposition，动态模态分解：Dynamic 动态、Mode 模态、Decomposition 分解 | 对时间序列快照做一阶算子的低秩近似，得到带增长/振荡率的相干结构 |
| 流形学习 | manifold learning（Isomap / LLE 等） | 假设数据躺在一张弯的低维曲面上；建近邻图后沿图走**测地距离**再降维 |
| 降维/参数化 | dimensionality reduction | 把 d 维压到 k 维（k ≪ d）；在 ASO 里就是"用 k 个数说清形状" |
| 核 PCA | kernel PCA | 先用核函数算样本间相似度再降维，是线性 PCA 的非线性版本 |
| 低秩 | low-rank | 矩阵里真正起作用的独立方向很少，其余方向近似为零 |

**死穴回顾**：讲 01 挑战①——设计变量一多，空间里满是畸形外形，
CFD 不收敛、优化低效。降维一次性解决三件事。

![降维一次解决三件事：维度变小、畸形挡在外面、搜索变便宜](./images/L03v2_s2_three_fixes_zh.png)

1. 维度从几百降到几维，代理模型精度回来（讲 02 §5 第三步那堵 R → I 的墙被推倒）；
2. 畸形形状落在流形之外，天然不会被采到；
3. 优化变量少了，无梯度法的评估次数从 c^74 掉到 c^8。

论文也把话说白了：对"输入高度相关"的回归问题，
降维能靠降低输入维数来缓解维度灾难[^L03-3]。

> 🧭 **呼吸点**：§4 的账——降维不只是省算力，
> 它顺手把**畸形外形**挡在采样范围之外。

#### 5. 数学从 0 到 1：三步 PCA，手推一遍

**先说结论**：PCA 只有**三步**——**中心化**、算**协方差矩阵**、做**特征分解**；
做完得到一组正交方向，外加每个方向上的**方差**。

设样本矩阵 X ∈ ℝ^{n×d}（n 个样本、每行一个 d 维形状）。

**第一步 · 中心化**：每列减自己的均值 → X̃ = X − μ̄。
不做这步，协方差会把"整体位置"当成最大的变化方向。

**第二步 · 协方差矩阵**：Σ = (1/(n−1)) X̃ᵀ X̃ ∈ ℝ^{d×d}。
它**对称半正定**，所以特征值全部 ≥ 0。
方差不能为负，这不是巧合，是半正定的定义。

**第三步 · 特征分解**：Σ = V Λ Vᵀ，Λ = diag(λ₁ ≥ λ₂ ≥ … ≥ λ_d)，
V 的列就是主成分方向；第 j 个主成分得分 = X̃ v_j。

论文对这一步的说法是"沿数据变化最大的方向去认主成分"[^L03-4]；
工程上更常用 SVD 来求，它把方阵的特征分解推广到了任意矩阵[^L03-5]。

**前 k 个保留的方差比例 = (λ₁+…+λ_k)/(λ₁+…+λ_d)**。
这一行就是选 k 的唯一判据，比"别人论文里用了 8 个"可靠得多。

<details>
<summary>LaTeX 渲染版</summary>

$$
\tilde{X} = X - \bar{\mu},\qquad
\Sigma = \frac{1}{n-1}\tilde{X}^{\top}\tilde{X},\qquad
\Sigma = V\Lambda V^{\top}
$$

$$
\text{保留比例}(k) = \frac{\lambda_1+\cdots+\lambda_k}{\lambda_1+\cdots+\lambda_d} \ge 99\%
$$

</details>

🔮 **下注**：三个二维样本 (1,1)、(2,2)、(3,3)。
只留 1 个主成分，方差能保留多少？先写一个百分数，再看下一行。

👊 **打脸**：答案是 **100%**——**一个数就装下了这三个点**。
第二个特征值等于 0，说明"垂直于这条直线的方向"上根本没有变化。

手算过程如下（`code/pca.py` 逐行复算）：

- 中心化后得 (−1,−1)、(0,0)、(1,1)；
- Σ = (1/2)·[[2,2],[2,2]] = [[1,1],[1,1]]；
- λ₁ = 2，方向 (1/√2)(1,1)ᵀ；λ₂ = 0，方向 (1/√2)(1,−1)ᵀ。

![三点 PCA 手算：预期留两个数，实测一个数就够](./images/L03v2_s3_pca_handcalc_zh.png)

把三点换成"三个叶型 × 180 个坐标"，结论不变：
λ₁ 就是最主要的整片变化（例如整体厚度），
而"累计方差 ≥ 99% 所需的最小 k"就是你该用的模态个数。

![特征值递减柱与累计方差曲线：99% 那条线指着的横轴点就是 k](./images/L03v2_s3_var_stack_zh.png)

> 图注下的口径：柱高与累计曲线是**示意值**（形状取自 `code/pca.py` 的自检场景），
> 判据本身是真的：**累计方差 ≥ 99%**，常用档还有 90%、95%。

**连你学过的两门课**：
① 概率论课题 07——λ_j 就是主成分得分的**方差**，V 的各列彼此**不相关**；
② 数理方程——"找一组正交方向使方差最大"与"找本征模态"是同一类瑞利商极值问题，
所以"模态"这个词在这里不是比喻。

论文还补了一句工程上的收益：PCA 能认出相关的变量，
把噪声和冗余信息一并拿掉[^L03-6]。

> 🧭 **呼吸点**：§5 的账——三步（中心化 → 协方差 → 特征分解），
> 产物是"方向 + 每个方向的方差"，而**方差**就是那把选 k 的尺子。

> 但它指出的失效模式是真的：**两块区域的交界处，两个专家都说了不算**。

![五张工具卡：输入形状、输出形状、什么时候用](./images/L03v2_s4_tool_cards_zh.png)

| 工具 | 输入形状 | 输出形状 | 中间几步 | 什么时候用 | 丢什么 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| k-means | (n, d) | k 个中心 + 每个点的堆号 | 初始化中心 → E/M 迭代 | 想把设计空间**分块**（混合专家 ME 的第一步，讲 02/07） | 形状假设硬（各堆同尺寸球形），边界硬切 |
| GMM | (n, d) | k 组 (π_c, μ_c, σ_c) + 后验概率 | E 步算归属概率（式 35）、M 步更新（式 36–38） | 要**软**归属、要椭圆形状时 | 仍受"由 k 个高斯拼"限制 |
| PCA | (n, d) 或 (d, n_s) 场 | 载荷 (d, k)、得分 (n, k) | 中心化 → 协方差 → 特征分解 | 线性关系够用、要**可解释**、要能反算回形状 | 只抓线性结构；弯曲流形上会被"平均"糊掉 |
| Isomap / LLE | (n, d) | 低维坐标 (n, k) | 建近邻图 → 最短路算测地距离 → 降维；Isomap 明确要"直接从训练数据构造核矩阵"[^L03-8] | 形状空间明显弯曲（例如"薄 → 厚"要绕着走） | 近邻图断裂就整体崩；样本少时更脆 |
| DMD | 快照序列 (d, n_t) | 模态 + 增长率/频率 | 把序列切成两半 → 对前一做 SVD → 求投影算子的特征对 | 时间相关/非定常流动（失速先兆、抖振） | 需要等间隔时间序列；非线性强时失真 |

**k-means 的三条实情**（都能回溯）：

- 样本分得开时它又快又稳[^L03-9]；
- 但 k 要你**事先指定**，这是个难题[^L03-10]；
- 它只会画直线边界[^L03-11]，所以气动里几乎不单用[^L03-12]。

**GMM 比 k-means 多的那一件事**：它不只看均值，还看协方差结构[^L03-13]。

它的假设是"所有点由若干个高斯混着生成"[^L03-14]。
EM 两步照旧[^L03-15]，起点仍是"先定 k 个中心"[^L03-16]。

**线性 vs 非线性模态，在叶型上的差别长这样**。
论文 Fig. 42（p44）画了 PCA / ASM / InfoGAN 三种模态。

线性的 PCA 与 ASM 模态在系数加倍时呈**线性叠加**效果。
InfoGAN 模态不同，网络里有非线性激活，
改一个潜变量会带来**全局性**的厚度与弯度变化[^L03-17]。

**记住这条区别，讲 06 会用到。**

![线性模态按系数等比叠加，非线性模态一改就全局联动（对照 Fig.42）](./images/L03v2_s5_linear_vs_nonlinear_zh.png)

> 🧭 **呼吸点**：§6 的账——聚类是"分块"，PCA 是"换坐标轴"，
> 流形学习是"允许坐标轴是弯的"，DMD 是"多拎出一个时间轴"。

#### 7. 数据与图表：怎么读 Fig. 21/22（PCA）与 Fig. 24（DMD）

- **Fig. 21（p22）**：归一化 → 协方差矩阵 → 奇异值分解 → 降维。
  **第一格"归一化"是命门**：叶型坐标（米级）和来流马赫数（O(0.5)）混在一起不归一化，
  PCA 会只看见量纲大的那一个。
- **Fig. 22（p23）**：黑箭头是主轴，箭头长度就是投影到该轴的方差[^L03-18]；
  图 (b) 把红点投到最长的那根轴上，短轴被丢掉。
  读图只问一句：**去掉第二维，点序会变吗？**（不会——这就是 100% 方差保留的画面）
- **Fig. 24（p25）**：DMD 把快照序列切两半、对前一半做 SVD。
  看着像障眼法，其实是在逼你回答"用什么算子描述演化"——**一阶线性近似**。

**你的审美挑剔用在这里**：这三张流程图是"编号 + 箭头"的统一模板，好读；
但 PCA 那张把"方差最大"这个**目标函数**藏起来了，只画了步骤——
一张只讲"怎么做"、不讲"为什么这么做"的图，教不出会挑 k 的人。

![Fig.21/22 读法：归一化是命门，去掉短轴后点序不变（对照原图）](./images/L03v2_s7_fig21_reading_zh.png)

**为什么还得有非线性那一家**。PCA 是线性方法，
只在"线性可分"的数据上好用[^L03-19]。

核 PCA 用核函数把它推广到非线性[^L03-20]。
Isomap 则先建近邻图、再拿图上的最短路当距离[^L03-21]，
等于用**最短路/测地距离**替换了直线距离[^L03-22]。

![直线捷径会穿过没有数据的空白区，沿面绕行才落在流形上](./images/L03v2_s7_manifold_geodesic_zh.png)

收益是真的：Isomap 在激波附近精度更高[^L03-23]，
Ripepi 等人用它预测表面压力分布，省下评估时间与存储[^L03-24]。

代价也是真的：Decker 等人的对比里，
**定常**预测反而是线性方法赢[^L03-25]。

LLE 走同一套流程，
只是把核矩阵换成了"用邻居重建自己的权重"[^L03-26]。

![DMD：快照序列切两半，SVD 之后得到模态与增长率（对照 Fig.24）](./images/L03v2_s7_dmd_two_halves_zh.png)

**把降维接回讲 02 的痛点**。样本数不变，把 d 从 74 打到 8，
每维实际摊到的点数 = 1000^(1/8) = **2.37**。

74 维时是 1000^(1/74) = 1.10，**提升约 2.2 倍**。

再看"每维 10 点"这件事：8 维要 10^8 个样本，74 维要 10^74 个。
**这就是为什么必须先把 d 压小，再谈代理模型精度。**

#### 8. 审稿人批判（本讲可攻击的点，含对论文本身的）

1. **§3.2 讲降维却不给"保留几个主成分"的行业惯例**：全文没写"方差保留 90%/95%/99% 哪个常用"，导致读者照抄别人论文里的 k；

5. **顺带批本白皮书自己**：本讲把"线性 vs 非线性"画成了对照图，
   但我们并没有在你的 74 维数据上真跑过 Isomap。
   上面的优劣全部来自论文引文，**不是实测**。

#### 11. 自测 10 题（2 选择 + 2 填空 + 6 问答；合上论文作答）

1. （选）PCA 第一步做中心化的目的是：A 让数据更好看 B 否则协方差会把"整体均值方向"当成最大变化 C 让特征值变负 D 为了去掉噪声
2. （选）DMD 处理的对象是：A 静态形状矩阵 B 时间序列快照 C 标签数据 D 概率分布
3. （填）PCA 的主成分方向是协方差矩阵的 __________，对应的 __________ 表示该方向上的方差大小。
4. （填）选 k（保留几个模态）的常用判据是 __________ ≥ 95%。
5. （答）用三句话说清 k-means 与 GMM 的差别（从"归属是硬是软"、"簇形状"、"迭代内容"三方面）。
6. （答）为什么线性 PCA 在一圈"弯曲"的叶型分布上会失效？画一张 5 秒能看懂的草图并解释。
7. （答）Isomap 为什么比 PCA 更能对付弯曲流形？它的失败模式是什么？
8. （答）把 1000×74 压到 8 维，"每维实际点数"从 1.10 变成多少？写出算式。
9. （答）如果老板要求"降维后必须能反算回原始几何用于出图"，你会拒绝哪一种降维方法？为什么？
10. （答）批判：为什么说"只讲步骤、不讲目标函数"的流程图会教出不会选 k 的人？

**答案要点**（一题一行，先做再看）：

1. B——不做中心化，协方差会把"整体均值方向"当成最大变化。
2. B——DMD 吃的是时间序列快照。
3. 特征向量、特征值。
4. 累计方差保留比例。
5. 硬 vs 软（后验概率式 35）、球形 vs 椭圆（各带协方差 σ_c）、更新中心 vs 更新 (π, μ, σ)。
6. 弯曲分布的"弦方向"落在流形外（中间是空的），投影会得到不存在的形状。
7. 用近邻图上的**最短路/测地距离**替代欧氏距离再降维；图不连通或采样稀疏处即崩。
8. 每维点数 = N^(1/k) = 1000^(1/8) = **2.37**，对比 74 维的 1000^(1/74) = **1.10** ⇒ 约 **2.2 倍**；若想"每维 10 点"，8 维需 10^8、74 维需 10^74 ⇒ 说明 8 维已经可以谈采样，74 维永远不能。
9. AE/VAE 的解码器能反算，但要**训练完冻结**；真正会拒绝的是"只给得分不给载荷"的黑箱降维（无逆映射）。
10. 因为没有目标函数，就没有"再降一维损失多少"的量化依据，k 只能靠抄。
