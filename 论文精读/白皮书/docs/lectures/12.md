#### 1. 生活与物理直觉引子：为什么"读完"是一种错觉

读完 103 页综述的人大多处于三种状态之一：
**记得图**（能想起 Kriging 那条置信带）、**记得话**（能背"维度灾难"）、**记得账**（知道每个方法省下什么、花掉什么）。
只有第三种能过组会这一关。本讲就是把你从第二种拽到第三种的那一下。

**先认词**：本讲不引入任何新词；若你在这里遇到没定义过的词，说明前面某一讲违规了（红线 A3），请当场记进 `../memory/ERRORS.md`。

#### 3. 从 0 到 1：Cold-Call 随机抽问的评分函数

验收标准不是"我觉得我懂"，而是**可打分的**。协议（照 `../章程与地图/12篇论文总规划.md` §三）：

1. 从 12 讲里随机抽 **5 个点**（一个公式 / 一张图 / 一个数字 / 一个失效条件 / 一个跨讲关系）；
2. 闭卷，每个点走**六层阶梯**（画面 → 拆词 → 操作 → 公式 → 数据 → 边界与回收）；
3. 打分：每层 1 分，**≥3 层算过**；5 点里 ≥4 点过 → 本讲次 ✅；
4. 未过的点写进 `../memory/drill-ledger/index.md`，标 `cw`（自信却错）或 `gap`（空白）。

**一张可自查的评分样例（以"Kriging 的 θ"为例）**

| 层 | 通过线 | 我的自问 |
| :--- | :--- | :--- |
| 画面 | 能用一句话说"θ 在管什么" | 邻居半径旋钮 ✔/✘ |
| 拆词 | θ 的下标 i 是什么维度 | 每个设计变量一个 θᵢ ✔/✘ |
| 操作 | 说清"如何估 θ" | 网格/极大似然，式 (18) ✔/✘ |
| 公式 | 写出 R(x,x′) | exp(−Σ((xᵢ−x′ᵢ)/θᵢ)²) ✔/✘ |
| 数据 | 举一个论文里的可比数字 | Kriging 高维退化：≤17 维仍主流（Table 4）✔/✘ |
| 边界与回收 | 说出失效条件 + 接到我的项目 | d 大 ⇒ R→I；我的 74 维需先降维 ✔/✘ |
