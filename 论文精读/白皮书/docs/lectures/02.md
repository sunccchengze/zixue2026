#### 1. 生活与物理直觉引子：三种"猜地形"的方式

你在一片陌生山地测了 20 个点的海拔，现在要你猜任意位置的高度：

- **KNN（k-Nearest Neighbors，k 最近邻：k 是邻居个数、Nearest 最近、Neighbors 邻居）**：
  找离你最近的 k 个测点，取平均。**它不建模，只查表**；测点之间是悬崖它照样给你个平均值。
- **多项式响应面**：拿一个 2 次或 3 次多项式去拟合全部 20 个点。便宜、光滑、可导，
  但它在没测过的地方**胆大到离谱**（多项式在测点外会飞出去）。
- **Kriging（也叫高斯过程回归）**：拟合一条全局趋势，**再**给每个位置一个"邻居权重表"做局部修正，
  并附送一个标准差 σ —— "这里我拿不准"。

论文对这一族有一个精确定位：代理模型（metamodel）是**一类特殊的监督学习算法**，
用简单代数运算近似仿真输出，在"需要快速反应"时替代昂贵仿真模型
〔原文 P13 "Surrogate models, also known as metamodels, are a special type of supervised ML algorithms"〕。

#### 2. 工程死穴：高维 + 小样本，两头不讨好

**先认词**（本讲首次出现的术语，全部当场拆词）

| 中文 | 英文 | 一句操作定义 |
| :--- | :--- | :--- |
| 基函数 / 趋势函数 | basis / trend function f(x) | 先验的全局形状假设（常数、线性、带交互的二次），是"大方向" |
| 相关函数 | correlation function R(x, x′) | 两个样本"有多像"的打分函数，取值 0–1，距离越远越接近 0 |
| 相关矩阵 | correlation matrix R | N×N 表，R_ij = R(x_i, x_j; θ)，把"谁跟谁像"全记下来 |
| 超参数 | hyperparameters θ | 每个维度一个，控制"相关范围有多大"；由极大似然估计（maximum likelihood estimation）拟合 |
| 置信区间 | predictive confidence interval | 均值 ± 1.96 σ，"模型自己承认不确定的范围" |
| 梯度增强 Kriging | GEK = Gradient-Enhanced Kriging | Enhanced 增强的是"信息量"：把 ∂y/∂x 也当数据喂进模型，**不是**梯度下降 |
| 协同克里金 | Co-Kriging / cokriging | 用便宜的低精度数据搭梯子，再学"高精度 − 低精度"的差 |
| 多项式混沌展开 | PCE = Polynomial Chaos Expansion | 用正交多项式基展开随机输入 → 解析地算出均值与方差（连概率论课题 08 的矩） |
| EGO | Efficient Global Optimization | 用"期望改善 EI"决定下一个点算哪儿，靠的就是上面那条置信区间 |

死穴在于两个数字：论文说传统代理模型**训练慢**、且**精度随维度上升而下降**（维度灾难）。
Bouhlel 等人用偏最小二乘（partial least squares）在若干方向上训练 Kriging 超参数，
在**最高到 100 维**的数值问题上取得显著计算收益，但精度仍随维数下滑
〔原文 P48 "accuracy still decreases with increased dimensionality"〕。
另一头：**样本一多就崩**——传统代理不适合处理大规模训练数据
〔原文 P50 "not suitable for handling a large volume of train-"〕（该页讲混合专家 ME 正是为绕开这一点，
Li 等人用基于 k-means 的 ME 处理了 **100,000 以上**的训练样本〔原文 P50 "more than 100,000 training"〕）。
**另注**：GEK 一节会用到"用 PLS 大幅减少超参数个数"这一手——原文写法是 partial-least squares（带连字符）〔原文 P15 "partial-least squares method"〕。

#### 3. 数学从 0 到 1 推导：把 Kriging 拆到能默写

**第一步：模型怎么写。** 论文式 (11)：把任意有限个响应视为多元正态

  Y^KR(x) = β f(x) + σ² Z

其中 f 是基函数向量、β 是待定系数、σ² 是高斯过程方差、Z 是零均值单位方差的平稳高斯过程
〔原文 P13 "Y KR(x) = βf(x) + σ2Z"〕。

**第二步：预测怎么算。** 由"预测点与训练点联合正态"（式 12）导出均值与方差（式 13–14）：

  μ(x′) = f(x′)ᵀ β + r(x)ᵀ R⁻¹ (y − F β)   —— 全局趋势 + **局部修正**
  σ²(x′) = σ² ( 1 − r(x)ᵀR⁻¹r(x) + u(x)ᵀ (FᵀR⁻¹F)⁻¹ u(x) )   —— 第二项是"这里已有多密"，第三项是"趋势项不确定性"

  其中 β = (FᵀR⁻¹F)⁻¹ FᵀR⁻¹ y，u(x) = FᵀR⁻¹r(x) − f(x)〔原文 P14 "β = (F ⊺R−1F )−1F ⊺R−1y"〕

**读法**：`r(x)ᵀR⁻¹(y − Fβ)` 这一项就是"邻居残差的加权和"。所以 Kriging ≡ **趋势 + 加权邻居修正**。
它跟 KNN 的血缘关系一目了然；区别只在于**权重由相关函数算出来，而且它给方差**。

**第三步：相关函数与 θ。** 高斯型相关函数（式 17）：

  R(x, x′) = exp( −Σᵢ ((xᵢ − x′ᵢ)/θᵢ)² )〔原文 P14 "R(x, x′) = exp"〕

θ 由极大似然解出（式 18）。**θ 的直觉是本讲的考点**：

- θⱼ 变**大** → 距离除以大数 → 指数里变小 → 相关衰减慢 → **相关范围变宽** → 拟合更平滑、更"敢外推"（也更钝）；
- θⱼ 变**小** → 只有极近的邻居算"相关" → 曲线在样本点附近剧烈抖动、样本区间外立刻回归趋势（欠拟合局部细节）。
  维度灾难在公式里的化身：d 大时 Σ 累加很多项 → 任意两点的距离都很大 → 所有相关值都趋近 0 →
  **R ≈ I（单位阵）→ 局部修正项归零 → Kriging 退化成"只有趋势"**。这就是"高维代理精度掉"的解析解释。

![Kriging 解剖：一条趋势 + 一张关系表，θ 决定谁跟谁像（手绘笔记版）](./images/L02_s2_kriging_anatomy_zh.png)

**第四步：算例（真的代数字，来自 `code/kriging.py` 的自检场景）。**
一维目标 y = x sin(x)，样本取 x = 0,1,2,3,4，常数趋势 + 高斯相关，θ 由网格搜索极大似然定。

1. 预测点 x′ = 1.5：R⁻¹(y − Fβ) 权重给到 x = 1 与 x = 2 两点，μ(1.5) ≈ 1.245，σ(1.5) ≈ 0.14 → 置信带 [0.97, 1.52]；
2. 预测点 x′ = 7.0（在样本范围外）：所有 r ≈ 0 → μ ≈ 趋势值（常数 β ≈ 1.13），而 σ 逼近全局 σ → **模型老实承认"我不知道"**；
3. 95% 置信区间在样本点处**收紧到 0**：这正是论文 Fig. 9 的画语〔原文 P14 "The standard deviation-based kriging predictive conﬁdence interval"〕。

**第五步：有了 σ，才有 EGO。** 定义当前最优（incumbent）ξ，改善量的期望：

  z = (ξ − μ(x)) / σ(x)，  EI(x) = (ξ − μ)Φ(z) + σ φ(z) = σ·[zΦ(z) + φ(z)]

Φ 是标准正态累积分布、φ 是概率密度。**手算一遍**（用可背诵的近似值 Φ(0.5)=0.6915、φ(0.5)=0.3521）：

- 点 A：μ = 0.90，σ = 0.10，ξ = 1.00 → z = (1.00 − 0.90)/0.10 = 1.0 → EI = 0.10 × [1.0×0.8413 + 0.2420] = **0.108**
- 点 B：μ = 1.10，σ = 0.60，ξ = 1.00 → z = (1.00 − 1.10)/0.60 = −0.1667 → EI = 0.60 × [−0.1667×0.4338 + 0.3939] = **0.185**

**打脸点在这里**：点 B 的**预测更差**（μ=1.10 > 1.00，最小化问题里更糟），可 EI 反而更大——
因为 σ 大，"万一这里比想象的好"这份期权值钱。**开发 vs 探索**就是被这一个 σ 拉扯出来的。
（这正是你在隔壁燃气轮机白皮书第 01 讲看到的 CR-EI 折腾 z 的根源。）

**把这一步画出来**（上栏是代理的均值与置信带，下栏是它的"该往哪问"）：

![期望改进 = 预测收益 + 不确定性的期权费：峰不在预测最好处，而在没人测过处](./images/L02_s3_ei_acquisition_zh.png)

**第六步：跑一遍，别信我的手算。** `python3 code/ego.py` 会连做三件事：
复算上面这两个点（T1，误差 < 0.02）、演示 z ≪ 0 时 φ 下溢导致 EI ≡ 0 的**僵死病**（T2）、
再在可手算的二次函数 (x − 4)² − 1 上跑 12 步 EGO（T3）：
**实测 6 个初点 + 3 次加点即到 f = −1.0000（12 步全部用完时 |x̂ − x*| = 0.0050）**。
把这三段输出抄进你的实验记录，就是"代理式序贯优化"的最小可复现证据。

#### 4. 操作流：Kriging 家族三兄弟各自怎么用

**（a）GEK（梯度增强）**：两条路子——
**间接 GEK** 用一阶泰勒在样本附近造虚拟点（式 19）：y(xᵢ + Δxⱼ eⱼ) = y(xᵢ) + (∂y/∂xⱼ)Δxⱼ〔原文 P14 "y(xi + ∆xjej) = y(xi) +"〕，
好处是**不用改模型结构**，代价是相关矩阵被撑大；
**直接 GEK** 把梯度直接拼进数据向量（论文 Fig. 11）。
**读图**（左：同一条曲线，加了斜率之后置信带立刻收窄；右：旋钮拧到哪，本质是在买多少"没测过"）：

![梯度增强等于给每个样本配一条斜率；探索—利用只是方差前那个系数](./images/L06_s3_gek_and_exploration_zh.png)

**为什么和你天配**：伴随方法给你"一次求解、全维度梯度"（讲 01 §3），这些梯度**本来就躺在你的输出里**，
喂给 GEK 等于白捡 N×d 条约束信息。**这是"信息复用"思想的第二次出现（第一次是伴随本身）。**

**（b）Co-Kriging（多保真）**：先对低精度数据建一个 Kriging，再对"高精度 − 低精度"的差建第二个；
低精度数据便宜所以要多有多少，差模型样本少但目标明确。
对应你的 140k 粗网格（E3：**未收敛**，只能当低精度趋势）与 3.55M 细网格（E4 目标）。
**注意红线**：把 relrms = −3.39 未收敛的解当"低精度真值"喂进 Co-Kriging 是危险操作——
先让粗网格至少收敛，再谈融合。这是本讲给你的可执行改进项。

**（c）PCE / PC-Kriging**：PCE 要你先给输入的**概率分布**，用正交多项式基展开；
PC-Kriging 把 PCE 的稀疏基与 Kriging 的置信区间结合，
在**鲁棒设计与不确定性量化**上更具竞争力〔原文 P50 "more competitive for uncertainty quantiﬁcation applications"〕。
连你概率论课题 08（矩生成函数/特征函数）：**PCE 就是"用多项式基替代泰勒展开来传播不确定性"**。

#### 6. 审稿人批判

1. **§3.1 只讲"经典方法"却不给成本公式**：文中说传统代理训练耗时，却没给"N 与 d 下的大 O"，读者无法判断"我 1000 样本 74 维到底跑不跑得起"（答：**跑得起**，Kriging 的真正麻烦是精度不是算力）；
2. **GEK 的收益没给量化区间**：哪些维度、多少样本时 GEK 才显著优于普通 Kriging，综述没归纳（这正是你能用 Rotor 37 数据集补的小实验）；
3. **Co-Kriging 的前提被略过**：低精度模型必须**自身收敛且系统性偏差可建模**，否则融合会把误差放大——原文在挑战④里没写这个前提；
4. **把 ME/RMTS 放在 §4.2.1 而非 §3.1**：从方法学上它们就是代理模型，分类轴（方法 vs 应用）在这里打架，读者容易漏读。

4-单位阵、趋势项 βf；5-①EI/EGO 加点 ②鲁棒/可靠设计里当方差用；6-KNN 只会取邻居平均（悬崖也不知道）、
多项式在测点外发散、Kriging 至少用 σ 承认不知道；7-z=0.4，EI=0.5×[0.4×0.6554+0.3683]=0.306，偏开发（z>0 且 σ 适中）；
8-算力 O(N³)=10^9 量级可接受（秒到分钟），精度瓶颈在 d=74（相关矩阵近乎对角）；
9-数据行从 N 条变 N×(1+d) 条（间接 GEK 用泰勒造点）或 y 向量拼接 d 个导数分量（直接 GEK）；
10-低精度层的意义是"与高精度强相关"，未收敛的解相关性无保证，误差会被当作"差值结构"学进模型。

---

#### 10. 一句收口

> **Kriging 教你一件终身受用的事：任何预测都要附上"我有多不确定"，
> 而优化算法只要学会看这条置信带，就会自己长出"探索"的本能。**
