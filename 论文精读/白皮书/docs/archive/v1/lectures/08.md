#### 1. 生活与物理直觉引子：两种"抄近路"

你从宿舍走到教学楼，有两条省时间的路子：

1. **别从门口起步**：先在楼上跳窗台（先给一个已经很接近答案的初场），再走完剩下的路。
   路本身没变短，但**你要走的部分短了** → 这就是"用 ML 猜初场"。
2. **把路面铺密一点反过来做**：本来每 10 米一步，现在每 80 米一步，但**每一步迈得更聪明**
   （用数据学出来的差分格式，粗网格也能算准）→ 这就是"数据驱动离散化"。

第二条比第一条激进得多：第一条只是**少走几步**，第二条是**改走路的方法**。
所以论文的措辞也不一样：第一条写的是"加速 1.9 到 7.4 倍"〔原文 P56 "accelerated the simulations by up to a factor of 1.9 to 7.4"〕，
第二条写的是"40 到 80 倍的计算加速"〔原文 P56 "40 to 80× computational speedups"〕。

> **本讲最重要的一句话**：加速比的数量级差别，正好对应"你在省钱"还是"你在改算法"。
> 写论文时必须把这两类分开报，混在一起报会被审稿人当成夸大。

#### 2. 工程死穴：把"加速"拆成三笔账

**先认词**

| 中文 | 英文 | 一句操作定义 |
| :--- | :--- | :--- |
| 初场 | initial field / initial guess | 求解器开跑前的流场分布；给得好，非线性迭代次数直线下降 |
| 保真度 | fidelity | 一次计算所代表的物理与数值精度等级；"高保真"= 细网格 + 可信湍流模型 + 已收敛 |
| 模态多网格 | mode multigrid | 用 DMD 模态把流场里的高频部分**削掉**，只在低频上迭代（讲 03 的模态语言在这里上岗） |
| 数据驱动离散化 | data-driven discretization | 不用教科书差分格式，而是**从数据里学**一套离散化系数，让粗网格也能算准 |
| 湍流闭合 | turbulence closure | RANS 里必须补的那个未知项（雷诺应力 / 涡黏）；ML 用来**拟合一个更好的闭合** |
| 分离传感器 | separation sensor | 一个能从压力/摩擦分布算出的标量场，用它当"抖振是否发生"的**替代指标** |
| 离设计点 | off-design | 非巡航设计状态（大攻角、抖振边界、失速前）；这些状态往往**只能非定常算** |
| 隐式约束 | implicit constraint | 不直接算目标量，而是约束**与它强相关的机理量**（如厚度模态）来间接达到要求 |

**死穴一：加速的天花板是"迭代次数"，不是"每次迭代的时间"。**
CNN 猜初场只砍前者：Obiols-Sales 等人的做法是**先预测速度、压力、涡黏这些基本流体属性**，
再让 CFD 从这个猜测继续算，稳住层流与湍流算例上拿到 1.9–7.4 倍〔原文 P56 "used a CNN to predict the primary fluid properties"〕。
一旦残差掉进最后两个数量级，**CFD 还是要自己爬完那段路**。

**死穴二：粗网格省下的钱，会被"你没验证过这个格式在你身上成立"吃掉。**
Bar-Sinai 等人的思路是**系统地推导离散格式**，让一维非线性方程在比标准有限差分**粗 4 到 8 倍**的网格上仍然算得准
〔原文 P56 "4 to 8 × coarser than standard"〕；Zhuang 等人把它用到二维湍流，**粗 4 倍仍保持精度**〔原文 P56 "still maintain the simulation accuracy"〕。
注意"仍保持精度"是**在这些作者自选的算例上**保持——它不是一条定理。

**死穴三：真正贵的不是目标函数，是那些"测不起的约束"。**
目标函数在巡航状态算一次就够，而**约束可能涉及非定常模拟，因此耗时得多**〔原文 P57 "constraints might involve unsteady simulations"〕〔原文 P57 "much more time-consuming"〕。
这才是高保真 ASO 的真实瓶颈：不是"算 C_D 贵"，是"算 C_L,max 与抖振起点贵到没人算"。

#### 3. 数学从 0 到 1：加速比到底是谁除以谁

**定义（先统一分母，否则数字没有意义）**

$$
\text{speedup} = \frac{T_{\text{baseline}}}{T_{\text{new}}}
\qquad\text{，}\qquad
T = N_{\text{iter}} \times t_{\text{iter}} \times N_{\text{cells}}
$$

平文本：`speedup = T_baseline / T_new`，`T = N_iter × t_iter × N_cells`。

三类加速动的正是三个不同的因子：

| 路数 | 动的因子 | 论文里的实测 | 为什么幅度是这样 |
| :--- | :--- | :--- | :--- |
| 猜初场 / 中间迭代修正 | $N_{\text{iter}}$（迭代次数） | 1.9–7.4×〔原文 P56 "accelerated the simulations by up to a factor of 1.9 to 7.4"〕；DMD 用于**中间迭代把解推向定常态**〔原文 P56 "to correct the solution closer to a steady-state condition"〕 | 只省迭代数，网格与单步成本不变 ⇒ 天花板是个位数 |
| 模态多网格 | $N_{\text{iter}}$（高频模态不迭代） | 3 到 6 倍且保证精度〔原文 P56 "achieved speedup ratios of 3 to 6"〕 | 同数量级：仍是"少迭代" |
| 数据驱动离散化 | $N_{\text{cells}}$（网格点数） | 4–8× coarser、40–80× speedup | **成本按网格点数近似线性（隐式求解约 N log N）超线性增长** ⇒ 同一物理精度下点数 ÷8，时间可以 ÷40 |

**代入数字算一遍（本讲唯一必须会算的账）**：
设一次定常 RANS：$N_{\text{cells}} = 1.4\times10^{5}$（你的 SU2 粗网格就是这个量级），$N_{\text{iter}} = 2000$，$t_{\text{iter}} = 30\,\mathrm{ms}$。

$$
T_{\text{base}} = 1.4\times10^{5} \times 2000 \times 30\times10^{-3}\ \text{s} \approx 8.4\times10^{6}\ \text{核·秒量级（单核计）}
$$

平文本：`T_base = 1.4e5 × 2000 × 30e-3 ≈ 8.4e6 秒`（单核名义值，只用来比"同分母"）。

- 走"猜初场"：$N_{\text{iter}}: 2000 \to 500$（省 4 倍） ⇒ 加速 ≈ **4×**，落在 1.9–7.4× 区间里；
- 走"粗 8 倍网格"：$N_{\text{cells}}: 1.4\times10^{5} \to 1.75\times10^{4}$（省 8 倍） ⇒ 加速 ≈ **8×**；
- 两者**能不能叠**？论文没这么说。你若要叠，得自己证明粗网格上的学习格式在**你的**激波强度下仍然成立——这就是审稿人会问的那一句。

**替代约束的数学（本讲的正菜）**：Kenway–Martins 抖振约束的做法是把非定常问题换成一个定常可算的标量：

$$
s(\mathbf{x}) \equiv \int_{\text{upper surface}} \left(\frac{\partial C_p}{\partial x}\right)_{\text{aft}} \mathrm{d}x \le s_{\max},\qquad s_{\max} = 4\%
$$

平文本：`s(x) = 上表面后段压力梯度积分 ≤ s_max`，`s_max = 4%`。
论文原文：**基于分离传感器函数构造抖振起点约束，上界 4% 由试验对比确定**〔原文 P58 "upper bound of 4%"〕。
它的**致命优点与致命缺点同一个**：便宜，但那个 4% 是**用有限次试验定的**（论文自己承认："虽然 4% 这个界限是用有限数量的观测定义的"，见 p58 同段）。
这就是"替代约束"的通用代价结构：

```
替代约束 = 机理量 + 一条由少量数据标定的阈值
        ⇒ 成本 ↓ 数个量级
        ⇒ 精度与适用范围由"标定时覆盖了几种外形/几个马赫数"决定，不收敛保证
```

#### 4. 操作流：把三招接到你自己的求解器上

以 SU2（你环境里已有 `SU2_CFD_AD` / `SU2_DOT` / `SU2_DEF`）为例：

```
① 换初场（最容易落地）
   几何 x (74 维) → 代理 Ũ(x), P̃(x), ν̃t(x)  →  写成 SU2 Restart 文件  →  SU2_CFD
   验收：T_new / T_base；同时必须报"初场预测误差"（Ũ 与真解的相对 L2）
   ⚠ 别只报收敛快：还要报收敛到的是不是同一个解（残差终值、C_D 差值）

② 换离散（难，但收益大一个量级）
   在细网格上采数据 → 拟合粗网格的修正通量/人工黏性 → 在粗网格上跑
   验收：同一外形上，粗格式 vs 细格式的压力分布逐点对比（不是只看 C_D）

③ 换闭合（研究性最强）
   DNS/高保真 LES 数据 → 训练雷诺应力模型 → 嵌入 RANS
   ⚠ 论文说得很清楚：这类工作**不是为了加速而设计**，只是可能顺带省算力〔原文 P56 "not designed to accelerate simulations"〕

④ 换约束（组会里最出彩的一招）
   把"要满足 C_L,max ≥ 目标"换成"厚度模态 + 后段压力梯度"这类定常可算量
   验收：替代式在 N 个已知样本上与真值的**一致率**（不只是相关系数），并给出错判率
```

#### 5. 数据与图表：Fig. 45 怎么读，以及它的"好看"与"不够"

论文本讲唯一的图是 **Fig. 45**（p57）：两张试验抖振起点工况下**平滑后的分离传感器在物面上的分布**。
图注原话是——**分离传感器能充分预测高亚声速与跨声速两种来流条件下的抖振起点，说明该方法具有合适的泛化能力**〔原文 P57 "The separation sensor adequately predicts"〕。

**读法（四步）**：
1. 先看**横轴是物面位置还是弦向站位**——传感器是按 $C_p$ 沿上表面后段算出来的，看图就知道它在哪儿"报警"；
2. 再看两个工况的曲线**峰值位置是否一致**：一致 ⇒ 说明这个量抓的是机理，不是拟合；
3. 找**4% 阈值线**：图里若没画阈值线，你就无法从图判断"裕度有多大"，只能读论文文字——这是本图的第一个不足；
4. 最后问：**样本量**。论文自己写了"上界由有限数量观测确定"，所以这张图证明的是"在这几个工况上不失效"，**不是**"在任意机翼上不失效"。

**把"换约束"这件事画成一页**（上：原来的约束为什么算不起；下：替代式为什么算得起、又欠了什么）：

![替代约束的本质：把「会不会抖」换成「后段压力梯度积分够不够小」，用少数试验标一个阈值](./images/L08_s5_separation_sensor_zh.png)

**同一段里的对照数字**：Li 等人那个 CNN 混合的机理型数据驱动抖振分析模型，
用**超过十万量级的数据点**训练，在 14,886 个未见测试数据上**抖振因子预测的平均绝对误差 0.05°**，
并被显示比 Kenway–Martins 传感器更可靠〔原文 P58 "mean absolute error of 0.05"〕。
——**这就是"便宜替代式"与"贵但准的模型"的正面交锋**：前者几十秒可评估、适用范围窄；后者训练成本极高（论文说用掉了超过 $10^{5}$ 次 CFD 模拟），准得多。

#### 6. 本讲收口前的审稿人批判

1. **加速比的分母不统一**：1.9–7.4×（含 CFD 收尾）与 40–80×（纯求解器成本）不是同一把尺。
   把它们并排写进同一个表格而不加说明，是综述式论文里最常见的"看起来更强"。
   → 你写组会汇报时，**每一行都标注"分母是什么"**。
2. **"保持精度"的验证集是作者自选的**：4–8× coarser、4× 保持精度这些结论，都在**一维/二维、作者挑的算例**上；
   跨音速激波 + 附面层干扰这种"精度最难保"的场景，论文没有给结论（p56 只写了二维湍流）。
3. **替代约束的阈值来源薄**：4% 由"试验对比"定，样本"有限"是论文原话级别的承认；
   把它当工程约束直接上优化环，等于**用一个未标定的经验常数决定飞机能不能飞**。
   → 你必须自己复现这个阈值，并报告错判率。
4. **本讲自己也有一处软**：上面那张图**不是论文原图**，是本白皮书画的直觉图（左/右栏对应"入口/出口"，不是论文的坐标）；
   它只帮你记结构，不能当证据引用。真正的证据在 `../资料原件/*.pdf` 的 p56–58 与 Fig. 45。

#### 10. 一句收口

> **少算（加速）与换量（替代约束）都不制造精度；它们只是把精度挪到你能验证的地方——
