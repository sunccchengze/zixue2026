#### 1. 生活与物理直觉引子：三种学法

- 有老师批改：**监督学习**（每份作业都有标准答案 = 每个外形都有 CFD 结果）；
- 只有教材、没人批改：**无监督学习**（讲 03，找结构）；
- **只有一半作业有答案**：把没批改的自己先做一遍、让模型自己给个答案当参照 → **半监督（伪标签）**；
- **完全没有答案，只有期末成绩**：反复试错、按分数调整策略 → **强化学习**。

气动设计的现实恰好落在后两种：**标签（CFD）又贵又慢**，而"好坏"往往只有一个标量。

#### 2. 工程死穴：标签从哪来

**先认词**

| 中文 | 英文 | 一句操作定义 |
| :--- | :--- | :--- |
| 伪标签 | pseudo label | 先用有标签数据训一个模型 M₀，再用 M₀ 给无标签数据"贴"一个假标签 y′，然后真标签 + 假标签合并再训 M_semi |
| 受限玻尔兹曼机 | RBM = restricted Boltzmann machine（restricted 受限：层内不相连；Boltzmann 玻尔兹曼：来自统计物理的能量分布） | 一层可见 v + 一层隐元 h 的二部图，学"哪些配置联合出现得多" |
| 对比散度 | CD = contrastive divergence | 不做完整马尔可夫链蒙特卡洛，只走几步就估梯度——把"采样到天荒地老"换成"走 1–10 步" |
| 深度信念网络 | DBN = deep belief network | 把 RBM **逐个堆叠**：训好一个冻结一个，把它的隐层输出当下一层的输入 |
| 强化学习 | RL = reinforcement learning（reinforcement 强化、learning 学习） | 学一个**策略** π：在状态 s 下该出什么动作 a，使**长期累计奖励**最大 |
| 状态 / 动作 / 奖励 | state / action / reward | 状态=当前局面（现在的气动系数分布 + 剩余裕度）；动作=怎么改（改哪几个模态系数）；奖励=改完好坏变化（ΔC_D） |
| Q 值 | Q(s,a) | "在 s 下执行 a，往后一共能拿多少分"的期望；Q-learning 就是把它列表/拟合出来〔原文 P30 "core idea of q-learning"〕 |
| DQN | Deep Q-Network | 用深度网络代替 Q 表；配合 ε-greedy 在"用已知最好"与"试新的"之间权衡（论文 Fig. 30） |
| 策略梯度 | policy gradient（确定性策略梯度 DPG 直接把状态映射到最优动作）〔原文 P31 "deterministic policy gradient method"〕 | 不估 Q，直接对 π 的参数求梯度 |

**死穴数据**：气动标签贵到什么程度？一次 CFD 几小时，1000 组样本就是一整个课题组一学期的机时。
半监督学习正是在"实验气动数据不完整且获取代价高昂"这一背景下出现的〔原文 P26 "data labels (e.g., experimental aerodynamic data) are incomplete and costly to obtain"〕。

#### 3. 数学从 0 到 1 推导

**（a）伪标签的更新式**：给定 (X_L, Y_L) 与 X_U：

1. M₀ = argmin Σ_{i∈L} (ŷ(x_i) − y_i)²（只在有标签上训）
2. y′_j = ŷ_{M₀}(x_j) 对所有 x_j ∈ X_U
3. M_semi = argmin [ Σ_{i∈L}(ŷ(x_i) − y_i)² + λ Σ_{j∈U}(ŷ(x_j) − y′_j)² ]

λ 是**信任折扣**（论文 Fig. 25 的流程即"真实标签与伪标签合并后再训一个监督模型"〔原文 P26 "predicts peudo labels"〕——原文把 pseudo 拼成了 peudo，照录，这是原文的错别字，我们不改它也不学它）。

**手算一遍**，看清风险在哪：假设 M₀ 在无标签点 x_u 上预测 C_D = 0.0180（真值 0.0205）。
第二轮训练把 0.0180 当事实去拟合，**误差被固化**；若 M₀ 对畸形外形的预测系统偏乐观，
伪标签会把模型往"畸形但看似好"的区域再拉一把——**自我强化的偏见**。
所以工程上必须加两道闸：① 置信度门槛（只接受 |σ| 小的伪标签）；② 每 K 轮用真实 CFD 抽查一批。

**（b）RBM 的能量直觉**：E(v,h) = −aᵀv − bᵀh − vᵀWh；联合分布 P(v,h) ∝ exp(−E)。
训一次"正相位"（让数据出现的配置概率↑）+ 一次"负相位"（让模型自造的配置概率↓），二者之差就是梯度。
**负相位要 Gibbs 采样到平衡 → 太慢 → 对比散度 CD-k 只走 k 步**（这就是 Fig. 27 的内容）。
"为什么叫 restricted"：层内不连，于是**给定一层的值，另一层各神经元条件独立** → 采样可以整层并行。这是它比 BM 快的全部秘密。

**（c）RL 的三件套翻译**：气动优化的 RL 化写法

- s_t = (当前设计变量、C_L、C_D、剩余约束裕度, t/总步数)
- a_t = (Δ 模态系数向量)，动作空间连续 → **必须用策略梯度/DPG 而非 Q 表**（离散 Q 值处理不了连续控制）
- r_t = (C_D,t − C_D,t+1)×10⁴（用"省了多少阻力计数"当奖励，是常见写法）
- 目标：max E[Σ_t γ^t r_t]

**为什么难训**：奖励稀疏（中间步 CFD 不收敛 = 0 分，噪声淹没信号）、约束不可微（"厚度 ≥ 2 mm"塞不进奖励）、
且**策略每改一次都要真实 CFD** → 试错成本 = 探索次数 × 几小时。这就是讲 09 里 RL 只在小维数上灵过的根因。

#### 4. 操作流：什么时候真的该用它们

| 场景 | 该不该用本讲工具 | 做法 |
| :--- | :--- | :--- |
| 你有 1000 组 CFD + 10 万组**未收敛/半收敛**的粗网格结果 | ✅ 半监督 | 把"残差降到 −2.5 但没收敛"的算例当无标签集，用高精度模型贴伪标签，λ 取 0.1–0.3 |
| 你要做**序贯决策**：每一步选"在哪个区域加点" | ✅ RL（或退化为一维 bandit） | 但先别上 DQN：用 Thompson 采样/EI（讲 02/09），它是"不需要训练"的策略 |
| 你要预训练一个能生成合理叶型的模型 | △ RBM/DBN 已过时 | 现在直接用 VAE/GAN（讲 05）；RBM 只需知道思想（逐层贪心 + CD） |
| 你只是想让 η 的置信区间更好看 | ✘ 与本讲无关 | 那是 UQ 问题，见讲 02 §8 与你的 MC Dropout 覆盖率 65%（E2） |

#### 6. 审稿人批判

1. **§3.3 半监督在 ASO 里只给了通用原理，没给气动应用案例数**：读者无从判断"这在气动圈到底用了没有"（我判断：几乎没被认真用——这是可写进组会的观察，属推断，非论文所述）；
2. **RBM/DBN 占了 2 页，而气动设计里早已被 AE/GAN 取代**：篇幅分配像为"教材完整性"服务，不像为读者决策服务；
3. **§3.4 讲 RL 却不给"奖励函数怎么写"的失败模式**：奖励塑造（reward shaping）是 RL 工程的第一大坑，综述把它略过了；
4. **RL 与代理优化的边界未讨论**：EI/UCB 本质上是"一步决策的 bandit"，与 RL 有明确联系，分开讲割裂了读者的直觉（这条在 §4.3.1/§4.3.3 也欠着）。

#### 9. 自测 10 题（2 选 + 2 填 + 6 答）

1. （选）RBM 之所以叫 restricted，是因为：A 隐元数受限 B 层内神经元不相连，导致给定一层时另一层条件独立 C 只能二分类 D 参数必须非负
2. （选）伪标签最大的风险是：A 计算慢 B 模型错误被固化并自我强化 C 需要 GPU D 破坏可导性
3. （填）半监督学习的定义是：用少量 __________ 数据与大量 __________ 数据联合训练。
4. （填）Q-learning 跟踪的对象是 __________；连续动作空间通常改用 __________ 方法。
5. （答）写出三步伪标签算法，并给出两个"闸门"的具体形式（含阈值写法）。
6. （答）用 RL 语言把你的 NSGA-II 循环重写：s / a / r 各是什么？为什么动作必须是连续的？
7. （答）对比散度 CD-k 用"k 步"替代了什么？代价是什么（偏差从哪来）？
8. （答）DBN 的"逐层贪心 + 冻结"为什么能训深层网络？它在今天被什么取代了？（两个具体原因）
9. （答）你的粗网格数据若做低精度层，必须满足什么前提才不算自欺？请用一行式子表达"相关性"判据。
10. （答）批判：为什么说"奖励函数写法"比"用 DQN 还是 PPO"更重要？给一个会翻车的奖励设计并解释。

**答案要点**：1-B；2-B；3-有标签、无标签〔原文 P26 "work with a small amount of labeled data and a large amount of unlabeled data"〕；
4-Q 值（状态-动作对的期望回报）、策略梯度（含确定性策略梯度）；
5-见 §3(a)；闸门①仅接受 σ̂(x) < 1.96σ̂ 区间内且 |σ| < 0.3σ_max；闸门②每 5 轮抽 5% 做真 CFD 校验，若 MAE 增 >10% 则丢弃该批伪标签；
6-s=(X, C_L, C_D, 裕度, t/T)、a=Δ模态系数∈ℝ^8、r=ΔC_D×10⁴；连续因模态系数无天然离散化，Q 表爆炸；
7-替代"采到平衡分布"的长链；偏差来自初始分布（训练样本）而非模型分布 → 负相位样本过于"像数据"，欠估模型分布 → 高估数据概率；
8-逐层训练保持每层梯度稳定、避免端到端小样本的梯度消失/鞍点；被 ResNet/BN/好初始化 + 端到端 Adam 取代；
9-corr(y_lf, y_hf) 足够高（工程上 |ρ| ≳ 0.9）且残差结构平稳：判据 ρ = cov(y_lf, y_hf)/(σ_lf σ_hf) ≥ 0.9，未收敛数据先补到收敛；
10-例：r = −C_D 会把策略推向"畸形但低阻"的外形（CFD 发散给 0，反而最"安全"）→ 必须加合法性惩罚与不可行动作终止，否则奖励在替你说谎。
