## 工作流（照抄，别自创）

```bash
cd 论文精读/白皮书
# 1. 语料/统计先刷新（白皮书里所有"实测数字"都来自它）
python3 tools/scan_corpus.py
# 2. 改讲稿
$EDITOR docs/lectures/08.md
# 3. 装配（生成 机器学习与气动外形优化自学白皮书.md）
python3 tools/build_whitepaper.py
# 4. 验收（6 项，任一 FAIL 不得交付）
python3 tools/verify_all.py
# 5. 代码自检（第五篇嵌入前，确保每个模块跑通）
for f in code/*.py; do echo "--- $f"; python3 "$f" | tail -3; done > images/selftest-report.txt
# 6. 收尾：更新 ../memory/PROGRESS.md 与 HANDOFF.md，commit + push（AGENTS.md 硬规则）
```

## 一讲的固定十一节结构（`verify_all.py` D 项按关键字检查）

| # | 小节名（必须出现） | 硬性要求 |
| :---: | :--- | :--- |
| 0 | 本讲元数据 | 范围 / 证据等级 / 前置 / 读完能做什么 / 一句话 |
| 1 | …引子 | 生活与物理画面，**不许用类比替代定义**（A1 禁令） |
| 2 | 工程死穴 + **先认词**表 | 三列：中文 / 英文（缩写逐个拆） / 一句操作定义 |
| 3 | 数学**从 0 到 1** | Unicode 平文本 + LaTeX 双写，**必须带一个代入数字的算例** |
| 4 | 操作流 | 输入形状 → 中间几步 → 输出形状 |
| 5 | 数据与图表 | 论文原图的读法 + "这图好在哪、不好在哪"（用户审美挑剔） |
| 6 | **审稿人批判** | ≥3 条，可攻击的点；顺带批判本白皮书自己 |
| 7 | **承前**启后 | 明确指向其他讲次编号 |
| 8 | 你的项目接哪一步 | 必须标 E0–E4 口径（见 `corpus/facts/P01-local.md`） |
| 9 | **自测** 10 题 | 2 选择 + 2 填空 + 6 问答（A2 硬比例），附答案要点 |
| 10 | 一句**收口** | 不超过两行 |

**引用铁律**：写"论文说……"必须写成 `〔原文 P## "语料里能找到的连续片段"〕`。
脚本会把引号里的片段扔回对应页做子串匹配，**核不过就整本不许交付**（A 项）。
注意语料里的连字（ﬁ/ﬂ/ﬀ）与断字符（`train-` 换行）——写关键词时宁可截短，也别赌整句。
