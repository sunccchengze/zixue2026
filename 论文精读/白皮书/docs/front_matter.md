| 项 | 内容（均已核对 PDF 实物） |

| 唯一蓝本 | `../资料原件/Machine learning in aerodynamic shape optimization.pdf`（**103 页**：正文 1–68，参考文献 69–103） |
| 实物统计 | **47 幅图**（索引见 `../资料原件/图表索引.md`）、**5 张表** |
| 可检索语料 | `../资料原件/论文全文-提取文本.md`（PyMuPDF 抽取，按页打标记，共 103 个页块） |
| 章节页码 | `../章程与地图/资料映射.md`（由 PDF 书签直读，**不是估算**） |
| 全文覆盖 | **A 级**：本地有全文，正文每一句都能回溯到提取语料的具体页 |

**全书只有一种"已核实"的写法**：正文里每一条数字、每一句"论文说……"，后面都跟着
`〔原文 P## "关键词串"〕`。这个标注不是装饰——
`tools/verify_all.py` 的 A 项验收会**逐条把引文串扔回 PDF 语料对应页里做子串匹配**，
匹配不上就整本白皮书不许交付。写书的人记错页码是常事，所以把记错变成机器报错。

**超出这本综述的内容**（例如 FNO / DeepONet / Transformer / 扩散模型 / SINDy），
一律显式标注 **〔延伸·待核实〕**，不混进正文当论文说的。
这不是谦虚，是因为作者们实测过：这五类关键词在综述 528 条参考文献里**0 命中**
（复现方法见 `../章程与地图/12篇论文总规划.md` §二），它写不进正文是事实，不是观点。

## 二、三条写作铁律（照抄 Mr.GUO 仓库重建版的教训，一条不改）

1. **没有出处的话不写。** 正文每个百分比、倍数、样本量后面都跟着 `〔原文 P## …〕`；
   查不到出处的一律标 `〔待核实〕` 或不写。
2. **跑不通的代码不交。** 第五篇代码由 `code/` 目录下的真实文件自动嵌入，
   每个文件都能 `python3 code/xxx.py` 直接运行并打印自检数字。
3. **对不上的数字不填。** 若通俗说法与原文冲突，以原文为准，并在讲稿里点名旧表述错在哪。

## 三、怎么读这本书

- **完全零基础**：先读第零章。它只用大一高数和一股脑的算术，把"CFD、优化、维度灾难"三件事说清楚；
- **赶组会**：直接读讲 01、讲 07、讲 10（流程、评估、结论），三讲合计不到一小时，够你在组会上把这篇综述定位清楚；
- **要推导**：每讲的「数学从 0 到 1 推导」小节都是自足的，只用第零章定义过的词；
- **要写代码**：进 `code/`，那里有能跑的 Kriging、PCA、维度灾难计算器；
- **要考试**：每讲末尾 10 题（**2 选择 + 2 填空 + 6 问答**），答不出的那几道决定你下一次会话开场先清哪张卡。
