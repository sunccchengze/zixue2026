# code/ · 可运行原型库

> 规矩只有一条：**跑不通的文件不许进白皮书**（`tools/verify_all.py` 会把每个模块跑一遍）。
> 本目录的每个模块都是"教学实现"：追求可逐行讲清，不追求性能；用真数据请换 sklearn/GPy。

| 文件 | 干什么 | 对应讲次 | 运行 |
| :--- | :--- | :---: | :--- |
| `curse.py` | 维度灾难计算器：每维点数、所需样本量、高维空间里"点都很边缘"的蒙特卡洛实证 | 第零章 0.4 / 讲 03 | `python3 code/curse.py` |
| `kriging.py` | 最小可用 Kriging：高斯相关 + 常数趋势 + θ 的极大似然网格搜索，输出 μ、σ | 讲 02 | `python3 code/kriging.py` |
| `ego.py` | EI 加点准则 + 20 步序贯优化，在 y = x·sin(x) 上找最小值，打印每步 z 与 EI | 讲 02 / 讲 09 | `python3 code/ego.py` |
| `pca.py` | PCA 三步（中心化 → 协方差 → 特征分解），打印特征值与累计方差保留曲线 | 讲 03 | `python3 code/pca.py` |

## 与白皮书的关系

- 白皮书第五篇的代码由 `tools/build_whitepaper.py` 从本目录**原样嵌入**；
- 正文里凡是"由 `code/xxx.py` 复算"的数字，都必须能在对应模块的自检输出里找到；
- 找不到的，按 `tools/verify_all.py` 的 A 项判为无出处 → 白皮书不得交付。
