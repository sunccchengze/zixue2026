## 0. 一页结论

**你的反馈（原话）**：「现在的白皮书不太适合作为一本 AI 时代自学的书。」

**判定**：v2 是对的，但它对的是「纸书时代」——它把**输入**做到了满分，
而 AI 时代自学的杠杆（你转来的那份热门讨论共识）全部在**输出侧**：

| 共识条款 | v2 书里的现状 | 后果 |
| :--- | :--- | :--- |
| 产出 > 输入（看 1 小时至少动手 2–3 小时） | 全书 355 KB，**没有一处要求你产出文件**；唯一硬交付（讲 12 一页报告）还被挂牌「待本人手写」 | 读得完 ≠ 学得会；合上书能带走的东西很少 |
| AI 只做教练不做替身，先自己再 AI | AI（本会话）在旧流程里当**全替身**（直接讲、直接判）；书当**全输入** | 没有人执行「先自己回忆 → AI 补漏 → AI 追问」的顺序 |
| 场景驱动、真实问题驱动 | 平台只是**书里的例子**：13 项修复清单（B4）全部停在书里，没有一项要求你真去改一行代码并回填证据 | 学习与组会/发论文两张皮 |
| 交付闭环、沉淀可复用资产 | 无资产槽；每讲 10 道自测（2+2+6）的答案就在同节末尾，反馈间隔 ≈ 0 | 学完知识还在书里，不在你手里 |
| 验收 = 能扛事 | 验收① = 「读完全书再答 3 题」——通读全书的路线约 6–10 小时纯输入、中间零验收点 | 战线长、无反馈、容易囤到周末突击 |

**方案一句话**：v2 成品书**一字不动**，原地降级为「教材卷」（JIT 翻阅的教材 + 全书的答案库与图库）；
在旁边新建一层 **「AI 教练训练场」**——13 个训练单元（U0–U12，对应第零章 + 讲 01–12），
每单元 = 一张**关卡卡**（你，运动员）+ 一份**教练脚本**（AI，教练），
把 v2 的六种装置从「自答自揭」改造成「教练主持的仪式」，把每讲的「读完你应该能」改造成**可验收的资产**。

**学完的标准从「读完 + 3 题」改成「13 单元 × 每单元 ≥1 件资产 + 收口四关」**
（§5、§6）。书没有废：它是训练场的地基、判卷的答案、打脸的出处。

**效果承诺（可测）**：产出/输入时间比 ≥ 2（共识硬指标）；全书硬资产 ≥ 13 件；
打脸记录 ≥ 13 处（每单元 ≥1）；错题按 1/3/7/21 天入复习队；U0+U1 两周内跑完并见效。

## 1. 判定与证据：为什么 v2 不适合当「AI 时代自学」的载体

不是挑刺，是挑**可复核**的刺。每一条都给你出处，不信可以自己核。

| # | 证据（可复核） | 为什么这与 AI 时代自学冲突 |
| :---: | :--- | :--- |
| 1 | 装配稿 355,228 字节、约 **6.4 万汉字** + 139 图 + 6 模块代码 + 每讲 10 道自测（120+ 题）（`机器学习与气动外形优化自学白皮书.md`） | 它是**单向输入的文本流**。共识第一条：被动看课/读教程无效，产出才是加速器。书写得再好，读它本身不产生任何产出 |
| 2 | 六种装置全部「自答自揭」：⏪ 上讲的数，答案在 3 行下的 `<details>`；🔮 下注，答案在下一段；自测 10 题，答案在同节末尾（如 `docs/lectures/01.md` §2 / §11） | 主动回忆需要**先想、再延迟验证**；答案与问题同屏 = 反馈间隔 ≈ 0，测试效应几乎不生效。这是书的形式决定的，重写也救不了 |
| 3 | 每讲元数据承诺「读完你应该能：① 徒手画出 XDSM…」（`docs/lectures/01.md` §0）——但**读完没有任何回填检查**；验收①的 3 题挂在「读完全书后」 | 承诺无人验收 = 没有闭环。中间 6–10 小时零反馈，错的理解一路带到结尾才暴露 |
| 4 | 你的平台·第 N 站写得很生动；B4 修复清单 13 项（三栏：只省钱/改模型/改流程，教材卷附录 B4）条条都写着「做什么」，**没有一条要求你交回「做了/没做 + 证据档位」** | 「场景驱动、当天就用上」缺最后一跳：例子永远是例子，变不成你的任务 |
| 5 | AI 在旧会话流程里是**全替身**（直接讲课、直接判卷）；书是**全输入**。两份资产之间没有「教练位」 | 共识核心：「先自己尝试 → AI 补漏 → AI 追问」的顺序必须有人执行。没人执行，就回到「外包大脑」 |
| 6 | 👊 打脸点（GEK 只换来 1.13×、n=10 反而 0.93×；EI 双图；2.3 万年）全部是**写好的结论**，出处挂得再严也是「他打我脸」，不是「我打我脸」 | 打脸要生效，你得先**下注**，再被自己的复算打脸。书里没有你的注，只有作者的注 |
| 7 | 全书零资产槽、零个人库出口；讲 12 的交付物（一页报告）唯一，且被前任明确标注「导师不许代写、待本人」 | 共识第四坑：「没有沉淀，下次又从零开始」。书的结构里没有「沉淀」这个动作的位置 |
| 8 | 教材卷 6.5 存疑清单 4 行（统计特征能否反算几何 / 0.4%↔R² 换算 / s_min 0.5 是否适配叶栅 / EI 在 74 维是否有效），每一行的「计划验证方式」都写着**要你的平台、你的数据、你的实验** | 作者自己都承认：书里的判断要闭合，缺一个「拿真实问题来验」的执行层。书在等一个训练场 |
| 9 | 原学习路径 = 12 次会话（每次 40–90 分钟）或「读完全书」；无论哪条，**进度感都来自读完多少页** | 共识：每日持续 > 周末突击；用「训练日 + 交付物」记账，比用「读了第几讲」记账更不容易烂尾 |

**结论**：v2 没有做错任何事，它只是完成了自己的角色——**一套顶级输入**。
AI 时代要补的不是更好的输入，是「谁在练、练什么、交什么、谁验收」。

### 2.1 三个候选方案对比（都想过，否决要有理由）

| 候选 | 做法 | 否决/采纳理由 |
| :--- | :--- | :--- |

## 3. 训练单元规格（U0–U12）

### 3.1 一个单元 = 一个「打脸链路」的三天剧本

每单元默认走**标准档 B**（2 个训练日，各 45–90 分钟）；另有快档 A 与精档 C。

| 档位 | 结构 | 适合 | 每单元总投入 |
| :--- | :--- | :--- | :--- |
| A 快档 | D1 压缩版：闸门 + 阅读地图 + 1 个输出任务 | 忙周 / 复习 / 已懂内容的单元 | 45–60 分钟 |
| **B 标准档（默认）** | D1 输入日 + D2 输出与落地日 | 绝大多数单元 | 2 × 45–90 分钟 |
| C 精档 | B + D3 挑战日（6.3 前瞻选题 / 平台落地） | 周末 / 与你论文直接相关的单元 | 3 × 45–90 分钟 |

**D1 输入日（侦察，产出比约 1 : 1）**——时间盒：闸门 15′ + 阅读 25–40′ + 抽问 10′ + 写账 5′

1. **开场闸门**：⏪ 上讲的数 2 题 + 本单元预测/下注 2–4 题（教练提问，**只收答案不判**，注封存）；
2. **阅读地图**：关卡卡指路——教材卷第几节、哪几张图、要不要先跑哪个 code 模块（JIT 按图索骥，不要求精读全书）；
3. **教练抽问 2 题**（检验「读了 ≠ 会了」，答不出 → 指回对应小节，不直接喂答案）；
4. 收尾：教练 3 行账进 PROGRESS，错题入队。

**D2 输出日（运动员上场，产出 : 输入 ≥ 2 : 1）**——时间盒：复述 20′ + 试卷 40′ + 资产草稿 20′ + 写账 5′

1. **口述知识树**（合上书）：把这一讲讲给 AI 听；教练只做两件事——对照教材卷结构**补漏**（指出你漏了哪节）与按**六层阶梯**报层数（你到了画面/拆词/操作/公式/数据/边界的哪层）；
2. **带走 3 个数自报**：教练对照 B3 附录核；
3. **自测 8–10 题**：答案在教练手里（教练脚本只写「答案见〔教材卷 讲NN §11 题j〕」，不重抄——防漂移）；教练判卷、按 §5a 纪律记错题；
4. **资产草稿**：本单元的硬资产在 D3 落盘，但 D2 收尾前必须写出草稿骨架（防「课后不落地」）。

**D3 落地日（产出与沉淀）**——只存在于标准/精档；快档把它的最小版并进 D2

1. 一个**真实任务**（C/D 类为主，见 §5）：改 `code/` 一个参数重跑 / 认领 1 项 B4 / 挑战线最小实验；
2. 把结果写成**资产文件**落盘 `units/uNN/资产/`（教练给模板，**不代写正文**）；
3. 教练按「验收线」收件（六层阶梯 + E0–E4 档位齐全），收一件 → 资产总账 +1 行；
4. 复习队列入队（错题 + 新认词）。

**裸奔日（防依赖机制）**：每 3 个训练日 1 次——你自己按关卡卡完成「闸门 + 口述 + 半套题」，不对话教练；
次日教练判卷。目的：把「AI 在场才学得动」这个依赖拆掉（共识第四坑的解药）。

### 3.4 引用语法（机器可核，防教练脚本内容漂移）

教练脚本与关卡卡里**不重抄教材卷内容**，一律引用：

| 语法 | 含义 | 核法（I3） |
| :--- | :--- | :--- |
| `〔教材卷 讲NN §k 题j〕` | 讲 NN 第 k 节自测第 j 题（或其答案） | 该讲文件存在 §11 且 j ≤ 题数 |
| `〔教材卷 讲NN §k 小节名〕` | 指向讲 NN 第 k 节 | 该节标题存在 |
| `〔code:xxx.py〕` | 指向 `code/` 模块 | 文件存在 |
| `〔B4 #n〕` / `〔6.3 选题 n〕` | 修复清单第 n 项 / 前瞻选题第 n 题 | 教材卷 6.8 / 6.3 表内 n 行存在 |
| `〔P01-local #n〕` | 项目侧事实账本第 n 行 | `corpus/facts/P01-local.md` 表内 n 行存在 |
| `〔存疑台账 #n〕` | 训练场存疑台账条目 | 训练场/存疑台账.md 存在 |

**训练场零新事实铁律**（继承教材卷 S13 与三条写作铁律）：关卡卡、教练脚本、资产模板
只许**调度与指路**，不许新增任何事实性内容；新增事实必须先有一手出处并登记，否则违规。
