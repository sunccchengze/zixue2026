## 二、三条写作铁律（本项目自缚）

1. **没有出处的话不写**：正文凡"论文说……"一律写成 `〔原文 P## "语料里能找到的连续片段"〕`，
   由 `tools/verify_all.py` A 项逐条扔回 PDF 语料核；**当前 133 条引用全过**。
2. **跑不通的代码不交**：第五篇代码由 `code/` 真实文件原样嵌入，`make checks` 全 PASS。
3. **对不上的数字不填**：旧说法若被推翻，写进 `part6.md` §6.4「公示」表（已登记 3 条，含本白皮书自己算错的一个）。

## 三、怎么用（新会话 30 秒上手）

```bash
cd 论文精读/白皮书
make all          # scan → 装配 → 代码自检 → 六项验收（约 10 秒）
# 想读：打开 机器学习与气动外形优化自学白皮书.md（目录有稳定锚点 part-*/lec-NN/code-*）
```

**续写一讲**：照 `docs/lectures/README.md` 的十一节模板写 `docs/lectures/08.md`，
再 `make all`。**讲次表的状态是脚本现算的**（查文件在不在、有没有 `<!-- TBD -->`），
所以"声称已完成"这件事本身也不会漂移。验收不过就改源，**不许绕过脚本手改白皮书**。
