## 全学科通用判例（继承段 · 源自大学化学 2026-09-05 判例⑬–⑯，学科中性版）

> 细则见 `skills/科研式学习导师/SKILL.md` §5a"命题与判卷纪律"；原始判例全文在
> `大学化学/memory/ERRORS.md`。以下四条对**本学科同样具有约束力**：

- **通用判例⑬（题干不得含答案）**：出题/提问时，题干只给条件与待求，
  不得写进结论、公式名、示例形状——否则该题作废重出。
- **通用判例⑭（旁白不算错）**：用户的思考旁白、括号吐槽、手滑联想不构成答案；
  判卷只看其最终结论与论证。
- **通用判例⑮（字符级核对）**：指数、上下标、角标、正负号必须逐字符放大核对再判；
  看不准就明说"这一处我不确定"并定点确认，不许凭印象误判。
- **通用判例⑯（收口要有证据）**：禁止用少量基础题"检测/安慰"；掌握 = 当次对 +
  隔 1~3 天无提示再对 + 能讲清；课题/阶段收口的最低门槛为真题级综合卷（C 档）
  正确率 ≥70%，且同点错 ≥3 次升级为 leech 换角度重教。发现题目过易，主动自首重出。

### J3 [2026-08-31 · 导师侧 · 已纠正] 差点按"大一水平"把这篇综述讲浅了

**情形**：上一版 LEARNINGS 直接继承"数学底子偏基础（高中/大一水平）"，据此把公式讲解定位为
"必须走三段式：直觉 → 类比 → 严格式"。这个定位**方向错了**：
他的原话是"你现在完全不给我把深度东西讲出来，只让我了解个大概就过去了。但是我做科研，
我怎么可能只了解这个大概呢？"——他要的不是降低难度，是**深入浅出但不减深度**（A1 六层阶梯）。

**纠正**：方法论改为六层阶梯（画面 → 拆词 → 操作 → 公式 → 数据 → 边界与回收），
**类比只能出现在第一层"画面"，之后必须落到操作与公式**；
验收标准从"能复述"升级为"能被随机抽问任何一点都答得详尽"（见 `论文精读方法论.md` §六）。

**红线**：→ R11。"基础"不等于"要浅"；他是零先验，不是低天花板。

### J5 [2026-08-31 · 导师侧 · 已认错] 让他在没有词汇时做预测，违反了自己的 A3

**红线**：→ R11 / R14 之间新增 **R16：预测题的前提是词汇已交付；词汇未交付就出题=无效题**。
