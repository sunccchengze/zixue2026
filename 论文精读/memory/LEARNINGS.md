## 偏好（从全仓库画像继承，本学科适用）

- **回合级 push（最高优先级）**：每次回答发出前先归档本回合进度 → 有改动则 commit → push 当前分支并确认成功。
- **批量提问**：每条消息 3–5 个编号问题，用户一口气答完；禁止零碎一问一答。
- **你多讲我多写**：导师每轮讲完要点，再集中发关键问题；用户在一张手写图上批量作答（上限 5 题）。
- **手写拍照答题**：用户不能发语音。收到图片直接识别、回显关键公式、逐题判卷；
  只有字迹/指数/正负号/上下标歧义影响判分时才定点确认。
- **绘图用生图模型**：图表一律 `generate_image` 生成 PNG 存进会话文件夹，不用 ASCII 文本块；
  重要公式出"手写体课堂笔记风"公式卡。
- **跳过逐篇审阅**：报告写完即标 ✅ 直接开下一节，全部读完统一回顾（审稿意见照写归档）。
- **多大师视角**：喜欢"一堆大师"参与，而非单一导师声音（→ `大师天团/`，待蒸馏）。
- **输出倒逼输入**：先让用户写/说，再纠正。
- **记忆锚**：交付新术语必带三件套（故事隐喻 + 口诀 + 符号位置法）。

## 已验证有效的讲法（继承 + 本学科适配）

- **打脸链路完全奏效**（概率论已验证）：用户用自己规则下注 → 实验/反例打脸 → 自己重构解法骨架。
  论文精读适配：论文本身就是"标准答案"，打脸成本极低——**先让他预测章节结构、数量、排序**，
  再翻到对应页码对比。
- **给具体数字让他下注**比抽象提问更能逼出真直觉（例：二维翼型要多少设计变量）。
- **指出两句话自相矛盾但不给答案**，他自己和解——发现式学习在本用户身上持久得多。
- **跨学科联想是他的认知资源**（曾主动把卷积↔CFD/神经网络连起来）：
  新概念主动问"和你在概率论/数理方程学的 XX 像不像"。
- **超额输出要表扬并命名**：他常列得比要求更多；把超额部分正式命名成结论能强化连接。
- **他会主动喊停**（"先到这里吧"）：立即判卷 + 总结 + 下次计划，不追加问题。
