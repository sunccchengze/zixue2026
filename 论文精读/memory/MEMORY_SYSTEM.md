# MEMORY_SYSTEM · 论文精读学科记忆架构

> 骨架照 `skills/科研式学习导师/SKILL.md` §3，并按论文精读特点加了 `MEMORY.md`（来自上游
> `-SKILL-` 的 `track-paper-aso` 模板）。

## 一、文件职责

| 文件 | 职责 | 更新时机 |
|---|---|---|
| `MEMORY_SYSTEM.md` | 本文件：架构说明 + 开局协议 | 架构变化时 |
| `HANDOFF.md` | **交接总账本**：进展到哪、下一句该问什么、判卷预案、会话记录 | **每回合末必更** |
| `MEMORY.md` | **论文理解主账本**：核心概念理解 + 学习日志（预测/打脸/修正）+ 跨学科联结 | 每次会话末 |
| `LEARNINGS.md` | 学习画像：偏好 / 卡点 / 已验证有效的讲法 / 知识背景 | 发现可迁移模式时 |
| `ERRORS.md` | 判例库：导师红线 + 用户判例（每条带红线） | 出错或发现误区时 |
| `PROGRESS.md` | 12 会话台账（⬜/🔄/✅/🔶） | 每次会话末 |
| `drill-ledger/index.md` | 间隔重复账本（简化 FSRS） | 每次判卷后 |
| `drill-ledger/topics/*.md` | 分主题卡片明细 | 同上 |

## 二、开局协议（新会话第一步，必须按序）

1. 读仓库根 `AGENTS.md`（**回合级 push 是全仓库最高优先级**）；
2. 读本目录 `HANDOFF.md`（永远最新）；
3. 扫 `LEARNINGS.md` 与 `ERRORS.md`；
4. 查 `PROGRESS.md` 与 `drill-ledger/index.md`；
5. **先清到期卡片，再从 HANDOFF 的"下一句"继续**；
6. 不重新自我介绍、不重讲规则、不重复问已答过的问题。

## 三、账本卡片表格式（简化 FSRS）

```
| # | concept | S(days) | D(1-5) | last | due | flags | history |
```

- 新卡：Again S=1.0 / Hard 1.5 / Good 3.0 / Easy 6.0，初始 D=3；
- 复习：S' = S × 系数（Hard 1.4 / Good 2.2 / Easy 3.0，再按 D 与准点率微调）；
  Again → S'=max(1.0, S×0.3) 且 D+1；
- flags：`cw`=自信却错、`leech`=累计 4 次 Again（换角度重教不重考）；
- **到期卡优先于新内容**；单次新卡 ≤7；history 记最近 8 档；
- 会话内重考：Again/Hard 的卡隔约 3 轮换表面形式再问，只写最终档。

## 四、论文精读特有约定

- **术语卡必带记忆锚三件套**（故事隐喻 + 口诀 + 符号位置法），不许只写定义；
- **每个概念必带页码**：卡片写 `p.NN`，方便回查原文；
- **MEMORY.md 的学习日志用三段式**：`预测` / `打脸` / `修正`，缺一段视为未完成；
- **未核实的用户项目事实不得写入**（见 `LEARNINGS.md` 卡点首条）。
