## 二、小学期参考代码（`2026年小学期测控实习代码/`）

- **性质**：**他人分享的参考代码**（说明文档署名：信息2405 王童汉、信息2403 王漫露、信息2401 牟昱霖、信息2406 张成渊），
  用户收藏作参考。**切勿直接抄袭**（说明文档原话："仅供参考，最好不要抄袭"）。
- **技术栈**：C++ + `winio.h`（WinIo 端口 I/O 库，需 `#pragma comment(lib, "winio.lib")`），Windows 环境。
- **结构**：

```
2026年小学期测控实习代码/测控代码/
├── 说明文档.txt              ← 署名与免责声明
├── bonus.txt                ← 示波器 XY 模式画图形（李萨如图同款模式）
├── 数字基础/ 任务1~3.txt      ← 数字量输入输出（含按位反转等）
├── 数字拓展/ 包装·楼梯·洗衣机·电梯·皮带.txt   ← 五类程序化动作例子
└── 模拟部分/ 模拟基础.txt、模拟拓展1~2.txt    ← A/D、D/A 电压读写（0~10V 输出、±10V 输入）
```

- **用途**：本学期实习若做同类台位（数字量/模拟量 I/O），可对照其**接口调用方式与任务组织**，
  但代码要自己写——既守学术诚信，也才能真正学会。
